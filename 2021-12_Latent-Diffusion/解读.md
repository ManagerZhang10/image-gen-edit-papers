# 大白话深读《Latent-Diffusion》

## 1. 30 秒定位

这篇论文提出 Latent Diffusion Models（LDMs，潜在扩散模型），核心做法是把扩散模型（Diffusion Models, DMs）的训练和推理从高维像素空间搬到一个预训练自编码器（autoencoder）产生的低维潜在空间。这样做的主要动机是像素空间扩散模型虽然生成质量强，但训练动辄数百个 V100 GPU 天，推理也要反复跑同一个大网络，成本很高。论文用感知压缩自编码器把图像压缩到原来的 1/4 到 1/8 分辨率（下采样因子 \(f=4\sim8\)），再在这个潜在空间训练扩散模型。论文用实验证明 LDM 在多个任务上达到或超过像素空间扩散模型的水平，同时显著降低训练和采样成本。例如类别条件 ImageNet 256×256 生成上，LDM-4-G 用 400M 参数、250 DDIM 步达到 FID 3.60（§4.3.1, Table 3），而像素空间 ADM-G 为 4.59。此外还通过交叉注意力（cross-attention）支持文本、布局、语义图等多种条件输入。论文还公布了预训练模型和代码。论文的主要贡献包括解耦的压缩与生成阶段、通用条件机制和卷积方式的大分辨率生成（§1, contributions (i)-(vi)）。

## 2. 为什么这篇论文会出现

在 LDM 之前，扩散模型已经在图像生成上展现出超过 GAN 的能力，但代价极高。论文指出，训练最强大的像素空间扩散模型往往需要 150 到 1000 个 V100 GPU 天（§1），而生成 50k 样本在单个 A100 上大约需要 5 天。原因在于扩散模型的前向和反向过程都在 RGB 像素空间进行，每一步都要在整个高分辨率张量上做前向和反向计算。即使使用重加权目标忽略部分不可感知的高频细节，梯度仍然要回传到所有像素（§2, Fig. 2）。例如，ADM 需要 25–1000 个采样步骤，每次完整推理都需在像素张量上运行 UNet（§1）。

另一方面，已有的两阶段方法如 VQ-VAE 和 VQGAN 先把图像编码到离散潜在空间，再用自回归 Transformer 建模潜在序列。但自回归模型需要把 2D 潜在表示展平成 1D 序列，这种排序是任意的，忽略了空间结构；而且为了控制序列长度，通常要采用较大的空间下采样（如 \(f=16\)），导致重建细节损失，限制了最终生成质量的上限（§1, Fig. 1）。例如 VQGAN 的 \(f=16\) 模型在 DIV2K 验证集上 PSNR 仅为 19.9，而 LDM 的 \(f=4\) 模型可达到 27.4 PSNR（Fig. 1, Tab. 8）。论文希望保留扩散模型对空间数据的归纳偏置，同时降低计算维度。因此提出在连续潜在空间中训练扩散模型，用卷积 UNet 作为骨干，避免 1D 序列排序，允许使用较温和的下采样因子，从而在计算效率和细节保留之间取得近乎最优的折中。此外，论文还观察到扩散模型尽管可以忽略部分不可感知细节，但仍需在所有像素上求梯度，这促使把压缩和生成显式分离。联合训练潜在空间与先验的方法（如 LSGM）需要精细权衡重建和生成损失，而解耦训练可以避免这个困难（§1, contribution (iii)）。总的来说，论文的出现是为了解决高分辨率扩散模型的算力门槛，同时保留其生成质量和灵活性。

## 3. 读懂前需要的最小概念

要读懂这篇论文，需要先理解几个基本概念。

**扩散模型（Diffusion Model）**：一种生成模型，通过一个固定的前向过程逐步向数据加噪声，最终接近标准高斯分布；然后学习一个反向过程逐步去噪，从噪声恢复数据。论文中前向过程被定义为 \(q(x_t|x_0)=\mathcal{N}(x_t|\alpha_t x_0, \sigma_t^2 I)\)，其中 \(\alpha_t,\sigma_t\) 构成噪声调度（§B, Eq. 4）。训练目标通常简化为预测每一步加入的噪声 \(\epsilon\)，即最小化 \(||\epsilon - \epsilon_\theta(x_t, t)||_2^2\)（§3.2, Eq. 1）。论文使用的 \(T=1000\)，采用线性噪声调度（Table 12-15）。

**潜在空间（Latent Space）**：自编码器的编码器将图像 \(x\) 映射到低维表示 \(z = E(x)\)，解码器 \(D\) 从 \(z\) 重建 \(\tilde{x} = D(z)\)。潜在空间维度远低于像素空间，但保留了可感知的语义和结构信息。论文中的感知压缩自编码器用感知损失和对抗损失训练，使重建图像更真实，而不是只用 L2/L1 导致模糊（§3.1）。例如 LDM-4 的潜在形状通常是 \(64\times64\times3\)，相比原图 \(256\times256\times3\)，空间尺寸缩小 4 倍，但通道数不变（Table 12）。

**下采样因子 \(f\)**：编码器将输入图像的空间尺寸缩小 \(f\) 倍。例如输入 256×256，\(f=4\) 得到 64×64 的潜在空间，通道数通常为 3。论文比较了 \(f=1,2,4,8,16,32\)，发现 \(f=4\) 和 \(f=8\) 在质量和效率之间最好（§4.1, Fig. 6）。较小的 \(f\) 保留更多细节但计算更贵，较大的 \(f\) 压缩更狠但细节损失不可逆。

**交叉注意力（Cross-Attention）**：在 Transformer 中，注意力机制的 Query 来自一个序列，Key 和 Value 来自另一个序列。在这里，Query 来自 UNet 的中间特征 \(\phi_i(z_t)\)，Key 和 Value 来自条件编码 \(\tau_\theta(y)\)（如文本、类别、布局），使条件信息能注入扩散模型的去噪过程（§3.3, Fig. 3）。条件编码器 \(\tau_\theta\) 可以是 Transformer、嵌入层或恒等映射，取决于条件类型（§E.2.1）。

**感知压缩和语义压缩的区别**：论文强调感知压缩阶段只去除不可感知的高频细节，而语义压缩由扩散模型完成。这不同于 VQGAN 等把大量语义压缩交给自回归模型的做法，LDM 允许用较弱的空间压缩，让扩散模型承担语义建模（§2, Fig. 2）。

## 4. 方法全景：先看数据流

LDM 的训练分为两个阶段：先训练感知压缩自编码器，再训练潜在空间中的条件扩散模型。推理时，从噪声出发在潜在空间逐步去噪，最后通过解码器还原图像。训练阶段的数据流用 ASCII 表示如下：

```
图像 x (RGB, H×W×3)
    │
    ▼
编码器 E  ────► 潜在 z = E(x)  (h×w×c, h=H/f, w=W/f)
    │                │
    │                │ 前向扩散 q(zt|z0): 加噪 t 步
    │                ▼
    │           噪声潜在 zt = α_t z0 + σ_t ε
    │                │
    │                ▼
    │     条件编码 τθ(y) ──► 交叉注意力注入 UNet εθ(zt, t, τθ(y))
    │                │               │
    │                │               ▼
    │                │        预测噪声 ε̂θ
    │                │               │
    │                └───── 计算损失 ||ε - ε̂θ||²
    ▼
解码器 D (第一阶段训练专用，不参与扩散训练)
    │
    ▼
重建图像 x̃
```

推理阶段的数据流：

```
随机噪声 z_T ~ N(0, I)
    │
    ▼
迭代 t = T, ..., 1:
   z_{t-1} = 去噪更新(zt, εθ(zt, t, τθ(y)))
    │
    ▼
最终潜在 z0
    │
    ▼
解码器 D ──► 生成图像 x̃ = D(z0)
```

核心组件拆解：

1. **感知压缩自编码器（Perceptual Compression Autoencoder）**  
   - 输入：RGB 图像 \(x \in \mathbb{R}^{H \times W \times 3}\)。  
   - 输出：潜在表示 \(z \in \mathbb{R}^{h \times w \times c}\)，其中 \(h=H/f, w=W/f\)。  
   - 目的：将图像映射到感知上等价但维度更低的连续空间，去除不可感知的高频细节。  
   - 假设：潜在空间保留了足够的语义和结构信息，足以支持高质量生成；且温和压缩不会丢失关键细节。  
   - 训练目标：感知损失 + 对抗损失 + 极小的正则项（KL 或 VQ）。KL 正则的权重约 \(10^{-6}\)，VQ 则用高维码本（§G, Eq. 25）。自编码器在 OpenImages 数据集上训练，其变体见 Table 8。

2. **潜在扩散模型（Latent Diffusion Model, LDM）**  
   - 输入：潜在表示 \(z\)（或其加噪版本 \(z_t\)），时间步 \(t\)，可选条件 \(y\)。  
   - 输出：预测的噪声 \(\epsilon_\theta(z_t, t, \tau_\theta(y))\)。  
   - 目的：学习潜在空间中的数据分布 \(p(z)\) 或条件分布 \(p(z|y)\)。  
   - 假设：潜在空间比像素空间更适合 likelihood-based 模型，因为语义信息集中，且维度更低。  
   - 骨干：时间条件 UNet（time-conditional UNet），主要由 2D 卷积层构成，继承了对空间数据的归纳偏置。UNet 中插入注意力层，用于处理空间长程依赖，注意力分辨率由超参数指定（Table 13, 15）。

3. **条件机制（Conditioning Mechanisms）**  
   - 对于低维条件如类别标签：用简单的嵌入层 \(\tau_\theta\) 映射为向量，再通过交叉注意力注入 UNet。例如类别条件模型 \(\tau_\theta\) 是单个可学习嵌入层，维度 512，将类别 \(y\) 映射为 \(\zeta\in\mathbb{R}^{1\times512}\)（§E.2.1 末尾）。  
   - 对于文本或布局：\(\tau_\theta\) 是一个未掩码的 Transformer 编码器，将 token 序列编码为上下文表示，然后 UNet 中的交叉注意力层用 \(\phi_i(z_t)\) 作为 Query，用 \(\tau_\theta(y)\) 作为 Key/Value 进行融合。文本模型使用 BERT tokenizer，Transformer 深度 32，维度 1280，序列长度 77（Table 17, §E.2.1）。  
   - 对于密集条件如语义图、低分辨率图、掩码：直接将条件与潜在 \(z_t\) 在通道维拼接（concat）后输入 UNet，此时 \(\tau_\theta\) 为恒等映射。拼接条件需要与潜在空间空间尺寸对齐，通常下采样到相同分辨率。  
   - 目的：让扩散模型支持任意类型的条件输入，无需任务专用架构。

## 5. 核心公式与直觉

本节仅保留理解 LDM 贡献必需的公式，并逐一解释。

**公式 1：像素空间扩散模型的简化训练目标**（§3.2, Eq. 1）
\[
L_{DM} = \mathbb{E}_{x, \epsilon \sim \mathcal{N}(0,1), t} \left[ \|\epsilon - \epsilon_\theta(x_t, t)\|_2^2 \right]
\]
其中 \(x_t\) 是原始图像 \(x\) 在第 \(t\) 步加噪后的版本，\(t\) 从 \(\{1,\dots,T\}\) 均匀采样，\(\epsilon\) 是标准高斯噪声，\(\epsilon_\theta\) 是参数为 \(\theta\) 的神经网络（通常为 UNet），预测在 \(x_t\) 中混入的噪声。这个目标来自变分下界的重加权（§B）。它让模型学会从任意噪声水平恢复原始信号。直觉是：训练一个去噪自编码器，输入不同噪声水平的图像，输出应该被去掉的噪声。

**公式 2：潜在空间扩散目标**（§3.2, Eq. 2）
\[
L_{LDM} := \mathbb{E}_{E(x), \epsilon \sim \mathcal{N}(0,1), t} \left[ \|\epsilon - \epsilon_\theta(z_t, t)\|_2^2 \right]
\]
这里 \(z_t\) 不再是像素空间的加噪图像，而是潜在表示 \(z=E(x)\) 经过前向扩散得到的加噪潜在。\(\epsilon_\theta\) 的输入维度是潜在空间的空间尺寸乘通道数，远小于像素空间。直觉：扩散过程被完全放在低维潜在空间进行，网络只处理语义和结构信息，不再为每个像素的高频噪声消耗计算。训练时，\(z\) 可以预先用编码器 \(E\) 从图像批量提取，实际训练中 \(z_t\) 可直接通过前向过程得到，无需经过解码器。对于 KL 正则潜在，\(z\) 由 \(E_\mu(x)+E_\sigma(x)\cdot\epsilon\) 采样；对于 VQ 潜在，取量化前的连续特征（§G）。

**公式 3：条件潜在扩散目标**（§3.3, Eq. 3）
\[
L_{LDM} := \mathbb{E}_{E(x), y, \epsilon \sim \mathcal{N}(0,1), t} \left[ \|\epsilon - \epsilon_\theta(z_t, t, \tau_\theta(y))\|_2^2 \right]
\]
其中 \(y\) 是条件输入（如文本 prompt、类别标签、布局），\(\tau_\theta\) 是特定领域的编码器，将 \(y\) 映射为中间表示。\(\tau_\theta\) 和 \(\epsilon_\theta\) 通过这个目标联合优化。直觉：条件信息通过交叉注意力注入 UNet，使去噪过程能够被外部条件指导，而无需为每种任务重新设计网络。

**公式 4：交叉注意力**（§3.3）
\[
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right) \cdot V
\]
其中
\[
Q = W_Q^{(i)} \cdot \phi_i(z_t), \quad K = W_K^{(i)} \cdot \tau_\theta(y), \quad V = W_V^{(i)} \cdot \tau_\theta(y).
\]
\(\phi_i(z_t)\) 是 UNet 第 \(i\) 层的中间特征（展平成序列），维度为 \(N \times d_\epsilon^i\)；\(\tau_\theta(y)\) 是条件编码，维度为 \(M \times d_\tau\)；\(W_Q, W_K, W_V\) 是可学习的投影矩阵。直觉：UNet 特征中的每个空间位置（作为 Query）都可以从条件序列（Key/Value）中检索相关信息，实现灵活的条件融合。这个机制让 LDM 能处理任意 token 化的条件，而不局限于类别标签或模糊图像。实际实现中，交叉注意力替换了 UNet 的自注意力层的一部分或与之交替（Table 16）。

**补充：前向扩散和反向过程的定义**（§B, Eq. 4-15）  
前向扩散 \(q(x_t|x_0)=\mathcal{N}(x_t|\alpha_t x_0, \sigma_t^2 I)\)；反向过程利用 \(p(x_{t-1}|x_t)=q(x_{t-1}|x_t, x_\theta(x_t,t))\)。通过重参数化 \(\epsilon_\theta(x_t,t)=(x_t-\alpha_t x_\theta(x_t,t))/\sigma_t\)，训练目标可写为去噪目标，最终得到 Eq. 1。此推导说明了为什么预测噪声等效于学习反向过程，并且权重被重加权为均等。

## 6. 训练到底怎么跑

LDM 的训练分两个阶段，解耦且可复用。

**第一阶段：训练感知压缩自编码器**（§3.1, §G）  
目标是得到一个感知等价的低维表示。输入图像 \(x\)，编码器 \(E\) 输出潜在 \(z\)，解码器 \(D\) 重建 \(\tilde{x}=D(E(x))\)。训练目标由三部分组成：重建损失 \(L_{rec}\)（如感知损失 LPIPS 或 L1）、对抗损失 \(L_{adv}\)（patch-based 判别器 \(D_\psi\)），以及正则项 \(L_{reg}\)。完整目标为：
\[
L_{\text{Autoencoder}} = \min_{E,D}\max_{\psi} \left( L_{rec}(x,D(E(x))) - L_{adv}(D(E(x))) + \log D_\psi(x) + L_{reg}(x;E,D) \right)
\]
（§G, Eq. 25）。正则项要么是极低权重的 KL 散度（权重约 \(10^{-6}\)），要么是向量量化层（VQ），通过选择高维码本（如 \(|Z|=8192\)）来保持重建质量。判别器和编解码器交替优化。所有自编码器在 OpenImages 数据集上训练，论文提供了多个下采样因子和正则类型的变体（Table 8）。训练完成后，自编码器固定，后续可重复用于多个扩散模型训练。

**第二阶段：训练潜在扩散模型**（§3.2, §3.3）  
固定 \(E\) 和 \(D\)。一轮训练 step 的流程是：

1. 从数据集中采样一个 batch 的图像 \(x\) 和对应条件 \(y\)（如类别、文本、布局）。  
2. 用编码器 \(E\) 计算潜在 \(z = E(x)\)。对于 KL 正则，\(z\) 是采样自高斯后验 \(z = E_\mu(x) + E_\sigma(x)\cdot\epsilon\)，其中 \(\epsilon\sim\mathcal{N}(0,1)\)；对于 VQ，取量化前的连续特征。如果需要对潜在空间重缩放，则用第一个 batch 估计的组分标准差 \(\hat{\sigma}\) 对 \(z\) 归一化，使潜空间具有单位标准差（§G）。  
3. 均匀采样时间步 \(t \in \{1,\dots,T\}\)（\(T=1000\)），并从标准高斯采样噪声 \(\epsilon\)。  
4. 根据固定的前向过程计算 \(z_t = \alpha_t z + \sigma_t \epsilon\)，其中 \(\alpha_t,\sigma_t\) 由噪声调度决定（§B, Eq. 4）。  
5. 如果条件为类别、文本或布局，将 \(y\) 输入条件编码器 \(\tau_\theta\)，得到上下文表示；如果是密集条件（如语义图、低分辨率图、遮挡掩码），则直接与 \(z_t\) 在通道维拼接。  
6. 将 \(z_t\)、时间步 \(t\) 和条件表示输入 UNet \(\epsilon_\theta\)，输出预测噪声 \(\hat{\epsilon}\)。  
7. 计算损失 \(L = \|\epsilon - \hat{\epsilon}\|_2^2\)，并对 \(\epsilon_\theta\) 和 \(\tau_\theta\) 的参数做梯度下降（如果 \(\tau_\theta\) 需要训练）。编码器和解码器不参与梯度更新。

实际超参数细节：CelebA-HQ 的 LDM-4 用 batch size 48，学习率 9.6e-5，训练 410k iterations，UNet 参数 274M（Table 12）；ImageNet 的 LDM-4 用 batch size 1200，学习率 1.0e-4，训练 178k steps，UNet 参数 400M（Table 15）。文本到图像模型在 LAION-400M 上训练，batch size 680，学习率 1.0e-4，迭代 390K，UNet 参数 1.45B，\(\tau_\theta\) 序列长度 77，Transformer 深度 32，维度 1280（Table 15, 17）。Layout-to-Image 模型在 OpenImages 上训练，\(\tau_\theta\) 的 Transformer 深度 16，维度 512，序列长度 92（Table 17）。所有模型均在单个 NVIDIA A100 上训练，除了 inpainting 模型使用 8 个 V100（§E.1）。训练中学习率会根据模型稳定性微调，Table 13/14 中不同 \(f\) 的学习率不同。

**重要细节**：对于类别条件模型，\(\tau_\theta\) 是一个单一可学习嵌入层，维度 512，将类别 \(y\) 映射为 \(\zeta\in\mathbb{R}^{1\times512}\)（§E.2.1 末尾）。对于密集条件任务，\(\tau_\theta\) 恒等，直接将条件与 \(z_t\) 拼接，因此不需要额外的条件编码器训练。

## 7. 推理到底怎么跑

推理阶段只用到训练好的 UNet \(\epsilon_\theta\)、条件编码器 \(\tau_\theta\)（如果有），以及固定的解码器 \(D\)。完整顺序如下：

1. 准备条件输入 \(y\)，并通过 \(\tau_\theta\) 编码（若为文本/类别/布局）；若为密集条件，则预处理到与潜在空间相同的空间尺寸（例如对语义图进行下采样，对低分辨率图缩放到相同分辨率）。  
2. 从标准高斯分布采样初始潜在噪声 \(z_T \sim \mathcal{N}(0, I)\)，形状为目标潜在空间的形状（例如 256×256 图像、\(f=4\) 时得到 64×64×3；\(f=8\) 时得到 32×32×4）。  
3. 选择采样器（论文主要用 DDIM，步骤数从 10 到 500 不等，常用 100、200 或 250）。从 \(t=T\) 开始，逐步执行去噪更新：  
   a. 将当前 \(z_t\)、时间步 \(t\)、条件表示输入 UNet，得到预测噪声 \(\hat{\epsilon} = \epsilon_\theta(z_t, t, \tau_\theta(y))\)。  
   b. 根据采样器（DDIM 或 DDPM 反向过程）计算 \(z_{t-1}\)（去除一部分噪声，可能加入少量随机噪声）。DDIM 的具体公式依赖原始工作，这里不展开，但每一步都要调用一次 UNet。  
   c. 重复直到 \(t=0\)，得到最终潜在 \(z_0\)。  
4. 将 \(z_0\) 输入解码器 \(D\)，得到像素空间图像 \(\tilde{x} = D(z_0)\)。解码器只需一次前向，因此解码成本相对固定。  
5. 若使用 classifier-free guidance（如文本生成或类别生成），每一步会同时计算条件预测和无条件预测，然后按：
\[
\hat{\epsilon} = \epsilon_\theta(z_t, t, \emptyset) + s \cdot (\epsilon_\theta(z_t, t, y) - \epsilon_\theta(z_t, t, \emptyset))
\]
组合，其中 \(s\) 是引导尺度（§4.3, Table 2/3）。这需要额外一次 UNet 前向，但显著提升视觉保真度。无条件预测通过将条件输入设为空（如零向量或空文本）实现。文本到图像模型 LDM-KL-8-G 使用 \(s=1.5\) 或 \(10.0\) 不等（Table 2, Fig. 5 描述），类别条件 LDM-4-G 使用 \(s=1.5\)（Table 3）。  
6. 对于卷积采样（生成更高分辨率图像），可以直接将训练在 256×256 上的 UNet 应用到 512×512 或 1024×1024 的潜在网格，因为 UNet 是全卷积的，没有固定空间尺寸限制。但需注意潜空间的信噪比和注意力层的特征统计，必要时进行潜在空间重缩放或对高分辨率微调半 epoch（§4.3.2, §4.5, §D.1）。

推理成本取决于采样步数和 UNet 大小。例如 LDM-4-G 在 ImageNet 上使用 250 DDIM 步，采样吞吐约 0.4 samples/sec on A100（Table 18）。相比之下，像素空间 ADM 的 250 步采样吞吐约 0.07 samples/sec。对于 inpainting 任务，LDM-4（VQ, w/ attn）在 256² 采样吞吐为 0.33 samples/sec，而 LDM-1 为 0.11；在 512² 上 LDM-4 为 0.34，LDM-1 为 0.07（Table 6）。这表明潜在空间推理吞吐提升约 2.7 倍以上。

## 8. 实验和消融到底证明了什么

论文的实验部分很丰富，我们用表列出至少 4 条关键证据，然后讨论最关键消融。

| 证据编号 | 任务 / 数据集 | 模型 / 对照 | 指标 | 结果 | 锚点 |
|:---|:---|:---|:---|:---|:---|
| E1 | 无条件生成 / CelebA-HQ 256² | LDM-4 vs LSGM | FID | 5.11 vs 7.22 | Table 1 |
| E2 | 类别条件生成 / ImageNet 256² | LDM-4-G vs ADM-G | FID / IS | 3.60 / 247.67 vs 4.59 / 186.7 | Table 3 |
| E3 | 文本到图像 / MS-COCO 256² | LDM-KL-8-G vs GLIDE | FID | 12.63 vs 12.24 | Table 2 |
| E4 | 超分辨率 / ImageNet 64→256 | LDM-4 vs SR3 | FID | 2.8 / 4.8 vs 5.2 | Table 5 |
| E5 | 图像修复 / Places 512² (40-50% mask) | LDM-4 big w/ ft vs LaMa | FID | 9.39 vs 12.31 | Table 7 |
| E6 | 训练/推理效率 / Places inpainting | LDM-4 vs LDM-1 | 吞吐 @256 / 训练时间 | 0.33 vs 0.11 samples/s; 7.04 vs 20.66 h/epoch | Table 6 |

**证据细节补充**：E2 中 LDM-4-G 参数 400M，ADM-G 参数 608M，且 LDM 在 250 DDIM 步下达到该结果（Table 3, Table 18）。E3 中 LDM-KL-8-G 为 1.45B 参数，使用 classifier-free guidance \(s=1.5\)，GLIDE 为 6B 参数（Table 2）。E5 中 LDM-4 big w/ ft 参数量 387M，而 LaMa 为专用修复模型，但 LDM 在 hard examples（40-50% mask）上 FID 更低（Table 7）。用户研究 Task 2 中，LDM-4 获得 70.6% 偏好分 vs 29.4% 给像素 DM（超分）；inpainting 中 LDM-4 为 68.1% vs LaMa 31.9%（Table 4）。

**最关键消融：下采样因子 \(f\) 的选择**（§4.1, Fig. 6）  
论文固定计算资源为单卡 A100，训练相同步数（2M steps），比较 \(f \in \{1,2,4,8,16,32\}\) 在 ImageNet 类别条件生成上的表现。模型参数基本匹配（391M–396M，Table 13）。结果：\(f=1\)（像素空间）训练极慢，FID 高；\(f=32\) 因过强压缩丢失信息，FID 在训练早期就停滞；\(f=4\) 到 \(f=16\) 之间达到较好平衡，其中 LDM-8 与 LDM-1 在 2M steps 后有 38 的 FID 差距（§4.1）。进一步结合采样步数（Fig. 7），LDM-4 和 LDM-8 在 CelebA-HQ 和 ImageNet 上均表现最优。在 CelebA-HQ 上，500k steps 后的 FID 对 \(f=4\) 最佳；在 ImageNet 上，2M steps 后的 FID 对 \(f=4,8\) 最低（Fig. 7）。这说明适度的压缩（4–8 倍）能让扩散模型把容量集中在语义信息上，同时保留足够细节。另外按 V100 天计算资源的分析（Fig. 17）得到类似结论，LDM-{4,8} 在固定 35 V100 天下最优。

**其他重要发现**：  
- 正则方式（KL vs VQ）对最终生成质量影响不大，甚至 VQ 有时略优（§4, Tab. 8），但 KL 连续潜在空间便于缩放和引导。Table 8 显示 \(f=4\) 的 KL 模型 R-FID 0.27，VQ 模型 0.47–0.58，但都远优于 \(f=16\) 的 5.15。  
- 交叉注意力条件机制使单个架构支持文本、布局、类别等多种条件，无需为每个任务重新设计（§4.3.1）。Layout-to-Image 的 LDM-4 微调 OpenImages 后在 COCO 上达到 FID 40.91，超越 SPADE 等；在 OpenImages 上 FID 32.02，比 VQGAN+T 的 45.33 提升近 11（Table 9）。  
- 卷积采样（convolutional sampling）让在 256² 上训练的 LDM 能泛化到 512² 甚至 1024² 的密集条件任务（语义合成、超分、修复），因为 UNet 是全卷积的，可以处理任意空间尺寸输入（§4.3.2, Fig. 9）。语义景观模型在训练时用 384² 的 256² 裁剪，推理可生成 512×1024 的图像（Fig. 9, 12, 24, 25）。

**失败模式与尚未完全证明的主张**：  
论文在 §5 中承认，虽然 LDM 显著降低计算，但顺序采样仍比 GAN 慢；在高精度像素任务上，自编码器的重建能力可能成为瓶颈（如超分辨率可能受此限制）。LDM-SR 使用 bicubic 退化，对不符合该退化的真实图像泛化差，需要引入 BSR 多样化退化（§D.6.1）。卷积采样对潜空间信噪比敏感，KL-reg 潜空间直接使用会导致全局结构不连贯，必须重缩放（§D.1, Fig. 15）。此外，注意力层在从 256² 推理到 512² 时可能出现特征统计不匹配，需要微调半 epoch（§4.5）。论文没有系统研究潜在空间正则化与下游任务的最优组合，例如对文本到图像生成，仅报告了 KL-8 的结果；也没有对潜在空间缩放的标准差估计方法进行广泛的消融。最后，LDM 的样本多样性和分布覆盖主要用 Precision/Recall 衡量，缺乏更严格的统计检验；论文也承认扩散模型可能泄露训练数据，但未量化 LDM 的风险（§5）。

## 9. 与前作怎么选

与 LDM 最接近的方案有三类：像素空间扩散模型、VQ-VAE/VQGAN + 自回归 Transformer、以及联合训练潜在空间和先验的 LSGM。

**像素空间扩散模型（如 DDPM、ADM）**  
- 何时选：如果需要严格的像素级保真度，或者数据本身高度结构化（如医学图像）且计算资源充足；或者需要与现有像素空间引导方法（如分类器引导）完全兼容。ADM 在 LSUN-Bedrooms 上 FID 1.90，LDM-4 为 2.95，像素空间略有优势但训练成本为 232 V100 天 vs LDM 的 60 V100 天（Table 1, Table 18）。  
- 何时选 LDM：计算资源有限，但希望保持高质量和灵活性；需要处理高分辨率或多模态条件。论文 Table 18 显示 LDM-4 在 ImageNet 上的训练成本仅为 ADM 的约 1/3 到 1/4，采样吞吐提高近 6 倍。

**VQGAN + Transformer（如 VQGAN + 自回归）**  
- 何时选：如果天然需要离散潜在表示（如后续接语言模型），或者需要自回归采样的确定性/可暂停性；对空间结构不敏感的任务。  
- 何时选 LDM：当空间结构和局部相关性重要时，2D 卷积 UNet 比 1D 自回归更高效；且 LDM 的连续潜在空间通常需要更温和的下采样，重建上限更高（Fig. 1, Tab. 8）。例如 \(f=4\) LDM 重建 PSNR 27.43 vs VQGAN \(f=16\) PSNR 19.9（Table 8）。

**LSGM（Score-based Generative Modeling in Latent Space）**  
- LSGM 也尝试在潜在空间训练扩散模型，但它联合训练自编码器和先验，需要仔细平衡重建损失和生成损失。  
- 何时选 LDM：论文显示 LDM 在 CelebA-HQ 上 FID 5.11 优于 LSGM 7.22（Table 1），且训练解耦更简单，自编码器可复用；LSGM 可能在需要端到端优化潜在空间时更有优势，但调参难度较高。论文明确说明 LDM 不需要 delicate weighting（§1 contribution (iii)）。

**本文内部选择**：对于无条件生成和一般条件生成，推荐 \(f=4\) 或 \(f=8\) 的 LDM，配合 DDIM 采样器和可选的 classifier-free guidance。对于内存受限的高分辨率密集条件任务，优先选 VQ 正则且无注意力的自编码器，因为解码时占用更少 GPU 内存（§4.5, Tab. 8 中 attention-free 版本）。LSUN-Churches 上 LDM-8（KL）取得 FID 4.02，而 LDM-4 在 Bedrooms 上 FID 2.95；具体选择可依据数据复杂度调整。

## 10. 工程判断：可行性、风险与上限

**可行性**：LDM 的架构基于现成 UNet 和标准 Transformer，实现门槛中等。训练分为两个独立阶段，可以先训练好自编码器，然后快速实验多个扩散模型变体，因为自编码器固定，扩散模型训练只处理低维潜在空间。论文提供了完整的超参数和代码链接，复现可行。实际落地时，自编码器需要在较大规模数据（如 OpenImages）上训练，但只需一次。推理时解码器一次前向即可，成本低。

**数据**：自编码器训练需要大量图像；论文使用 OpenImages，评估在 ImageNet-val 上。对于特定领域，需要重新训练或微调自编码器，否则潜在空间可能不匹配。文本条件模型需要大规模图文对（如 LAION-400M），并依赖预训练 tokenizer（BERT tokenizer）。数据偏见和泄露风险常规存在，论文在 §5 中讨论了 deep fakes、训练数据记忆和偏见问题，但仍未量化具体威胁。

**算力/延迟**：尽管 LDM 比像素空间 DM 便宜一个数量级，但它仍需顺序采样（通常 100–500 步），单样本生成时间仍高于 GAN。例如 LDM-4-G 在 A100 上约 0.4 samples/s（Table 18），而 StyleGAN2 可达数十 samples/s。对于实时应用，需要结合蒸馏、快速采样器或减少步数；论文实验显示 10–50 步也能工作，但质量会下降（Fig. 7）。Table 18 中 LDM-8 在 LSUN-Churches 上训练成本 18 V100 天，采样吞吐 6.80 samples/s，明显优于 StyleGAN2 的 59M 参数但生成速度在 GAN 范围内。

**实现难点**：  
- 自编码器的感知损失和对抗训练要平衡，否则重建模糊或引入伪影。正则化权重必须很小，但太小可能导致潜在方差过大，影响扩散模型训练。论文在 §D.1 提到需要根据潜方差调整 SNR，必要时对潜在空间重缩放。重缩放时使用第一个 batch 的组分标准差，这个估计对后续稳定性有影响。  
- 交叉注意力的实现需要将 UNet 的中间特征展平为序列，并在多个分辨率层插入；不恰当的注意力分辨率或头数可能导致训练不稳定或显存爆增。论文 Table 13 中 LDM-1/2/4/8/16/32 的 CA-resolutions 分别不同，需根据潜在空间尺寸调整。  
- 密集条件任务（如修复）在高分辨率下需要注意力层适应新的特征统计，论文观察到 256² 训练到 512² 推理时有差异，需要额外微调半 epoch（§4.5）。  
- 卷积采样虽然能提升分辨率，但潜空间的信噪比会影响效果，KL 潜在空间可能需要缩放，否则全局结构可能不连贯（§D.1, Fig. 15）。VQ 空间方差接近 1，不需要缩放。

**失败环节**：若下采样因子选得过大（如 \(f=32\)），生成质量上限被第一阶段的压缩损失限制，FID 停滞；若选得太小（\(f=1\)），计算成本回到像素空间。自编码器若重建质量差，所有下游任务都会受损，且无法通过扩散模型弥补。引导尺度 \(s\) 太大会导致失真或过度锐化，太小则条件遵循差（论文仅给了一些数值，如 ImageNet 类别条件 \(s=1.5\)，文本生成 \(s=1.5\) 或 10.0，无系统调参指导）。对于超分任务，固定的 bicubic 退化对真实世界图像泛化差，LDM-SR 在真实图像上可能失败，需要 BSR 退化训练（§D.6.1）。

**监控信号**：训练扩散模型时，重点监控损失曲线的平稳下降，以及定期在小样本集上评估 FID 和 IS。对于条件生成，还要检查条件一致性和样本多样性（如 Precision/Recall）。自编码器训练则需监控重建 FID、PSNR、LPIPS 以及潜空间方差。Table 8 提供了一套重建质量基准，可用于对照。

**指标上限**：从论文看，即使在最优配置下，LDM 的 FID 仍与专用 GAN（如 ProjectedGAN 的 1.59 于 LSUN-Churches）有差距（Table 1），说明该架构并未在所有数据集上达到绝对的 SOTA。在文本生成上，LDM 虽接近 GLIDE，但参数更少；这表明上限受限于潜在空间的信息损失和扩散模型采样步数。对于需要精确像素级控制的任务（如高清文字渲染、细微纹理），上限偏低。论文在 §5 中承认对于高精度要求任务，\(f=4\) 自编码器重建可能成为瓶颈，超分模型可能已受此限制。

**未回答问题**：论文未系统分析 LDM 在不同数据规模下的扩展性；未给出关于潜在空间维度与生成质量之间的理论解释；未验证在视频、3D 等更多模态上的适用性；未详细评估训练数据记忆与隐私泄漏风险。此外，自编码器的对抗训练是否导致生成样本中的对抗性扰动也未被讨论。\(\tau_\theta\) 是否应加入时间步条件，论文选择不加以减少推理延迟，但未进一步分析（§E.2.1）。

## 11. 放回研究脉络并收束

LDM 出现在扩散模型开始统治图像生成的早期阶段。2021 年，Dhariwal 与 Nichol 的 ADM 展示了扩散模型击败 GAN，但训练成本高昂；VQGAN 等方案用自回归建模离散潜在，但也面临压缩率与序列长度的矛盾。LDM 的核心贡献是把这两个传统结合起来：用感知压缩获得连续低维空间，再在其中训练扩散模型，既保留了扩散模型的稳定训练和高效采样器，又获得卷积 UNet 对空间结构的归纳偏置。论文还通过交叉注意力把条件机制通用化，使 LDM 成为多任务多模态的生成框架。后来很多工作（如 Stable Diffusion）直接沿用了这一范式，但论文本身只报告了截至 2021/2022 初的结果。

**读完必须记住的 5 件事**：

1. LDM 将扩散过程的训练和推理放在感知压缩的连续潜在空间，而非像素空间，显著降低计算成本，同时保留细节。压缩和生成阶段解耦，自编码器一次训练可复用。  
2. 最优下采样因子在 \(f=4\sim8\)，过大或过小都会损害效果。\(f=1\) 慢，\(f=32\) 因信息损失导致 FID 停滞。  
3. 交叉注意力条件机制是通用的：文本、类别、布局等都用同一套架构，通过 \(\tau_\theta\) 编码后注入 UNet。密集条件则直接通道拼接。  
4. 像素扩散模型、VQGAN+Transformer、LSGM 是主要对照；LDM 在多数任务上达到或超过它们，且参数更少、训练更快。  
5. LDM 具有卷积采样能力，可在训练分辨率之上生成更大的密集条件图像，但需注意潜空间 SNR 和注意力层适配，必要时进行潜空间重缩放或微调。

**5 道自测题**：

1. LDM 中自编码器的两个正则化选项是什么？它们分别对潜在空间有什么影响？  
2. 为什么 \(f=32\) 的 LDM 在训练早期 FID 就停滞了？请结合第一阶段信息损失解释。  
3. 交叉注意力中 Query、Key、Value 分别来自哪里？对于类别条件，\(\tau_\theta\) 的输出维度是多少？  
4. 在文本到图像生成中，classifier-free guidance 的推理开销是多少？它如何提升 FID？  
5. 如果要在 1024² 分辨率上做语义图到图像的生成，可以用论文中的哪种技术？需要注意什么？请列举至少两个注意事项。

最终一句话总结：Latent-Diffusion 把扩散模型从像素空间搬进低维感知潜在空间，并以 \(f=4\sim8\) 的温和压缩、交叉注意力条件和解耦的自编码器实现了质量、效率与多任务灵活性的平衡，是扩散模型走向可负担和大规模应用的关键一步。
