# 大白话深读《SpatialFusion》

## 1. 30 秒定位

SpatialFusion 是一篇研究如何让“统一图像生成模型”具备内在 3D 几何意识的方法论文。它观察到现有主流模型（如 GPT-4o、OmniGen2）虽然能理解语义并生成逼真图像，但在需要精确空间推理的任务上表现很差：例如“显示摩托车的左侧”“让男人面对右边”“把电风扇放在离女人 1 米处”这类指令常常被忽略或搞错。论文把原因归结为两个环节：第一，多模态大语言模型（MLLM）的隐状态缺少几何信息，无法被探测出有意义深度图；第二，扩散主干没有显式几何约束，只能依赖高层语义，无法锚定精确空间布局。SpatialFusion 的解决方案是引入一个并行的空间 Transformer（Spatial Transformer），通过 Mixture-of-Transformers 架构与 MLLM 共享自注意力，从语义上下文预测目标图像的 metric-depth 图；再通过一个专门的深度适配器把该深度图注入扩散模型的潜变量，用逐元素加法提供几何约束。论文采用两阶段训练：先用 VGGT 作为教师预训练深度预测，再联合训练扩散模型。实验显示，在 GenSpace 空间感知基准上，SpatialFusion 平均分从 OmniGen2 的 31.78 提升到 46.33（T2I，Table 1）和从 26.18 提升到 35.40（编辑，Table 2），同时标准基准上也有增益，且推理延迟增加不到 3%（Table 5）。

## 2. 为什么这篇论文会出现

现有统一图像生成模型通常采用“理解增强生成”的范式：用一个多模态大语言模型（MLLM）提取文本和图像的语义特征，再把这个语义条件输入扩散 Transformer（DiT）去迭代去噪生成图像。这种架构在语义一致性和真实感上取得显著进展，但最近多项研究（如 GenSpace、SmartSpatial 等）揭示其在空间感知任务上存在根本缺陷，包括物体姿态理解、空间关系推理和度量测量遵守。论文将这种缺陷归因于两个机制性问题：

第一，理解阶段产生“几何贫乏”的隐状态。MLLM 的训练目标主要是语义对齐，其特征虽与类别概念强相关，但与几何属性（如位置、朝向、距离）相关性弱。论文通过一个探测实验：在冻结的 MLLM 隐状态上微调深度预测头，结果无法生成语义对齐的深度图（Fig. 1(a)）。这说明 MLLM 内部缺乏可靠的 3D 结构支架。论文进一步引用经验研究[3,35,51,57]指出 MLLM 特征与类别概念强相关但与几何属性弱相关，因此无法提供可靠的内部 3D 支架。

第二，生成阶段没有几何约束。扩散模型本质是迭代去噪，没有自然的结构先验，仅靠高层语义嵌入无法锚定精确空间布局（Fig. 1(b)）。当注入稠密几何信号（如深度图）时，模型倾向于生成空间结构更连贯的图像。

此前有两条技术路线尝试提供几何指导：一是布局到图像方法（如 LayoutDiffusion、GLIGEN），使用 2D 边界框或分割图，但纯 2D 性质无法处理 3D 几何任务；二是注入外部 3D 线索（如深度、法线），但依赖辅助信息，在纯文本场景不可用，且只是“条件执行器”，没有内化几何意识。与此同时，3D 基础模型（尤其是 VGGT）展示了统一 Transformer 架构可以学习丰富的 3D 几何信息，从输入视图单次前向即可推断相机参数和深度图，暗示 2D 语义与 3D 几何可以共享表征框架。论文由此提出核心问题：能否把这种统一框架扩展到生成模型，让 2D 语义派生出 3D 结构支架，再反过来引导 2D 图像合成？SpatialFusion 就是对这一问题的直接回答。

## 3. 读懂前需要的最小概念

**统一图像生成模型（Unified Image Generation Model）**：将理解模块和生成模块结合在一个框架中的模型。通常用一个多模态大语言模型（MLLM）作为语义编码器，将文本指令和输入图像转化为隐状态，然后以这些隐状态为条件，驱动一个扩散模型生成或编辑图像。代表工作有 OmniGen2、UniWorld-V1、BAGEL 等。OmniGen2 使用 Qwen2.5-VL-3B 作为 MLLM，并有一个约 40 亿参数的定制扩散解码器（§4.1）。

**Mixture-of-Transformers（MoT）**：一种多模态架构，不同模态使用独立的 transformer 层参数（称为模态特定层），但共享自注意力层，以实现模态间的信息交互。这样既保留各模态的专门能力，又能低成本融合语义和几何信息。SpatialFusion 的空间 Transformer 与 MLLM 共享自注意力，但各自保留独立的投影和前馈网络。

**Metric-depth map（度量深度图）**：不是相对深度，而是具有真实尺度（如米）的逐像素深度值。对于空间测量任务（如“离相机 1 米”）至关重要。VGGT 模型可以在单次前向中直接推理场景的度量深度、相机参数等。SpatialFusion 的目标就是让模型从语义输入预测目标图像的度量深度图。

**VGGT（Visual Geometry Grounded Transformer）**：一个 3D 基础模型，能从输入视图直接推断场景的关键 3D 属性。其架构是一个标准的大型 Transformer，与语言模型和视觉骨干同构，为跨模态集成提供了便利。SpatialFusion 利用 VGGT 作为教师提供伪真值深度图，并复用其 DPT 头进行深度预测。

**DPT head（Dense Prediction Transformer head）**：一种用于稠密预测任务的 Transformer 解码头，可从分层的视觉特征中生成像素级输出（如深度图）。论文使用 DPT head 从空间 Transformer 的几何隐状态解码出度量深度图，公式(5)中的 L_depth 即监督该输出。

**扩散 Transformer（DiT）**：将扩散模型中的 U-Net 替换为 Transformer 的架构，在潜在空间上迭代去噪。每一步根据当前噪声潜变量和时间步预测噪声。SpatialFusion 在 DiT 的输入潜变量上融合深度特征，并在潜变量 patchification 之前进行。

**VAE（变分自编码器）**：将高分辨率图像压缩到低维潜在空间，减少扩散过程的计算量。图像生成时，扩散模型在潜在空间去噪，再通过 VAE 解码到像素空间。深度适配器输出的特征与 VAE 编码后的潜变量在相同空间分辨率上逐元素相加。

**GenSpace 基准**：专门评估图像生成模型空间感知能力的基准，包含三个维度：空间姿态（相机姿态、物体姿态、复杂姿态）、空间关系（自我中心、异我中心、内在关系）、空间测量（物体大小、物体距离、相机距离）。论文所有空间实验均以 GenSpace 的平均分为核心指标。

**DINOv2**：一个自监督视觉特征提取器，提供图像的低层几何相关信息。SpatialFusion 用 DINOv2 特征增强可学习查询 token，为空间 Transformer 提供底层视觉线索。

## 4. 方法全景：先看数据流

ASCII 数据流如下：

```
输入文本 prompt + 可选源图像
        │
        ▼
  ┌──────────────┐
  │   Text Tokenizer / ViT   │
  └──────────────┘
        │
        ▼
  ┌──────────────────────────────┐
  │  MLLM (Qwen2.5-VL-3B)        │
  │  语义理解，输出 H_sem         │
  └───────────────┬──────────────┘
                  │ 共享自注意力（MoT，Uniform Sampling）
  ┌───────────────▼──────────────┐
  │  并行 Spatial Transformer    │
  │  10层，查询token+DINOv2       │
  └───────────────┬──────────────┘
                  │ H_geo
                  ▼
             ┌─────────┐
             │ DPT Head │
             └────┬────┘
                  │ 度量深度图 D
                  ▼
          ┌──────────────┐
          │ Depth Adapter │
          └──────┬───────┘
                 │ F_depth
                 │
  输入图像/噪声 → VAE → z_t ──⊕──> ẑ_t（在latent patchification前）
                                  │
                                  ▼
                        ┌─────────────────┐
                        │   DiT 去噪网络  │ ← H_sem (MLLM最后隐状态)
                        └────────┬────────┘
                                 │ ε_θ(ẑ_t, t, H_sem)
                                 ▼
                         去噪后的潜变量 → VAE解码 → 输出图像
```

核心组件及输入输出：

1. **MLLM（语义理解器）**  
   - 输入：文本指令、参考图像（若编辑任务）。  
   - 输出：最后一层隐状态 \(H^{(M)}_{sem}\)，同时为空间 Transformer 提供中间层语义特征。  
   - 目的：解析用户指令中的语义意图，为生成提供高层语义条件。  
   - 假设：MLLM 预训练权重冻结或部分冻结，保留强大语义能力。具体采用 Qwen2.5-VL-3B（§4.1）。

2. **并行空间 Transformer（Spatial Transformer）**  
   - 输入：可学习查询 token 与 DINOv2 特征拼接后的初始几何状态 \(H^{(0)}_{geo}\)；通过共享注意力接入 MLLM 的 K/V。  
   - 输出：几何感知的隐状态 \(H^{(L)}_{geo}\)，送入 DPT head 预测度量深度图 \(D \in \mathbb{R}^{H\times W\times 1}\)。  
   - 目的：从语义上下文推导目标图像的 3D 结构。  
   - 假设：共享自注意力足以让几何查询从语义特征中提取空间信息，无需独立跨模态编码器。空间 Transformer 仅有 10 层，每层与 MLLM 的对应层通过层映射 \(j=\lfloor i\cdot M/L\rfloor\) 交互。

3. **深度适配器（Depth Adapter）**  
   - 输入：度量深度图 \(D\)。  
   - 输出：与扩散潜变量同空间分辨率的特征 \(F_{depth} \in \mathbb{R}^{h\times w\times c}\)，其中 \(h=H/8, w=W/8\)。  
   - 目的：将深度图映射到扩散潜在空间，进行对齐。  
   - 假设：通过残差相加注入比拼接更稳定，不破坏预训练先验。论文消融（Table 5）验证了这一点。

4. **扩散 Transformer（DiT）**  
   - 输入：融合深度特征的噪声潜变量 \(\hat{z}_t = z_t \oplus F_{depth}\)，以及 MLLM 的语义条件 \(H^{(M)}_{sem}\)。  
   - 输出：预测噪声 \(\epsilon_\theta(\hat{z}_t, t, H^{(M)}_{sem})\)。  
   - 目的：在几何约束下进行空间一致的图像合成。  
   - 假设：显式深度先验能锚定空间布局，提升空间任务成功率且不损害通用生成。融合发生在潜变量 patchification 之前，以便几何约束作用于最基础的空间层。

5. **VAE**  
   - 输入：原始图像或噪声潜变量。  
   - 输出：压缩的潜在变量 \(z_t\)，以及最终解码图像。  
   - 目的：降低扩散过程计算量。  
   - 假设：潜在空间能保留足够空间细节供深度特征注入。

## 5. 核心公式与直觉

SpatialFusion 的贡献集中在两个机制，公式不多但关键。我们逐一解释。

**公式 (1)-(3)：语义引导的几何注意力**

空间 Transformer 第 \(i\) 层，几何状态 \(H^{(i)}_{geo}\) 和对应的 MLLM 语义状态 \(H^{(j)}_{sem}\)（其中 \(j=\lfloor i\cdot M/L\rfloor\)，\(M>L\)，L=10）分别通过各自的投影矩阵生成 Q、K、V：

\[
Q^{(i)}_{geo}, K^{(i)}_{geo}, V^{(i)}_{geo} = \text{QKV}_{geo}(H^{(i)}_{geo})
\]

\[
Q^{(j)}_{sem}, K^{(j)}_{sem}, V^{(j)}_{sem} = \text{QKV}_{sem}(H^{(j)}_{sem})
\]

然后拼接键和值，让几何查询同时关注语义内容：

\[
\text{Attn}^{(i)}_{geo} = \text{softmax}\left(\frac{Q^{(i)}_{geo} [K^{(j)}_{sem} \circ K^{(i)}_{geo}]^T}{\sqrt{d}}\right) [V^{(j)}_{sem} \circ V^{(i)}_{geo}]
\]

直觉：几何查询 token 本身没有语义背景，但通过共享注意力，它可以“看到” MLLM 的语义表示。这样可以基于文本指令中蕴含的语义关系（如“在左边”“面向右侧”）推导出相应的深度结构。关键操作是 K/V 的拼接，不改变 MLLM 自身的前向传播，只影响空间 Transformer 的注意力计算。层映射 \(j=\lfloor i\cdot M/L\rfloor\) 保证 10 层空间 Transformer 均匀覆盖 MLLM 的低层到高层语义；消融（Fig. 4a）显示 Uniform Sampling（均匀采样）比只取前 10 层（Shallow）或后 10 层（Deep）效果更好，因为均匀覆盖了从低级到高级的语义特征谱。

**公式 (4)：几何约束注入扩散**

\[
\hat{z}_t = z_t \oplus F_{depth}
\]

其中 \(F_{depth} = E_\phi(D)\)，\(E_\phi\) 是深度适配器。\(\oplus\) 表示逐元素相加。直觉：把深度特征作为残差项加到噪声潜变量上，可以看作给每个潜在空间位置提供几何先验偏移。相比于拼接，相加不改变输入维度，对预训练 DiT 的分布冲击更小。论文消融实验（Table 5）证实 Addition 优于 Concatenation：Addition 在 GenSpace T2I 上得到 46.19，而 Concatenation 只有 42.81。

**公式 (5)：深度回归损失**

\[
L_{depth} = \frac{1}{|M|} \sum_{i \in M} \| D^{(i)}_{gt} - D^{(i)}_{pred} \|_2
\]

这是 Stage 1 唯一的损失。\(M\) 是有效图像区域掩码，\(D_{gt}\) 来自 VGGT 教师预测的伪真值度量深度。用 L2 距离监督几何推导，使空间 Transformer 学会从语义上下文预测准确的深度图。直觉：这是一个稠密回归任务，强制几何分支捕捉空间结构，而不是只输出模糊的类别式深度。损失只在有效区域计算，避免无效像素（如背景填充）干扰训练。

**公式 (6)：两阶段联合损失**

\[
L_{total} = L_{diff} + \lambda L_{depth}
\]

Stage 2 同时优化扩散损失和深度损失，\(\lambda\) 控制两者平衡。论文通过实验确定 \(\lambda=0.5\) 时 GenSpace 总分与深度损失达到最佳权衡（Fig. 4b）。增大 \(\lambda\) 会提升深度预测精度，但过度强调深度会损害图像生成质量，因为模型可能过度关注几何推导而牺牲扩散主任务的表现。

## 6. 训练到底怎么跑

训练分两个阶段，分别有明确的目标和策略。每个阶段内部还采用粗到细课程学习：先在大规模数据混合上训练以建立广泛对齐，再在高质量子集上微调以提升空间精度和视觉保真度。

**Stage 1：几何感知预训练**  
- 冻结 MLLM 和扩散骨干，只训练并行空间 Transformer、可学习查询 token 和 DPT head。  
- 数据来自论文构建的百万级（million-scale）数据集中的空间感知子集，优先选择需要严格结构遵循的任务。  
- 伪真值深度图由冻结的 VGGT 从目标图像预测得到。查询 token 经过 MoT 层后，输出隐状态送入 VGGT 的冻结 DPT head 预测深度 \(D_{pred}\)（§3.3）。  
- 使用公式 (5) L2 深度损失监督。  
- 每一轮 step 大致流程：采样一个 batch 的文本/图像对 → MLLM 前向得到语义隐状态 → 空间 Transformer 共享部分自注意力，生成几何隐状态 → DPT head 输出深度预测 → 与 VGGT 伪真值计算 L2 损失 → 反向传播更新空间 Transformer 和查询 token。  
- 论文没有明确给出 Stage 1 的训练步数或 epoch，仅说明使用粗到细课程学习，先在大规模数据混合上训练，再在高质量子集上微调（§3.3）。

**Stage 2：几何引导联合训练**  
- 解冻扩散骨干，与空间 Transformer 一起端到端优化。  
- 使用全部训练任务：基础图像生成（标准 T2I、指令引导编辑）、空间感知生成（空间姿态、空间关系、空间测量）、几何一致编辑（几何接地物体添加、结构感知物体移除、主体替换等）。  
- 空间 Transformer 实时预测深度图，通过深度适配器注入 DiT。  
- 总损失 = 扩散损失 + \(\lambda\) 深度损失（公式 6）。深度损失与 Stage 1 完全一致。  
- 每个训练 step 大致：采样一个 batch 的训练任务样本 → 文本/图像进入 MLLM → 并行空间 Transformer 预测深度 → 深度适配器生成 \(F_{depth}\) → 图像经 VAE 编码得到潜变量 \(z_t\)（加入噪声） → 与 \(F_{depth}\) 逐元素相加得到 \(\hat{z}_t\) → DiT 以 \(H^{(M)}_{sem}\) 为条件预测噪声 → 计算扩散损失 L_diff → 计算深度损失 L_depth（与伪真值深度） → 加权求和后反向传播，更新扩散骨干、空间 Transformer、深度适配器等。  
- 使用 16 张 NVIDIA H200 GPU，全局批量大小 256，采用 bucket-based 采样支持不同宽高比（§4.1）。  
- 同样采用粗到细课程：先大规模数据混合，再高质量子集微调。

关键超参数：\(\lambda\) 最终设为 0.5（Fig. 4b）。共享注意力采样策略选择 Uniform Sampling（均匀采样）在验证深度损失上最佳（Fig. 4a）。空间 Transformer 有 10 层，MLLM 为 Qwen2.5-VL-3B，层数映射公式 \(j=\lfloor i\cdot M/L\rfloor\)。

## 7. 推理到底怎么跑

推理阶段不需要 VGGT 教师，也不需要计算深度损失。完整推理顺序如下：

1. **输入处理**：接收文本指令，如果是编辑任务还需接收源图像。  
2. **MLLM 前向**：文本 token（和可选图像 token）输入 MLLM，计算所有层的隐状态。保留最后一层 \(H^{(M)}_{sem}\) 作为 DiT 的条件，同时中间层用于空间 Transformer 共享注意力。  
3. **空间 Transformer 前向**：可学习查询 token 用 DINOv2 特征增强后，与 MLLM 的 K/V 拼接进行共享注意力，逐层更新几何状态 \(H_{geo}\)。  
4. **深度预测**：最后一层几何状态输入 DPT head，输出度量深度图 \(D\)。  
5. **深度适配**：\(D\) 通过深度适配器 \(E_\phi\) 映射到扩散潜空间，得到 \(F_{depth}\)。  
6. **扩散采样初始化**：从高斯噪声采样初始潜变量 \(z_T\)（或根据编辑任务添加噪声的源潜变量）。  
7. **迭代去噪**：对每个时间步 \(t\)，将当前噪声潜变量 \(z_t\) 与 \(F_{depth}\) 逐元素相加得到 \(\hat{z}_t\)，连同时间步 \(t\) 和语义条件 \(H^{(M)}_{sem}\) 输入 DiT，预测噪声 \(\epsilon_\theta\)，然后执行去噪更新得到 \(z_{t-1}\)。重复直到 \(z_0\)。  
8. **VAE 解码**：将最终的潜变量 \(z_0\) 输入 VAE 解码器，生成输出图像。

注意：深度图只在推理开始时预测一次，并在整个去噪过程中保持不变。论文未明确说明是否每步都使用同一个 \(F_{depth}\) 还是每步更新；从公式 (4) 看，\(F_{depth}\) 与时间步无关，工程上通常一次性预测并复用，这有利于保持几何一致性，并避免每步重复空间 Transformer 前向带来的延迟。

推理开销：相比 OmniGen2 基座，参数总量增加 18.5%，但单张图像推理延迟在 H200 GPU 上 T2I 增加 0.26 秒（12.32→12.58），编辑增加 0.83 秒（30.24→31.07），均小于 3%（Table 5）。这得益于空间 Transformer 轻量（10 层）且深度预测只做一次。

## 8. 实验和消融到底证明了什么

论文主要实验结论有四点：空间感知基准显著提升、标准基准不降反升、消融验证几何注入必要性、推理开销可忽略。下面用表格列出关键证据。

| 证据编号 | 实验设置 | 核心数字与对照 | 论文锚点 | 证明的主张 |
| --- | --- | --- | --- | --- |
| E1 | GenSpace T2I 平均分 | SpatialFusion 46.33 vs OmniGen2 31.78，GPT-4o 43.22 | Table 1 | 在空间感知 T2I 上超越最强基线，空间姿态得分从 31.74→55.82 |
| E2 | GenSpace 编辑平均分 | SpatialFusion 35.40 vs OmniGen2 26.18，GPT-4o 31.91 | Table 2 | 在空间感知编辑上提升显著，姿态任务相对提升 45% 以上 |
| E3 | 标准基准（GenEval / T2I-CompBench++ / DPG-Bench） | GenEval Overall 0.84 vs OmniGen2 0.801；T2I-CompBench++ Avg 66.4 vs 64.4；DPG 84.28 vs 83.57 | Table 3 | 内在 3D 意识不损害通用 T2I 性能，反而有增益 |
| E4 | 编辑标准基准（ImgEdit-Bench / GEdit-Bench） | ImgEdit Overall 4.01 vs OmniGen2 3.44；GEdit SC 7.92 vs 7.16 | Table 4 | 几何约束改善目标插入、替换、移除等编辑任务 |
| E5 | 几何注入消融 | w/o Injection 35.22，Concatenation 42.81，Addition 46.19（T2I GenSpace） | Table 5 | 性能增益来自 3D 几何注入而非数据过拟合；相加优于拼接 |
| E6 | 深度损失权重消融 | λ=0.5 时 GenSpace 总分约 0.46，λ=0.1 约 0.42，λ=2.0 约 0.38 | Fig. 4b | 需要平衡扩散损失与深度损失，过大 λ 损害生成质量 |
| E7 | 共享注意力采样策略消融 | 所有共享变体优于 no sharing；Uniform 采样验证深度损失最低 | Fig. 4a | 共享语义先验对几何推导至关重要，均匀覆盖低到高层语义效果最好 |
| E8 | 推理延迟 | T2I 12.58s vs 12.32s（+0.26s，+2.1%）；编辑 31.07s vs 30.24s（+0.83s，+2.7%）；参数量 +18.5% | Table 5 | 推理开销可忽略 |

**最关键消融**是 Table 5 中的几何注入机制对比。它直接回答“性能提升是否来自几何引导”这一核心问题。`w/o Injection` 表示空间 Transformer 和深度预测仍然存在，但不把深度特征注入扩散模型，只是训练时使用了相同的空间感知数据。该配置相比 OmniGen2 基座有提升（31.78→35.22），但远小于完整 Addition 的 46.19，说明数据增强带来部分收益，但显式几何注入贡献了主要提升。`Concatenation` 将深度特征与潜变量在通道维度拼接，虽然也提升到 42.81，但低于 Addition。原因是拼接改变了输入维度，干扰预训练先验；而加法作为残差注入，对分布偏移更小。这个消融支持了论文设计的合理性。

此外，论文还报告了两个相对提升：在空间关系维度上，SpatialFusion 相比最强基线 GPT-4o 在 allocentric（异我中心）任务上相对提升约 23%，在 intrinsic（内在关系）任务上相对提升约 31%（§4.2）。编辑任务中，物体姿态操控精度相对 GPT-4o 提升超过 45%。这些相对数字进一步支持空间推理能力的增强。

**尚未证明的主张**：论文声称“内在几何意识提升整体生成与推理能力”，标准基准上确有提升，但提升幅度较小（如 GenEval Overall 仅 +0.039），且没有在更大规模或更多类型的模型上验证。论文没有报告在非空间任务上是否会有潜在退化，也没有报告对低资源或长尾指令的鲁棒性。另外，VGGT 伪真值深度的质量影响未被消融，VGGT 对某些场景（如透明物体、强透视）的深度预测误差是否会传导至生成质量尚不清楚。

## 9. 与前作怎么选

与 SpatialFusion 最接近的方案有三类：布局到图像方法（如 LayoutDiffusion、GLIGEN）、外部 3D 条件注入方法（如 T2I-Adapter、ControlNet 深度版本）、以及 VGGT 本身作为外部条件提供者。下面比较选择。

**GLIGEN / LayoutDiffusion**  
- 输入：2D 边界框或分割图。  
- 何时选：只需要粗略的 2D 平面布局，不涉及 3D 姿态、朝向或度量距离。  
- 何时不选：需要“左侧/右侧”“面向关系”“距离 1 米”等 3D 语义时，它们无法处理；且需要额外布局输入，不是纯文本驱动。

**T2I-Adapter / ControlNet（深度条件）**  
- 输入：用户提供的深度图或其他外部稠密条件。  
- 何时选：用户手里有现成的深度图，或者需要显式控制生成结果的结构，不受文本指令限制。  
- 何时不选：纯文本场景下没有深度图可用，或者希望模型从语义自动推理空间结构，而不是依赖外部传感器。  
- 差异：这些方法是条件执行器，没有“内部化”几何理解；SpatialFusion 用语义自动预测深度并内化到模型。

**VGGT + 外部深度注入**  
- 若直接把 VGGT 深度图作为 ControlNet 条件，需要额外的前向 VGGT 计算且 VGGT 从参考图像预测深度，而纯生成时无参考图像。  
- SpatialFusion 将深度预测合并到生成框架中，共享语义上下文，避免了外部模型调用，且通过 MoT 使深度预测与文本指令对齐。  
- 何时选 SpatialFusion：需要在统一模型中处理空间感知任务，同时不牺牲通用生成能力，且希望推理延迟极低（<3% 增加）。  
- 何时不选：如果只关心普通 T2I 且对空间任务没有需求，SpatialFusion 引入额外参数和训练复杂度不值得；或者显存受限，18.5% 参数量增加可能超出部署限制。

## 10. 工程判断：可行性、风险与上限

**数据**  
论文自行构建了百万级数据集，涵盖基础生成、空间感知生成和几何一致编辑，具体来源为“web-sourced and synthetic samples”（§3.2），但论文未明确披露各任务样本占比、数据清洗流程和合成方式。依赖百万级数据训练可能对算力要求较高，尤其涉及多任务混合和不同宽高比的 bucket 采样。VGGT 作为教师提供深度伪真值，其质量直接影响 Stage 1 学习效果；如果 VGGT 在特定场景（如透明物体、强透视）预测错误，空间 Transformer 会学到错误先验。论文没有报告数据领域偏差或伪标签噪声率。

**算力与延迟**  
训练使用 16 张 NVIDIA H200 GPU，全局 batch size 256（§4.1）。推理延迟增加小于 3%（T2I +0.26s，编辑 +0.83s），因为空间 Transformer 只有 10 层，且深度预测只做一次。但注意 H200 是高端 GPU，在更低端设备上绝对延迟和相对开销可能不同。参数总量增加 18.5%，主要来自空间 Transformer、深度适配器和 DPT head，对显存占用有影响。

**实现难点**  
- MoT 层映射：需要精确对齐 MLLM 中间层和空间 Transformer 层，论文选择均匀采样（Uniform Sampling）并在消融中验证最优，但实现时需要处理不同层输出维度和前向顺序。  
- 深度适配器：将 1 通道深度图映射到扩散潜空间的 c 维特征，需要可训练的编码器，论文未详细说明其结构，工程上可能需要调参。  
- 两阶段训练稳定性：Stage 2 同时优化扩散损失和深度损失，λ 调优敏感。Fig. 4b 显示 λ 过大导致生成质量下降，实际训练需监控两个损失的平衡。  
- 数据采样策略：bucket-based 采样应对不同宽高比，需保证深度图与潜变量分辨率对齐（h=H/8, w=W/8）。

**失败环节**  
可能的失败点：深度图预测错误导致几何先验错误注入，产生伪影或错误布局；λ 设置不当导致生成质量下降；共享注意力没有充分传递语义时，空间 Transformer 退化；编辑任务中源图像与目标深度不一致可能导致背景扭曲。论文中 GenSpace 的复杂姿态（Complex Pose）和度量距离子项分数仍然较低，说明这些场景仍是高风险点。

**监控信号**  
训练时应监控：Stage 1 的验证深度损失 L_depth；Stage 2 的联合损失、扩散损失、深度损失、GenSpace 验证分数（或代理指标）；共享注意力可视化；生成图像与深度图的一致性；参数量和显存占用。推理时应监控：深度预测的合理性（如尺度范围）、延迟、生成图像的空间属性。论文未提供具体的监控面板，但上述指标可从训练目标和消融中合理推断。

**指标上限**  
GenSpace 平均分仍只有 46.33（T2I）和 35.40（编辑），远未达到满分 100，说明空间感知生成仍有很大提升空间。论文没有给出人类评估或误差分析的上限。潜在挑战包括：复杂关系推理（内在关系仅约 25.02%）、度量精确控制（物体距离、相机距离仍低，Table 1/2）、多物体互相遮挡时的深度一致性。另外，依赖 VGGT 伪真值深度可能存在天花板，若教师模型本身在复杂场景下不准确，学生难以超越。

**未回答问题**  
- 深度预测与生成质量之间的因果关系是否完全成立，缺少更细粒度的因果实验。  
- 对更大规模模型或不同 MLLM backbone 的适用性未知。  
- 空间 Transformer 与 MLLM 的层数比例、层选择是否最优尚未充分探索。  
- 处理动态场景、视频或 3D 输出是否可行未提及。  
- 数据集的版权、隐私、偏差问题未讨论。

## 11. 放回研究脉络并收束

SpatialFusion 处于两个研究潮流的交叉点：统一图像生成模型（强调理解-生成协同）与 3D 基础模型（强调单次前向恢复几何）。此前统一生成模型擅长语义对齐但缺乏空间推理，而 3D 基础模型能提供几何先验但未与生成深度耦合。SpatialFusion 通过 MoT 架构让 MLLM 的语义表征直接派生深度图，再用深度适配器把几何约束注入 DiT，实现了“语义→几何→生成”的闭环。这一思路与 ControlNet/T2I-Adapter 等外部条件注入不同，它是内化 3D 意识，而非外部控制。论文在 GenSpace 基准上的大幅提升验证了该方向的有效性，同时标准基准的增益表明几何意识可作为通用先验。

**读完必须记住的 5 件事**  
1. SpatialFusion 通过并行空间 Transformer（10 层，MoT 结构）与 MLLM 共享自注意力，从语义上下文预测目标图像的度量深度图。  
2. 深度图通过专用深度适配器映射到扩散潜空间，以逐元素加法注入噪声潜变量，而不是拼接，避免了预训练先验破坏（Table 5 消融）。  
3. 两阶段训练：Stage 1 用 VGGT 作为教师预训练深度预测，Stage 2 联合优化扩散损失和深度损失，λ=0.5 平衡二者（Fig. 4b）。  
4. 核心实验证据：GenSpace T2I 平均分从 OmniGen2 的 31.78 提升到 46.33，编辑从 26.18 提升到 35.40，同时标准基准不降反升，推理延迟增加 <3%。  
5. 消融证明几何注入是性能提升的主因，且相加注入优于拼接；共享注意力均匀采样比浅层或深层采样更好（Fig. 4a）。

**5 道自测题**  
1. SpatialFusion 如何解决“MLLM 几何贫乏”问题？核心组件是什么？  
2. 公式 \(\hat{z}_t = z_t \oplus F_{depth}\) 中 \(\oplus\) 为什么优于拼接？请在论文消融中找到证据。  
3. 训练 Stage 1 和 Stage 2 的目标分别是什么？Stage 2 的 λ 过大可能导致什么现象？  
4. 如果用户想在没有深度图的情况下生成“一个男人面向右侧”，SpatialFusion 和 ControlNet 深度条件的主要区别是什么？  
5. 假设你部署 SpatialFusion 到移动端，最需要关注的三个工程指标是什么？为什么？

最终一句话总结：SpatialFusion 通过“语义推导深度、深度约束扩散”的闭环，为统一图像生成模型注入了内在 3D 几何意识，在空间感知任务上取得显著提升，同时保持通用能力并几乎不增加推理延迟，但空间推理的准确率远未饱和，依赖伪标签的深度预测上限和复杂关系推理仍是未来挑战。
