# VIBE：决策型详细阅读笔记

## 一句话结论

VIBE 是首个系统性面向“视觉指令驱动图像编辑”的 benchmark（Section 1），包含 1,034 个手工标注或核验样本、10 类任务、3 个交互层级（Section 1、Figure 2）。它用 GPT-5.1 作为 LMM-as-a-judge 做任务化自动评分（Section 2.3、Section 3），主实验显示专有模型整体强于开源模型，但最强的专有模型在 Causal 层仍低于 50 分（Table 1）。对“简单人像编辑 + 身份保持 + 局部保持”类方案，VIBE 适合作为外部视觉指令跟随能力参考，但不是训练集，也缺乏像素级定位与身份保持的精细测度；其 Deictic 层 IA/CP/VC 只是粗粒度二值判断，不能直接替代 mask IoU、人脸相似度或局部感知指标。适用边界明确：只能用于模型能力分级与初筛，不能作为像素级验收标准。

## 问题与适用边界

论文的核心判断是：现有图像编辑系统与基准仍以文本指令为主，而文本在表达空间位置、结构约束时认知负担高、歧义大（Section 1）。VIBE 将“视觉指令”形式化为空间锚定线索，如框、箭头、草图、姿态参考等，并定义编辑函数为 `I_out = φ(I_in, T, V)`，其中 `T` 是文本指令，`V` 是视觉指令，可作为独立图像或叠加标注（Section 2.1、Equation 1）。作者进一步提出认知递进的三层交互层级：Deictic 层把视觉指令当 selector，Morphological 层当 blueprint，Causal 层当 catalyst（Section 2.2、Figure 3）。该设计意图弥补文本-only 基准无法系统评估视觉定位、结构约束与物理因果的缺口。论文明确把视觉指令的“指代、蓝图、催化”三种角色作为划分任务难度的理论基础，说明其目标不是简单扩展文本编辑测试，而是建立一套跨任务、跨粒度的统一评估框架。这一动机意味着对简单人像编辑而言，若输入包含空间标记，VIBE 能提供文本基准无法给出的定位与约束评估视角。

## 方法与数据构造

VIBE 共 1,034 个测试样本，3 个层级、10 个任务（Figure 2）。Deictic 层含 Addition、Removal、Replacement、Translation 四任务，各 100 例，共享同一批源图，风格分布为 34 真实、33 动画、33 草图（Section 2.2）。Morphological 层含 Pose Control、Reorientation、Draft Instantiation，各 100 例；其中 Pose Control 由 27 张人像源图和 26 张姿势参考图手动配对成 100 对（Appendix B.2）。Causal 层含 Light Control 100 例、Flow Simulation 100 例、Billiards 134 例；Billiards 先用脚本合成 200 个候选，再经人工筛除不清样本（Section 2.2、Appendix B.3）。论文写明这些样本都是人工标注或核验的测试实例，不是配对编辑训练集；除 Billiards 有轨迹/碰撞的 golden label 图外，多数任务没有唯一 ground truth 输出（Section 2.3）。因此，VIBE 只能用于评测，不能直接作为编辑模型的监督训练目标。这一设计意味着它的价值在于能力分级和模型对比，而非提供可回归的编辑目标；工程上也不存在从该 benchmark 直接构造训练对的可能性。

## 评测设计与指标

评测采用 LMM-as-a-judge，评估器为 GPT-5.1 的 2025-11-13 版本，每个样本独立评 3 次取均值以减少随机方差（Section 2.3、Section 3）。Deictic 层使用统一式三元指标：Instruction Adherence（IA）、Contextual Preservation（CP）、Visual Coherence（VC），最终 `Score = (IA·CP·VC)^(1/3)`（Equation 2）。其中 IA 是“视觉定位正确性、操作类型一致性、文本动作语义一致性”三个二值子项的平均；CP 是二值判断非目标区域是否被改动；VC 是“风格一致、视觉无缝、无伪影”三个二值子项的平均。若 IA=0，则 VC 强制为 0。几何平均公式意味着任何一项得分为零都会使总分归零，体现三项指标的同时性硬约束；这属于工程推断，论文未在正文单独解释该公式的设计动机，但可由 Equation 2 直接推出。

需要注意：Deictic 层的“定位正确”只是 IA 中的一个二值子项，不存在 IoU、mask 重合率或像素级距离。身份保持也不是 Deictic 层独立指标；它只在 Pose Control 中以 Character Identity Consistency（CIC）出现，在 Reorientation 中以 Identity Consistency（IC）出现（Section 2.3、Appendix D.1）。Morphological 与 Causal 层各有任务专属 rubric：Pose Control、Reorientation、Light Control、Flow Simulation、Billiards 分别有不同公式（Equation 3–7、Appendix D.1）。人评验证仅覆盖 Nano Banana Pro 和 GPT-Image-1 两个模型，每个模型抽 100 例，4 名专家按同一 rubric 评分后取均值，再与 LMM 分数计算 Pearson 相关（Section 4.3、Figure 7）。这一验证没有覆盖全部 17 个模型、全部 1,034 个样本；因此，论文报告的相关性只能支持这两个专有模型在该采样上的 judge 一致性，不能外推为全局可靠性。

## 关键结果与原文锚点

主结果 Table 1 显示：Nano Banana Pro 总体 65.15，Deictic 层平均 84.83，Morphological 65.46，Causal 45.17；即便最强的专有模型在 Causal 层也低于 50 分。专有模型在所有层级都明显高于开源模型；专有模型自身也呈现 Deictic → Morphological → Causal 的得分下降（Section 3.1）。例如 Nano Banana Pro 从 84.83 降至 45.17，GPT-Image-1 从 58.56 降至 23.13（Table 1）。这些是实验支持的直接观测，不是论文推断。

风格分析表明，Deictic 层模型存在明显风格偏好，Seedream 4.5 在草图风格上显著变差，而 GPT-Image-1 在真实图上更好（Section 4.1、Figure 4）；Draft Instantiation 上多数模型在动画风格表现更高（Section 4.1、Figure 5、Table 4/5）。多任务组合实验中，单任务 → 双任务 → 三任务的性能下降是可重复的：Nano Banana Pro 由 84.83 → 80.22 → 75.48，GPT-Image-1 由 58.56 → 47.32 → 42.85（Section 4.2、Table 2）。这些同样属于 benchmark 观测结果，说明多视觉指令组合是当前编辑能力的明显短板。

LMM-as-judge 可靠性方面，论文报告总体 Pearson r=0.9602，Nano Banana Pro r=0.9673，GPT-Image-1 r=0.9531（Figure 7、Section 4.3）。但必须限定：这是两个专有模型、每模型 100 个样本上的相关性，不能推断为 GPT-5.1 judge 对所有 17 个模型、所有任务都可靠。此外，作者把“专有模型优势归因于模型规模与训练数据多样性”属于解释性论述，论文并未做消融或因果验证；该归因应视为未证实主张，而不是由 Table 1 直接推出的结论。

## 局限与未证实主张

第一，VIBE 是评测集而非训练集：没有配对编辑输出，多数任务无唯一 ground truth，不能作为监督训练信号。第二，自动评分较粗：CP、VC、IA 的定位项主要是二值或分项二值，无法捕捉轻微背景漂移、发丝级伪影、面部 ID 相似度变化或 mask 局部一致性。第三，人评验证覆盖范围有限：仅两个前沿专有模型、各 100 例；对开源模型或低分模型，GPT-5.1 judge 是否会放大误差尚不明确。第四，身份保持证据不足：Deictic 层没有独立身份指标，Pose Control 的 CIC 是语义级二值判断，不能替代人脸 embedding 或 landmark 指标。第五，风格与视觉提示边界复杂：部分任务使用参考图或叠加标注，评估依赖 LMM 对语义对象变化的理解，并不等价于目标 mask 的严格保持。第六，样本规模有限：每个子任务约百级样本，难以覆盖所有风格、对象类别和边界情形；因此，在该 benchmark 上得到的排名和差距可能对数据分布有一定的敏感性。这些局限中有的是论文直接提到的，有的来自对指标定义和样本规模的工程推断。

## 对简单人像编辑、身份保持与局部保持的决策意义

若你的方案输入包含框、箭头、草图或姿态参考，VIBE 可作为外部视觉指令跟随能力基准。Deictic 层的 IA/CP/VC 可拆成三道闸：改对位置、非目标不变、边缘融合一致（Section 2.3）。这套逻辑对简单人像局部编辑有借鉴意义，例如换衣时“只改衣物区域、保留背景、风格不崩”。

但不要直接把 VIBE 分数当作像素级局部保持或身份保持的验收标准。IA 中对“定位正确”只是二值判断，没有 mask IoU、轮廓贴合度或边界距离；CP 也是语义对象级而非像素级，不能捕捉皮肤纹理微漂移或发丝断裂。因此，对于人像编辑，建议在 VIBE Deictic 之外补充以下指标：人脸相似度（ArcFace/FaceNet embedding cosine）、关键点或 landmark 误差、目标 mask 区域内 LPIPS/SSIM、非编辑区域像素差或 mask 外变化检测。Pose Control 的 CIC 可以作为姿态编辑时身份保持的语义级辅证，但仍需数值型身份指标兜底。

LMM-as-judge 适合作为低成本初筛，但不能用 r=0.9602 直接说明它在你的模型和任务上一定可靠；应在你的方案上做小规模人评校准，再决定是否采用 GPT-5.1 或同类 judge 做自动评估。若目标是训练阶段自动验收，VIBE 不能提供训练信号；只有评测或方法选择价值。多任务结果也提示：简单人像编辑若涉及多个视觉指令组合，当前模型可能在组合执行上明显退化（Table 2），方案设计时应考虑单指令拆分或显式空间绑定，不宜假设模型能天然组合多个视觉约束。在工程上，可以先用 VIBE Deictic 层快速筛掉明显无法跟随视觉定位的模型，再在自己的人像编辑数据集上做精细指标验证；但最终的身份保持和局部保持必须依赖像素级或 embedding 级指标，而非 VIBE 的语义级二值判断。

### 选择子集时的实际建议

若产品只支持框选或箭头指示，应优先使用 Deictic 四任务，不必用 Causal 分数决定模型去留；若支持姿态参考，则单独加入 Pose Control，并保留 CIC 作为语义级辅证。发布阈值应在自有模型上重新校准，因为论文的高相关只覆盖两个专有模型。这样能避免把与产品无关的物理因果任务混入总分，也避免用粗粒度 judge 掩盖人脸局部漂移。
