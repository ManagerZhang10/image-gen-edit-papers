# 大白话深读《MAR》

## 1. 30 秒定位

这篇论文解决的是图像自回归生成是否必须依赖向量量化（VQ）离散 token 的问题。它提出用扩散过程建模每个连续值 token 的条件分布，称为 Diffusion Loss，从而去掉离散 tokenizer。代价是每个 token 位置都要运行一个小型去噪 MLP，并在训练时对每个位置多次采样扩散时间步，推理时每个生成步骤内部还要做若干步反向扩散；不过论文用实验支撑：在 ImageNet 256×256 上，MAR-L 使用 Diffusion Loss 可达到 w/ CFG 的 1.98 FID，推理约 0.288 秒/图（Table 1、Table 3），相比同架构交叉熵损失大幅降低 FID。

## 2. 为什么这篇论文会出现

过去把语言模型式的自回归生成搬到图像时，主流做法是先用 VQ-VAE 或 VQGAN 把图像编码成离散 token，再用 Transformer 做“下一 token 预测”。这样做的直接原因来自一个普遍观念：自回归模型天然与离散表示绑定，因为离散值可以方便地用分类分布和交叉熵损失建模（论文 §1 写明）。但论文指出，真正需要的不是“离散”本身，而是能够衡量分布差异的损失函数和能够从分布中采样的采样器；这两件事在离散空间很容易做，在连续空间也可以有替代方案（§3.1）。同时，VQ tokenizer 有几个已知痛点：训练困难、对梯度近似策略敏感、重建质量通常不如连续 tokenizer（§1 提到）。此外，近期 GIVT 已经尝试用高斯混合模型建模连续 token，但论文认为固定混合数会限制可表示的分布类型（§2）。扩散模型在表示任意分布上已经显示出有效性，因此论文把“全局扩散”缩小到“每个 token 的局部扩散”，与自回归的 token 间依赖建模结合起来，这是本文出现的主要动机。

## 3. 方法全景：先看数据流

整体数据流可以画成下面这样（训练阶段）：

```
图像 x
  │
  ▼
连续 tokenizer（如 LDM 的 KL-16，冻结）
  │  得到连续 token 序列 {x^1,...,x^n}
  ▼
随机排列 / 随机掩码，划分已知 token 与未知 token
  │
  ├─▶ 已知 token + 位置编码 ─▶ Transformer 编码器
  │
  ▼
拼接 mask token + 位置编码 ─▶ Transformer 解码器
  │
  ▼
每个未知位置输出条件向量 z_i
  │
  ▼
Diffusion Loss 的小 MLP ε_θ(xt|t, z_i)
  │
  ▼
与真实噪声 ε 算 MSE，梯度回传到 Transformer 和 MLP
```

推理阶段的数据流略有不同：从全 mask 开始，按余弦调度逐步降低掩码比例；每一步把已知 token 经编码器得到条件 z，对每个未知位置用训练好的去噪 MLP 做若干步反向扩散，采样出连续 token；采出的 token 加入已知集合，重复直到所有位置生成完毕。

下面拆解核心组件。

**连续 tokenizer**：输入是原始图像，输出是连续值 token 序列。论文默认使用 LDM 代码库提供的 KL-16 tokenizer，它是一个没有 VQ 的 KL 正则化自编码器，步长为 16。对于 256×256 图像，序列长度未在正文直接写出，但可从附录 D.2 “512×512 下 KL-16 给 32×32 序列”推出 256×256 约为 16×16=256 个 token；这是基于步长的工程推断。该 tokenizer 在训练时是否参与梯度更新，论文未明确披露，但使用“publicly available tokenizers”“provided by LDM”的表述更接近冻结；本文按冻结处理并标注为工程推断。它的假设是 token 重建质量会影响生成上限，Table 2 的 rFID 与生成 FID 相关性支持这一点。

**Transformer 编码器-解码器**：输入已知 token 加位置编码，编码器用双向注意力让所有已知 token 互相看见；再在中间层引入 mask token 并再次加位置编码，解码器让所有未知 token 看见所有已知 token。输出是每个未知位置的条件向量 z∈R^D。对于 MAR-L，论文写明编码器和解码器各占一半块数，默认 32 块、宽度 1024；MAR-B/H 分别为 24/40 块、宽度 768/1280（附录 B）。目的不是直接预测 token 值，而是为每个位置产出一个能指导扩散采样的条件向量。假设是 token 间依赖由 Transformer 建模，token 内分布由扩散建模。

**Diffusion Loss 去噪 MLP**：输入是加噪 token xt、时间步 t 和条件 z；输出是预测噪声 ε_θ。默认 3 个残差块、宽度 1024，约 21M 参数（Table 3）。它等价于一个参数化损失函数，其梯度回传到 z，从而训练 Transformer。它的假设是给定 z 时，连续 token 的真实分布 p(x|z) 可用扩散模型足够近似；这一点由生成质量实验间接支持。

## 4. 核心公式与直觉

论文贡献中最关键的公式是 Diffusion Loss 的去噪准则（原文式 (1)）：

\[
L(z, x) = E_{\varepsilon,t}\left[\|\varepsilon - \varepsilon_\theta(x_t|t, z)\|^2\right]
\]

其中 x∈R^d 是当前要预测的连续 token，z 是自回归模型为该位置产生的条件向量，ε∼N(0,I) 是标准高斯噪声，xt=√ᾱt x+√(1−ᾱt) ε 是加噪后的 token，ᾱt 来自余弦噪声调度，t 是扩散时间步。ε_θ 是去噪 MLP，输入 xt 并条件在 t 和 z 上。这个损失在优化上相当于让 MLP 学习 p(x|z) 的分数函数（score function）相关量，也就是 ∇log p(x|z) 的方向；论文写明这一点。对 z 求梯度时，这个 MSE 损失扮演了“衡量 z 质量”的角色，所以叫 Diffusion Loss。工程上，论文为了不重复计算 z，对每个 z 在训练时采样 t 四次，提高了损失利用率。

第二个公式是标准自回归分解（式 (2)）：

\[
p(x^1,...,x^n)=\prod_{i=1}^{n} p(x^i|x^1,...,x^{i-1})
\]

它说明生成问题被拆成“给定前文预测下一个 token”。在本文中，这个条件概率不是由一个分类 softmax 给出，而是先由 Transformer 产生 z_i=f(x^1,...,x^{i-1})，再用扩散模型定义 p(x^i|z_i)。这保持了自回归的分解方式，但把每步的分布换成了连续扩散分布。

第三个公式是掩码自回归的统一分解（式 (3)）：

\[
p(x^1,...,x^n)=p(X^1,...,X^K)=\prod_{k=1}^{K} p(X^k|X^1,...,X^{k-1})
\]

这里 X^k 是第 k 步一次性预测的一组 token 集合，所有集合的并集是完整序列。这个公式把 MaskGIT/MAGE 这类掩码生成模型也纳入“下一组 token 预测”的自回归框架。直觉上，随机顺序的 MAR 相当于每次预测一个或多个被 mask 的位置；与 MAGE 的关键差异是 MAR 使用完全随机顺序，并把温度采样作用在每个 token 的分布上，而不是作用在位置选择上（§3.4、附录 C）。

## 5. 训练与推理怎么跑

**一轮训练 step**：从 ImageNet 取一批图像，经冻结的连续 tokenizer 得到 token 序列。对每个样本随机采样一个排列，并随机采样掩码比例（论文写为 [0.7, 1.0]，即至少 70% 位置为未知）。已知 token 进入编码器，未知位置用 mask token 占位并加位置编码，进解码器。解码器对每个未知位置输出 z。对每个未知 token，Diffusion Loss 采样 t 四次，按式 (1) 计算噪声预测 MSE；损失只在未知 token 上计算（MAE 式）。梯度同时更新 Transformer 和去噪 MLP；tokenizer 不更新（工程推断，论文未写明）。优化器是 AdamW，权重衰减 0.02，动量 (0.9,0.95)，批大小 2048，学习率 8e-4。Diffusion Loss 版本用 100 epoch 线性预热后保持常数；交叉熵版本用余弦学习率调度。训练默认 400 epoch，系统对比时增加到 800 epoch；使用 EMA，动量 0.9999。

**完整推理顺序**：从头生成时，序列开始时全部位置为 mask。论文默认使用 64 个自回归步骤的余弦调度，逐步把掩码比例从 1.0 降到 0。每一步，当前已知 token 经编码器产生条件 z；对每个待预测位置，用训练好的去噪 MLP 执行反向扩散。反向扩散默认从 1000 步训练调度重采样到 100 步推理；采样器从 xT∼N(0,I) 开始，迭代得到 x0，近似从 p(x|z) 采样。采样时支持温度 τ：论文采用缩放噪声项 σtδ 的做法，τ 越大样本多样性越高。CFG 也直接支持：训练时 10% 样本用 dummy class token；推理时分别跑条件和无条件两种 z，对预测噪声做线性外推，并按论文沿用 MUSE 的 CFG 调度。默认推理约 64 步 AR、100 步扩散；系统级最优结果则用 256 步 AR。AR 基线使用因果注意力和 kv-cache，逐 token 生成；MAR 不使用 kv-cache，但一次可以生成多个 token，因而步数更少。

哪些参数训练、哪些冻结，论文只明确说“denoising network is trained jointly with the autoregressive model”，即 Transformer 和去噪 MLP 都训练；tokenizer 冻结属于工程推断，这源于论文说用的是公开预训练 tokenizer，且没有提到 tokenizer 训练损失。这种联合训练是 Diffusion Loss 的核心机制：MLP 的噪声预测误差作为 z 的学习信号。

## 6. 实验和消融证明了什么

论文的主要实验在 ImageNet 256×256 类条件生成上，使用 FID、IS、Precision、Recall 指标。下表列出几条关键证据。

| 证据锚点 | 对比条件 | 关键结果 | 支持什么 |
|---|---|---|---|
| Table 1 | MAR rand bidirect, 1 pred, Diff Loss vs CrossEnt | w/o CFG FID 3.43 vs 8.75；w/ CFG 1.84 vs 3.50 | 同架构下扩散损失显著优于交叉熵 |
| Table 1 | AR raster causal, Diff Loss vs CrossEnt | w/o CFG FID 19.23 vs 19.58；w/ CFG 4.69 vs 4.92 | 即便是逐 token 的 AR，扩散损失也不弱于离散基线 |
| Table 2 | 同 Diff Loss 下 KL-16 vs VQ-16 tokenizer | rFID 1.43 vs 5.87；w/o CFG FID 3.50 vs 7.82 | 连续 tokenizer 重建质量更好，生成 FID 更低 |
| Table 5 | MAR 随机顺序 vs MAGE 式在线置信度顺序 | CrossEnt FID 8.79 vs 8.72 | 随机顺序与在线顺序效果接近，但随机顺序训练推理更一致 |
| Table 6 | ImageNet 512×512, MAR-L Diff Loss | w/o CFG 2.74 FID；w/ CFG 1.73 FID | 方法在更高分辨率上仍有竞争力，但只做了 512 的 MAR-L |

最关键的一个消融是 Table 1 中 MAR 默认设置下 Diffusion Loss 对 CrossEnt 的对比：w/o CFG 从 8.75 降到 3.43，w/ CFG 从 3.50 降到 1.84。这个结果直接支撑了论文的核心主张——去掉 VQ 并改用扩散损失，能带来明显收益。但要注意，这个收益里同时混杂了两个因素：连续 KL-16 tokenizer 本身重建质量更好，以及扩散分布比分类分布建模能力更强。论文在 Table 2 中通过“对 VQ tokenizer 也使用 Diff Loss 处理量化前连续潜在”得到 7.82 FID，相比 Table 1 的 VQ+CrossEnt 8.79 有所改善，说明扩散分布单独有贡献；而 KL-16 的 rFID 更低则说明 tokenizer 质量贡献另一部分。这个拆解是论文中比较有说服力的地方。

尚未被证明的主张包括：方法能否扩展到文本到图像或视频生成；是否在其他数据集上仍优于离散 token 方案；扩散损失相比 GIVT 的高斯混合模型在同等计算预算下是否更好；以及更大规模或更长训练下的稳定性。论文系统级对比 Table 4 展示了与 GIVT、DiT 等的结果，但训练资源和 epoch 不完全一致，也没有做 GMM 与 Diffusion Loss 的同架构控制消融，所以不能把“Diffusion Loss 必然优于 GMM”当成已被严格证明。

## 7. 与前作怎么选

论文主要与三类方法形成对比：GIVT（连续 token 但用高斯混合模型）、MAGE/MaskGIT（离散 token 的掩码生成）、DiT（全局潜在扩散）。下面表格基于论文列出的基线比较。

| 方案 | token 空间 | per-token 分布 | 生成顺序/步数 | 论文中的相对表现 |
|---|---|---|---|---|
| MAR + Diffusion Loss | 连续 token | 扩散过程，小 MLP | 随机顺序，64/256 步 | MAR-H w/ CFG 1.55 FID；速度快于 DiT |
| GIVT | 连续 token | 固定数量高斯混合 | 序列模型 | 304M 模型 w/ CFG 3.35 FID |
| MAGE | 离散 VQ token | 分类 softmax | 在线置信度顺序 | 230M 模型 w/o CFG 6.93 FID |
| DiT-XL/2 | 连续潜在 | 全局扩散，整个 Transformer 去噪 | 扩散步数控制 | 675M 模型 w/ CFG 2.27 FID |

何时选 MAR + Diffusion Loss：如果希望保留序列生成的速度优势、避免 VQ tokenizer 的训练难题、并且能接受局部扩散推理开销，那么本文方案合适；论文 Figure 6 显示它在速度-精度曲线上优于同条件下的 DiT。何时选 GIVT：如果实现简单性优先，且已知目标分布可以用少量高斯混合近似，GIVT 的采样会比多步扩散更轻，但论文认为其分布表达能力受限。何时选 MAGE/MaskGIT：如果已有成熟的 VQ tokenizer 和分类头，且不追求连续重建质量，交叉熵方案实现更直接；不过 Table 1 显示同架构下效果弱于 Diffusion Loss。何时选 DiT：如果视觉质量上限优先，且推理延迟不是关键，全局扩散在更高容量和更多步数下仍有竞争力；但论文指出其速度-精度曲线不如 MAR。

## 8. 工程判断与收束

数据方面，论文只在 ImageNet 256×256 做过系统验证，另有 512×512 的有限实验，以及一个 64×64 像素空间实验（分组 4×4 像素，FID 2.93，未展开）。因此把它推广到自然图像、文本条件或视频生成时，数据覆盖不足，这是明确写出的局限。算力上，训练主要在 16 台 8×V100 服务器上完成；MAR-L 400 epoch 约 2.6 天，而论文写 DiT-XL/2 同集群 400 epoch 约 4.6 天、LDM-4 约 9.5 天。推理延迟在 A100、批大小 256 下约 0.288 秒/图，默认 MLP 宽度 1024；作者认为开销主要来自内存通信而非计算，所以加大 MLP 宽度对延迟影响很小。

实现难点在于掩码生成与随机顺序的一致性：MAGE 的在线顺序会在训练/推理间引入偏差，MAR 用随机顺序规避了这一点，但要保证每个位置在解码器里通过位置编码知道“预测哪里”。另一个难点是温度与 CFG 的联合调参：论文提到要为每个模型 sweep 最优 guidance scale 和 temperature 组合，说明这两个超参数对 FID/IS 很敏感。最可能失败的环节是 tokenizer 质量成为上限：如果连续 tokenizer 重建 rFID 太差，生成结果会被限制；论文 Table 2 显示 rFID 与生成 FID 大致正相关，但关系不是线性，也没有证明 rFID 越低生成一定越好。此外，论文没有验证去噪 MLP 的深度/宽度在更大模型上是否仍是 5% 参数量级就能维持分布建模能力。

指标上限目前是 ImageNet 256×256 下 MAR-H 的 w/ CFG FID 1.55、IS 303.7（Table 4）；512×512 只跑了 MAR-L，w/ CFG FID 1.73。未回答的问题包括：Diffusion Loss 在其他连续生成任务中是否通用；局部扩散与全局扩散在理论表达能力上的边界；以及在没有预训练 tokenizer 的情况下，端到端训练连续 tokenizer 与扩散损失联合优化是否稳定。论文在附录 D.1 虽提到像素空间 64×64 实验，但只是初步探索。

读完必须记住的 5 件事：

1. Diffusion Loss 用局部扩散分布替代离散 softmax，使自回归模型可以处理连续 token。
2. 论文将 AR 与掩码生成统一为“下一组 token 预测”，MAR 用随机顺序和双向注意力实现。
3. 最关键的消融是 Table 1：同架构下 Diff Loss 比 CrossEnt 的 FID 从 8.75 降到 3.43（w/o CFG）。
4. 连续 tokenizer 的 rFID 与生成 FID 相关，KL-16 明显优于 VQ-16，但这只在一个基准上验证。
5. MAR + Diffusion Loss 在 ImageNet 256 上速度快于 DiT，但尚未在文本图像或视频等更真实场景得到验证。
