# 大白话深读《Self-Guidance》

## 1. 30 秒定位

这篇论文提出一种叫 **self-guidance（自引导）** 的方法，让预训练文本到图像扩散模型（text-to-image diffusion model）在生成过程中根据自身内部表征来“自我修正”，从而实现对物体位置、大小、形状、外观等属性的细粒度控制。它不需要额外训练任何模型，也不需要配对数据或外部分类器，只需在采样时对 U-Net 内部的交叉注意力图（cross-attention maps）和激活（activations）定义能量函数，并把能量梯度注入采样更新方向。作者展示了移动、缩放、替换物体、借用另一张图的布局或外观、从多张图拼贴生成、编辑真实图像等一系列操作，实验基于 Imagen 模型生成 1024×1024 图像，结果以定性展示为主，没有报告 FID、CLIP score 或用户研究等数值指标。核心贡献可以概括为：论文发现注意力图可以给出物体位置、大小、形状的可微代理，激活在注意力掩码内聚合后可以给出外观描述；这些内部信号足以引导复杂操作，而不需要辅助模型或额外监督。该方法的工作方式与标准 classifier guidance 相似，但能量函数完全来自预训练模型自身，因此被称为 self-guidance。

## 2. 为什么这篇论文会出现

在大规模文本到图像模型（如 Imagen、DALL·E、Stable Diffusion）出现后，用户主要通过文字 prompt 表达构图意图，但很多图像属性——例如“把甜甜圈往左移动一点”“把这只狗的毛发外观复制到另一只狗上”“让杯子精确占画面三分之一”——很难甚至无法用文字准确传达。即使反复调整 prompt，仍可能无法得到用户脑中的精确构图。现有方案大致有三类：一类需要微调，如 DreamBooth 用几张图微调模型来绑定特定外观，Textual Inversion 学习新的文本嵌入来表示新概念；一类需要优化循环，如 Imagic、Text2LIVE 在推理时优化潜变量或模型权重以实现编辑；还有一类零样本编辑，如 Prompt-to-Prompt（P2P）通过交换或修改交叉注意力图来保持结构、改变文本条件，Plug-and-Play 通过注入激活特征做结构保留的图像翻译。但这些方法要么有训练成本，要么控制维度有限：P2P 适合替换词语并保持布局，但不容易做精确几何变换；Plug-and-Play 偏向保持全局结构，而非精确操纵单个对象。

作者观察到 P2P 和 Plug-and-Play 虽然利用扩散模型内部特征，但主要是把特征复制到另一次采样中，而不是把特征作为可微约束去引导采样过程。于是提出问题：能否把这些内部表示变成可优化的能量函数，像 classifier guidance 那样在每一步修正采样方向？这样就能获得更细致、可组合、零样本的控制能力。此外，一些基于注意力的引导方法（如 Layout-Guidance）虽然也使用注意力约束，但往往需要外部条件或仅针对有限属性。论文的动机就是摆脱外部监督和微调，直接利用预训练模型已经学到的对象结构（注意力）和外观（激活）信号，实现对单个对象的几何与外观编辑，以及跨图像组合。因此，self-guidance 本质上是一种训练自由的、基于能量的采样控制方法，把扩散模型内部表征从“被观察的副产品”提升为“可优化的控制手柄”。

## 3. 读懂前需要的最小概念

**扩散模型（diffusion model）** 是一类生成模型，通过逐步去噪把随机噪声变成图像。`z_t` 表示第 t 步的含噪图像，`ε_θ(z_t; t, y)` 是网络预测的噪声，y 是文本条件。训练目标是让网络预测出真实加入的噪声，如 Eq.1 所示；采样时从 `z_T ~ N(0,I)` 出发，反复估计并去除噪声，直到得到清晰图像。**U-Net** 是去噪网络，包含多个分辨率的自注意力（self-attention）和交叉注意力（cross-attention）层。

**交叉注意力图（cross-attention map）** 是文本 token 与空间位置之间的注意力权重，形状为 `A_{i,t} ∈ R^{H_i × W_i × K}`，其中 H_i、W_i 是第 i 层空间尺寸，K 是 token 数量。对物体名词 token 的注意力通道 `A_{i,t}[:,:,k]` 通常高亮该物体出现的区域，因此可以当作软分割掩码（soft mask）。**激活（activations）** 用 `Ψ_{i,t} ∈ R^{H_i × W_i × D_i}` 表示，是 U-Net 中间特征图，携带局部外观信息，后续会被解码为图像内容。论文选择了特定层的激活：解码器倒数第二层（即预测头前两层）的激活，并结合最后一次交叉注意力操作。

**Classifier-free guidance（CFG）** 是在采样时同时用条件预测和无条件预测混合来增强文本一致性：`(1+s) ε_θ(z_t;t,y) - s ε_θ(z_t;t,∅)`，其中 s 是引导强度。**能量引导（energy-based guidance）** 更通用：在 CFG 基础上加上 `v σ_t ∇_{z_t} g(z_t;t,y)`，其中 g 是任意可微能量函数，σ_t 是当前噪声尺度，用于把 score 函数缩放为噪声预测。Self-guidance 的核心就是设计 g，让它依赖模型内部特征而不是外部模型。

**软阈值（soft threshold）** 是论文中对注意力图进行可微二值化的操作，用于减少注意力背景噪声，使大小和形状计算更稳健。具体实现如附录 Eq.14–16：先把注意力图归一化到 0–1，减去 0.5，通过斜率为 s=10 的 sigmoid，再归一化使最大值为 1、最小值为 0。这样得到的 `A_thresh` 保留梯度，但更接近二值掩码。质心计算不需要软阈值，因为背景噪声对质心影响相对较小。

## 4. 方法全景：先看数据流

Self-guidance 不改变扩散模型的训练，只在推理采样循环中插入一个内部特征约束模块。整体数据流如下：

```
输入: 文本 prompt y; 可选: 源图像 A/B 及其内部特征
                ↓
     从 z_T ~ N(0,I) 开始采样循环 t = T...1:
                ↓
     当前含噪图 z_t 送入预训练 U-Net 一次前向
                ↓
     取出中间特征:
       - 各层交叉注意力图 A_{i,t}
       - 指定层激活 Ψ_{i,t}
                ↓
     根据任务选择属性:
       centroid(k):  位置质心
       size(k):      软阈值注意力面积
       shape(k):     软阈值注意力空间图
       appearance(k): 形状加权的激活均值
                ↓
     构建能量函数 g(z_t;t,y) = Σ w_j * 属性差异项
                ↓
     计算 g 对 z_t 的梯度 ∇_{z_t} g
                ↓
     CFG 基础预测: (1+s)ε_θ(z_t;t,y) - sε_θ(z_t;t,∅)
                ↓
     最终噪声预测: ε̂_t = CFG + v σ_t ∇_{z_t} g
                ↓
     z_{t-1} = update(z_t, ε̂_t, t, t-1, ...)
                ↓
     最终 z_0 解码为图像
```

核心组件拆解：

- **特征提取器（feature extractor）**：直接复用预训练 U-Net 前向过程。输入 `z_t` 和文本 `y`，输出若干层的注意力图和激活。形状项作用于所有 36 个交叉注意力交互层，涵盖编码器、瓶颈、解码器，分辨率包括 8×8、16×16、32×32。外观项使用解码器倒数第二层（预测头前两层）的激活和最后一层交叉注意力。作者还尝试过编码器早期特征以降低外观与布局的纠缠，但发现效果显著更差，因此没有采用。

- **属性计算器（property calculator）**：对 token 索引 k 的注意力通道计算质心（Eq.5）、大小（Eq.6/16，先软阈值）、形状（Eq.7，直接用软阈值图）。外观（Eq.8）是形状掩码与激活逐空间加权平均，得到 D_i 维向量，表示该对象的局部外观描述。为了避免退化解，外观项中对注意力部分做 stop-gradient，只让激活的梯度回传到图像。

- **能量组合器（energy composer）**：根据编辑意图选择不同属性项组合。例如 Eq.9 同时固定其他对象形状、固定所有对象外观、将被编辑对象的形状引导到经变换后的原始形状；Eq.10 只固定所有对象形状来采样新外观；Eq.11 从图 A 借形状、从图 B 借外观；Eq.12 从多个图像中各取一个对象的外观和形状拼贴；Eq.13 从真实图像中仅复制一个对象的外观。各项权重按附录经验值选择，布局项通常比外观项高 1~2 个数量级；总权重建议不超过约 5，否则容易出现伪影。

- **梯度注入器（gradient injector）**：把 `v σ_t ∇_{z_t} g` 加到 CFG 预测上。由于属性项是特征对像素的复合函数，梯度会反向传播到 `z_t`，推动含噪图像在下一步去噪时生成满足约束的结构。论文设定全局引导系数 v=7500，因为像素梯度幅度通常在 10⁻⁷ 到 10⁻⁶ 量级，需要较大系数才能产生可见变化。

关键假设：
1. 交叉注意力图近似对象空间范围，可微且能响应图像扰动；
2. 激活在形状掩码内聚合后能表示对象外观，且与布局基本可分离（虽然论文承认有泄漏）；
3. 预训练模型内部特征足够丰富，无需外部监督；
4. 真实图像可以通过前向加噪提取的特征近似反向采样过程，分布不匹配不会严重破坏编辑结果。

## 5. 核心公式与直觉

论文中理解贡献必需的核心公式有四个：通用能量引导（Eq.4）、位置/形状/大小/外观属性（Eq.5-8）、以及一个组合操作示例（Eq.9）。下面逐一解释。

**通用引导公式**：

```text
ε̂_t = (1 + s) ε_θ(z_t; t, y) - s ε_θ(z_t; t, ∅) + v σ_t ∇_{z_t} g(z_t; t, y)   (4)
```

- `s`：classifier-free guidance 强度，控制文本与图像一致性；
- `v`：self-guidance 能量项权重，控制内部约束强度；
- `σ_t`：噪声尺度，用于把 score 函数 `∇_{z_t} log p` 转换为噪声预测；论文中将 score 乘 σ_t 得到与 ε 同量纲的修正量；
- `g`：由内部特征定义的能量函数，越小表示越满足用户约束。

优化动作：采样时每一步都沿着降低 g 的方向更新 `ε̂_t`，等价于在去噪过程中施加一个“向满足约束样本”的拉力。工程上，`v` 通常设为 7500，因为像素梯度幅度在 10⁻⁷~10⁻⁶ 量级，需要较大系数才能产生可见变化。

**对象属性定义**：

```text
centroid(k) = ( Σ_{h,w} w·A_{h,w,k} / Σ A_{h,w,k}, Σ_{h,w} h·A_{h,w,k} / Σ A_{h,w,k} )   (5)
```

变量：h、w 是空间坐标，A 是注意力图。这是对注意力权重求空间质心，表示对象在画布上的位置。引导时可以用 L1 距离匹配目标质心。

```text
size(k) = (1/HW) Σ_{h,w} A_thresh_{h,w,k}   (6)
```

其中 `A_thresh` 是对 A 做可微软阈值后的图。size 表示注意力覆盖面积，相当于对象大小的代理。

```text
shape(k) = A_thresh_k   (7)
```

直接使用软阈值注意力图作为对象形状掩码，可以引导到用户指定的二值掩码，也可以是从另一张图提取的形状。T 可以对该形状做平移、缩放、旋转等变换。

```text
appearance(k) = Σ_{h,w} shape(k) ⊙ Ψ / Σ_{h,w} shape(k)   (8)
```

`⊙` 是逐元素乘法，`Ψ` 是激活。该式对形状掩码内的激活做空间平均，得到一个外观描述向量。注意论文在反向传播时对 shape 做了 stop-gradient，避免通过注意力图影响外观项时产生退化解。论文还对所有形状损失项做了空间平均、外观损失项做了激活维度平均，公式中为简洁省略。

**组合操作示例（移动物体而不改变其他内容）**：

```text
g = w0 * (1/(|O|-1)) Σ_{o≠ok} (1/|A|) Σ_i || shape_{i,t,orig}(o) - shape_{i,t}(o) ||_1
  + w1 * (1/|O|) Σ_o || appearance_{t,orig}(o) - appearance_t(o) ||_1
  + w2 * (1/|A|) Σ_i || T(shape_{i,t,orig}(ok)) - shape_{i,t}(ok) ||_1   (9)
```

- 第一项固定其他对象的形状不变，防止场景整体漂移；
- 第二项固定所有对象的外观，防止编辑一个对象时改变颜色/纹理；
- 第三项把对象 ok 的形状引导到原始形状经过变换 T 后的版本；T 可以是平移、缩放、旋转等。
- `shape_{orig}` 和 `shape` 分别来自原始生成和编辑生成时同一步的注意力图；`|A|` 是所有使用的注意力层数。

直觉：联合优化这三项，就相当于对采样过程施加一个“弹簧系统”，只允许目标对象的几何属性改变，其他内容被约束在原位。这就是论文实现单对象解耦编辑的公式基础。附录还提供了基于质心和 size 的替代式 Eq.17，可以显式匹配 target_centroid 并保持 size 不变，权重范围在附录 B 中给出。

## 6. 训练到底怎么跑

需要首先澄清：Self-guidance **不训练任何新参数**。它完全依赖一个已经训练好的文本条件扩散模型，并在该模型的推理采样阶段添加引导项。论文没有提出新的训练目标或微调过程。但为了完整理解其前置条件，下面说明它依赖的预训练扩散模型的一轮标准训练 step，以及为真实图像编辑所做的“特征提取准备”。

**预训练扩散模型的一轮训练 step（背景，来自 Eq.1）**：

1. 从数据分布采样一张真实图像 `x`；
2. 采样时间步 `t ~ U(1,T)`，通常 T 在 1000 左右；
3. 采样噪声 `ε_t ~ N(0,I)`；
4. 构造含噪图 `z_t = α_t x + σ_t ε_t`，其中 α_t、σ_t 由噪声调度决定；
5. 计算网络预测 `ε_θ(z_t; t, y)`，y 是图像对应文本；
6. 计算损失 `L = w(t) || ε_t - ε_θ(z_t; t, y) ||²`；
7. 反向传播更新 θ。

论文使用的 Imagen 就是通过这种训练得到的，其中 `w(t)` 通常设为 1。Self-guidance 不需要修改这个训练过程，它只是在该模型已经学会的内部表示之上做后验控制。

**为编辑真实图像做准备（不是训练，但属于数据准备）**：

如果要对真实图像进行编辑或外观转移，Self-guidance 需要获得该图像的“内部特征序列”。具体做法是：
1. 给定真实图像 x 及其文本 caption；
2. 对每个时间步 t = 1...T，构造加噪版本 `z_t = α_t x + σ_t ε_t`，其中 `ε_t ~ N(0,I)`，T 个独立噪声；
3. 将每个 `z_t` 送入预训练 U-Net，提取对应时间步的注意力图 `A_t` 和激活 `Ψ_t`；
4. 将这些特征按时间步拼接，当作在反向采样过程中会出现的内部特征序列使用。

这一步骤近似“反转”了前向扩散过程，使 Self-guidance 能像操作生成图像一样操作真实图像。它不是训练，但需要额外前向计算和特征缓存。论文强调这种简单方法有效，尽管可能存在分布不匹配。此外，该方法不需要共享噪声序列来保证一致性，但共享噪声可以帮助获得更高精度。

**超参数与平台设置**：论文在 Imagen 上使用 N=1024 步 DDPM 采样；self-guidance 步调度是：前 `3N/16` 步施加引导，最后 `N/32` 步不施加引导，中间 `25N/32` 步交替使用引导和不使用引导。全局引导系数 v=7500；属性权重按任务经验设置（见附录）。作者还提到方法在 256 步和 512 步下也能工作，但 self-guidance 权重可能需要偶尔调整。

## 7. 推理到底怎么跑

推理阶段就是 Self-guidance 的实际采样循环。以“移动物体”为例，完整顺序如下：

1. **初始化**：设置文本 prompt y、随机噪声 `z_T ~ N(0,I)`、从参考生成中提取的原始属性 `shape_{orig}`、`appearance_{orig}` 等；
2. **可选**：如果要求与原始图像高度一致，可共享同一噪声序列；否则随机种子也可以，论文中的结果大多使用不同种子；
3. 对 t = T, T-1, ..., 1 循环：
   - 将当前含噪图 `z_t` 和文本 y 输入 U-Net，得到所有交叉注意力图 `A_{i,t}` 和指定激活 `Ψ_{i,t}`；
   - 根据任务需求选择属性项，构建能量 g（例如移动时使用 Eq.9，混合布局/外观时用 Eq.11，外观转移用 Eq.13）；
   - 对 g 计算关于 `z_t` 的梯度 `∇_{z_t} g`；
   - 计算 CFG 基础预测：`(1+s) ε_θ(z_t;t,y) - s ε_θ(z_t;t,∅)`；
   - 更新噪声预测：`ε̂_t = CFG + v σ_t ∇_{z_t} g`；
   - 通过 DDPM 或 DDIM 更新规则从 `z_t` 得到 `z_{t-1}`；
4. **引导调度判断**：根据当前 t 在全局步数的位置决定是否跳过 self-guidance。论文采用前 3N/16 步引导、最后 N/32 步不引导、中间交替引导。因此每一步需要检查是否计算额外梯度；
5. 循环结束后得到 `z_0`，解码为最终图像。

关键实现细节：外观项只对激活做反向传播，对形状部分使用 stop-gradient；形状项对注意力图进行软阈值；所有形状损失在层间和空间求平均，外观损失在激活维度求平均。引导强度由 v 和各项权重共同决定。不同任务只需替换能量 g 的组成，其余采样逻辑相同。权重选择遵循启发式：布局项权重通常为 0.5~5，外观项为 0.01~0.3，低 1~2 个数量级；总权重不超过约 5 以避免伪影。如果同时约束多个词，可以对 token 做 mean-pooling，但作者发现这并不总是改善结果。

## 8. 实验和消融到底证明了什么

论文没有报告数值指标（例如 FID、CLIP score、用户研究等），主要依靠定性示例展示能力。作者采用非 cherry-picked 协议：手动选择有趣 prompt，验证无引导生成结果与 prompt 对齐，从典型权重开始尝试 3~5 个配置，然后用前 8 张生成图像，不做进一步过滤。核心证据及支持内容如下表：

| 证据编号 | 实验/设置 | 关键观察 | 支持结论 | 证据锚点 |
|---|---|---|---|---|
| 1 | 对生成图像中的单个对象施加平移/缩放（如东京塔场景中的“massive sun”、猫场景中的“oil painting of cheese”、浣熊场景中的“raccoon in a barrel”） | 目标对象的位置/大小改变，场景其余部分基本保持 | 形状、质心、大小等内部属性可以独立操纵单个对象 | 图3；附录图11、图12 |
| 2 | 给定目标布局（真实图像或生成图像）只约束形状，采样新外观（Eq.10） | 生成图像保持原布局，但对象和场景外观可发生变化 | 通过 Eq.10 可以将布局与外观解耦；较高权重能更精确保留布局，但会牺牲外观多样性 | 图4；附录图13 |
| 3 | 从一个真实图像提取对象外观，引导生成新场景（如 Chow Chow 穿超人服、茶壶浮在海面，Eq.13） | 引导生成结果比同 prompt 随机采样更接近源对象外观；无引导时外观变化很大 | Eq.13 能从单张真实图像零样本转移外观，无需微调 | 图7；附录图16 |
| 4 | 多图像拼贴：从若干图中各取一个对象（毯子、树、汽车），组合到新场景（Eq.12） | 生成图像保留各对象的外观、形状、位置/大小，或只保留外观并套用新布局 | 属性项可组合，支持复杂构图；可以只借用外观，丢弃原始位置/形状，适配新布局（Eq.19） | 图6；Eq.12、Eq.19 |
| 5 | 移动/重定位非名词 token（动词“laughing”、形容词“messy”、颜色绑定“red/yellow”） | 可改变非对象属性的位置，甚至修正属性绑定错误 | 自引导不仅适用于名词，也可用于其他词性，但需要注意抽象词的注意力模式与场景布局相关 | 图9 |
| 6 | 混合布局与外观：从图 A 复制形状、从图 B 复制外观（Eq.11） | 生成图像采用 A 的布局、B 的对象外观，对角线为输入图，对角线外为组合结果 | 跨图像布局和外观可分别独立迁移 | 图5 |

**最关键消融**：附录图16 展示了外观转移的对比。对 Fig.7 中提到的 prompt（“a photo of a chow chow wearing a superman outfit”和“a dslr photo of a teapot floating in the sea”）在没有 self-guidance 的情况下随机采样，结果中对象外观变化很大，与源图明显不同；加入 Eq.13 的外观引导后才能保持目标对象外观。这验证了外观引导的有效性，而不是仅仅依赖文本 prompt 就能复现对象外观。作者指出，该对比可以排除“文本本身足以描述外观”的替代解释。

**论文尚未证明的主张**：
- 没有定量指标或用户研究，无法评估方法的整体质量、一致性或成功率；
- 没有在大规模多样本上报告统计成功率或失败率；所有结果基于少量手工 prompt；
- 没有严格比较与 ControlNet、P2P 的定量差异，只是定性展示 Fig.4 中的几组例子；
- 声称“解耦”控制，但论文自己报告了外观-布局泄漏和对象纠缠，说明解耦有限；
- 没有测试对文本中未提及对象的控制，也没有处理遮挡、复杂交互、多实例等困难场景；
- 真实图像编辑的近似反转没有定量保真度评估。

因此，实验支持“该方法能在若干定性示例上实现上述操作”，但尚不足以证明其普遍可靠性或优于现有方法的定量优势。

## 9. 与前作怎么选

**与 Prompt-to-Prompt（P2P）对比**：P2P 通过交换或编辑交叉注意力图实现文本编辑，例如替换一个词、改变形容词，保持图像结构。它适合“改变词语但保留布局”的编辑，但很难精确移动或缩放对象，因为它不定义几何属性损失。Self-guidance 通过质心/大小/形状能量可以显式做几何变换。如果只做文本替换且希望保持原构图，P2P 更简单；如果要做空间变换或跨图像外观/布局混合，选 Self-guidance。

**与 ControlNet 对比**：ControlNet 需要额外训练一个可接受空间条件（边缘图、深度图、姿态等）的副本网络，需要配对数据或自行构造条件。它的优势是能接受精确的外部空间输入，稳定性较高；Self-guidance 无需训练，但依赖注意力质量，无法输入精确边缘图。如果手头有精确空间条件且需要高保真布局控制，选 ControlNet；如果只能从模型自身特征出发做零样本控制，或不想训练，选 Self-guidance。

**与 DreamBooth 对比**：DreamBooth 用几张特定对象的图片微调模型，将该对象绑定到特殊 token，生成时保持对象外观。这需要微调和多张图像，但个性化外观更稳定；Self-guidance 只需要单张图、无需微调，但外观转移可能不如 DreamBooth 稳定，且对象外观绑定与画布内其他内容更依赖特征质量。如果重视长期身份保持且可接受训练成本，选 DreamBooth；如果追求零样本、快速试错，选 Self-guidance。

**与 Universal Guidance 对比**：Universal Guidance 使用外部预训练分类器、CLIP 等模型定义能量函数，也能零样本控制，但需要额外模型且可能需处理噪声相关性问题。Self-guidance 完全使用扩散模型内部特征，不需要外部模型，代价是只能控制模型内部可表征的属性。如果需要超出了模型内部表示的约束（如特定分类器偏好、人脸识别等），Universal Guidance 更合适；否则 Self-guidance 更自足。

## 10. 工程判断：可行性、风险与上限

**数据**：Self-guidance 不需要训练数据或标注，因此工程实现上数据门槛低。但编辑真实图像时需要提供与图像匹配的文本 caption，否则注意力和激活会偏离对象对应关系，影响引导质量。论文指出当描述不够具体或对象外观较为 out-of-distribution 时，外观转移可靠性下降。例如 Fig.7 使用“A photo of a Chow Chow...”和“A DSLR photo of a teapot...”作为 prompt；如果换用更笼统的描述，作者提到可靠性较差。

**算力/延迟**：方法需要额外的梯度计算和注意力/激活缓存。每步采样都要保留中间特征并进行反向传播，内存和计算开销显著高于普通 CFG 采样。论文使用 N=1024 步，且前 3N/16 步引导、中间交替引导，意味着约一半以上步骤需要额外反向传播。总推理延迟可能比标准文本生成高数倍，具体取决于特征层数和梯度计算规模，论文未披露精确延迟数字。此外，对真实图像编辑需要 T 次前向加噪和特征提取，也会增加预处理时间。

**实现难点**：
- 注意力软阈值参数 s=10 的选择可能影响形状质量，过软会导致背景噪声，过硬会损失梯度；
- 外观项需要在形状上做 stop-gradient，否则优化会走向退化解；
- 全局 v=7500 较大，梯度幅度小，需要谨慎调参；权重项之间量级差异大（布局项 vs 外观项差 1~2 个数量级），易引发不稳定；
- 引导步调度（前 3N/16 引导、最后 N/32 不引导、中间交替）对稳定性和编辑效果影响大，不能随意更改；
- 对于多 token 概念，mean-pooling 或不 mean-pooling 没有一致优劣，需要实验验证。

**失败环节**：
- **外观特征泄漏布局**：高外观引导权重会使对象位置向源对象位置漂移（图10a-b），因为激活特征可能编码了空间信息；作者测试过编码器早期特征来减少这种泄漏，但效果显著更差；
- **布局引导泄漏外观**：对全部 token 施加高强度形状约束可能意外传递外观信息（图10c-d），作者推测是因为注意力通道之间的交互可能编码了高频外观模式；
- **交互对象纠缠**：多个对象在注意力空间相关时，移动一个对象会带动另一个（图10e-f）；例如“potato”和“couch”场景中移动 potato 导致 couch 也变化；
- **未在文本中出现的对象无法控制**：方法依赖 token 索引，无法处理未描述的对象；
- **真实图像反演不完美**：用前向加噪提取的特征近似反向采样，分布不匹配可能导致编辑后细节丢失或异常；
- **权重过高导致伪影**：总权重超过约 5 会导致图像质量下降，出现伪影。

**监控信号**：工程中可以监控各属性损失项的数值变化、梯度范数、最终图像中对象注意力质心/大小的实际偏移、以及用户指定形状与生成形状的 L1 距离或 IoU。论文未使用定量指标，但可自行构造。

**指标上限**：由于依赖注意力图作为对象分割代理，而注意力图本身有噪声和对象间重叠，精确像素级形状控制很难达到；外观与布局的纠缠限制了彻底解耦；生成质量受基座模型限制，无法超越 Imagen 本身能力。因此，Self-guidance 的上限是“提供有用但非精确的零样本控制”，不适合需要像素级保真或严格几何约束的任务。

**未回答问题**：论文没有给出定量评估、对更多对象数量的扩展性、自动权重调整策略、对注意力纠缠的系统缓解、在非 Imagen 模型上的验证、以及对人类感知质量的影响。这些都是后续工程落地需要解决的风险点。

## 11. 放回研究脉络并收束

Self-guidance 位于“利用扩散模型内部表示进行可控生成”的研究脉络中。沿线索：P2P 发现交叉注意力图编码结构信息，Plug-and-Play 发现激活特征可用于纹理转移；这两者把内部特征当作**内容源**，通过复制/粘贴到新采样中实现编辑。Self-guidance 进一步把这些特征转化为**可微能量**，用 classifier guidance 的形式在采样过程中显式拉动图像，获得更灵活的组合控制。同期还有 Layout-Guidance 等基于注意力的引导方法，但 Self-guidance 特别强调无需外部模型、对象属性可组合、真实图像可编辑。它还与通用能量引导（Universal Guidance）形成对照：用内部能量替代外部模型能量，证明扩散模型自身是丰富的控制器。论文还把自己定位为一种“打开扩散模型内部工作机制的窗口”，为后续研究提供实验证据。

**读完必须记住的 5 件事**：

1. Self-guidance 是在预训练扩散模型的采样循环中加入 `v σ_t ∇_{z_t} g` 项，其中 g 由内部交叉注意力图和激活定义，不引入额外模型或训练；全局 v=7500。
2. 四个基本属性：质心（位置）、软阈值注意力面积（大小）、软阈值注意力图（形状）、形状加权激活均值（外观），这些属性都是从模型内部特征提取的可微量。
3. 复杂编辑通过组合能量项实现：例如 Eq.9 固定其他对象形状、固定所有外观、只变换目标对象形状，便可移动/缩放单个对象；Eq.11 借别人的布局、借另一人的外观；Eq.12 从多图拼贴对象。
4. 真实图像编辑采用近似反转：对真实图像在不同噪声水平前向加噪并提取内部特征，当作反向采样特征序列来引导生成。
5. 主要限制是外观与布局互相泄漏、交互对象注意力纠缠、以及只适用于文本中明确提及的对象；论文并未提供定量指标或全面消融，因此其通用性仍需谨慎评估。

**5 道自测题**：

1. Self-guidance 与 classifier guidance 在更新方向上的共同点是什么？区别是什么？
2. shape(k) 和 appearance(k) 分别由哪些内部特征计算？appearance 项为什么要对 shape 做 stop-gradient？
3. 在“只移动一个物体”的任务中，Eq.9 的三个损失项分别起什么作用？如果去掉第二项会出现什么问题？
4. 如何用 Self-guidance 将真实图像中某对象的外观转移到新的文本 prompt？需要什么前置步骤？
5. 论文通过哪些定性实验支持“属性可组合”这一结论？它没有证明哪些更重要的事情？

**一句话总结**：Self-guidance 证明了预训练扩散模型内部注意力图和激活本身就可以作为可微控制信号，在零样本条件下实现相当灵活的物体级编辑与组合，但它是一个定性展示的原型，距离稳定、精确、可量化的工程工具还有距离。
