# 大白话深读《DMD》

## 1. 30 秒定位

这篇论文解决扩散模型生成图像时需几十到几百次前向、难以实时交互的问题。它提出分布匹配蒸馏（Distribution Matching Distillation，DMD），把预训练扩散模型蒸馏成单步生成器。核心办法不是让单步生成器逐样本复现扩散模型的噪声到图像映射，而是用两个分数函数之差构造梯度：一个表示“更像真实图像”，另一个表示“更像当前假图像”，再加一个配对回归损失防止模式崩塌。代价是训练时要额外维护并持续更新一个“假分布”扩散模型，还要预计算一批噪声-图像对；推理时只需一次前向，论文报告在 FP16 下约 20 FPS 生成 512×512 图像。

## 2. 为什么这篇论文会出现

扩散模型在图像生成上质量高、训练稳定，但采样本质是迭代去噪，通常要十几到几十次甚至上百次神经网络评估。已有加速路线大致分两类：一类是改进采样器，从上千步降到 20～50 步，但继续降低步数会让质量明显变差；另一类是蒸馏，把原扩散模型的噪声到图像映射直接压缩进单步学生网络。后者的难点是：为了计算一次学生损失，往往要跑完教师模型的完整去噪轨迹，成本很高。渐进蒸馏、一致性模型、InstaFlow 等方法通过逐步缩短采样距离或自洽 ODE 条件来减少轨迹运行，但论文指出这些单步方法仍明显落后于原多步扩散模型。

与此同时，生成对抗网络（GAN）和分布匹配类方法在单步生成上效率高，但在大规模文本到图像上稳定扩展困难。ProlificDreamer 提出的变分分数蒸馏（Variational Score Distillation，VSD）已经在 3D 粒子优化里展示了“真实分数减假分数”的分布匹配能力，但还没有被直接用于训练完整生成器蒸馏扩散模型。DMD 的切入点是：既然预训练扩散模型能近似分数函数，就让它同时估计真实分布和生成器产生的假分布分数，再用两者之差更新生成器；同时引入一个简单的 LPIPS 回归损失，避免纯分布匹配下的模式崩塌。这样得到单步生成器，并在 ImageNet 64×64、CIFAR-10 和零样本 MS COCO 上显著优于已发布的少步扩散方法。

## 3. 方法全景：先看数据流

DMD 的数据流可以分为两条训练路径和一条假分数更新路径。核心组件包括：预训练真实扩散模型 μ_base、一步生成器 G_θ、固定的真实分数估计器 μ_real、动态更新的假分数估计器 μ_fake、预计算的配对数据集 D，以及两个损失函数。

先画 ASCII 数据流：

```text
噪声 z ~ N(0,I)
        |
        v
   G_θ(z) = x  （假图像/假潜变量）
        |
        +----> 加噪: xt ~ N(αt·x, σt²·I)
        |              |
        |              v
        |        μ_real(xt,t)  ──> 预测 preal(x)方向
        |              |
        |              v
        |        μ_fake(xt,t)  ──> 预测 pfake(x)方向
        |              |
        |              v
        |        score差 = s_fake - s_real  → 加权后传给生成器梯度 ∇θDKL
        |
        +----> 配对路径: 从 D 取 (z_ref, y_ref)
                        G_θ(z_ref)=x_ref
                        LPIPS(x_ref, y_ref) → Lreg
```

下面对组件逐个拆解。

**预训练扩散模型 μ_base**：输入是加噪样本 xt 和时间步 t，输出是去噪后的数据预测（论文用均值预测形式）。它来自 EDM 或 Stable Diffusion v1.5，在训练 DMD 时作为教师和初始化来源，但本身不直接作为可训练结构，而是复制为 μ_real 固定模型和 μ_fake 初始模型。

**一步生成器 G_θ**：架构与基础扩散去噪器相同，但移除了时间条件。初始化时直接把 μ_base 在 T−1 时间步的权重复制过来，即 G_θ(z) = μ_base(z, T−1)。输入是随机高斯噪声 z，输出是假图像 x。在类条件 ImageNet/CIFAR 中 x 是像素张量；在 LAION 文本到图像实验中，x 是潜变量张量，之后会经 VAE 解码成图像。G_θ 是训练更新的主要对象。

**真实分数估计器 μ_real**：就是固定的预训练扩散模型副本，参数不更新。它接收噪声样本 xt 和时间步 t，输出对真实扩散分布的分数近似 s_real(xt,t)。目的是把当前生成样本往“更像真实数据”的方向推。

**假分数估计器 μ_fake**：结构也是扩散去噪器，初始权重来自 μ_base，但会在训练中持续更新。它接收同一个 xt 和时间步 t，输出假分布的分数近似 s_fake(xt,t)。由于生成器分布不断变化，μ_fake 要跟着训练，否则 s_fake 会滞后。它的输入会使用 stopgrad 后的生成样本 x，前向扩散得到 xt，再用标准去噪损失 Eq.(6) 更新。

**配对数据集 D**：预先用教师扩散模型和确定性 ODE 求解器生成噪声-图像对。CIFAR-10 用 100k 或 500k 对，ImageNet 用 25k 对，LAION 用 500k 或 12M 对。每条数据是（噪声 z，教师输出 y）。它只用于回归损失，不参与分布匹配路径。

**分布匹配损失路径**：从标准高斯采 z，经 G_θ 得 x；在随机时间步 t 给 x 加噪得到 xt；xt 同时输入 μ_real 和 μ_fake，得到两个去噪预测；两者之差按论文权重加权后，作为生成器梯度的一部分回传。

**回归损失路径**：从 D 取 z_ref 和 y_ref，用 G_θ(z_ref) 得到 x_ref，计算 LPIPS(x_ref, y_ref)。这个损失鼓励生成器在相同输入噪声下靠近教师输出的大尺度结构，抑制纯分布匹配可能导致的模式崩塌。

两个损失共同更新 G_θ，但 μ_fake 不接收来自回归损失或生成器梯度的更新，只由去噪损失 L_denoise 更新。

## 4. 核心公式与直觉

DMD 的生成器目标最初是假分布 p_fake 与真实分布 p_real 之间的 KL 散度：

```text
D_KL(p_fake ∥ p_real) = E_{x~p_fake} [ log p_fake(x) - log p_real(x) ]
```

直接对 x 求密度不可行，但对生成器参数 θ 求梯度后，可以得到分数函数之差：

```text
∇θ D_KL = E [ -(s_real(x) - s_fake(x)) · dG/dθ ]
```

其中 s_real = ∇x log p_real，s_fake = ∇x log p_fake。直觉上，s_real 把生成样本拉向真实分布的高密度区域，−s_fake 则把生成样本推开，防止所有样本坍缩到最近的真实模式。这个式子的问题是：对低概率样本，分数会发散，且扩散模型只提供加噪分布的分数。

因此论文把精确分数替换为扩散模型在加噪样本 xt 上的近似分数，并在时间步上取期望：

```text
∇θ D_KL ≃ E_{z,t,x,xt} [ w_t α_t ( s_fake(xt,t) - s_real(xt,t) ) · dG/dθ ]
```

其中 xt ~ N(α_t x, σ_t² I)，α_t 和 σ_t 来自扩散噪声计划。真实分数由固定教师 μ_base 通过式 (4) 转换得到；假分数由动态 μ_fake 通过式 (5) 转换得到。PDF 抽取中上标/下标有错位，这里按论文原意解释：σ_t² 是噪声方差，α_t 是信号缩放因子。

为了稳定训练，论文引入时间权重 w_t，把它设为：

```text
w_t = (σ_t² / α_t) · C·S / || μ_base(xt,t) - x ||_1
```

其中 C 是通道数，S 是空间位置数。这个权重把不同噪声水平下的梯度幅度归一化，避免高噪声时间步梯度过大或低噪声时间步梯度过小。工程上对应的是在 Algorithm 2 中用一个类似绝对误差均值来缩放 pred_fake 与 pred_real 之差。该权重在消融中比 DreamFusion/ProlificDreamer 使用的 σ_t/α_t 或 σ_t³/α_t 有更低的 FID。

## 5. 训练与推理怎么跑

**一轮训练 step**：

从标准高斯采样一批 z，从配对数据集 D 采样一批（z_ref, y_ref）。先让 G_θ 生成 x = G_θ(z) 和 x_ref = G_θ(z_ref)。在 LAION 实验中，如果数据集是 LAION，会把 x 和 x_ref 沿 batch 维拼接后一起走分布匹配损失；否则只用 x。分布匹配损失按 Eq.(7)：随机采样时间步 t，对 x 前向加噪得到 xt；在关闭梯度状态下用 μ_real 和 μ_fake 分别预测去噪结果；计算 pred_fake 与 pred_real 的差，并用论文权重缩放；这个损失只更新生成器 G_θ。回归损失则对 x_ref 与 y_ref 计算 LPIPS，乘 λ_reg（默认 0.25）后也更新 G_θ。两个损失相加后反向传播，更新 G_θ 参数。随后更新 μ_fake：从 (0,1) 均匀采样时间步 t，对 stopgrad(x) 前向加噪得到 xt，用 μ_fake 预测去噪结果，与 stopgrad(x) 计算去噪损失 Eq.(6)，只更新 μ_fake。μ_real 在这期间完全冻结。

**能够训练或冻结的模块**：G_θ 可训练；μ_fake 可训练；μ_real 固定；LPIPS 网络和 VAE/解码器在正文中未写明是否更新，但从损失计算角色看通常固定；论文只在附录提到 VAE 解码器用于 LAION 回归损失，且部分实验用小 VAE 替代标准 VAE 以省内存。

**完整推理顺序**：输入一个随机噪声 z，以及可选类别标签或文本条件；G_θ 一次前向生成潜变量或图像；在文本到图像 SD 蒸馏中，生成器输出潜变量后需经 SD 的 VAE 解码为 512×512 图像（这一点从论文回归损失需解码 latents 可推出，正文未在推理部分重复复述）。整个推理只需 1 次神经网络评估。论文报告的延迟是 0.09 秒/张（batch size 1），而作为教师的 Stable Diffusion 50 步约 2.59 秒；在 FP16 推理下可达 20 FPS。对于类条件 CIFAR/ImageNet，生成器直接输出像素图像，不需要 VAE 解码。

## 6. 实验和消融证明了什么

评估协议方面，论文用 FID 衡量图像质量，CLIP Score 衡量文本-图像对齐。COCO 使用 30k 验证集生成图像，与 40,504 张真实图像比较；ImageNet/CIFAR 各生成 50k 张计算 FID。下面列出关键证据。

| 证据 | 任务与指标 | DMD 结果 | 对照结果 | 锚点 |
|---|---|---|---|---|
| 类条件 ImageNet-64×64 单步 FID | ImageNet FID↓ | 2.62 | 教师 EDM 512 步 2.32；Consistency Model 6.20；Diff-Instruct 5.57 | Table 1 |
| 类条件 CIFAR-10 FID | CIFAR FID↓ | 2.66（条件） | 教师 EDM 35 步 1.84；Consistency Model 3.55 | Appendix Table 6 |
| 零样本文本到图像 MS COCO-30k | FID↓ | 11.49 | 教师 SDv1.5 8.78；InstaFlow-0.9B 13.10；UFOGen 12.78 | Table 3 |
| 高引导蒸馏 COCO-30k | FID / CLIP↑ | 14.93 / 0.320 | 教师 SDv1.5 13.45 / 0.322；LCM-LoRA 4 步 23.62 / 0.297 | Table 4 |
| 去掉分布匹配损失 | CIFAR / ImageNet FID↓ | 完整 2.66 / 2.62 | 去掉 DM：3.82 / 9.21 | Table 2 左 |
| 去掉回归损失 | CIFAR / ImageNet FID↓ | 完整 2.66 / 2.62 | 去掉回归：5.58 / 5.61 | Table 2 左 |
| 时间权重策略 | CIFAR FID↓ | Eq.(8) 2.66 | σ_t/α_t 3.60；σ_t³/α_t 3.71 | Table 2 右 |

最关键消融是同时移除两项损失之一：去掉分布匹配损失后 ImageNet FID 从 2.62 升到 9.21，说明分布匹配贡献很大；去掉回归损失后 ImageNet FID 升到 5.61，且 Figure 5 显示出现模式崩塌，说明回归损失对多样性有保护作用。二者缺一不可。

不过尚有一些主张未被论文完全证明。论文只用 FID 和 CLIP Score，缺少人工偏好评估或多样性指标（如 Inception Score、精确率/召回率）；高引导 LAION-Aesthetic 6+ 模型是经过 12 个版本训练日志调参得到的，Table 5 显示 FID 从 23.88 波动到 14.93，说明训练不稳定且最终 V12 参数可能不是全局最优；部分基线数据来自其他论文或使用不同条件，不能完全保证同条件对比；论文也没有展示与原始 SD 在文本语义多样性或复杂组合提示上的系统比较。

## 7. 与前作怎么选

DMD 最接近的对比方法是渐进蒸馏（Progressive Distillation）、一致性模型（Consistency Model）和 InstaFlow。它们都在追求把多步扩散压缩到极少步或单步，但训练目标和数据需求不同。

| 方案 | 训练目标要点 | 是否需要预计算配对数据 | 性能报告 | 主要限制 |
|---|---|---|---|---|
| DMD | 真实/假分数差做分布匹配 + LPIPS 回归 | 需要，但论文称可少于 1% 训练成本 | ImageNet 64 单步 FID 2.62；COCO 11.49 | 需额外训练假分数扩散模型，训练内存大 |
| Consistency Model | 让学生在不同时间步自洽于 ODE 解 | 不需要配对轨迹 | ImageNet 64 单步 FID 6.20 | 单步性能仍与教师差距较大 |
| Progressive Distillation | 逐步把教师采样步数减半，用回归蒸馏 | 需多次跑教师轨迹 | ImageNet 64 单步 FID 15.39 | 蒸馏轨迹成本较高，最终质量受限 |
| InstaFlow | 整流流逐步拉直采样路径 | 需训练流模型 | COCO 单步 FID 13.10 | 文本到图像质量仍明显低于教师 |

何时选 DMD：已经有一个高质量预训练扩散模型，能容忍训练时同时保留生成器和假分数两个扩散模型，且可以预先跑出一批噪声-图像对时，DMD 能带来较低的单步 FID，同时保持与教师模型较接近的结构。何时不选 DMD：如果训练显存紧张，或不想维护动态假分数模型，或数据集规模大到无法预计算配对结果，则一致性模型、InstaFlow 等更轻量的少步方法可能更容易部署。论文明确承认训练两个扩散网络会导致显著内存使用，并提到 LORA 可能是缓解方向，但没有给出具体训练结果。

## 8. 工程判断与收束

数据方面，CIFAR-10 蒸馏集 10 万或 50 万对，ImageNet 只用 2.5 万对，LAION-Aesthetic 6.25+ 用 50 万对，LAION-Aesthetic 6+ 用 1200 万对。这说明回归损失对配对数据量的需求不高，但大规模文本到图像仍需要较多配对样本才能压住模式问题。算力方面，CIFAR 用 7 GPUs、总 batch 392、30 万迭代；ImageNet 用 7 GPUs、总 batch 336、35 万迭代；LAION-Aesthetic 6.25+ 用 72 块 A100、总 batch 2304、2 万迭代，约 36 小时；LAION-Aesthetic 6+ 用约 80 块 A100，训练两周。推理延迟从 SD 50 步的 2.59 秒降到 0.09 秒，约 30× 加速；FP16 下 20 FPS。

实现难点在于：分布匹配梯度需要同时前向 μ_real 和 μ_fake，还要回传到生成器，显存压力大；LAION 实验需要把潜变量解码成图像才能计算 LPIPS，额外引入 VAE 成本，论文用更小的 VAE 缓解；高引导版本训练不稳定，Table 5 显示多个超参版本 FID 在 23.88 到 14.93 之间波动，最终方案依赖训练日志试探。最可能失败的环节是假分数模型跟不上生成器变化，导致分布匹配梯度失效或训练震荡；另外如果回归权重 λ_reg 太小，纯分布匹配下会出现模式崩塌，如消融所示。

指标上限上，DMD 在 ImageNet 上已接近但未超过教师：2.62 对教师 2.32；在 COCO 低引导下仍有 2.7 FID 差距；高引导下 CLIP Score 几乎追平教师（0.320 对 0.322），但 FID 仍有 1.48 差距。尚未回答的问题包括：是否可以在更少配对数据下取得接近结果、如何降低训练内存、在更多样化的复杂提示和人工偏好上是否真正接近原模型、以及该方法能否直接用于视频或音频扩散模型。

读完必须记住的 5 件事：

1. DMD 用“真实分数减假分数”的分布匹配梯度更新单步生成器，而不是逐样本复现教师扩散轨迹。
2. 真实分数来自固定预训练扩散模型，假分数来自持续训练的第二份扩散模型，两者之差是核心训练信号。
3. 额外的 LPIPS 回归损失预计算教师噪声-图像对，用来防止模式崩塌并保持大尺度结构。
4. 在 ImageNet 64×64 上 DMD 单步 FID 为 2.62，接近 512 步教师 2.32，但推理快约 500 倍。
5. 训练代价不小：需要额外训练一个假分数扩散模型，大规模文本到图像训练在数十张 A100 上耗时数天到两周。
