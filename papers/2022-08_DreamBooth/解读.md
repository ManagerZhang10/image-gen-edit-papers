# 大白话深读《DreamBooth》

## 1. 30 秒定位

DreamBooth 是一篇 2022 年 Google Research 提出的方法，目标是“主体驱动生成”（subject-driven generation）。它解决的是：给一个特定物体或宠物只拍 3～5 张日常照片，之后仅靠文本提示，就能生成同一主体在不同场景、姿态、视角、材质或艺术风格中的新图像。方法核心是把一个稀有标识符（rare token identifier）绑定到这个具体主体，并对预训练文本到图像扩散模型做整体微调，同时加入“类别先验保留损失”（class-specific prior preservation loss）防止模型忘记同类别的正常外观和输出多样性。论文在 Imagen 和 Stable Diffusion 上都做了实现；实验用 DINO、CLIP-I、CLIP-T 和用户研究对比了当时并行的 Textual Inversion，显示 DreamBooth 在主体保真度和提示保真度上明显更高。结论是这一微调路径能把具体主体“植入”扩散模型的输出域，完成此前难以做到的新场景合成。

## 2. 为什么这篇论文会出现

在 DreamBooth 之前，大型文本到图像模型如 Imagen、DALL-E 2、Parti、Stable Diffusion 已经展示出很强的文本语义生成能力，但它们缺少一种控制：无法让模型根据几张参考图稳定复现“同一个特定主体”的外观。论文明确写出，即便是非常详细的文字描述，也可能生成外观不同的同类物体；共享语言-视觉空间的模型也只能生成内容变体，不能准确重建给定主体的外观（§1，Figure 2）。例如，输入一个特定黄色闹钟，并写“复古风格黄色闹钟、白色表盘、右侧有黄色数字 3”，模型仍难以稳定保留那些细粒度身份特征。

与之相邻的技术路径各有短板。图像合成（image composition）通常只做前景贴到新背景，受限于光照、阴影、接触关系，难以生成新姿势；3D 重建可用于新视角，但往往要求多视角输入和刚体对象；文本驱动编辑依赖 CLIP 指导或掩码，强在修改已有图像，而不是生成同一个主体的新样本；GAN 个性化先验如 MyStyle 需要约 100 张人脸图且限于人脸域。论文还提到当时并行的 Textual Inversion，它在冻结的扩散模型中学习小文本嵌入，但受限于冻结模型本身的表达能力，主体保真度有限。

因此，DreamBooth 的出现理由是：需要一种能利用扩散模型强语义先验，同时把具体主体绑定到模型输出域中的方法。它把问题形式化为“扩展语言-视觉词典”，通过微调预训练模型来写入新的“词-主体”绑定。论文同时指出，直接微调会出现语言漂移和输出多样性下降，所以需要专门的先验保留损失来对抗过拟合。

## 3. 读懂前需要的最小概念

扩散模型（diffusion model）是 DreamBooth 的基础。这类模型通过逐步去噪一个初始高斯噪声来生成图像。训练时输入真实图像，先按噪声调度加入噪声得到中间表示，再让网络预测原始图像或噪声；损失是重构误差的加权平方项。文本到图像扩散模型把文本条件 c 送入去噪网络，使生成过程受文本控制。Imagen 用 T5-XXL 文本编码器得到条件嵌入；Stable Diffusion 则在低维潜空间（latent space）执行扩散并用解码器还原图像。

微调（fine-tuning）是在预训练权重上继续训练。DreamBooth 微调所有层，包括受文本嵌入条件影响的层，以便把新主体写进输出分布。问题在于语言漂移（language drift）：模型在特定任务上微调后，可能逐渐忘记原语言-语义关系。论文观察到扩散模型中的类似现象：模型会忘记如何生成目标主体同类别的其他正常个体。另一个风险是输出多样性下降，少样本训练可能让模型只重复少数姿势或训练背景。

稀有标识符（rare token identifier）是 DreamBooth 用来避免与常见词先验冲突的手段。若用“unique”“special”等常见英文词，模型需要先解除原义再重新绑定，效果差；随机字母串看起来稀有，但 tokenizer 会拆成单字母，而单字母在语言模型中有强先验，也不好。DreamBooth 在词表中寻找低频 token，并把 token 反解成文本字符，得到形似乱码的 [V]。

评估指标方面，DINO 是自监督 ViT 特征，被论文作为主体保真度首选指标；CLIP-I 是生成图与真实图 CLIP 嵌入的平均成对余弦相似度；CLIP-T 是提示与图像 CLIP 嵌入的余弦相似度，衡量提示保真度。LPIPS 是感知距离，论文用它衡量同一提示、同一主体生成图之间的多样性。

## 4. 方法全景：先看数据流

DreamBooth 不是一个独立的推理模型，而是一套在已有预训练扩散模型上的微调协议。下面先看整体数据流，再拆关键组件。

```
主体输入: 3-5 张同一主体的照片 x
                │
                ▼
文本绑定: 所有照片统一标注为 "a [V] <class noun>"
                │
    tokenizer f / 文本编码 Γ
                │
                ▼
条件向量 c = Γ(f("a [V] dog"))
                │
                ▼
微调轮次:
    真实主体图 x 加噪 z_t = α_t x + σ_t ε
       → 扩散模型预测 x̂_θ(z_t, c)
       → 对 x 计算 MSE 误差 (第1项)
                │
  同时，预先生成类别先验图 x_pr = 冻结模型采样("a dog")
                │
    x_pr 加噪 z_t' = α_t' x_pr + σ_t' ε'
       → 同一微调模型预测 x̂_θ(z_t', c_pr)
       → 对 x_pr 计算 MSE 误差，乘 λ 再加总 (第2项)
                │
                ▼
推理时:
   用户提示 "a [V] dog in the jungle"
   → tokenizer 把 [V] 映射到曾选定的稀有 token
   → 文本编码为条件 c
   → 从 N(0,I) 采样噪声，用 DDIM 或 ancestral sampler 逐步去噪
   → 级联超分/潜空间解码
   → 生成同一主体在新场景中的图像
```

核心组件拆解如下。

第一，唯一标识符设计。DreamBooth 不写详细图像描述，而是把所有输入主体图像都统一标记为“a [identifier] [class noun]”。它的目标是利用类别词所对应的先验，把新主体与这个类别绑定。论文强调，用正确类别名词能显著提高主体保真度；错类名会产生“圆柱形背包”之类的污染；不用类名则难以收敛（Table 4）。标识符本身来自稀有 token 查找：在 T5-XXL tokenizer 的 5000～10000 区间随机采样 token，要求每个 token 对应不超过 3 个 Unicode 字符且无空格。这样得到序列长度 k 通常为 1～3，之后反解为文本作为 [V]。其目的和假设是：低频 token 在语言模型和扩散模型中都只有弱先验，因此微调时不需要先抹除强语义，更容易绑定新主体。

第二，全量微调而不是只训练少量 token。论文指出，在精心设置的扩散损失下，大型文本到图像模型能整合新信息而不忘记旧先验、不过度坍缩。微调所有层能最大化主体保真度，尤其是文本条件层；但这样会放大语言漂移和多样性下降风险。

第三，类别先验保留损失（PPL）。这是方法的关键。在微调前，先用冻结的原始扩散模型，以“a [class noun]”为条件，通过祖先采样生成一批类别先验图像 x_pr。然后在每个训练步骤中，同时学习两张图：一张是真实主体图，目标是把它绑定到 [V]；另一张是模型自己生成的类别先验图，目标是继续生成正确的类别分布。第二项损失带权重 λ，防止模型把“dog”这个词本身重新绑定到某一只具体狗上。

第四，级联超分和潜空间实现的适配。对 Imagen，论文发现除了 base 64×64 模型，还需要微调 64×64→256×256 的超分模型，有时也微调 256×256→1024×1024 模型。如果不微调，超分阶段会幻觉出错误的高频纹理；如果沿用原始噪声增强水平 10⁻³，则细节会模糊。补充材料把超分微调时噪声增强降到 10⁻⁵。对 Stable Diffusion，则直接在潜空间 fine-tune U-Net，固定解码器。

## 5. 核心公式与直觉

公式主要来自论文 §3.1 和 §3.3。这里只需要两个公式，再加一个关于稀有 token 的描述。

首先，预训练文本到图像扩散模型的基础损失（式 1）：

\[
\mathbb{E}_{x,c,\epsilon,t}\left[
w_t \|\hat{x}_\theta(\alpha_t x+\sigma_t \epsilon,c)-x\|_2^2
\right]
\]

其中 x 是真实图像，c 是文本条件向量，ε 是标准高斯噪声，t 是扩散时间，通常从 [0,1] 均匀采样。α_t、σ_t、w_t 是噪声调度和样本质量的权重，由扩散过程决定。模型 \hat{x}_θ 在带噪输入上预测原始图像 x。这是 DreamBooth 微调的起点。

DreamBooth 的核心是对这个损失做扩展，得到式 2：

\[
\mathbb{E}_{x,c,\epsilon,\epsilon',t}\left[
w_t \|\hat{x}_\theta(\alpha_t x+\sigma_t \epsilon,c)-x\|_2^2
+\lambda w_{t'} \|\hat{x}_\theta(\alpha_{t'} x_{pr}+\sigma_{t'} \epsilon',c_{pr})-x_{pr}\|_2^2
\right]
\]

第一项和基础扩散损失相同，只是 x 现在是用户拍摄的主体照片。真实图每条都标记成“a [V] class”，所以 c = Γ(f(“a [V] class noun”))。第二项是 DreamBooth 新增的先验保留项。x_{pr} 是冻结模型从“a class noun”采样生成的类别先验图；c_{pr} 是“a class noun”的条件向量；λ 控制这一正则项的强度。该公式的工程动作是：每个训练 step 需要两套加噪图和条件对，对同一个可训练模型分别做前向与反向，再合并损失。

直觉上，第一项把具体主体压缩进 [V] 与类别词的联合表示中；第二项则维护“dog”等类别词原来的分布。没有第二项，模型会逐步把“dog”绑定到训练集中这条特定狗，导致语言漂移；同时输出多样性下降，例如只能生成与输入照片相似的姿势和背景。PPL 相当于用模型自己的生成样本作为锚点，保留类别分布。λ=1 时两项等效加权，训练约 1000 步；论文发现这样可以更久训练而不易过拟合。PPL 的代价是略微降低主体专用保真度，但换回更好的多样性和类别先验。

稀有 token 的公式化描述是：先找一个 tokenizer 映射 f，使 f(\hat V) 是词表中的低频 token 序列，且反解文本 \hat V 作为用户提示中的 [V]。这个步骤没有给出严格数学式，更多是一个查找过程。其目标是最小化标识符本身被预训练赋予强语义的可能性。

## 6. 训练到底怎么跑

训练不是重新训练整个模型，而是在预训练权重上做少样本微调。以一轮训练 step 为例，可以分成真实主体分支和先验保留分支。

先准备数据。用户提供 3～5 张某主体的照片，所有照片统一配文“a [V] <class noun>”。[V] 在训练前就已选定，使用 rare token 查找。类别名词可以由用户指定或分类器给出。用 tokenizer 和文本编码器把这句提示转成条件向量 c。

为了运行 PPL，还需要一批类别先验图 x_pr。这些图来自冻结的原始模型，以“a <class noun>”为条件采样得到。论文通常生成约 1000 张，但也说可以更少。每个训练 step 从主体图集中采样一张真实图，并从先验池中采样一张生成图。

对于真实图分支，采样噪声 ε 和时间 t，构造加噪输入 z_t = α_t x + σ_t ε；模型以 c 为条件，输出对原图 x 的预测；对 x 计算加权 MSE。对于先验图分支，采样另一个噪声 ε' 和时间 t'，构造 z_t' = α_t' x_pr + σ_t' ε'；模型以 c_pr 为条件，输出对 x_pr 的预测；对 x_pr 计算加权 MSE。两个损失按 λ 加权合并后反向传播。

所有模型层都可训练，包括受文本嵌入条件影响的层。论文给出的超参是：约 1000 次迭代，λ=1；Imagen 学习率 10⁻⁵，Stable Diffusion 学习率 5×10⁻⁶。在 Imagen 上一张 TPUv4 上约 5 分钟，在 Stable Diffusion 上用一张 NVIDIA A100 约 5 分钟。这些数字来自论文正文 §3.3。

对 Imagen 实现，还有级联超分模型需要处理。论文发现若不微调超分会出现高频纹理幻觉；若沿用训练超分网络的噪声增强 10⁻³ 会变糊。所以在微调相应 SR 模型时把噪声增强降到 10⁻⁵。这个调整只针对超分阶段，不改变 base 模型扩散损失形式。Stable Diffusion 在潜空间微调 U-Net，解码器冻结。

训练配置里一个值得注意的选择是没有只训练文本嵌入或只训练交叉注意力，这不同于 Textual Inversion。这也意味着每个新主体都要保存一份完整模型权重或模型 delta，而不是一个小 token 嵌入。

## 7. 推理到底怎么跑

推理时的任务是：给定用户提示，比如“a [V] dog in the jungle”，生成同一主体在新场景中的图像。完整顺序如下。

第一步，把提示中的 [V] 文本通过 tokenizer 映射回训练时选定的稀有 token。这个映射预先确定，不需要在推理时重新搜索。然后文本编码器 Γ 输出条件向量 c。

第二步，采样初始噪声 z_{t1} \sim N(0,I)。从高噪声时间 t1 开始，逐步去噪到时间 tT=0。论文补充材料说明采样可以用确定性 DDIM 或随机 ancestral sampler。中间点 z_{t1},...,z_{tT} 按降噪调度产生；每一步模型 \hat{x}_θ 输出对干净图像 x 的预测，再根据采样器规则更新下一步隐变量。

第三步，如果是 Stable Diffusion，扩散过程发生在潜空间。采样结束后，用冻结的解码器把潜码解码为图像。如果是 Imagen，base 模型先生成 64×64 图像，然后依次送入微调后的 64×64→256×256 和 256×256→1024×1024 超分模型。论文指出，经过低噪声增强微调的超分模型可以保持主体细粒度细节，同时减少高频纹理幻觉。

生成时并不需要再次提供参考图。参考图的信息已经通过微调写入模型权重。因此，只要 [V] 不变，同样的提示可以生成多个不同样本。论文展示了重新语境化、新视角合成、艺术风格化、属性修改、配饰添加等应用。例如“a painting of a [V] dog in the style of Michelangelo”会保留该狗脸部不对称白色条纹等身份特征，同时产生训练集中未见过的姿势和构图。

需要特别区分：推理阶段既可以使用训练过的 [V] 来生成该主体，也可以继续用“a dog”等普通类别词生成普通类别图像；PPL 的目的就是为了保留后一种能力。如果训练时没有 PPL，输入“a dog”也可能总是输出那只被绑定过的特定狗，这就是语言漂移的直接表现。

## 8. 实验和消融到底证明了什么

论文构建了一个 30 个主体的数据集，包含 21 个物体和 9 个活体/宠物；为物体设计 20 个重新语境化提示和 5 个属性修改提示，为活体设计 10 个重新语境化、10 个配饰和 5 个属性修改提示。评估时每个主体、每个提示生成 4 张，共 3000 张图。指标上，DINO 和 CLIP-I 衡量主体保真度，CLIP-T 衡量提示保真度。

关键对比之一是与 Textual Inversion 的量化结果（Table 1）：

| 方法 | DINO↑ | CLIP-I↑ | CLIP-T↑ |
|---|---:|---:|---:|
| 真实图像 | 0.774 | 0.885 | N/A |
| DreamBooth (Imagen) | 0.696 | 0.812 | 0.306 |
| DreamBooth (Stable Diffusion) | 0.668 | 0.803 | 0.305 |
| Textual Inversion (Stable Diffusion) | 0.569 | 0.780 | 0.255 |

这里 DreamBooth 比 Textual Inversion 在 DINO 上高出约 0.1，在 CLIP-I 上高约 0.02～0.03，在 CLIP-T 上高约 0.05。Imagen 版比 Stable Diffusion 版更接近真实图像上界。论文认为差距来自 Imagen 更大的表达力和更高输出质量。

用户研究（Table 2）比指标更有说服力。对 72 个用户、1800 个回答做多数投票，DreamBooth 在主体保真度上获得 68% 偏好，Textual Inversion 为 22%，另有 10% 无法判断；提示保真度上 DreamBooth 为 81%，Textual Inversion 为 12%，7% 无法判断。这表明数值指标中的差距能转化为明显的人眼偏好。

PPL 消融（Table 3）是关键内部证据：

| 设置 | PRES↓ | DIV↑ | DINO↑ | CLIP-I↑ | CLIP-T↑ |
|---|---:|---:|---:|---:|---:|
| DreamBooth (Imagen) 有 PPL | 0.493 | 0.391 | 0.684 | 0.815 | 0.308 |
| DreamBooth (Imagen) 无 PPL | 0.664 | 0.371 | 0.712 | 0.828 | 0.306 |

PRES 是“先验保留指标”，越高说明类别先验越坍缩到特定主体；DIV 用 LPIPS 度量同一主体同一提示下的生成多样性，越高越好。无 PPL 时 DINO 和 CLIP-I 略高，但 PRES 明显更差、DIV 更低。也就是说，单纯提高主体保真度可能是以类别多样性和抗语言漂移为代价。PPL 的取舍是牺牲一点主体专用相似度，换取更好的类别泛化和姿势多样性。定性图 Figure 6 也显示，无 PPL 时模型容易复现输入图像的姿势和环境，有 PPL 后姿势和场景更丰富。

类别名词消融（Table 4）显示：正确类名 DINO 0.744、CLIP-I 0.853；无类名 DINO 0.303、CLIP-I 0.607；错误类名 DINO 0.454、CLIP-I 0.728。这表明类先验在绑定新主体时起重要作用；不用或错用会显著降低主体保真度，且可能导致形状或细节错误。

训练图片数量实验（补充材料 Table 5）对 Corgi 狗和背包两个主体分别用 1～5 张训练。狗在 4 张时 DINO 最高为 0.876，背包在 4 张时 DINO 最高为 0.604；超过 4 张不再明显提升。论文据此把 3～5 张定为主体的常规设置。这里应该注意：补充材料 Table 6 中 Backpack 行的 CLIP-T 数据与 Table 5 Dog 行完全一致，疑似 PDF 抽取或排版噪声，因此不应采信该行；但 Table 6 Dog 行显示 4 张时 CLIP-T 最高为 0.740，与“4 张较好”的趋势一致。

尚未证明的主张主要包括：论文没有给出对更复杂多主体绑定、视频或长时间一致性的结果；没有在多个不同版本扩散模型上系统验证 PPL 的权重 λ 敏感性；用户研究只比较 Stable Diffusion 版 DreamBooth 与 Textual Inversion，未直接让人比较 Imagen 版；关于“本文是首个解决该任务的技术”只是相对其所知范围的说法，并且它同时承认 Textual Inversion 是并行工作。失败模式（Figure 9）表明：罕见提示下环境生成可能错误；上下文与主体外观可能纠缠，例如背包颜色被环境改变；提示接近原始训练环境时更容易过拟合。

## 9. 与前作怎么选

最直接的前作或并行方案是 Textual Inversion。它冻结整个扩散模型，只在嵌入空间中学习一个小 token 向量。DreamBooth 与之最大的不同是全量微调。选择 DreamBooth 的时机是：用户允许访问完整模型权重，可以接受每主体几分钟的训练，追求更高的主体保真度和提示保真度，并且不在意每次个性化都保存完整权重。论文实验表明，DreamBooth 在 DINO、CLIP-I、CLIP-T 和用户偏好上均显著优于 Textual Inversion。尤其是需要生成复杂新姿势、新视角或细粒度身份特征（例如猫额头花纹、狗脸部不对称条纹）时，冻结模型的小嵌入可能表达力不足。

选择 Textual Inversion 的时机是：计算资源有限、不希望分发完整模型、只想要一个可分享的 token 嵌入，或者任务更偏向风格/简单对象而非高保真主体。Textual Inversion 没有 DreamBooth 的 PPL 和全层微调成本，但代价是保真度上限较低。论文并没有隐藏这一点，而是把 Textual Inversion 视为唯一可比的并行工作。

另一个基线是详细提示工程（prompt engineering），即不微调，只写长文本让 DALL-E 2 或 Imagen 复现主体。论文在 Figure 2 和补充材料 Figure 23 中显示，即使反复试错，模型仍难以精确保留闹钟表盘数字、字体和形态。这个方法适合通用、示例性、不需要身份严格一致的任务，不适合把同一只宠物或同一个包反复稳定生成。

图像引导生成和编辑/反演方法，例如 ILVR、Blended Diffusion、Prompt-to-Prompt 等，本质是修改已有图像，而不是生成同一个主体的大量新样本。它们可以在保留某张参考图结构时改背景，但难以连续生成新姿势、新视角或交叉物种等强语义变化。选择这些方法通常是因为用户手上只有一张或几张图，且想要对原图本身做局部编辑，而不是生成一个可反复调用的“个人化模型”。

GAN 少样本个性化方法如 MyStyle 需要约 100 张人脸并限于特定域；Instance-Conditioned GAN 可能无法保留所有主体细节。相比这些，DreamBooth 的优势在通用对象和宠物，但对计算资源要求更高，并依赖预训练扩散模型本身质量。

## 10. 工程判断：可行性、风险与上限

从数据看，DreamBooth 的输入门槛很低，3～5 张即可。但这不是均匀适用于所有主体。补充材料实验显示，Corgi 狗这种接近分布中心的常见主体，一或两张图也能捕获身份；罕见的背包则需要更多图，4 张时指标最高。主体稀缺性、拍摄背景复杂性和纹理细粒度都会影响成功率。潜在失败还包括：输入图背景与训练提示过于接近时，模型可能只是复制原环境；如果提示中出现罕见或低概率共现的语境，生成环境可能错误；上下文可能反向污染主体外观，如背景色改变背包颜色。

从算力和延迟看，训练约 5 分钟在 TPUv4 或 A100 上，并不算高，但这依赖已有预训练权重和可微调权限。Imagen 需要微调 base 加超分模型，Stable Diffusion 只需潜空间 U-Net。全层微调意味着显存占用较大，保存每个主体的结果也不像小嵌入那么轻量。推理成本论文没有给出明确数字，但大致等于基础模型的采样成本、加上级联超分成本。对于需要快速切换大量主体的服务，这种每主体训练一次的成本可能成为瓶颈。

实现难点集中在几个地方。一是稀有 token 查找依赖 T5-XXL tokenizer 词表区间，对其他编码器需要用类似方法重新选择。二是 PPL 需要先用冻结模型采样类别先验图，这增加了训练前准备。三是 Imagen 的超分噪声增强默认值不适用，必须调低到 10⁻⁵ 才能避免糊化。四是如果类名选错，或者没有类名，性能大幅下降，因此需要可靠地给出类别标签。五是过拟合边界微妙：训练过久容易损失多样性和类别先验；PPL 虽然可缓解，但不是完全消除。

监控信号方面，论文实际上给出了一个完整评估套件。DINO 和 CLIP-I 用于主体保真，CLIP-T 用于提示保真；PRES 用于检测类别先验坍缩；DIV/LPIPS 用于检测输出多样性。工程复现时可以周期性用这些指标观察训练过程，尤其注意 PRES 上升意味着语言漂移，DIV 下降意味着姿势/背景多样性恶化。训练损失本身只是 MSE，不足以捕捉对主体的感知保持程度。

指标上限上，DreamBooth Imagen 的 DINO 是 0.696，接近真实图像 0.774，但仍低于真实分布上的成对相似度；CLIP-I 是 0.812，真实图像是 0.885；CLIP-T 是 0.306。即使最好的版本也没有完全达到真实图像水平和任意提示完美匹配。用户研究也显示约 10% 无法判断、其他方案也占有一定比例。这是主体驱动的固有限制：微调只能近似，不能保证在所有语义修改中都保留身份。

论文未回答或未充分回答的问题有：如何扩展到多个主体同时绑定；如何在视频主体一致性中使用；不同扩散模型结构对 PPL 超参的敏感度；身份伪造、隐私和恶意使用如何系统性缓解；以及更大规模用户和更多样主体上的统计稳健性。此外，公开数据集 30 个主体虽然便于对比，但还不足以覆盖长尾主体类型。

## 11. 放回研究脉络并收束

如果把 DreamBooth 放回研究脉络，它处于“通用文本到图像扩散模型成熟之后，向个性化生成扩展”的节点。它没有发明新的扩散模型，而是提出一种少样本微调协议：用稀有 token 绑定主体，用类别先验保留损失对抗语言漂移。与它并行的 Textual Inversion 选择了冻结模型学习嵌入，而 DreamBooth 选择全量微调，这形成了个人化扩散模型的两种路线。论文本身把这一点说得很清楚：冻结模型可以生成变体，但受限于输出域表达能力；微调模型能把主体植入输出域，获得更高保真度。其工作也提供了一个评估主体驱动生成的数据集和协议，使后续工作可以比较 DINO、CLIP 和用户偏好。

但要严格限制在论文内部：论文没有讨论后续研究中常见的 LoRA、多概念组合或更高效微调策略。这些都不属于本文证据范围。

读完必须记住的 5 件事：

1. DreamBooth 的输入是 3～5 张同一主体照片，统一配文“a [V] class noun”；[V] 来自 T5-XXL 词表低频 token，避免强先验。
2. 核心机制是微调整个预训练文本到图像扩散模型，而不是只训练文本嵌入，因此能把主体绑定进模型输出域。
3. 先验保留损失 PPL 使用冻结模型生成“a class noun”类别图，再作为正则项参与微调，防止语言漂移和多样性下降。
4. 与 Textual Inversion 相比，DreamBooth 在 DINO 上高约 0.1，用户偏好上主体保真高 68% 对 22%，但需要全量微调和保存完整个性化权重。
5. 工程复现中需要注意类别名词必须正确、PPL 权重 λ=1、约 1000 步、Imagen SR 噪声增强降到 10⁻⁵，并监控 PRES 和 DIV 而不是只看 MSE。

5 道自测题：

1. DreamBooth 为什么不用“special”这种英文词作为主体标识符，而要在词表中找稀有 token？它如何反解出用户提示中的 [V]？
2. 写出 DreamBooth 微调损失的两项，并解释第二项中 x_pr 和 c_pr 分别从哪来、为什么需要它们。
3. 如果训练时去掉 PPL，DINO 和 CLIP-I 会不会一定变差？论文 Table 3 展示了怎样的 PRES 和 DIV 变化？这说明了什么取舍？
4. Imagen 版 DreamBooth 需要处理超分模型，为什么不能直接用原始超分噪声增强？补充材料中如何调整？
5. 用 DINO 和 CLIP-T 分别衡量什么能力？在论文 Table 1 中，真实图像 DINO 上界是多少，DreamBooth Imagen 达到了多少，差距意味着什么？

最终总结一句话：DreamBooth 用低频 token 绑定、全量微调和类别先验保留损失，把 3～5 张照片中的具体主体植入文本到图像扩散模型，从而在多个新场景中保持主体身份，代价是每主体训练和完整权重存储。
