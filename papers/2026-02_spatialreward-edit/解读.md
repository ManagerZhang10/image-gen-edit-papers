# 大白话深读《spatialreward-edit》

## 1. 30 秒定位

这篇论文解决的是图像编辑领域中“奖励模型不可靠”的问题，具体落脚在在线强化学习（Online RL）训练编辑模型时，反馈信号需要同时具备细粒度、跨图比较和绝对打分能力。作者发现现有评估器——尤其是基于多模态大语言模型（MLLM）的点式生成式奖励模型——存在一个系统性缺陷：模型注意力会坍塌到单一的“盲判断”状态，忽略原图与编辑图的跨图对应关系，导致对细微编辑不一致（比如风格漂移、未按指令保留的非目标区域变化）视而不见。论文称这种现象为 Attention Collapse（注意力坍塌）。为解决此问题，作者提出 SpatialReward，核心是一个“Think-with-Boxes”机制：先预测编辑区域边界框，再将框 token 作为空间锚点注入推理文本，强制模型进行像素级跨图验证。方法在 260k 空间感知数据上训练，并在三个基准上（MMRB2、EditReward-Bench、新提出的 MER-Bench）达到或超过现有最优；更重要的是，作为 Online RL 的奖励信号，它使 OmniGen2 在 GEdit-Bench 上提升 +0.90，几乎是 GPT-4.1（+0.45）的两倍，也超过 EditReward 的 +0.77。论文的定位是“用显式空间推理弥合在线 RL 在图像编辑中的感知差距”。

## 2. 为什么这篇论文会出现

图像编辑模型近年从简单风格迁移走向复杂多指令编辑，例如“把布料改成丝绸，同时保留人物身份和背景一致性”。但纯监督微调（SFT）倾向于拟合训练数据的平均模式，在长尾或组合指令上表现不稳定，容易在成功执行某个编辑的同时破坏源图一致性。因此，研究社区把希望寄托在在线强化学习上：让模型在试错中探索分布外数据，并利用奖励信号对齐人类偏好。这个范式在 LLM 中已经成功（RLHF），在生成模型中也有 Flow-GRPO、Dance-GRPO 等算法。

然而，在线 RL 对奖励模型提出了很高要求：可靠、高效、可解释、细粒度空间感知。现有三类奖励机制各自不满足：

- **成对奖励（pairwise）** 只输出相对排序，例如 MMRB2 上闭源模型虽强，但无法提供在线 RL 所需的绝对标量信号；而且成对推理通常是 O(N²) 的延迟，训练时不可接受。
- **点式判别模型**（如 EditReward）在 VLM 嵌入上接线性头回归偏好分，缺乏显式推理路径，且依赖昂贵人工标签，可扩展性差。
- **点式生成式“MLLM 作裁判”方法** 有推理链，但缺少空间锚点；即使像 GPT-5 这样的先进模型，在跨图区域比较时也会出现感知差距。这种缺点在蒸馏到定制奖励模型（如 EditScore）时被放大。

论文 Fig.1 给出了具体案例：编辑指令是“把面料改成丝绸”，编辑图确实改了面料但颜色和风格有偏差。基线 EditScore 因 Source Neglect（源图忽视）而给出通过判断；SpatialReward 则通过区域锚定发现了颜色和风格偏离。这说明当前的评估器不是简单地“不会看”，而是注意力坍塌到了错误的接收状态，把源图变得“不可见”。因此，可靠奖励模型必须建立在显式空间推理之上，通过锚定感知来保证精确验证与打分。

## 3. 读懂前需要的最小概念

**点式生成式奖励模型**：输入一张或两张图像加一条编辑指令，输出一个绝对分数（例如 0-25），同时可能输出文字推理。与输出“A 比 B 好”的成对模型不同，点式模型能直接作为标量奖励用于策略优化。本论文的 SpatialReward 属于此类。

**VIEScore 评估协议**：一种面向条件图像合成的可解释评估框架，将质量分解为多个子维度并按层次聚合。论文在 VIEScore 基础上定义了两个顶层维度：语义一致性（Semantic Consistency, SC）和感知质量（Perceptual Quality, PQ）。其中 SC 再分为指令遵循（Instruction Following, s_if）和源图一致性（Source Consistency, s_con）；PQ 再分为自然度（s_nat）和伪影（s_art）。每个子分数范围是 0-25。这些维度不是并列的，而是通过加权和与几何平均形成最终奖励。

**Group Relative Policy Optimization（GRPO）**：一种在线强化学习算法。与 PPO 不同，GRPO 不需要价值网络，而是对同一输入采样一组输出，用组内奖励的均值和标准差计算优势。论文用 GRPO 做两件事：一是第二阶段训练 SpatialReward 本身，由 Gemini-3-Flash 当在线监督者；二是在下游实验中用 Flow-GRPO 训练图像编辑策略。GRPO 的核心优势在于降低了奖励尺度不确定性的影响，因为只依赖组内相对排名。

**边界框 token 与交错推理**：多模态大模型（如 Qwen-VL 系列）支持在文本中插入特殊 token 来引用图像中的空间位置。例如 `<|bbox_0|>` 指代第 0 个预测框。SpatialReward 的输出 Y 被定义为结构化元组 Y = (B, T, s)，其中 B 是边界框集合，T 是含框 token 的文字推理，s 是分数向量。这种“先框后推理”确保了文字判断与像素证据绑定。此外还有一个 `<|global|>` token 用于触发全局上下文扫描，防止模型只关注局部区域。

**Attention Collapse**：论文提出的现象概念。在需要跨图比较的场景中，模型注意力没有对称分布在源图和编辑图上，而是高度集中到某个“沉没” token 或单图区域，导致跨图验证退化为单图评价。论文用注意力熵（Entropy）、集中度指数（Concentration Index）和样本间稳定性（Inter-Sample Correlation）等指标量化，具体定义在附录 C.1：Balance 用源图与编辑图注意力熵差的绝对值 |ΔH|；Source Awareness 用源图注意力熵 H_src 和 Concentration Index（top 10% token 的累积概率质量）；Stability 用不同样本扁平注意力图之间的平均 Pearson 相关系数。

## 4. 方法全景：先看数据流

### 训练数据生成流程

```
原始图像对 + 编辑指令
        │
        ▼
[Step I: 空间定位]  Qwen3-VL-235B-A22B 预测编辑区域框 B
        │
        ▼
[Step II: 专家路由标注]  
    人像编辑 → Gemini-2.5-Pro（裁剪聚焦）
    通用编辑 → GPT-5（画框叠加）
    输出初始推理 T_raw 与分数 s
        │
        ▼
[Step III: 对齐与验证]  Qwen3-VL 将 B 与 T_raw 融合为带 <|bbox_id|> 的交错文本
        │
        ├─ 一致性检查通过 → 保留
        └─ 一致性检查失败 → 丢弃（幻觉）
        │
        ▼
SPATIALREWARD-260K 数据集：
   Refined EditScore (100k) + Repurposed EditReward (100k) + Custom Multi-Edit (60k)
```

### SpatialReward 推理数据流

```
输入：编辑指令 + 原图 I_in + 编辑图 I_out
        │
        ├───────────────────────────────┐
        ▼                               ▼
[SC Stream 语义一致性]          [PQ Stream 感知质量]
  输入: I_in + I_out               输入: 仅 I_out
  预测 B（编辑框集合）             无 B（B=∅）
  生成 T（含 <|bbox_id|> 和      生成纯文本 T
   <|global|> 标记）              输出 s_pq = [s_nat, s_art]
  输出 s_sc = [s_if, s_con]
        │                               │
        └───────────────┬───────────────┘
                        ▼
        聚合：S_SC = 0.6*s_if + 0.4*s_con
              S_PQ = 0.5*s_nat + 0.5*s_art
              R_final = (S_SC)^0.8 * (S_PQ)^0.2
                        ▼
                 最终标量奖励
```

**核心组件拆解**：

1. **SC Stream（语义一致性流）**：模拟人类“先定位，再检查”的编辑验证方式。输入原图与编辑图，模型先预测所有被编辑区域的边界框 B（Localization），再生成推理 T，其中每个框前有 `<|bbox_id|>` 触发对像素的“回看”，最后用一个 `<|global|>` 触发全局扫描。输出两个分数：s_if（指令遵循）和 s_con（源一致性）。目的：把语义判断锚定在像素证据上，防止跨图比较退化成单图评价。在实际提示模板（附录 D.1.1）中，s_if 评分 0-25 衡量编辑是否成功执行，s_con 评分 0-25 衡量过度编辑程度，0 表示编辑图与原图完全不同，25 表示最小且有效的编辑。

2. **PQ Stream（感知质量流）**：采用“感知解耦”策略，只把编辑图 I_out 输入模型，进行无参考的全局扫描，评估绝对视觉保真度。输出纯文本推理和两个分数：s_nat（自然度）和 s_art（伪影）。附录 D.1.3 的提示定义了这两项：s_nat 评估视觉自然性（如距离感、阴影、光照），s_art 评估伪影（如扭曲、水印、划痕、模糊面部、不和谐主体）。目的：避免语义分数与质量分数相互干扰，让 PQ 独立于编辑指令。

3. **结构化输出 Y = (B, T, s)**：B 是边界框列表，T 是文字推理（SC 流中带特殊 token，PQ 流中纯文本），s 是分数列表。训练时模型以自回归方式生成整个 Y，确保推理与分数在同一输出序列中。对于多参考图编辑场景，附录 D.1.2 提供了 Multi-Image SC Scoring Prompt，模型需要识别成功融合的元素并输出框与 [s_if, s_fusion] 分数。

4. **层次化聚合**：先对子维度加权求和得到 S_SC 和 S_PQ，再用加权几何平均得到最终奖励。几何平均能惩罚“短板”，避免模型在某个维度极低时总分虚高。超参数 α=0.80，w_SC={0.6,0.4}，w_PQ={0.5,0.5}，这些值通过 2000 样本验证集网格搜索确定（附录 B.1.3，Fig.10），搜索范围 α∈[0.60,0.95]，w_SC^(0)∈[0.40,0.75]，步长 0.05，最优组合验证准确率达 0.736。

**假设**：显式空间定位是防止注意力坍塌的关键；模型只有在知道“往哪里看”的情况下，才能正确对齐跨图区域并验证细节。论文主张这是必要的，而非仅仅有帮助。

## 5. 核心公式与直觉

本文公式不多，核心是损失函数和奖励聚合。以下选取两个理解贡献必需的公式。

### 公式 1：层次化奖励聚合

论文在 §3.1 定义最终奖励为：

```
S_SC = w1 * s_if + w2 * s_con
S_PQ = w3 * s_nat + w4 * s_art
R_final = (S_SC)^α * (S_PQ)^(1-α)
```

其中论文实际使用的权重为 w1=0.6, w2=0.4（SC 内部），w3=0.5, w4=0.5（PQ 内部），α=0.80。所有子分数 s 的范围均为 0-25。

**直觉**：子维度加权和保存了不同信息；几何平均则对不平衡质量进行重罚。如果一个编辑的语义完全正确（25分）但感知质量极差（0分），算术平均可能给出中等分数，而几何平均直接归零。这符合“deal-breaker”性质：某些视觉错误（如严重伪影）不可接受。论文在 §5.4 消融中表明加权几何平均优于算术平均（0.771）和 Bucket Principle（0.774），最终达到 0.803。Bucket Principle 取各维度最小值的几何平均，虽能惩罚短板，但论文指出其梯度稀疏，导致在线 RL 中早期饱和（Fig.11 中 VIEScore 峰值仅 7.12，而加权几何平均可达 7.32）。

**工程对应**：在在线 RL 训练中，奖励的梯度密度很重要。如果奖励经常是常数或不可微的极值，策略无法稳定优化。加权几何平均提供了平滑且敏感的梯度，同时保持对严重缺陷的惩罚。

### 公式 2：GRPO 目标函数

论文 §3.4 的 Stage 2 使用 GRPO 训练 SpatialReward，目标函数为：

```
J_GRPO(θ) = E_{q~P(Q), o_i~π_old(·|q)}[
    (1/G) Σ_{i=1}^G (π_θ(o_i|q) / π_θold(o_i|q)) Â_i
] - β D_KL(π_θ || π_ref)
```

其中：

- G 是组大小（论文设 G=4）；
- π_θ 是当前策略，π_θold 是采样时的旧策略；
- Â_i 是优势函数，按组内奖励的标准化计算： `Â_i = (r_i - mean({r_j})) / std({r_j})`；
- β 是 KL 惩罚系数（论文设 β=0.02）；
- D_KL(π_θ || π_ref) 是当前策略与参考策略之间的 KL 散度。

**直觉**：GRPO 对同一个输入采样多个输出，用组内相对排名而非绝对奖励来更新策略，降低了奖励尺度不确定性的影响。KL 惩罚防止策略偏离参考模型太远。在 SpatialReward 的 RL 阶段，奖励来自 Gemini-3-Flash 对模型推理一致性的打分（0~1），因此这个目标实际上是在“模仿”更强大的在线监督者，同时抑制幻觉。附录 B.1.2 显示，GRPO 训练 500 步内 Gemini 一致性奖励从约 0.60 上升到 0.85，KL 散度稳定在 0.01~0.06，最终选择 300 步 checkpoint。

**优化动作**：模型在 SFT 阶段已经学会了生成结构化输出 Y；GRPO 阶段进一步调整分布，使模型更少产生与视觉证据矛盾或自相矛盾的推理，并让分数与推理对齐。附录 D.4 的 Oracle 验证提示明确检查七个方面：与现实一致性、过度编辑意识、细粒度细节、幻觉、逻辑自洽、错误过度编辑标记、分数-推理对齐。

## 6. 训练到底怎么跑

### SpatialReward 模型训练

训练分为两个阶段：SFT 和 Online Consistency RL（GRPO）。基座模型为 Qwen3-VL-8B-Instruct，使用 LoRA 微调（r=32, α=64），优化器为 AdamW，精度 bf16，学习率调度为 Cosine。

**Stage 1：Supervised Fine-Tuning**

- 数据：SPATIALREWARD-260K，包含 26 万个结构化样本。来源为：从 EditScore 数据清洗得到 100k（清洗噪声 T/s 并注入空间先验 B）；从 EditReward 数据重新利用 100k（丢弃原始粗粒度分数，重新生成细粒度推理组件）；以及自定义多编辑集合 60k（遵循第 4.2 节的任务分类法构造）。
- 目标：最大化目标序列 Y 的概率。对于 SC 任务，Y 展开为 (B, T, s)；对于 PQ 任务，Y 展开为 (T, s)。
- 损失函数：`L_SFT = -Σ_{t=1}^T log P_θ(y_t | y_{<t}, X)`，其中 X 是输入图像与指令。
- 关键超参数：全局批量大小 128，学习率 1e-4，训练 10 个 epoch，最大序列长度 8192 token，硬件为 8×H800（单节点）。这些参数在附录 Table 6 中明确给出。

**Stage 2：Online Consistency RL（GRPO）**

- 数据：从训练集中挖掘 7k 个低分困难样本，即 SFT 模型在这些样本上表现不佳。
- 在线监督者：Gemini-3.0-Flash，用于生成一致性分数（0~1）作为奖励。附录 D.4 提供了 SC 和 PQ 两个验证提示，分别检查推理的事实性、过度编辑意识、幻觉、逻辑一致性、分数对齐等。
- 损失：最大化 §5 中的 J_GRPO，组大小 G=4，KL 系数 β=0.02，采样温度 0.9，最大序列长度 1024。
- 关键超参数：学习率 5e-7，全参数微调（注意与 SFT 阶段的 LoRA 不同），硬件为 32×H800（4 节点）。
- 训练动态：论文 Fig.9 显示六个监控曲线——Gemini 一致性奖励、训练损失、KL 散度、平均响应长度、零奖励标准差比例、裁剪比例。奖励持续上升，KL 与 loss 稳定，最终在 300 步时根据验证集性能选择 checkpoint（附录 B.1.2）。
- 一个重要细节：SFT 阶段使用 LoRA，但 GRPO 阶段论文写明为“Full Fine-Tuning”，这是一个不同点，可能意味着需要先合并 LoRA 权重后再进行全参数 RL 训练。

### 下游 OmniGen2 策略训练（Online RL 应用）

这部分是验证 SpatialReward 的实用性，不是训练 SpatialReward 本身。

- 基座：OmniGen2，使用 LoRA（rank 32, alpha 64），学习率 4e-4，全局批量大小 576。
- 算法：Flow-GRPO，采样组大小 G=12，采样步数 T=20，KL 惩罚 β=0.04，优势裁剪范围 5.0。
- 硬件：32×H800（4 节点）用于策略训练；另部署 8×H800 节点运行 SpatialReward 奖励模型，通过 vLLM 提供低延迟推理。
- 训练步骤：总共 1000 步，最终在 Step 800 选择 checkpoint，因为论文观察到后续出现 reward hacking。附录 B.2.1 提到“training beyond a certain point led to reward hacking”。
- 奖励信号来自 SpatialReward 的输出 R_final，使用加权几何平均聚合。Fig.6(a) 显示 SpatialReward 的 training reward mean 在 0.70~0.90 之间稳定上升，而 Fig.6(b) 显示 VIEScore 峰值达 7.32。

## 7. 推理到底怎么跑

SpatialReward 的推理流程与训练时的生成一致。完整顺序如下：

**输入**：编辑指令、原图 I_in、编辑图 I_out。

**步骤 1：SC Stream 推理**

- 将 I_in 和 I_out 一起输入 SpatialReward 模型，使用 §D.1.1 的系统提示（SC Scoring Prompt）。
- 模型自回归生成结构化 JSON，包含：
  - `edit_region`：预测的编辑区域列表，每个区域有 `id`、`label`、`bbox_2d`（归一化 0-1000 坐标）。如果编辑失败（两图相似），此字段为空列表。
  - `reasoning`：带 `<|bbox_id|>` 和 `<|global|>` token 的文字推理。
  - `score`：列表 `[s_if, s_con]`，分别是指令遵循分和源一致性分，范围 0-25。s_if 的 0 表示完全未遵循指令，25 表示完美遵循；s_con 的 0 表示编辑图与原图完全不同，25 表示最小且有效的编辑。
- 注意：模型是先预测 B，再生成 T 和 s，这保证了推理锚定到框。

**步骤 2：PQ Stream 推理**

- 只将 I_out（编辑图）输入模型，使用 §D.1.3 的 PQ Scoring Prompt。
- 模型生成推理 `reasoning`（纯文本，无框 token）和分数 `[s_nat, s_art]`，分别评估自然度和伪影，范围 0-25。s_nat 的 0 表示完全不自然，25 表示完全自然；s_art 的 0 表示大量伪影，25 表示无伪影。
- 输入隔离确保 PQ 评估不受指令影响。

**步骤 3：聚合**

- 计算 S_SC = 0.6*s_if + 0.4*s_con。
- 计算 S_PQ = 0.5*s_nat + 0.5*s_art。
- 计算最终奖励 R_final = (S_SC)^0.80 * (S_PQ)^0.20。

**多图扩展**：论文还提供了多参考图编辑的 SC 提示模板（§D.1.2），适用于多张输入图像融合成一个编辑输出的场景。模型会为每个成功融入的元素预测框，并输出 [s_if, s_fusion] 两个分数。这是为了支持 UniRef-Image-Edit 实验（Table 3 第 3 部分）。

**推理硬件与延迟**：论文在附录 B.2.3 报告，在 8×H800 GPU 节点上，批大小 576，SpatialReward 的延迟为 72.7ms/image，吞吐 13.8 img/s；相比之下 EditReward 为 110.5ms/image，吞吐 9.3 img/s。加速来自 vLLM 的 PagedAttention 和 prefix caching：在 Flow-GRPO 中，同一组 12 个样本共享系统提示和指令上下文，可以大量复用 KV cache。注意这一数字是批处理场景下的平均延迟，单次低并发推理的实际延迟会更高。

## 8. 实验和消融到底证明了什么

论文的主要实验分为三类：奖励模型基准评估、在线 RL 下游验证、消融与注意力分析。以下是关键证据表。

| 证据 | 任务/数据集 | 指标 | SpatialReward | 主要对照 | 锚点 |
|---|---|---|---|---|---|
| 1. 空间锚定带来大幅提升 | EditReward-Bench | Overall Accuracy | **0.803** | EditScore-8B: 0.690；GPT-5: 0.755；EditReward (判别式): 0.792 | Table 1 |
| 2. 在编辑评估基准 MMRB2 上超过判别式最优 | MMRB2 (ImgEdit) | Overall | **0.661** | EditReward: 0.657；GPT-5: 0.619；EditScore-8B: 0.570 | Table 1 |
| 3. 复杂多约束基准上对高难组有韧性 | MER-Bench | 4-Pair Accuracy | **0.215** | Gemini-3.0-Flash: 0.195；GPT-5: 0.160；EditScore-8B: 0.100 | Table 1 |
| 4. 下游 Online RL 提升最大 | GEdit-Bench (OmniGen2) | Δ Overall | **+0.90** | GPT-4.1: +0.45；EditScore: +0.61；EditReward: +0.77 | Table 3 |
| 5. 注意力指标证明修复了坍缩 | EditReward-Bench (N=776) | Entropy Gap | **1.16** | Baseline: 3.48 | Table 5 |
| 6. 消融：RL 阶段获益 | EditReward-Bench | Accuracy | SFT w/ Think-with-Box: 0.778 → RL w/ Think-with-Box: 0.803 | Box Only: 0.761；无空间 ground: 0.743 | Table 4(I) |

**MER-Bench 构造细节**：论文 §4.2 和附录 A 说明，MER-Bench 包含 15 个细粒度子任务，来源图像来自 laion2B-en-aesthetic、CC12M 和 headshot pexels v1，指令由 Qwen-3-VL-235B-A22B-Instruct 生成，每条指令含 2-5 个编辑操作，类别分布约为 General: Human-Centric Basics: Human-Centric Fine Details = 2:1:1。11 个生成系统包括 Step1X、Qwen-Edit、OmniGen、FLUX、Bagel、seedream 等，每个指令采样 6 个输出。最终基准含 600 个评估组、1800 个样本：200 个 2-Pair 组、200 个 3-Pair 组（含 Good/Medium/Poor 各一个）、200 个 4-Pair 组（在 3-Pair 基础上增加一个仅能通过子维度区分的样本）。人类标注由 5 名专家独立评估 SC、PQ 和 Overall，采用 3 级 scale，最终标签通过多数投票产生，要求至少 3/5 一致，否则进入专家评审（附录 A.1）。

**最关键消融**：Table 4(I) 展示了两项独立因素。仅 SFT 阶段加上 Box 预测（Box Only）比无空间 grounding 的 SFT 基线提升了 0.018（0.743 → 0.761）；而 Think-with-Boxes（交错 token）进一步提升到 0.778；再加上 RL 阶段达到 0.803。这说明：预测框本身有用，但把框作为 token 插入推理、强迫模型“回看”，比仅仅做检测更有效；而 RL 阶段对最终分数有约 0.025 的额外贡献，虽然不算巨大，但在最优基准上已算显著。

**注意力量化分析**：附录 C.1 给出具体测量方法：聚合 VLM 最后 5 层 transformer 的跨模态注意力权重（从生成 token 到图像 token），平均所有 head，归一化到 24×24 网格。在 N=776 个 EditReward-Bench 样本上，基线表现出熵差 3.48、源图熵 2.88、集中度 0.84、稳定性 0.04；SpatialReward 则为熵差 1.16、源图熵 5.71、集中度 0.37、稳定性 0.12。这直接量化了“注意力坍塌”和修复效果。

**尚未证明的主张**：论文的结论是“空间推理对于解锁有效的图像编辑对齐至关重要”。这一结论的强形式（必要性）并未通过对照实验严格证明——没有展示一个无空间 grounding 但用相同数据和 RL 训练的模型在注意力指标和下游 RL 中的表现对比。此外，论文在 MER-Bench 的 Overall Accuracy 上低于 Gemini-3.0-Flash（0.483 vs 0.508），虽然论文强调 4-Pair 子集上 SpatialReward 最高，但整体处于第二或第三的位置。因此“超过所有专有模型”的表述需要限定在与生成式基线 EditScore 比较，或特定子集上。

**实验设计的一个结构性争议**：EditReward-Bench 在 Table 1 中有一个 “-” 号，论文解释为 EditReward（判别式）的人类标注只关注指令遵循，没有源一致性维度，因此无法评估该维度。这使得该基准上的 Overall 比较可能不公平，因为判别式模型缺失了一个维度，但论文仍将其列为对照。读者需注意这一局限性。

## 9. 与前作怎么选

### 与 EditScore（生成式基线）比较

- **相同点**：都使用 VIEScore 协议、Qwen-3-VL 8B 基座、生成式点式打分，都可用于在线 RL。
- **不同点**：EditScore 从 GPT-4.1 蒸馏推理但缺少显式空间锚点，论文指出其在跨图比较时出现 Attention Collapse。SpatialReward 在其数据基础上重构了空间感知训练集并加入 Think-with-Boxes。实验上，SpatialReward 在 EditReward-Bench 上比 EditScore-8B 高 0.113，在 MMRB2 上高 0.091，在下游 RL 中提升 +0.90 vs EditScore 的 +0.61。
- **何时选 EditScore**：如果只需要快速搭建一个简单的编辑奖励模型，且不打算处理多区域复杂编辑，或者计算资源极有限，EditScore 无框预测成本可能稍低；但从实验看其准确性明显弱于 SpatialReward。
- **何时选 SpatialReward**：当需要可靠的在线 RL 信号，尤其涉及多指令、多区域、人像细粒度编辑时。其空间推理能力在复杂样本上优势更明显，且延迟并非劣势（反而因 vLLM 优化而更快）。

### 与 EditReward（判别式）比较

- **相同点**：都是开源点式奖励模型，可直接输出标量。
- **不同点**：EditReward 在 VLM 嵌入上接线性回归头，没有文本推理链；其训练标注只涵盖指令遵循，缺乏源一致性建模。论文在 Table 3 中显示，尽管 EditReward 基准分数不错（GEdit-Bench Δ +0.77），但用于 RL 时导致严重的 content drift（内容漂移），如图 7 所示，模型会过度修改未提示区域。而 SpatialReward 通过同时建模 s_con 保持了更平衡的优化（SC 7.64 vs 7.43，PQ 8.01 vs 7.89）。
- **何时选 EditReward**：如果下游任务只需评估“是否执行了指令”而不关心保留源图，且推理延迟要求极高（判别式前向比生成式短）时，可以选 EditReward；但论文报告 SpatialReward 因 vLLM 优化在实际吞吐上反而比 EditReward 快 1.5 倍（Table 7），所以延迟优势不再明显。
- **何时选 SpatialReward**：当编辑需要同时满足指令遵循和源图一致性（例如人像编辑、局部修改）时，SpatialReward 更优。

### 与专有模型（GPT-5、Gemini-3.0-Flash）比较

- **何时选专有模型**：如果无法部署 8B 本地模型，或者需要极端泛化能力而不考虑成本与隐私，专有模型在 MER-Bench Overall 上（Gemini-3.0-Flash 0.508）略高于 SpatialReward（0.483）。但在在线 RL 中，闭源 API 有隐私和延迟风险，论文表明 GPT-4.1 作为奖励模型提升仅有 +0.45，低于 SpatialReward 的 +0.90。
- **何时选 SpatialReward**：需要本地部署、隐私可控、低延迟高吞吐的在线 RL 训练场景。它的开源权重和结构化输出更适合与 vLLM 深度集成。

## 10. 工程判断：可行性、风险与上限

### 数据

训练数据 SPATIALREWARD-260K 是合成数据，由 Qwen-3-VL、Gemini-2.5-Pro、GPT-5 等教师模型生成。这意味着数据质量和教师能力高度相关。如果教师模型本身在细粒度空间比较上就有缺陷，即使加了框也可能继承偏差。论文通过一致性检查丢弃幻觉样本，但未披露丢弃比例，也未讨论数据中是否存在系统性静默错误。此外，260k 规模对 8B 模型尚可，若要扩展到更复杂的多参考编辑（如 UniRef-Image-Edit），可能需要更大规模或更高质量的标注。论文未报告教师模型的内部一致性或人类评估者在相同样本上的表现，因此数据上界未知。

### 算力与延迟

论文报告 SpatialReward 训练需要 8×H800 做 SFT，32×H800 做 GRPO；推理部署在 8×H800 节点上达到 72.7ms/image。对于在线 RL，奖励模型的延迟必须远低于策略的采样时间，否则会成为瓶颈。论文显示其吞吐为 13.8 img/s，在 Flow-GRPO 中共享前缀缓存有效降低了实际延迟。但注意该数字是在批大小 576 测量，小批量推论的延迟会更高。如果预算只有单卡 GPU，延迟可能显著上升，妨碍在线 RL 部署。

### 实现难点

1. **边界框预测与 VLM 生成协调**：模型需要在同一自回归序列中先生成 JSON 框，再生成带 token 的推理。训练时必须保证框坐标格式正确，否则后续 token 引用无效。论文未讨论框预测失败（如 OOD 图像上框缺失）时如何处理，推理阶段如果模型生成了非法 JSON，可能导致解析崩溃。
2. **两流融合**：SC 和 PQ 是分开推理的，实际上每次评价需要两次前向。虽然论文报告了每图延迟，但未明确说明是否合并为一次批处理；工程上需要两个不同的提示和输入组合，可能增加调度复杂度。
3. **GRPO 阶段的全参数微调与 LoRA 合并**：SFT 用 LoRA，GRPO 用全参数微调，这意味着需要先将 LoRA 适配器合并回基座模型，这可能引入精度问题，也需要更多显存。论文未给出具体合并步骤。
4. **奖励 model 的 Reward Hacking**：论文在下游策略 RL 中观察到 1000 步后出现 reward hacking，最终选 800 步 checkpoint。这表明 SpatialReward 本身可能存在可被利用的弱点，例如模型偏向某些视觉模式而忽略真实质量。监控指标应包括验证集上的真实 VIEScore 而非仅看训练奖励。

### 失败环节与监控信号

- 在数据构造阶段，如果 Qwen-3-VL 定位不准确，或者一致性检查漏过幻觉，会产生错误训练样本。应监控生成框的 IoU 与人工抽查一致率。
- 在 RL 阶段，应监控 Gemini 一致性奖励、KL 散度、零优势比例和裁剪比例（论文 Fig.9 展示了这些曲线）。如果零优势比例过高，说明组内奖励差异太小，GRPO 无法有效学习。附录 Fig.9 中“Fraction of Zero Reward Std”曲线可反映这一点。
- 在下游策略 RL 中，需要定期在权威基准（如 VIEScore 评估）上验证，防止 SpatialReward 被策略模型“欺骗”。论文使用了 GEdit-Bench 的 VIEScore 作为外部验证指标，并在 Fig.6(b) 中显示加权几何平均能持续上升至 7.32，而 Bucket Principle 早期饱和于 7.12。

### 指标上限与未回答问题

论文报告的最优基准准确率来自 EditReward-Bench 的 0.803，并非接近 1.0。一个可能的上界是合成生成 GT 标签的固有噪声：如果教师模型在打分一致性上只有 0.85 左右的准确率，学生模型很难超过这个上界。论文未测量教师模型的内部一致性，也未给出人类评估者在相同样本上的表现。此外，论文未回答：空间推理是否真正解决了所有类型的跨图比较问题？例如极端遮挡、大范围变换或不可见的内部结构变化，框定位可能无法提供有效锚点。区域级奖励分配是论文“Future work”提到的方向，但当前只输出全局标量，尚未实现对单个编辑操作的信用分配。

## 11. 放回研究脉络并收束

这篇论文处于图像编辑评估与生成模型对齐的交叉点。沿着“从成对到点式”、“从隐式到显式推理”的路线，SpatialReward 首次把 VLMs 中的空间 grounding 能力（如 Shikra、Ferret）引入编辑奖励模型，以显式边界框锚定解决跨图比较中的注意力坍塌。它的锚点选择不是简单地用视觉特征匹配，而是把“看哪里”作为生成序列的一部分，使推理本身带上空间约束。这比以往 EditScore、RewardDance 等方法更接近人类编辑验证的认知过程。论文通过数据管道、两阶段训练和系统的基准/RL 验证，证明了这一思路的有效性，但同时也留下了若干开放问题：必要性未严格证明、教师模型噪声上界未知、区域级信用分配尚未实现。

**读完必须记住的 5 件事**：

1. Attention Collapse 是点式生成式奖励模型在跨图编辑评估中的核心缺陷：模型注意力坍缩到单图或沉没 token，忽略源图一致性。量化指标包括熵差、集中度和稳定性。
2. SpatialReward 的贡献核心是 “Think-with-Boxes”：先预测编辑框，再用 `<|bbox_id|>` 和 `<|global|>` token 将推理锚定到像素，强制跨图验证。
3. 采用双流评估：SC 流同时看原图和编辑图，PQ 流只看编辑图；最终用加权几何平均聚合（α=0.80），惩罚短板并保留梯度密度。
4. 训练分 SFT + GRPO，数据来自 260k 空间先验引导构造；GRPO 用 Gemini-3-Flash 做在线监督，组大小 G=4，在 300 步选 checkpoint，有效减少幻觉。
5. 实验中，SpatialReward 在多个基准上超过生成式和判别式基线，并在 OmniGen2 的在线 RL 中带来 +0.90 提升，但 MER-Bench Overall 略低于 Gemini-3.0-Flash（0.483 vs 0.508），且“空间推理必要性”尚未被完全证明。

**5 道自测题**：

1. 论文所称的 Attention Collapse 具体表现是什么？它与注意力熵、集中度指数有何关系？
2. SpatialReward 的 SC Stream 和 PQ Stream 输入有何不同？为什么这样设计？
3. 空间先验数据管线的 Step III 做了哪两件事？一致性检查的作用是什么？
4. 在消融实验中，仅添加 Box 预测（Box Only）与 Think-with-Boxes 相比，效果差异说明了什么？
5. 在 OmniGen2 的在线 RL 中，为什么选择 Step 800 而不是 Step 1000 的 checkpoint？这反映了什么问题？

**最终一句话总结**：SpatialReward 用显式空间锚点改造点式奖励模型，把“看哪里”嵌入推理序列以修复跨图注意力坍塌；它在奖励基准和在线 RL 中表现强劲，但空间推理是否是不可替代的必要条件，仍需更严格的对照实验来回答。
