# 大白话深读《qwen-image-rl》

## 1. 30 秒定位

本文是 Qwen-Image-2.0-RL 的技术报告，介绍一种后训练流程，把强化学习人类反馈（RLHF）和在线策略蒸馏（On-Policy Distillation，OPD）应用到 Qwen-Image-2.0 扩散模型上。目标不是发明新的图像生成架构，而是让已经预训练好的模型更符合人类偏好：文本生成图像（T2I）要更美、更对齐提示词；图像编辑要更准确执行指令、并保持人脸身份。论文的贡献可以概括为三点：第一，基于 VLM 的复合奖励模型，针对 T2I 与编辑分别设计不同的奖励维度；第二，一个可扩展的 GRPO 训练框架，引入混合 CFG、异步奖励管线、多奖励归一化和按类别权重校准；第三，用 OPD 把两个任务专用教师蒸馏到单一学生模型，避免多任务冲突。

作者的核心做法是：先用共享 base 模型分别训练两个任务专用 RL 策略——T2I 教师和编辑教师；T2I 使用分层奖励（对齐、美学、人像），编辑使用指令遵循和人脸身份保持；然后用 OPD 把两个教师压缩到单一学生。评估显示，在 Qwen-Image-Bench 上总分 57.84，比 base 的 55.23 提升 2.61；T2I Elo 从 1115 升到 1193（+78），编辑 Elo 从 1256 升到 1349（+93）。结论是任务分解 RL 再蒸馏，优于混合奖励一起训。

## 2. 为什么这篇论文会出现

监督训练扩散模型的主流目标是最小化去噪分数匹配或流匹配损失，例如式 (2) 的速度场 MSE。这个目标直接学到数据分布，但并没有直接编码“构图和谐、纹理真实、提示词忠实、风格连贯”这类人类审美判断。结果是：即使模型在似然或 FID 类指标上不错，人类看上去仍可能觉得不够好。论文开篇也提到，预训练和监督训练的差距持续存在，尤其是人类对美学质量、纹理细节、提示忠实度的期望没有被直接建模。

LLM 领域里 RLHF 已经很成功，说明用奖励信号直接微调策略可以弥补监督训练与人类期望之间的差距。把这个范式搬到扩散模型却有三个难点。第一，奖励信号必须覆盖多个维度，而且任务差异很大：T2I 关注全局美学和提示对齐，编辑则更关注细粒度身份保持；单一标量奖励不够可靠。第二，已有扩散 RL 研究大多在 LoRA 或较小规模上验证；真实系统需要多奖励、多任务和全参数训练，这在论文写作时尚未充分探索。第三，部署时通常只能用一个模型，而专门为 T2I 优化的策略可能损害编辑，反之亦然；需要把多个任务策略合并且不牺牲单任务质量。此外，扩散模型本身面临 CFG 训练与采样的稳定性问题：GRPO 要求在线 rollout，但 CFG 在训练中可能导致梯度不稳定，关闭 CFG 又可能遗忘预训练知识。

正是在这种背景下，论文选择 Qwen-Image-2.0 作为基础模型，构建面向 T2I 和编辑的复合奖励，再通过 GRPO 变体和 OPD 完成从预训练模型到部署模型的最后一公里。它不是要取代预训练，而是补上“审美对齐”这一段后训练路径。商业系统和统一架构已经提升了生成质量，但如何系统性地把人类偏好注入扩散模型并合并多任务能力，仍是一个未被充分探索的工程问题。

## 3. 读懂前需要的最小概念

**流匹配（Flow Matching）**：扩散模型这里不使用常见的去噪分数匹配，而是在时间 t 从 0 到 1 上定义线性插值 \(x_t=(1-t)x_0+t\epsilon\)，其中 \(x_0\) 是干净图像，\(\epsilon\sim N(0,I)\) 是噪声。对应速度场 \(v=\epsilon-x_0\)。网络 \(v_\theta(x_t,t,c)\) 学习预测这个速度。生成时从 \(x_1\sim N(0,I)\) 出发，反向解概率流 ODE \(dx_t/dt=v_\theta(x_t,t,c)\) 到 t=0。本文所有训练和推理都建立在这个框架上。

**GRPO（Group Relative Policy Optimization）**：一种来自 LLM 的在线策略优化方法。对同一提示 c，策略生成一组 G 张图像，用奖励模型给每张打分；先在同组内做均值方差归一化得到优势，再做策略梯度更新。它比 PPO 简单，不需要单独的 critic 网络。

**扩散 RL 的 MDP 视角**：去噪或流匹配的多步轨迹被视为 Markov 决策过程（MDP）。策略是每一步的转移概率。Flow-GRPO 通过等价随机采样器把确定性 ODE 变成带高斯转移的随机过程，从而能计算重要性采样比，使用 clipped surrogate 目标更新。随机采样器的形式为 \(dx_t=\left[v_\theta(x_t,t)+\frac{\sigma_t^2}{2t}(x_t+(1-t)v_\theta(x_t,t))\right]dt+\sigma_t dw_t\)，其中 \(\sigma_t\) 控制噪声尺度，\(w_t\) 是标准维纳过程；在 Euler-Maruyama 离散下转移密度为高斯，因此可以写出重要性采样比 \(r_t^{(i)}(\theta)\)。

**CFG（Classifier-Free Guidance）**：推理时把条件分支输出 \(v_\theta(x_t,t,c)\) 和无条件分支输出 \(v_\theta(x_t,t,\varnothing)\) 组合，例如 \(v_{\text{cfg}}=v_{\text{uncond}}+w(v_{\text{cond}}-v_{\text{uncond}})\)。它能显著提升结构和语义质量，但如果在 RL 优化中也保留 CFG，梯度会同时流过两个分支，造成不稳定。论文研究了三种 CFG 策略：rollout 与训练都开 CFG、都关 CFG、仅 rollout 开 CFG。

**在线策略蒸馏（OPD）**：不是让学生学教师生成的固定轨迹，而是学生按自己当前策略生成轨迹，再在这些轨迹点上匹配教师的速度。这样学生修正的是“自己会走错的地方”，更接近在线学习。附录 A 从 Wasserstein-2 距离的上界推导了该目标，证明最小化速度 MSE 等价于最小化学生输出分布与教师输出分布距离的上界。

**VLM 点式奖励模型**：用视觉语言模型（VLM）给图文打分。模型输出 1 到 5 的离散分数，奖励为概率加权期望 \(R_\phi(x,c)=\sum_{s\in\{1,\dots,5\}} s\cdot p_\phi(s|x,c)\)。与成对比较不同，点式回归直接拟合绝对分数，论文认为这提供更丰富的校准信号。点式注释在论文中体现为人类在 5 点 Likert 量表上打分，并覆盖质量与保真度两个维度。

## 4. 方法全景：先看数据流

整个系统分为三个阶段：基础模型 → 任务专用 RL 教师 → OPD 统一学生。下面是 ASCII 数据流：

```
                        Qwen-Image-2.0 Base
                                |
        +-----------------------+-----------------------+
        |                                               |
  [T2I RL 训练]                                  [Edit RL 训练]
  prompt c                                        (source image, instruction)
        |                                               |
  40-step ODE rollout, CFG ON                    40-step ODE rollout, CFG ON
        |                                               |
  async reward API:                              async reward API:
  alignment / aesthetic / portrait                instruction-following / face ID
        |                                               |
  per-group normalization + weighted sum          per-group normalization + weighted sum
        |                                               |
  GRPO update, CFG OFF                            GRPO update, CFG OFF
        |                                               |
  T2I Teacher                                     Edit Teacher
        +-----------------------+-----------------------+
                                |
                          [OPD 蒸馏]
                     student from base, CFG OFF
                     self-generate trajectory
                     choose teacher by task type
                     teacher velocity matching (CFG ON for teacher)
                                |
                    unified Qwen-Image-2.0-RL
```

**核心组件拆解**：

1. **VLM 复合奖励模型**：输入是生成图像和提示词（编辑任务还包含源图像），输出 1–5 的标量奖励。T2I 有三个奖励：对齐奖励考察物体存在与数量、属性正确性、空间关系忠实度、动作与姿态准确性，并明确“未通过最高优先级标准则分数封顶”；美学奖励考察构图平衡、真实光照、纹理忠实度和整体艺术连贯性；人像奖励额外关注面部比例、身份保持的面部细节、皮肤和发丝纹理，并检查手指数量错误、面部扭曲和身体比例异常等常见失败模式。编辑任务有两个奖励：指令遵循奖励将指令分解为核心编辑要求与非核心辅助要求，评估核心指令是否完成、非核心要求是否处理、整体输出是否视觉连贯；人脸身份保持奖励用嵌入级模型补充 VLM 无法捕捉的细粒度身份漂移。目的：提供稳定的、多维的人类偏好信号。假设：点式绝对分数优于成对偏好，且不同维度可以线性加权。

2. **混合 CFG 策略**：rollout 采样时开启 CFG，以生成结构更可靠、质量更高的候选图像；策略优化目标中关闭 CFG，只更新条件分支。目的：既利用预训练知识，又避免联合优化条件/无条件分支带来的不稳定。假设：训练阶段 CFG 是造成崩溃和知识遗忘的关键因素之一。论文用 Figure 3 的三组定性结果支撑：两者都开 CFG 导致训练不稳、最终图像崩溃；两者都关导致风格能力与世界知识逐步丢失；仅 rollout 开 CFG 是唯一稳定且保留预训练能力的设置。

3. **异步奖励管线**：奖励模型部署为远程 VLM API。策略在 GPU 上推理生成图像后，后台线程异步提交奖励请求；返回后所有 rank 同步收集分数、做组内归一化和优势计算。目的：把远程网络 I/O 延迟隐藏在 GPU 推理后面，避免训练循环阻塞。假设：网络延迟远高于本地计算，且奖励模型服务可以并行扩展。论文说明该管线能“几乎把奖励延迟隐藏在推理计算之后”，使扩展到多个奖励模型时训练时间不按比例增加。

4. **多奖励优势计算**：采用公式 (13)。对每个奖励模型在同提示组内求均值和标准差，归一化后按权重 \(w_k\) 加权。目的：让数值范围不同的奖励模型在复合优势中具有可比贡献。假设：奖励模型有稳定的组内尺度，且类别可大致覆盖生成质量的各个方面。该设计部分受 Gdpo（Liu et al., 2026b）启发。

5. **时间步子集训练**：rollout 使用 40 步 ODE，但训练只更新部分时间步，偏向高噪声端。目的：高噪声时间步决定全局结构和语义布局，更适合作为优化信号；同时限制所有时间步训练导致的快速奖励黑客。假设：减少时间步能减慢奖励利用。论文观察到对全部 40 步施加 RL 目标会在少数迭代内导致奖励黑客和退化，因此必须限制。

6. **提示词筛选**：训练前用 base 模型对每个候选提示做 G 次 rollout，计算组内奖励范围（最大减最小）；只保留范围超过阈值的提示。目的：把计算集中在策略有改进空间的提示上，过滤掉所有采样都很好或都很差的低信号提示。假设：组内奖励范围能代表提示的优化潜力。论文称该步骤显著提高训练效率。

7. **按类别奖励校准**：将提示按语义类别组织，如人像、风景、排版、通用，给不同类别分配不同奖励权重。例如人像提示获得更高的人像保真度权重，排版提示更强调对齐准确性。目的：防止模型收敛到单一视觉风格，为不同领域保留不同质量要求。假设：类别边界清晰且目标审美可以按类别分解。

8. **OPD 多教师蒸馏**：学生从 base 初始化，自生成轨迹保存每一步 \(x_{t_n}\)。根据当前样本的任务类型选择 T2I 教师或编辑教师；活跃教师留在 GPU，其余卸载到 CPU。学生匹配教师速度，教师使用 CFG，学生不使用。目的：在不依赖奖励模型的情况下，把两个任务策略压到单一部署模型，避免多任务梯度冲突。假设：学生自己生成的轨迹能提供足够覆盖，且教师速度可以指导跨任务知识整合。论文说明 OPD 之后学生模型会整合 CFG 用于推理。

## 5. 核心公式与直觉

论文理解贡献只需抓住三个公式：流匹配目标、多奖励优势、OPD 轨迹速度匹配。

**流匹配目标（式 (1)–(2)）**

前向路径：  
\[
x_t=(1-t)x_0+t\epsilon,\quad t\in[0,1]
\]  
\[
L_{\text{FM}}(\theta)=\mathbb{E}_{t,x_0,\epsilon}\|v_\theta(x_t,t,c)-(\epsilon-x_0)\|^2
\]

变量：\(x_0\) 是干净图像，\(\epsilon\) 是高斯噪声，\(t\) 是时间，\(x_t\) 是中间噪声态，\(v_\theta\) 是网络预测的速度场，\(c\) 是文本或其他条件。优化动作是让网络在任意中间时刻 \(t\) 预测“从噪声态到干净图像的速度”\(\epsilon-x_0\)。工程对应：这是 Qwen-Image-2.0 预训练阶段已经完成的目标；本文所有 RL 和 OPD 都假设这个基础速度场已经足够好，只需在人类偏好维度做小步修正。

**多奖励优势（式 (13)）**

\[
A(x_0^{(i)},c)=\sum_{k=1}^{K} w_k\cdot\frac{R_k(x_0^{(i)},c)-\mu_k}{\sigma_k}
\]

变量：\(R_k\) 是第 k 个奖励模型的分数；\(\mu_k,\sigma_k\) 是在同一个提示 c 生成的 G 张图像中，该奖励的均值和标准差；\(w_k\) 是权重，满足 \(\sum_k w_k=1\)。优势 A 是归一化后的加权和。直觉：如果不归一化，一个天然分数范围 1–5 的人像奖励很容易被范围 0–100 的美学奖励压过，导致某些维度永不更新。组内归一化还能自动适应不同提示的难度：对于容易或困难的提示，优势尺度保持一致。工程对应：在异步奖励管线返回后，必须按 prompt group 分桶求统计量，再跨 rank 聚合。论文强调“per-prompt-group normalization is critical”，因为不同奖励模型的数值范围差异巨大，若不归一化，单一奖励会主导优势信号。

**OPD 损失（式 (14)）**

\[
L_{\text{OPD}}=\mathbb{E}_{c,x_{[1:N]}\sim\pi_\theta(\cdot|c)}\left[\sum_{n=1}^{N}\|v_\theta(x_{t_n},t_n,c)-v_{\theta^*}(x_{t_n},t_n,c)\|^2\right]
\]

变量：\(N\) 是离散时间步数，\(x_{t_n}\) 是学生策略 \(\pi_\theta\) 自生成轨迹上的点；\(v_\theta\) 是学生模型，\(v_{\theta^*}\) 是任务对应教师。优化动作是让学生在每个自身经过的中间态上逼近教师的预测速度。直觉：这与老师给学生改错题类似。学生自己先做一遍题（自己生成噪声态），老师在学生做错的步骤上给出正确速度，学生朝老师的方向修正自己。为什么不用教师轨迹？因为学生分布与教师分布不同，只在学生自己走过的路径上学习可以减少分布偏移。附录 A 从 Wasserstein-2 上界推导了这个目标：在教师速度场 Lipschitz 正则性假设下，\(W_2(p_0^\theta,p_0^{\theta^*})\) 被一个包含 \(\mathbb{E}_{x_t\sim p_t^\theta}\|v_\theta-v_{\theta^*}\|^2\) 的指数上界所限制，因此最小化速度 MSE 等价于最小化输出分布距离的上界。

## 6. 训练到底怎么跑

训练不是单一循环，而是先并行训练两个教师，再做 OPD 蒸馏。

**一条 T2I RL 训练 step**：

1. 从已经过筛选的提示池中抽一批提示 c。每个提示属于某语义类别，携带对应类别的奖励权重向量 \(w_k\)。筛选过程已在训练前完成：对每个候选提示，base 模型做 G 次 rollout，计算组内奖励范围，只保留范围超过阈值的提示。
2. 当前策略网络（初始化自 base）在 rollout 阶段开启 CFG，用 40 步 ODE 生成 G 张候选图像 \(x_0^{(1)},\dots,x_0^{(G)}\)。40 步 ODE 是 rollout 的具体步数，但训练目标不会应用于全部 40 步。
3. 每张图像和提示 c 被后台线程异步提交到远程 VLM 奖励 API。此时 GPU 可以继续处理其他批次或等待返回。远程 API 返回后，所有 rank 同步收集分数。
4. 等所有 rank 的奖励响应返回后，对每个奖励模型 \(R_k\)，在每个提示组内计算均值 \(\mu_k\) 和标准差 \(\sigma_k\)。这一步严格按 prompt group 分桶，不能全局统计。
5. 用公式 (13) 计算每张样本的复合优势 \(A\)。
6. 从 40 个 rollout 时间步中取子集，偏向高噪声端；对选中的时间步计算 Flow-GRPO 的 clipped surrogate 损失。此时关闭 CFG，只更新条件分支。具体哪个时间步子集论文未明确披露，但说明“特别强调高噪声时间步（更接近 t=1）”。
7. 优化器反向更新策略参数，完成一步。之后策略可以继续下一轮 rollout。如果不开时间步子集限制，全 40 步训练会在几个迭代内导致 rapid reward hacking 和退化。

**编辑 RL 训练 step** 与 T2I 类似，但输入是源图像和编辑指令，奖励 API 返回指令遵循和人脸身份保持分数。指令遵循奖励会把指令分解成核心编辑要求和非核心辅助要求，对编辑结果按三层结构判断：核心指令是否完成、非核心需求是否处理、整体视觉是否连贯。人脸身份保持奖励由专门的人脸身份评分模型提供，它输出嵌入级一致性，弥补 VLM 在细粒度人脸识别上的不足。

**OPD 蒸馏 step**：

1. 学生模型从 base 初始化，参数 \(\theta\) 可训练。两个教师模型已经训练完毕，分别为 T2I 教师和编辑教师。
2. 对一个 batch，每个样本带任务标签（T2I 或编辑）。根据标签选择活跃教师：如果当前是 T2I 样本，加载 T2I 教师到 GPU；否则加载编辑教师。另一教师保持在 CPU 或卸载状态，以节省显存。论文称这种动态教师激活允许使用多个大教师模型而不按比例增加 GPU 显存。
3. 学生模型关闭 CFG，从 \(x_{t_0}\sim N(0,I)\) 开始，用 N 步 ODE 生成轨迹 \(\{x_{t_0},x_{t_1},\dots,x_{t_N}\}\)，并将每个中间态保存。N 是离散步数，论文没有给出具体值，但 rollout 阶段为 40 步。
4. 对每个轨迹点 \(x_{t_n}\)，使用对应教师预测速度 \(v_{\theta^*}(x_{t_n},t_n,c)\)。教师此时使用 CFG，学生不使用。这是因为教师原本是在 CFG 下训练的，保留 CFG 能让它充分表达预训练能力；而学生最终要学习没有 CFG 的条件速度场，之后再整合 CFG 用于推理。
5. 用公式 (14) 计算学生速度与教师速度的 MSE，反向更新学生参数。该损失是沿学生自身轨迹的逐点速度匹配。
6. 切换下一个 batch 的任务类型，按需要加载/卸载教师。最终得到统一模型。论文说明 OPD 之后学生模型也会整合 CFG 用于推理。

这个训练策略的关键约束是：RL 阶段不能用 CFG 训练，但 rollout 必须用 CFG；异步管线必须做好 rank 间同步，否则某 rank 先拿到奖励会导致数据错位；教师切换要保证 GPU 显存峰值不超过单教师模型大小。论文没有披露学习率、batch size、训练步数、数据规模或优化器细节，因此复现仍有不确定性。

## 7. 推理到底怎么跑

推理阶段已经没有奖励模型、没有教师、也没有异步管线。最终 Qwen-Image-2.0-RL 是单一模型，推理流程与常见流匹配模型一致，但使用 OPD 后整合进来的 CFG。

**T2I 推理顺序**：

1. 输入文本提示 c。条件编码器将 c 编码成模型需要的条件表示。论文未给出编码器细节，但依据 Qwen-Image-2.0 背景，应是多模态基础模型。论文指出统一架构支持 T2I 和编辑，因此编码器可以处理文本和图像。
2. 采样初始噪声 \(x_1\sim N(0,I)\)，时间从 \(t=1\) 开始。
3. 对每一步 \(n\)，从 \(t_n\) 向前一步 \(t_{n-1}\)，按概率流 ODE 更新：
   \[
   x_{t_{n-1}}=x_{t_n}+(t_{n-1}-t_n)\,v_{\theta}^{\text{cfg}}(x_{t_n},t_n,c)
   \]
   其中 \(v_{\theta}^{\text{cfg}}\) 是 CFG 组合后的速度。步数在 rollout 中为 40，推理阶段论文未明确披露步数，但不排除沿用或减少。
4. 重复到 \(t\approx 0\)，得到潜空间干净表示，再解码为最终图像。论文未给出 VAE 细节。

**图像编辑推理**：

1. 输入源图像和编辑指令。源图像先编码为潜表示；条件编码器同时处理指令和图像上下文。
2. 从噪声出发解 ODE，初始条件为源图像/图像条件。编辑任务使用同一统一模型，但条件输入包含源图像；速度网络在每一步接收 \(c=(source, instruction)\)。
3. 逐步去噪到 t≈0，生成编辑后的图像。

推理不依赖远程奖励 API，因此延迟主要由 ODE 步数、网络前向和 CFG 叠加决定。论文没有给出端到端延迟或推理步数，所以无法做出精确成本判断。对于编辑任务，身份保持依赖模型已经通过 reward 训练和 OPD 内部化的表示，不再需要额外的人脸识别模块。综合来看，最终模型是单模型、单次推理，相比训练流程大幅简化，但 CFG 的计算开销仍然存在。

## 8. 实验和消融到底证明了什么

论文的证据分为整体基准提升、人类偏好提升、奖励范式消融、CFG 策略消融和 OPD 对 Mix-RL 的定性对比。Qwen-Image-Bench 是一个创造者导向的基准，由 5 个一级支柱（Quality, Aesthetics, Alignment, Real-world Fidelity, Creative Generation）和 56 个三级维度组成，由 Q-Judger 评估，Q-Judger 训练于超过 130K 人类标注的图文对，标注者来自 80 位专业艺术家。

| 实验/对比 | 数据集/基准 | 指标 | 对照 | 结果与结论 | 锚点 |
|---|---|---|---|---|---|
| T2I 整体质量 | Qwen-Image-Bench | Overall 分（0–100） | Qwen-Image-2.0-Base vs RL | 55.23 → 57.84，+2.61；五个一级支柱均提升，最大增益：Creative Generation +6.72，Real-world Fidelity +4.29 | Table 1 |
| T2I 人类偏好 | text-to-image arena | Elo 评分 | Qwen-Image-2.0-Base vs RL | 1115 → 1193，+78；3D +93，Photorealism +91；八个子类别均提升 | Figure 4 |
| 编辑人类偏好 | image edit arena | Elo 评分 | Qwen-Image-2.0-Base vs RL | 1256 → 1349，+93 | Figure 4 |
| 奖励训练范式 | 自建共享 AIGC 图像池的两套注释数据 | 视觉质量、伪影 | pairwise vs pointwise | pointwise 输出更少伪影、纹理更细 | Figure 2 |
| CFG 策略 | 代表性文本提示 | 训练稳定性、风格保持 | CFG both / no CFG / rollout only | rollout only 保持稳定且不遗忘预训练知识 | Figure 3 |
| OPD vs Mix-RL | T2I 和肖像编辑场景 | 纹理、指令、身份 | Base vs Mix-RL vs OPD | OPD 一致优于 Mix-RL，避免跨任务冲突 | Figure 5/6 |

**Table 1 的具体分数**：Base 在 Quality 52.29、Aesthetics 57.10、Alignment 57.64、Real-world Fidelity 47.54、Creative Generation 58.22，总分 55.23；RL 后依次为 54.39、58.67、59.28、51.83、64.94，总分 57.84。虽然整体仍低于若干商业基线（如 GPT Image 2 的 64.69、Nano Banana 2.0 的 59.82），但相对自身提升明确，并且超过 Seedream 4.5 的 56.78 与 Seedream 5.0 的 57.22。

**最关键消融**：论文中最关键的消融是混合 CFG 策略，因为它直接决定训练能否进行。Figure 3 显示：如果用“rollout 和训练都开 CFG”，训练会不稳定，图像最终完全崩溃；如果“两者都关”，奖励分虽然上升，但模型逐渐丢失风格能力和世界知识，例如无法再现名人外观；只有“rollout 开 CFG、训练关 CFG”才能同时保持训练稳定和预训练能力。这个结论支撑了整个 RL 框架的可行性。

第二个关键消融是 OPD 对比 Mix-RL。Figure 5/6 显示 Mix-RL 已经比 base 更好，说明奖励套件本身有效；但 OPD 模型在纹理细节、提示符合度、面部身份保持上又优于 Mix-RL。这支持论文的中心设计：任务分解 RL 再蒸馏，而不是把所有任务和奖励放在一个 RL 循环里。Mix-RL 在复杂编辑下仍有身份漂移或不完整编辑，而 OPD 表现更稳定。

**尚未证明的主张**：论文没有给出奖励模型自身的注释一致性、与人类评分的相关系数或奖励模型评估误差；没有报告点式与成对奖励模型在 RL 后 Qwen-Image-Bench 或 Elo 上的定量差异，只有 Figure 2 的定性图片。论文也没有给出 prompt curation、timestep subset、per-category calibration 各自的定量消融；这些组件的贡献被整体结果覆盖，但无法单独归因。此外，论文没有报告训练步数、学习率、数据量或计算资源，因此“可扩展”和“全参数训练”的具体条件和上限难以判断。定性图只展示了个例，缺乏统计显著性检验。

## 9. 与前作怎么选

**Flow-GRPO（Liu et al., 2026a）**：将流匹配轨迹视为 MDP，引入等价随机采样器和 importance ratio。本文的 RL 基础框架直接继承它，采用 clipped surrogate 目标。适合：单任务 T2I、单奖励或少数奖励、LoRA 或小规模实验、希望快速实现在线 RL。不适合：需要同时处理 T2I 和编辑的多任务部署，因为原始 Flow-GRPO 不解决任务合并，也没有本文的 hybrid CFG 和多奖励组归一化细节。

**DiffusionNFT（Zheng et al., 2025）**：用前向扩散过程构造正负速度预测，并把奖励缩放到 [0,1] 后加权两个方向，再加 KL 惩罚。适合：希望避免重要性采样方差、不把去噪轨迹显式当作 MDP、需要在优化中显式约束离参考策略不远。不适合：如果希望用 GRPO 的组内归一化多奖励机制，或者需要 OPD 教师蒸馏，本文方案更完整。

**Flow-OPD / DiffusionOPD（Fang et al., 2026; Li et al., 2026b）**：这两个是并发工作，扩展 OPD 到流匹配，但论文明确说它们主要面向单奖励 T2I 教师。本文不同在于按任务类型划分教师（T2I 和编辑），并从 Wasserstein-2 上界推导目标。适合选本文：有多个异质任务需要合并，并且任务间奖励容易冲突。不适合选本文：如果只有 T2I 教师、单奖励、资源紧张，外部 OPD 实现可能更简单。另外还有 AWM（Xue et al., 2025）和 GRPO-Guard（Wang et al., 2025a），它们分别关注前向过程在线 RL 和过优化防护，但论文没有将其作为方法基础，只是相关文献。

**Mix-RL**：把 T2I 和编辑数据与所有奖励混在一起联合 RL。优点是工程简单，只需一个模型和一个训练循环；缺点是不同任务目标互相拉扯，容易产生次优折中。Fig 5/6 支持这个判断。适合：任务间天然接近、领域差异小，或预算不允许维持多个教师。不适合：需要同时高强度优化 T2I 美学和编辑身份保持的生产级系统。论文的 OPD 还消除了后续推理对奖励模型的依赖，这是相对于 Mix-RL 的部署优势。

## 10. 工程判断：可行性、风险与上限

**数据**：论文没有披露训练数据规模、提示数量、注释数据量或类别分布。从描述可知：点式注释数据的图像来自“高质量 AIGC 模型池”，提示采样自高质量人像参考并重写；成对注释也有类似来源。点式注释包含质量与保真度两个维度：质量评估清晰度、光照、色彩平衡、风格一致性、材质纹理；保真度评估结构正确性、物理一致性、无 AI 伪影（如非自然平滑或纹理重复）。成对注释遵循严格优先级：图文一致性 > 结构失真 > 纹理质量 > 美学吸引力。这意味着数据分布偏向已有人工生成审美，可能引入模型偏置。如果目标应用是照片级真实世界图像，需要额外验证。编辑指令的具体覆盖类型也只提到物体替换、属性修改和风格迁移，未列出更复杂布局或多人身份等场景。

**算力与延迟**：论文明确说明了异步奖励管线可以隐藏远程 VLM API 延迟，但未给出端到端训练时间、GPU 数量、显存占用或奖励 API 的吞吐量。全参数 RL 加上两个教师和远程奖励模型，成本大概率很高。OPD 使用动态教师激活，降低显存峰值，但切换教师时会引入 CPU-GPU 数据传输开销。训练与推理均涉及 40 步 ODE 在 rollout 阶段，但最终推理步数未披露。如果推理步数保持 40，CFG 叠加会增加双倍前向计算，延迟可能比 base 更高；如果步数减少，则可能牺牲质量。

**实现难点**：第一，多奖励归一化必须严格按 prompt group 计算，异步管线跨 rank 同步若出现不一致，优势就是错位数据。第二，hybrid CFG 需要在 rollout 图和训练图之间切换，且确保训练时只有条件分支获得梯度；框架必须支持同一模型的两套前向配置。第三，奖励模型本身可能给出噪声或错误高分，尤其在编辑任务中，VLM 对细粒度身份保持的误差需要额外模型补偿。第四，OPD 多教师需要可靠的任务标签和调度策略，否则一个 batch 加载错教师会导致梯度污染。第五，异步远程 API 如果没有超时与重试机制，一个节点故障会导致训练挂起。

**失败环节**：最可能的失败是奖励黑客。如果某个奖励模型存在容易利用的捷径，例如用高对比度或过锐化来刷美学分数，“全部时间步训练会导致快速 reward hacking”（论文已提到）。减少训练时间步只是缓解，不保证根除。另一个风险是复杂编辑下的身份漂移，Figure 6 显示 Mix-RL 的 Face ID 不如 OPD，但 OPD 也可能在未知身份上退化。在没有定量消融的情况下，prompt curation 阈值和类别权重的设置可能对结果高度敏感，但论文未给出具体值。

**监控信号**：论文未列出明确监控指标。根据其流程，实践中应监控每个奖励模型的组内均值与方差、优势分布、复合奖励趋势、Qwen-Image-Bench 或 Elo 的周期性评估、CFG 开启与关闭时梯度范数，以及异步队列长度。若发现单一奖励均值持续上升而其他奖励下降，可能提示权重校准失效。若组内方差趋近 0，可能说明策略坍缩或提示池失去多样性。此外，OPD 阶段应监控学生速度与教师速度的 MSE 是否下降，以及教师切换后的 loss spikes。

**指标上限与未回答问题**：Table 1 显示 Qwen-Image-2.0-RL 的 57.84 仍明显低于 GPT Image 2 的 64.69、Nano Banana 2.0 的 59.82，说明对齐流程尚未触及架构或数据规模带来的上限。人类 Elo 虽大幅提升，但没有绝对成功率或错误率。论文未回答：奖励模型准确率和偏差多大？数据规模与训练步数多少？时间步子集如何选择？prompt curation 阈值和类别权重具体值？OPD 是否在每个任务的单教师分数上有所损失？最终推理步数和 CFG 权重是多少？这些缺口意味着复现和成本估算仍有很大不确定性。虽然论文展示了完整系统，但缺乏可复现的实验配置和定量消融，工程落地仍需大量内部调参。

## 11. 放回研究脉络并收束

这条工作座落在三条研究脉络的交汇处。第一条是扩散模型从 DDPM 到 latent diffusion 再到 flow matching，Qwen-Image-2.0 本身已经是 VLM 条件编码器的大规模产物。第二条是 RLHF 从 LLM 普及后迁移到扩散模型：Flow-GRPO 建立了流匹配的 GRPO 形式，DiffusionNFT 给出前向过程目标，GRPO-Guard 关注过优化，AWM 引入前向过程在线强化；本文在此基础上补足多任务、多奖励和全参数训练实践。第三条是蒸馏从 LLM 的 GKD 扩展到流匹配的 OPD；Flow-OPD 和 DiffusionOPD 是并发工作，而本文用多教师任务分解和 W2 上界推导做了差异化整合。

**读完必须记住的 5 件事**：

1. T2I 和编辑使用不同的复合奖励：T2I 是对齐、美学、人像；编辑是指令遵循、人脸身份保持。奖励模型是 VLM 点式评分，输出 1–5 的期望，配合思维链注释；点式注释提供绝对校准，优于成对偏好。
2. CFG 只在 rollout 中开启，训练优化目标关闭 CFG。三个策略中只有这个能避免崩溃和知识遗忘，因为 CFG 关闭可稳定梯度，并且不会在训练阶段破坏条件分支。
3. 多奖励优势必须按同一个 prompt 组归一化后加权，否则数值范围大的奖励会主导训练。公式 (13) 中的 \(\mu_k,\sigma_k\) 是在同一提示的 G 张图像内计算的，这一点至关重要。
4. OPD 是统一两个教师的关键：学生从 base 初始化，在自己生成的轨迹上匹配任务对应教师的速度；教师用 CFG，学生不用。OPD 避免了 T2I 与编辑目标的直接冲突，并且消除了部署模型对奖励 API 的依赖。
5. 评估上 Qwen-Image-Bench 从 55.23 到 57.84，T2I Elo +78，编辑 Elo +93；任务分解 RL + OPD 优于混合 RL，尤其在 Creative Generation 和 Real-world Fidelity 支柱上增益最大。

**5 道自测题**：

1. 为什么点式奖励训练比成对奖励训练在本文中更好？预期回答：点式分数提供绝对质量校准信息，编码“有多好”，成对偏好只告诉相对好坏，信号更弱；因此点式训练的奖励模型用于 RL 后生成图像伪影更少、纹路更细（Figure 2）。
2. 如果 CFG 在训练和 rollout 都用，会发生什么？预期回答：训练不稳定，图像最终崩溃（Figure 3）。原因是联合优化条件与无条件分支导致梯度问题。
3. 公式 (13) 中 \(\mu_k,\sigma_k\) 在哪里计算，为什么不能全局算？预期回答：每个 prompt 组内算，确保不同提示难度和不同奖励尺度下优势可比，避免单一奖励主导；全局统计会忽略提示内奖励差异，丧失组内相对优势信息。
4. OPD 损失匹配的是学生轨迹还是教师轨迹上的速度？为什么？预期回答：学生自生成轨迹，因为学生分布与教师不同，在自身路径上修正可以减少分布偏移；附录 A 从 Wasserstein-2 上界推导，速度 MSE 沿学生路径积分给出输出分布距离的界。
5. 从 Table 1 看，RL 后提升最大的两个一级支柱是什么，各提升多少？预期回答：Creative Generation +6.72（从 58.22 到 64.94），Real-world Fidelity +4.29（从 47.54 到 51.83）。

一句话总结：Qwen-Image-2.0-RL 通过任务专用复合奖励、hybrid CFG 的 RL 训练，以及基于自身轨迹速度匹配的多教师 OPD，把两个偏好方向压进一个部署模型；它清晰地展示了从预训练到人类偏好对齐的工程路径，但数据规模、奖励模型可靠性和最终性能上限仍留待后续回答。
