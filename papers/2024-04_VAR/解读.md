# 大白话深读《VAR》

## 1. 30 秒定位

VAR（Visual AutoRegressive Modeling）提出一种新的图像自回归生成范式：不再像 VQGAN、DALL-E、RQ-Transformer 那样，把图像离散 token 按“从左到右、从上到下”的扫描顺序逐 token 预测，而是按分辨率从粗到细做“下一尺度预测”。它把图像编码成多尺度离散 token 图，比如 256×256 图像在最终 latent 分辨率 16×16 下，生成过程从 1×1 的粗尺度开始，每一步基于前面所有更粗尺度，并行预测下一整张更细尺度 token 图；Table 1 显示 #Step=10，论文未逐层列出完整分辨率序列，但明确从 1×1 token map 开始（§1、Figure 2(c)）。训练分两阶段：先训练多尺度 VQVAE，再训练 GPT-2 风格的 decoder-only Transformer。实验上，VAR-d30 在 ImageNet 256×256 类条件生成上达到 FID 1.92，配合拒绝采样后 FID 1.73、IS 350.2；而 VQGAN AR 基线 FID 是 18.65、IS 80.4。论文称这是 GPT 式自回归模型首次在该基准上超过 DiT、L-DiT 等强扩散模型，同时推理速度约为 VQGAN 的 20 倍、DiT-XL/2 的 45 倍（§5.1、Table 1）。在 512×512 类条件生成上，VAR-d36-s 达到 FID 2.63、IS 303.2，同样优于 DiT-XL/2 的 FID 3.04、IS 240.8（Table 2）。论文还展示 18M–2B 参数范围内模型规模与最优训练算力上的幂律缩放，Pearson 相关系数接近 −0.998（Figure 5/6），并对 in-painting、out-painting、class-conditional editing 任务给出零样本可视化结果（Figure 8）。

## 2. 为什么这篇论文会出现

论文的出发点是：语言模型 GPT 系列的成功依赖“下一 token 预测”这一自监督目标，它带来两个关键性质——缩放律和零样本泛化。视觉社区希望把类似 AR 模型用于图像生成，但结果不理想。VQGAN、ViT-VQGAN、RQ-Transformer 等沿用 raster-scan 的逐 token 顺序，将 2D token grid 按 row-major raster scan、spiral 或 z-curve 等策略 flatten 成 1D 序列（§3.1），性能远落后于扩散模型。论文在 Introduction 与 Related Work 中明确指出的问题不是“AR 不行”，而是“图像 AR 的顺序定义有问题”。它总结了 vanilla AR 在图像上的四个缺陷：一是数学前提违背，VQVAE 编码器产生的 token 之间存在双向依赖，但自回归假设只能依赖前缀，论文在 Appendix A 用 VQGAN 编码器最后一个自注意力层的 attention heatmap 展示了这种双向依赖（Figure 9）；二是零样本泛化受限，无法根据图像下半部分预测上半部分；三是拉平操作破坏空间局部性，比如 2D 邻居 token q(i,j±1)、q(i±1,j) 在 1D 序列中被拉远；四是复杂度高，生成 n×n token 需要 O(n²) 个自回归 step、总计算 O(n⁶)，论文在 Appendix B 给出证明。Figure 3 显示，既有 AR 模型在 ImageNet 256 上 FID 显著差于 DiT 和 L-DiT 等扩散模型；例如 VQGAN FID 18.65 vs DiT-XL/2 2.27（Table 1），AR 路线长期被扩散压制。与此同时，人类通常先捕捉全局结构、再补充局部细节，这种 coarse-to-fine 特性给出了一种图像“顺序”的自然定义。论文也受多尺度设计，如 SIFT [54]、FPN [52]、progressive GAN [44]、稀疏分层 mask 建模 [81] 的启发。因此，论文的核心动机是：通过重新定义图像数据的“顺序”，让 AR Transformer 摆脱不适合 2D 结构的线性扫描假设，并在图像生成上恢复 LLM 式的缩放与泛化能力。相关工作中还指出 MaskGIT、MagViT、MUSE 等 BERT 式 masked-prediction 模型以及 DiT、U-ViT 等扩散 Transformer 路线；VAR 希望形成第三条严格 AR 的视觉生成路线，并首次在类条件 ImageNet 上超越扩散 Transformer。论文还提及 Parti 基于 ViT-VQGAN 扩展到 20B 参数但工作受限，说明传统 AR 即使扩规模也没有解决顺序问题。VAR 的提出是把这些多尺度思想与自回归结合，重新定义视觉生成中的归纳偏置。

## 3. 读懂前需要的最小概念

需要理解四个基础概念。第一，自回归建模。序列 x=(x₁,…,x_T) 的概率被分解为 p(x)=∏ₜ p(xₜ|x₁,…,xₜ₋₁)，即 Equation (1)。语言模型里的“下一 token 预测”就是优化这个条件概率。图像是连续 2D 信号，必须先离散化。第二，VQVAE。编码器 E 输出特征图 f∈R^{h×w×C}；量化器 Q 把每个空间位置 f(i,j) 映射到词典 Z∈R^{V×C} 中最近邻码本向量的索引，即 q(i,j)=arg min_v ‖lookup(Z,v)−f(i,j)‖²（Equation 3）；解码器 D 用查表得到的近似特征重建图像。训练 VQVAE 使用重建损失、特征损失、感知损失和判别器损失的复合损失，见 Equation (5)。在 VQVAE 中，每个码本向量维度是 C，V=4096；量化器的输出是整数索引，因此后续 AR 模型可以把它当作离散 token。第三，多尺度 token 图。VAR 不把 token 拉平成一维，而是把特征图表示成一系列分辨率递增的离散 token 图 R=(r₁,r₂,…,r_K)，其中 r_k∈[V]^{h_k×w_k}，r_K 对应最终 latent 分辨率。所有尺度共享同一个码本，V=4096；不同尺度之间的差异来自分辨率和残差更新，而不是不同词典。论文未给出每个 h_k,w_k 的具体数值，但推理步数 K=10（Table 1），开始于 1×1（§1），256×256 输入最终 latent 为 16×16（§4 的 downsample ratio=16）。第四，Transformer 与 AdaLN。VAR 使用类似 GPT-2 的 decoder-only Transformer，采用自适应 LayerNorm（Adaptive Layer Normalization, AdaLN）注入类别条件，并把类别 embedding 作为 start token [s]。AdaLN 在标准 LayerNorm 基础上增加可学习的 scale 和 shift 参数，这些参数由类别 embedding 通过一个 MLP 生成；这样类别信息不是只出现在序列起点，而是调节每个 Transformer block 的归一化。需要注意，VAR 的“自回归单元”不是单个 token，而是整张 token 图；每个 r_k 内部所有位置可以在当前 step 并行生成，但 r_k 整体只能依赖 r_{<k}。训练时用 block-wise causal attention mask 强制这种依赖：同一尺度块内允许全注意力，跨尺度保持因果；推理时因为不生成未来尺度，无需 mask，可用 KV cache。理解这四点后，后续数据流和公式会自然展开。最后还需知道，论文在 Transformer 中归一化 query 和 key 到单位向量，以稳定训练（§4），这属于训练技巧而不是架构必需。

## 4. 方法全景：先看数据流

VAR 训练分两个完全分离的阶段，两阶段之间的数据流如下：

```
阶段 1：训练多尺度 VQVAE（Algorithm 1 / 2 和 Figure 4 左）
原始图像 im
  │ 编码器 E
  ▼
连续特征 f ∈ R^{h×w×C}
  │ 循环 k=1..K
  ▼
r_k = Q(interpolate(f, h_k, w_k))     ← 把当前 f 插值到第 k 尺度并最近邻量化
  │ 查表 z_k = lookup(Z, r_k)         ← 取 r_k 对应码本向量
  ▼
z_k 上采样到最终分辨率 h_K×w_K
  ▼
残差更新：f ← f − φ_k(z_k)           ← 用第 k 个卷积 φ_k 重构该尺度贡献，并从 f 中减掉
  │ 收集 R=(r₁,…,r_K)
  ▼
重建阶段（Algorithm 2）：f̂ = 0
  │ 对每个 r_k：查表、上采样、过 φ_k、累加 f̂ ← f̂ + φ_k(z_k)
  ▼
解码器 D
  ▼
重建图像 îm；VQVAE 总损失 L = ‖im−îm‖² + ‖f−f̂‖² + λ_P L_P(îm) + λ_G L_G(îm)（Equation 5）
```

```
阶段 2：训练 VAR Transformer（Figure 4 右和 Equation 6）
训练输入：[s] 类别 start token + r₁ + r₂ + … + r_{K−1}
  │ 每个 token：word embedding + 尺度/位置 embedding
  │ 论文提到 “word embedding and up-interpolation”，但未披露尺度间对齐的具体实现
  ▼
VAR Transformer（decoder-only；AdaLN 条件来自类别 embedding）
  │ block-wise causal attention mask：
  │   第 k 个尺度的位置只能注意 r_{≤k}；每个 r_k 内部允许全注意力
  ▼
输出：对每个前缀位置预测下一尺度 token 图的 logits
  │ 第 k 个尺度输出 h_k×w_k 个位置、每个位置 V=4096 的 logits
  │ 逐位置 softmax 交叉熵
  ▼
优化目标：最大化 ∏_{k=1}^{K} p(r_k | r_1,…,r_{k-1})（Equation 6）
```

组件拆解：

**多尺度量化编码器**：对应 Algorithm 1。输入连续特征 f，输出多尺度离散 token maps R=(r₁,…,r_K)。具体循环：第 k 步先 interpolate(f,h_k,w_k)，再做最近邻量化得到 r_k；r_k 查表得到 z_k；z_k 上采样到最终分辨率 h_K×w_K；再用第 k 个卷积 φ_k 变换并从 f 中减去 φ_k(z_k)，作为下一尺度量化的输入。目的：让 r_k 主要编码前 k−1 个尺度尚未表示的残差信息。假设：粗尺度先捕获全局结构，细尺度补局部细节，残差式编码比独立多尺度插值更高效。论文称这种残差设计“akin to RQ-Transformer”且比独立插值更好（§3.2 Tokenization），但正文未给出该消融的定量证据。无需在降采样后加卷积。这里的关键是，每个 φ_k 是独立的小卷积层，输出通道数与 f 相同，使 z_k 的上采样结果和 f 对齐后才能相减。

**共享码本**：所有尺度共用 V=4096 的同一个词典。目的：保证跨尺度 token 词汇一致，便于第二阶段统一建模；减少词典参数量。假设：同一个离散符号在不同尺度可以用不同空间上下文表达不同结构。K 个额外卷积 {φ_k} 仅增加约 0.03M 参数（§4）。如果每个尺度独立码本，跨尺度条件概率会需要映射不同词汇表，增加复杂度；共享码本还使得 word embedding 矩阵只需 V×d_model，而不是 K×V×d_model。

**VAR Transformer**：输入不包含当前预测的 r_k，而是给定前缀输出整个 r_k 的预测。每个输入 token 先经 word embedding 和尺度/位置 embedding；论文提到对 query 和 key 做单位向量归一化以稳定训练（§4），Table 3 也消融了该操作。输出：第 k 个尺度 h_k×w_k 个位置、每个位置 V=4096 的 logits。目标：最大化 Equation (6)。假设：图像分布可以用尺度链式条件分布表达，且每个尺度内部 token 之间没有顺序约束。模型架构是 GPT-2 类 decoder-only，但实际训练时输入序列包含多个尺度的 token，长度不是固定为最终 token 数，而是前缀尺度 token 的累计和。对于 256×256 输入，最终 latent 16×16，如果分辨率按 2 倍递增，则前缀 token 总数接近 1²+2²+4²+8²+16²=341（论文未明确此序列，只用于理解计算量）。

**Block-wise causal attention mask**：训练时限制注意力，保证第 k 个尺度只能注意 r_{≤k}；尺度块内部允许双向注意力。目的是将图内并行性和图间自回归性统一。推理时由于生成当前尺度时前缀已知且未来尺度不可见，因此可以去掉 mask 并用 KV cache。这一机制是 VAR 能并行生成整张 token 图的原因。块大小不同，实际实现需要构造分块对角上三角形式的 attention bias，不是普通单 token 因果 mask。

**AdaLN 与类别 start token**：类别信息同时进入 start token [s] 和 AdaLN 的 scale/shift 参数。目的：让类别条件同时作用于序列初始状态和每个 Transformer block 的归一化。假设：双路条件注入比仅输入 token 更稳定有效。Table 3 显示，在 VAR-d16 上加 AdaLN 后 FID 从 5.22 降到 4.95。512×512 的 VAR-d36-s 因资源限制，使用单个共享 AdaLN 替代所有 block 独立 AdaLN，参数量大幅减少（脚注 3）。这说明 AdaLN 对质量有帮助，但共享版本在 512 上仍有效，说明条件注入有一定冗余。

## 5. 核心公式与直觉

**公式 6：下一尺度预测的似然**

\[
p(r_1,\dots,r_K)=\prod_{k=1}^{K} p(r_k|r_1,\dots,r_{k-1})
\]

变量：r_k∈[V]^{h_k×w_k} 是第 k 个尺度的 token 图，V=4096；前缀 (r_1,…,r_{k-1}) 是尺度链式条件。优化动作：Transformer 对第 k 个尺度输出 h_k×w_k 个位置、每个位置 4096 类的 logits，在每个位置独立做 softmax 交叉熵。工程对应：这不是逐 token 的链式分解，而是尺度级链式分解；每一步内部并行为每个 token 生成分布，因此生成步数从 raster AR 的 h_K×w_K（对 256×256 最终 latent 为 256）降到 K=10（Table 1 #Step）。注意公式 6 仍是一种自回归分解，但单元从 token 变成尺度，因此条件分布不是单 token 的条件概率，而是整张尺度 token 图的联合条件分布。Block-wise causal mask 训练时保证每个 r_k 的输出只依赖 r_{≤k}，推理时天然满足。这个公式暗示每个尺度内部 token 的联合分布不需要进一步分解，因此属于“整图生成”，这也保留了二维空间局部性。

**公式 5：VQVAE 复合损失**

\[
L = \|im-\hat{im}\|^2 + \|f-\hat f\|^2 + \lambda_P L_P(\hat{im}) + \lambda_G L_G(\hat{im})
\]

变量：im 原图，îm 重建图；f 编码特征，f̂ 残差累积特征；L_P 感知损失（LPIPS，Equation 5 中引文 [97]），L_G 判别器损失（StyleGAN 判别器损失），λ_P、λ_G 是损失权重。优化动作：端到端训练编码器 E、量化器 Q、解码器 D 以及 K 个卷积 φ_k。工程对应：该损失沿用 VQGAN baseline，保证多尺度 token 能重建足够好的图像；四项分别约束像素级重建、特征级重建、感知相似度和对抗真实性，例如 λ_P L_P 惩罚视觉纹理偏差，λ_G L_G 用判别器促进高频细节。若 tokenizer 重建能力不足，第二阶段 VAR Transformer 即使完美也会受限于 token 表达瓶颈。论文未披露 λ_P、λ_G 的具体数值，但指出 loss 与 VQGAN 训练协议一致。

**公式 7/8：模型形状与参数量**

\[
w=64d,\quad h=d,\quad dr=0.1\cdot d/24
\]

\[
N(d)=d\cdot 4w^2 + d\cdot 8w^2 + d\cdot 6w^2 = 18dw^2 = 73728d^3
\]

变量：d 是 Transformer depth；w 是宽度；h 是注意力头数；dr 是 drop rate。4w² 来自自注意力的 Q/K/V/O 权重，8w² 来自 feed-forward MLP，6w² 来自 AdaLN 相关参数。优化动作：深度 d 线性拉动宽度、头数和 drop rate，使不同尺寸模型保持结构配比。工程对应：d=16、20、24、30 分别对应约 310M、600M、1.0B、2.0B 参数；Table 3 中 d16 基础行因为未开 AdaLN，参数量为 207M。论文脚注 3 还说明 512×512 实验由于资源限制，d36-s 使用单个共享 AdaLN，此时参数约 12dw²+6w²≈49152d³，少于独立 AdaLN 的 73728d³。这里表达了模型形状的可预测缩放，也是 scaling law 实验的基础。

**公式 11/12：参数缩放律**

\[
L_{\text{last}}=(2.0N)^{-0.23},\quad L_{\text{avg}}=(2.5N)^{-0.20}
\]

\[
Err_{\text{last}}=(4.9\times 10^2 N)^{-0.016},\quad Err_{\text{avg}}=(6.5\times 10^2 N)^{-0.010}
\]

变量：N 是参数数量；L 是测试交叉熵损失，下标 last 表示最后一个尺度、avg 表示全局平均；Err 是 token 预测错误率。优化动作：在 12 个模型、18.5M 到 2.0B 参数范围上，对 log N 和 log L / log Err 做线性拟合，Pearson 相关系数接近 −0.998。工程对应：幂律关系允许用较小模型预测较大模型的测试性能，有助于训练前估算资源。论文还给出了最优训练算力 Cmin 的缩放律，例如 L_last=(2.2×10⁻⁵ Cmin)^{-0.13}，L_avg=(1.5×10⁻⁵ Cmin)^{-0.16}（Equation 13/14），并称这些关系在 6 个数量级的 Cmin 上保持，说明大模型在充足数据下往往更计算高效。这些公式是 VAR 声称“初步模拟 LLM 两个重要性质”的核心证据之一，但仅限于 ImageNet 类条件生成范围。还需要说明，这里的损失 L 是 reducible loss 归一化后的结果，与 LLM scaling laws 的定义一致（§5.2 Background）。

## 6. 训练到底怎么跑

训练分两个完全独立的阶段，先训练并冻结 VQVAE，再训练 VAR Transformer。

**阶段 1：多尺度 VQVAE 一轮 step**

第一步，从 OpenImages 抽一张图像，编码器 E 输出连续特征 f，其空间分辨率由输入图像和 downsample ratio 决定；论文对 256×256 生成沿用 16× 空间下采样，因此最终 latent 分辨率是 16×16（§4、§5.2）。第二章 VQVAE 的输入分辨率可能不是固定 256×256，但训练目标是重建任意 OpenImages 图像。第二步，按 Algorithm 1 循环 k=1 到 K：把当前 f 插值到第 k 个目标分辨率 (h_k,w_k)，对每个空间位置做最近邻词典查表得到 r_k；把 r_k 对应的码本向量 z_k 上采样到最终分辨率 h_K×w_K；用第 k 个卷积 φ_k 变换；再从 f 中减去 φ_k(z_k)，作为下一尺度量化的输入。第三步，收集 R=(r₁,…,r_K)。第四步，按 Algorithm 2 重建：f̂ 从 0 开始，对每个 r_k 依次查表、上采样、过 φ_k 并累加，解码 D 得到 îm。第五步，按 Equation (5) 计算复合损失，反向传播更新 E、Q、D 以及 φ_k。值得注意的是，Algorithm 1 和 2 中的插值都是特征层面的，不是 RGB 图像；z_k 上采样到 h_K×w_K 后经 φ_k 再进入残差，因此 φ_k 可以学习不同尺度的上采样误差补偿。论文对该阶段的优化器、学习率、迭代数和总 batch size 未明确披露，只说 VQVAE 架构沿用 VQGAN，码本 V=4096，K 个额外卷积总共约 0.03M 参数，损失和训练协议与 VQGAN baseline 一致。如果读者想复现，需参考 VQGAN [30] 的超参数设置，但 VAR 论文本身没有提供额外细节。

**阶段 2：VAR Transformer 一轮 step**

第一步，从 ImageNet 训练集抽一张带有类别标签的图像，用冻结的 VQVAE 编码器得到 K 个多尺度 token 图 R。第二步，构造预测样本：给定一个预测步 k，输入前缀为 [s]（类别 start token）和 r₁,…,r_{k-1}，每个 token 经过词嵌入和尺度/位置嵌入；论文提到 “word embedding and up-interpolation” 用于尺度间对齐，但未披露具体张量形状和插值方式。实际实现中，不同尺度的 token 图会被 up-interpolation 到最终分辨率或统一序列位置，以进入同一个 Transformer；这个是 VAR 实现的关键细节但论文没有展开。第三步，送入 VAR Transformer。注意力使用 block-wise causal mask：第 k 个尺度的输出位置只能注意 r_{≤k} 的前缀，而每个 r_k 内部位置可以互相注意。第四步，模型输出第 k 个尺度每个位置的 logits，计算 softmax 交叉熵；训练目标由 Equation (6) 给出。实际操作中，同一张图的不同 k 可以构造成不同样本用于并行训练；论文没有明确说明是否在同一前向中一次计算所有尺度的损失，但 Figure 4 显示输入 [s], r₁,…,r_{K−1} 并预测 (r₁,…,r_K)，与 block-wise causal mask 配合时，相当于在序列中每个尺度位置预测下一尺度。因此一个训练样本包含多个预测损失项，分别监督不同尺度的输出。第五步，优化器为 AdamW，β₁=0.9，β₂=0.95，weight decay=0.05；基础学习率 10⁻⁴ per 256 batch size；实际 batch size 为 768–1024，训练 epoch 数 200–350，具体取决于模型大小。模型宽度、头数和 drop rate 遵循 w=64d、h=d、dr=0.1·d/24。论文在 scaling law 实验中训练了 12 个不同深度（d=6 到 d=30）的模型，参数量从约 18.5M 到 2.0B，ImageNet 训练集每个 epoch 1.28M 图像，约 870B image token，最大总 token 数达到 3050 亿（§5.2）。这一阶段没有使用先进 LLM 技术如 RoPE、SwiGLU 或 RMSNorm（§4），说明性能不依赖这些改进。

## 7. 推理到底怎么跑

推理是纯自回归的，但每次自回归步生成一个完整尺度，而不是一个 token。

1. 输入类别标签。类别 embedding 同时作为 start token [s] 和 AdaLN 条件参数；这一类别条件用于后续所有尺度的预测。2. 第 1 步：以 [s] 为输入，生成最粗尺度 token 图 r₁，论文明确生成开始于 1×1 token map（§1、Figure 2(c)）。每个位置输出 V=4096 的 logits，使用 top-k 采样；消融显示 top-k 设置为 600（Table 3）。可选使用 classifier-free guidance（CFG）比率 2.0，这会把推理成本从 0.016 提高到 0.022，但 FID 从 4.64 进一步降到 3.60（Table 3）。CFG 在 VAR 中的实现细节未说明，但一般需要同时前向条件和无条件分支，或调整 logits；论文只报告了比率和成本变化。3. 第 2 步：将 [s] 和已生成的 r₁ 作为前缀，预测 r₂ 的 h₂×w₂ 个 token，所有位置并行采样。这一步会复用上一尺度计算的 KV 缓存，避免重算前缀注意力。4. 重复直到第 K 步，得到完整的多尺度 token 图 R=(r₁,…,r_K)，K=10（Table 1）。每一步的新 token 是下一尺度的所有位置，因此解码步数与尺度数相等。5. 将 R 转化为图像：用冻结的 VQVAE 解码模块 Algorithm 2，对每个 r_k 查表、上采样到最终 latent 分辨率、过 φ_k 并累加得到 f̂，最后由解码器 D 生成 RGB 图像。6. 若执行 in-painting、out-painting 或 class-conditional editing，则在每个尺度上 teacher-force 已知区域之外的真实 token，只对 mask 内部 token 进行采样。in/out-painting 不注入类别标签；class-conditional editing 则按 MaskGIT 的方式注入类别，并只在给定 bounding box 内生成。论文正文说这些任务没有网络修改或参数微调，结果见 Figure 8。这里的 teacher-forcing 意味着在生成每个尺度时，非 mask 区域的 token 直接使用 ground truth 而不是模型采样，以保证边界一致性。7. 推理时可缓存已生成尺度的 KV，新尺度只需计算当前 query；由于没有未来尺度，注意力不需要 block-wise causal mask，天然满足因果。但注意，同一尺度内部仍是全注意力，因此在计算当前尺度时，所有新 token 可以互相看到对方；用户不需要 mask 但需要正确处理位置嵌入，以免不同尺度的相对位置关系丢失。

推理速度方面，Table 1 将 VAR-d30 相对时间记为 1；VQGAN-re 和 VQGAN 分别约为 24 和 19，ViT-VQGAN 为 >24，RQ-Transformer 为 21，DiT-XL/2 为 45，MaskGIT 为 0.5。论文据此给出约 20 倍于 VQGAN、约 45 倍于 DiT-XL/2 的墙钟速度倍数。这些是论文报告的相对时间，具体 GPU 型号和 batch 设置未见完全披露，因此应将倍数视为受测试条件限制的证据。此外，拒绝采样虽然不改变推理步数，但会增加采样次数并造成额外计算成本；论文没有报告拒绝率。

**最关键消融**：Table 3 第一行到第二行把 vanilla raster-scan AR 直接换成 VAR，模型参数量从 227M 到 207M 略有下降，FID 从 18.65 降到 5.22，推理成本降为 0.013×。这是范式贡献的核心证据，说明收益主要来自“尺度顺序”而非复杂增强。后续逐项叠加：加 AdaLN 后 FID 4.95；加 top-k 采样（k=600）后 FID 4.64；加 CFG 比率 2.0 后 FID 3.60；加 query/key 归一化后 FID 3.30；再从 d16 放大到 d30（2.0B）并配合拒绝采样得到 FID 1.73。这个消融的局限是：每行都叠加在上一行之上，没有逐项单独拆除，因此无法精确分配每个增强的独立收益；但足以定位最大单步收益来自 AR→VAR 的范式切换，因为后续所有增强合计带来的 FID 改善（从 5.22 到 3.30）小于第一步的 13.43 下降。另外，Table 3 最后一行使用拒绝采样，但没有给出接受率或采样预算，其 FID 1.73 不能视为与普通采样直接可比。

**数据效率对比**：论文指出 VAR 只需 350 训练 epochs 就达到其最佳结果，而 DiT-XL/2 需要 1400 epochs（§5.1，Efficiency comparison）。这被用来支持 VAR 在数据效率上优于扩散 Transformer。但需要注意，两者训练数据规模和图像分辨率不同；VAR 使用的是 ImageNet 128 万图像，DiT 也使用 ImageNet 但训练细节可能不同，论文没有提供完全等价的对照设置，因此数据效率结论需要在相同 tokenizer 和训练预算下谨慎解读。

**缩放效应的可视化**：Figure 7 比较了 4 个不同大小模型（depth 6、16、26、30）和 3 个训练阶段（20%、60%、100% 总训练 token）生成的 256×256 样本。为保持内容一致，使用相同随机种子和 teacher-forced initial tokens。论文列出的 9 个类别包括 flamingo 130、arctic wolf 270、macaw 88、Siamese cat 284、oscilloscope 688、husky 250、mollymawk 146、volcano 980、catamaran 484。观察结果是更大模型和更多训练计算会提升视觉保真度与结构合理性，与 Figure 5/6 的缩放律趋势一致，但这只是视觉示例，不是定量指标。图中没有提供 FID 数值，因此只能作为定性支持。

**尚未证明的主张**：

1. **零样本泛化只有定性展示**：Figure 8 显示 in-painting、out-painting、class-conditional editing 有合理结果，但没有定量指标（如 FID、LPIPS、编辑一致性得分）、基线或用户研究；因此不能得出“泛化能力达到可生产水平”的强结论。2. **视频生成扩展**：正文 Limitations 明确说视频生成未实现，只是提出多尺度 3D pyramid 的“3D next-scale prediction”设想，并论述其对长时依赖的潜在优势；没有一个视频实现或指标。3. **文本条件生成**：论文称 text-prompt generation 是 ongoing direction，但本工作未实现文本到图像建模；VAR 不等同于文本到图像模型。4. **缩放律只覆盖类条件 ImageNet**：Figure 5/6 的 power law 在 18M–2B、单一数据集、固定 VQVAE tokenizer 下成立；跨数据集、跨任务、替换 tokenizer 或更大规模是否继续保持未验证。5. **“超越 DiT”在特定指标和设置下成立**：FID/IS 和相对时间优于 DiT，但 precision/recall 与 DiT 各有优劣；且 DiT 与 VAR 使用不同 latent 空间和不同训练 epoch 数（VAR 350 epochs vs DiT-XL/2 1400 epochs），FID 不是完全同条件比较。6. **拒绝采样影响**：VAR-d30-re 的 FID 1.73 低于验证集参考 FID 1.78，这可能与拒绝采样的选择偏差有关；论文没有报告接受率或采样预算，因此不能把 “-re” 结果当作标准无条件生成的代表值。论文也没有讨论 VQVAE latent 与扩散 latent 不同可能带来的 FID 偏差。7. **VQVAE 残差设计的消融未给出定量结果**：论文说残差式多尺度量化比独立插值更好，但没有 Table 中的消融支持，属于未验证的工程选择。

## 9. 与前作怎么选

**VAR vs VQGAN / ViT-VQGAN / RQ-Transformer**：这些是 raster-scan 逐 token 的 AR 模型。VQGAN 的 token 顺序生成导致 256 步和较高 FID；RQ-Transformer 用堆叠残差码本减少步数到 68 步，但仍是 token 顺序，速度较慢。VAR 在相同 GPT 式框架下把生成 step 从 256 降到 10，并带来更低的 FID。若任务需要沿用 VQVAE + GPT 类 AR 栈，且目标是快速生成 256/512 类条件图像，可以选择 VAR；若需要依赖已经过于文本到图像生态的模型，则单用 VAR 不够，因为它未实现文本条件。此外，ViT-VQGAN 的 tokenizer 是基于 ViT 的编码器，VAR 没有采用，而沿用 CNN 架构，这也是选择时需要考虑的：如果已有 ViT tokenizer 训练管线，VAR 的迁移需要重新训练多尺度 VQVAE。

**VAR vs MaskGIT / RCG**：MaskGIT 是 BERT 式 masked prediction，通过迭代贪心解码；它不是严格逐 token AR，但也不是粗到细尺度 AR。Table 1 中 MaskGIT #Step=8、相对时间 0.5，速度接近甚至快于 VAR-d30，但 FID 6.18 明显更差。VAR 的优点是严格的 AR 概率分解、可推导的 scaling law 和与 LLM 架构更直接的对齐；缺点是采样时仍需自回归地维护前缀，不像 MaskGIT 可以全局考虑掩码。若任务是图像编辑或 token 补全且需要灵活的双向条件，MaskGIT 可能更简单；若看重 scaling law 和后续 LLM 统一，VAR 路线更契合。论文还指出 RCG 是 self-conditioned 生成，FID 3.49，也不如 VAR 最终模型。

**VAR vs DiT / L-DiT**：DiT 是扩散 Transformer，生成质量稳定，但推理需要 250 步；VAR 在论文报告的 ImageNet 类条件 FID/IS、数据效率（350 vs 1400 epochs）、推理相对时间和模型规模可扩展性上都更优。但 DiT 路线已有 Stable Diffusion 3、SORA 等文本/视频生态，且 latent 扩散有成熟的蒸馏和采样加速方案。若目标是类条件单图生成且重延迟，可以评估 VAR；若目标是文本条件、复杂构图或者与现有扩散工具链兼容，应优先选 DiT 系列。还需注意，VAR 的 latent 是离散 token，而 DiT 使用连续 latent，这与下游文本条件、control 等模块的兼容性不同。

**何时不选 VAR**：需要文本到图像、视频生成、极高分辨率（>512 且显存受限）、需要与 Stable Diffusion 等现有生态无缝连接，或者无法接受两阶段 VQVAE 可能带来的纹理伪影。VAR 512 模型 d36-s 因为资源限制使用了单共享 AdaLN，说明直接扩展分辨率仍有额外的内存和参数成本。另外，VAR 论文没有开源文本条件模型，因此如果产品依赖 prompt 控制，不能直接选用 VAR 作为替换。如果只能使用官方发布的模型且没有训练资源，应基于论文提供的 checkpoint（如 VAR-d16/d20/d24/d30/d30-re）选择合适尺寸；论文官方 repo 提供这些模型。但推理代码和微调支持在论文中未详细说明，部署前需要额外验证。

## 10. 工程判断：可行性、风险与上限

**数据**：复现 VAR 需要 OpenImages 训练 VQVAE，以及 ImageNet 训练 Transformer。ImageNet 训练集 128 万图像，按 VQVAE 16× 下采样后每 epoch 约 870B image token（§5.2）。码本 V=4096，最终 latent 分辨率 16×16，属于中等 tokenizer 成本。最重模型 d30 有 2B 参数，训练 epoch 200–350，batch size 768–1024；论文未披露 GPU 型号和总训练时长，但 3050 亿最大训练 token 意味着 Transformer 阶段训练成本较高。基于这些数字可以推断，完整从零训练 VQVAE + 12 个 scaling models 需要大量算力；如果只复现 d16 或 d30 单点，成本会低很多，但仍需要先有 tokenizer。OpenImages 用于 VQVAE 训练，包含大量网页图像，可能引入与 ImageNet 分布偏移；不过 VQGAN 和 VAR 都这样使用，论文未分析该偏移影响。

**算力/延迟**：推理时 VAR 只需 K=10 次 Transformer 前向，比 DiT 的 250 步扩散快得多。但每次前向需要处理所有前缀 token；随尺度增大，序列长度从 1² 增长到 16²。按照 K=10、最终 latent 16×16 的设定，前缀 token 数是对各尺度分辨率平方求和；如果分辨率从 1×1 递增到 16×16，总 token 量会在十到几百级别，不是 raster AR 的 256 个 token 线性增长，而是更短的序列。论文用 O(n⁴) 表示总复杂度，其中 n 是最终 latent 边长；而 raster AR 是 O(n⁶)（Appendix B）。即便如此，2B 模型在 256×256 生成中需要缓存越来越多的前缀 token，512×512 下 d36-s 的内存压力更大，可能需要多卡或显存优化。相对墙钟时间来自论文报告，实际部署时应重新基准测试。拒绝采样和 CFG 都会增加推理成本；CFG 比率 2.0 使成本从 0.016 增加到 0.022（Table 3），这在低延迟场景下需要纳入。

**实现难点**：多尺度 VQVAE 的残差量化循环 Algorithm 1 要仔细处理插值、查表、卷积 φ_k 和残差减法的顺序；如果残差减法不稳定，可能导致后续尺度信号过弱或梯度异常。论文提到对 query 和 key 做单位向量归一化以稳定 Transformer 训练，说明训练稳定是一个实际关注点。Block-wise causal mask 的构造也容易出错：不同尺度块大小不同，需要生成块内全 1、块间下三角的注意力矩阵；如果错误允许高分辨率尺度看到未来，会破坏自回归假设并造成训练/推理不一致。CFG 在 AR 中需要每步额外前向或条件注入，增加了推理成本。还有一点，VAR 的多尺度 embedding 和 up-interpolation 细节未公开，复现时需要自行设计；这可能导致不同实现的 token 对齐方式不同，从而影响性能。

**失败环节与监控信号**：如果 VQVAE 重建质量不足，会在 token 层锁死后续生成质量上限；Figure 3 中 ImageNet validation FID 1.78 是参考下界，VAR-d30-re 已经达到 1.73，说明 tokenizer 不再是最主要瓶颈，但仍需监控 VQVAE 重建 FID/LPIPS。如果残差更新没有正确减去前一尺度贡献，后续尺度会重复编码相似信息，浪费模型容量；监控指标可以是在不同尺度 token 图上的熵、互信息或者重建误差下降曲线。训练 Transformer 时，应定期记录最后尺度 token 错误率、全局平均 token 错误率、测试交叉熵、FID、IS、precision/recall，并绘制 log N 与 log L 的斜率；如果斜率突然消失或负转正，可能表示数据、tokenizer 或优化器在更大模型上的瓶颈。此外，若发现训练后期 FID 波动或质量崩溃，应检查 AdaLN 参数是否由类别 embedding 正确生成，以及 query/key 归一化是否关闭后导致训练不稳定。

**指标上限与未回答问题**：ImageNet validation FID 1.78 是参考下界，但 FID 不为零；VAR-d30-re 达到 1.73，低于该参考下界，这可能是 FID 估计噪声、生成分布与验证集近似但不同、或拒绝采样导致的选择偏差，不能认为实际视觉质量已达平台期。IS 350.2 远高于验证集 236.9，说明 IS 对生成模型有系统性偏差，不能单用 IS 判断真实分布覆盖。论文未回答的问题包括：K（尺度数）如何选择、分辨率序列如何设定、替换更强 tokenizer 后 scaling law 是否改变、文本条件如何自然接入、零样本任务能否量化、视频扩展是否达到实用水平。这些在论文中只有方向性讨论，没有实验证据。还有，VAR 训练的 350 epochs 是否足够收敛以实现更优性能、更大模型（>2B）是否还能继续改善、不同 batch size 和 tokenizer 对 scaling law 指数的影响也未探索。

## 11. 放回研究脉络并收束

VAR 不是孤立的 tokenizer 改进，而是把“AR 顺序”从语言式的线性顺序改成视觉式的多尺度顺序。它位于 VQGAN/RQ-Transformer 的 AR 路线、MaskGIT 的 mask 路线和 DiT 的扩散路线交叉处。论文的策略是把范式从 next-token 切换为 next-scale，使 GPT 式 Transformer 在 ImageNet 类条件生成上首次在 FID/IS、速度、数据效率和可扩展性方面超过 DiT，并展示类 LLM 的缩放律和零样本泛化雏形。从研究脉络看，它试图解决视觉 AR 长期被扩散压制的核心矛盾：顺序假设与 2D 空间结构的冲突。即使 tokenizer 仍是 VQVAE，信息损失和重建伪影依然存在，但顺序改变已经大幅提升 AR 的性能和速度。论文同时明确把文本条件、视频生成和更强 tokenizer 留作未完成方向，因此 VAR 更像是一个可扩展的生成框架起点，而非封闭的最终系统。它也为后续统一视觉生成与 LLM 提供了更自然的接口，因为其预测单元与语言序列不同但也遵循因果分解，可能更容易被多模态模型吸收。

**读完必须记住的 5 件事**

1. VAR 的自回归单元是整张多尺度 token 图，不是单个 token；在 ImageNet 256×256 类条件下，生成步数 K=10，远小于 VQGAN 的 256（Table 1）。  
2. 多尺度 VQVAE 的编码方式是残差级：每个尺度先量化当前残差特征，再上采样并减去 φ_k(z_k)，所有尺度共享词典 V=4096。  
3. 最终性能：VAR-d30-re 在 ImageNet 256 达到 FID 1.73 / IS 350.2，相对 VQGAN 约快 20 倍，相对 DiT-XL/2 约快 45 倍；但 precision/recall 与 DiT 各有优劣。  
4. 参数规模 N=73728d³，测试损失拟合为 L_last=(2.0N)^{-0.23}，Pearson≈−0.998；这支持 18M–2B 范围内小模型预测大模型的缩放律。  
5. 零样本 in-painting/out-painting/editing 只有定性可视化，没有定量指标；视频生成和文本条件生成是论文未来工作，不是本文已验证的能力。

**5 道自测题**

1. Equation (6) 与标准 next-token AR 的似然分解有什么不同？为什么这种尺度级分解能把 256 步降到 10 步？  
2. Algorithm 1 中 f ← f − φ_k(z_k) 的作用是什么？如果取消这个残差减法，编码过程会有什么潜在问题？  
3. Table 3 中从 AR baseline 到 VAR 的 FID 变化是多少？这如何说明核心收益来自范式切换而非后续增强？  
4. 推理时为什么不需要 block-wise causal mask，却还能保持自回归性质？KV cache 在其中起什么作用？  
5. 论文的 scaling law 结论适用于哪些数据和任务范围？要把它推广到文本生成或视频生成，还缺哪些实验？

**一句话总结**：VAR 通过“下一尺度预测”重新定义图像自回归顺序，在 ImageNet 类条件生成上同时获得高于 DiT 的质量与远高于 raster AR 的速度，并初步验证了 LLM 式的缩放律；但其文本条件、视频生成和更强零样本泛化能力，仍停留在论文的未完成清单上。
