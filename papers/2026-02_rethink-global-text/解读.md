# 大白话深读《rethink-global-text》

## 1. 30 秒定位

这篇论文回答一个看似很小、但直接影响扩散 Transformer 设计的问题：**全局文本条件，也就是 CLIP 的 pooled embedding 通过调制层（modulation）注入模型，到底有没有用？** 作者先做系统分析，发现它在 FLUX schnell、HiDream-Fast、COSMOS、FLUX Kontext 等模型里影响很弱：FLUX schnell 长提示下几乎不起作用，HiDream-Fast 更是完全无感，COSMOS 补上 CLIP 后自动指标不变甚至略有下降。但作者没有简单丢弃它，而是换了个视角：把 pooled embedding 当作**引导信号**，用正负提示在调制空间做方向外推，得到修正后的全局条件向量。这个方法称为 modulation guidance，训练无关、实现简单、几乎不增加推理时间，并且能提升图像美学、复杂度、物体计数、手部修正、视频动态程度以及图像编辑强度。对原本没有 CLIP 的模型如 COSMOS 和 CausVid，作者用冻结主干、只训一个小 MLP 的方式先补上 CLIP 条件入口，再用同样引导。整体结论：全局文本条件不应被删除，它有一个新用途——作为一个几乎零成本的质量与属性控制旋钮。

## 2. 为什么这篇论文会出现

扩散模型主架构从 UNet 转向 Transformer（DiT）后，文本如何进入模型出现两条路径：一是 token 级别的注意力条件，通常用 T5 编码后的词序列；二是全局条件，用 CLIP 的句子级 pooled embedding，通过 MLP 与时间步结合，再进入调制层做 scale/shift。这个调制机制本身继承自 StyleGAN（Karras et al., 2019），早期在 GAN 中已证明能做语义控制和变换；进入扩散模型后，SDXL（Podell et al., 2023）率先在 UNet 中引入 CLIP pooled embedding，后来 DiT 架构的模型如 FLUX、SD3.5、HiDream 也保留了这条路。但近期工作，例如 Wan、Qwen-Image、Sana，开始去掉全局文本条件，只保留注意力，理由是两者效果差不多。论文指出这个趋势“没有严格论证”，因为没人系统测过 pooled embedding 在当代模型里的真实贡献。

作者首先做诊断：在 FLUX schnell 上，长提示中去掉 CLIP，CLIP Score 从 33.1 降到 32.8（−0.3），PickScore 21.0→21.0（−0.0），ImageReward 反而从 10.3 升到 10.4（+0.1）；短提示下影响稍大，CLIP Score 30.1→29.0（−1.1），ImageReward 6.2→4.5（−1.7）。在 HiDream-Fast 上，短提示去掉 CLIP 后 CLIP Score 从 30.3 到 30.3（−0.0），PickScore 21.8→21.8（−0.0），ImageReward 7.9→8.1（+0.1）；长提示同样几乎无变化。附录 A 还展示 FLUX Kontext 编辑任务中去掉 CLIP 后 CLIP Score Image 从 79.3 升到 80（+0.7），Text 保持 29.3。这些直接说明常规用法中 pooled embedding 是“半失效”甚至“全失效”。但作者受两件事启发：一是 StyleGAN 调制层可以驱动语义变化（§3）；二是 CLIP 本身训练成图文共享的可解释几何空间（Radford et al., 2021）。既然常规注入没用，那不如把它当作**方向引导**：用一对正负 prompt，在 CLIP 空间和调制空间之间建立方向，主动把生成轨迹推向往更理想的模式。这一点与 CFG 和注意力引导有些相似，但发生在更小的全局调制向量上，因此开销更小，也能覆盖不使用 CFG 的少步蒸馏模型。

## 3. 读懂前需要的最小概念

**扩散 Transformer（Diffusion Transformer, DiT）**：图像被表示成连续 token 序列，和文本 token 拼在一起，经过多个 transformer block，每块包含 MLP、归一化和注意力。预测的是噪声或速度场，迭代去噪生成图像。与 UNet 不同，DiT 没有卷积下采样，天然适合序列建模。在本文考察的模型中，DiT block 的隐藏维度、层数、注意力头数等配置各不相同，但都保留了调制层这一共同机制。

**调制层（Modulation Layer）**：对特征张量做逐点仿射变换：`Mod(s,y)=α_s(y)·s+β_s(y)`，其中 `α_s` 和 `β_s` 是缩放、平移系数，由全局条件向量 `y` 经小 MLP 生成。每个 DiT block 有自己独立的系数生成网络，从同一个 `y` 出发产生该层独有的 `α_s` 和 `β_s`。工程上这等价于对 channel 或 token 维度做重标定和偏置，类似常见的 AdaGN/AdaLN。它在不同层共享语义，但系数不同，因此既能全局调控又能逐层细化。这个机制继承自 StyleGAN，本质是 channel-wise 的重标定和偏置。

**两类文本编码**：CLIP 文本编码器给出一个句子级 `pooled embedding`，它代表整句语义；T5 编码器给出 token-level 序列，供 cross-attention 使用。前者适合全局、整句级别的属性表达，后者适合细粒度文本对齐，如对象数量、属性绑定。CLIP 是 contrastive 训练，让图文在共享空间中对齐，所以其向量差天然有语义方向含义；T5 是自回归/掩码语言模型，擅长长文本的逐词理解。本文的调制引导充分利用了 CLIP 的第一个性质。

**Classifier-Free Guidance（CFG）**：在推理时通过线性外推“条件输出 - 无条件输出”来增强条件一致性。设条件预测为 `x_cond`，无条件预测为 `x_uncond`，CFG 输出为 `x_uncond + w·(x_cond - x_uncond)`。但 CFG 通常需要额外前向计算无条件分支，对少步蒸馏模型不友好；很多少步模型（如 FLUX schnell）干脆去掉了 CFG。本文的调制引导不依赖 CFG，并且能与 CFG 叠加（附录 C，图 15）。

**正负方向引导**：输入一个希望增强的正向 prompt 和一个希望抑制的负向 prompt，计算它们的特征差作为方向，再加到原始特征上。本文就是让这个方向作用于 CLIP pooled embedding 对应的调制向量，而不是注意力图或去噪输出。与注意力引导（attention guidance）不同，调制引导的空间维度很小（只是一个全局向量），因此几乎零开销。

## 4. 方法全景：先看数据流

下面是推理时的数据流。如果不需要引导，可以直接删除右上角的正负 prompt 部分，模型回到原始路径。

```
prompt p ──> T5(p) ─────────────┐
                                 │
        └─> CLIP(p) ──┐         │
                        │        v
time t ──> MLP(t, CLIP(p)) ──> y ──> 调制层
                                 │
prompt p+ ─> CLIP(p+) ──┐        │
                        │        │
prompt p- ─> CLIP(p-) ──┤        │
                        v        v
        y_hat = y + w*(y(p+)-y(p-)) ──> 所有 block 共享
```

核心组件拆解：

**条件编码对**：输入 prompt，分别得到 T5 token embeddings 和 CLIP pooled embedding。T5 负责细粒度语义，CLIP 负责全局方向。其关键假设是 CLIP 的共享图文空间能提供可解释的语义方向。对于无 CLIP 的模型，先需通过训练好的小 MLP 将 pooled embedding 映射到 timestep embedding，使后续能计算 `y(p,t)`。在 COSMOS 和 CausVid 的适配训练中，CLIP 分支被冻结，只有这个小 MLP 可训练。

**时间步 + CLIP MLP**：输入时间步 `t` 和 pooled embedding `CLIP(p)`，输出全局调制向量 `y`。若 CLIP 置零，模型退化为仅由时间步驱动的调制，文本信息完全依赖注意力。该 MLP 在所有 block 之前产生一个全局向量，各 block 再用自己的线性层把 `y` 转成各自的 scale/shift 系数。论文将 `t` 和 `CLIP(p)` 作为两个输入写进 `MLP(t, CLIP(p))`，但未明确内部是拼接还是相加；在无 CLIP 的模型上，作者的做法是把新 MLP 的输出加到 timestep embedding 上，当 pooled embedding 设为零时与原始模型严格一致。

**调制层**：每一个 DiT block 都有独立的 scale/shift 系数生成网络，它们根据全局向量 `y` 对隐藏状态 `s` 做仿射。不同层对语义层次的影响不同：附录 B 的注意力分析（图 10(a)）发现，局部特征（如 hands、face、eyes）在两层区间（10–30 层和 42–58 层）被重点处理；全局特征（realism、cinematic、crisp）在各层相对恒定，只在 20–35 层略有下降。这为按层动态引导提供了依据。

**调制引导**：额外编码正负 prompt 得到 `y(p+)` 和 `y(p-)`，把两者差乘以强度 `w`，再加到原始 `y` 上，得到 `y_hat`。`y_hat` 只影响调制系数，不改变注意力序列。正负方向是启发式定义的，例如美学用 `Ultra-detailed, photorealistic, cinematic` 对 `Low-res, flat, cartoonish`，复杂度用 `Extremely complex, the highest quality` 对 `Very simple, no details at all`，手部修正用 `Natural and realistic hands` 对 `Unnatural hands`，物体计数用 `[n] [objects]` 对 `Very simple, no details at all`。这些在附录 D（Table 5）中完整列出。值得注意，正负 prompt 可以缓存编码结果，在多次生成中复用。

**动态引导策略**：很多实验表明一个常数 `w` 从头到尾都加很容易过度强调 prompt 而忽略原描述。作者在附录 B 提出四种逐层策略：策略 1 是简单步进函数，前 `i` 层 `w=0`，之后 `w` 固定；策略 2 是两个区间，在 `i1` 到 `i2` 层激活；策略 3 是两个指数函数，中心在 `i1=20, i2=50`；策略 4 是三个区间，`i1=13, i2=30, i3=45`，前两段用 `w1=3`，后一段用 `w2=1`。这些策略的目的是让引导发生在模型真正处理相应属性的层。例如文本到图像美学用策略 1：`i=5, w=3`；手部修正用策略 4。对于不同的任务，不需要对整个模型所有层统一施加，而是避开早期层来保留原图结构。

对于没有 CLIP 的 COSMOS 和 CausVid，作者在主干外训练一个小 MLP 把 pooled embedding 映射到 timestep embedding，当 pooled embedding 设为 0 时模型退化为原始模型。训练细节在第 6 节展开。关键在于：并非每个模型都天然具备 CLIP 条件入口，本文证明了即使缺乏该入口，也可以通过极轻量的适配补上，且不破坏原始生成能力。

## 5. 核心公式与直觉

理解本文只需要三个公式。

**公式 1：全局条件向量生成**
```
y(p,t) = MLP(t, CLIP(p))
s = [T5(p), x]
```
`p` 是 prompt，`t` 是时间步，`CLIP(p)` 是 pooled embedding，`x` 是图像 token 序列。`y` 是全局调制向量，由时间步和 CLIP 共同决定。`s` 是待处理的序列，把图像 token 和 T5 文本 token 拼起来。这个公式说明全局条件和注意力条件是两条独立信息流。论文中的 `MLP(t, CLIP(p))` 并未展开内部拼接或加法方式，可视为两个输入共同进入一个小网络；在实现上，CLIP pooled 通常先投影再与时间步 embedding 相加或拼接。工程对应是：每个 DiT block 之前有一个共享的 embedding 网络，先把 `t` 和 `CLIP(p)` 变成某个中间向量，再由各 block 的轻量线性层把它映射成该层专属的调制系数。

**公式 2：调制层作用**
```
Mod(s,y) = α_s(y)·s + β_s(y)
```
`α_s` 和 `β_s` 是缩放和平移系数，由 `y` 经过小 MLP 产生。它相当于对特征做 channel-wise 的重标定和偏置。工程上等价于 StyleGAN 风格注入，每个 block 的系数各自独立。作者认为，这个仿射变换对语义变化非常敏感，是全局文本条件能起作用的物理机制。当 `CLIP(p)→0` 时，`y` 仅由时间步决定，调制层仍能工作，但失去文本驱动的语义特异性。直觉上，`α_s` 控制某个通道特征的强弱，`β_s` 控制偏置，两者共同决定该层激活模式的整体风格。

**公式 3：调制引导**
```
y(p,t) ──> ŷ(p,p+,p-,t) = y(p,t) + w·(y(p+,t) - y(p-,t))
```
`p+` 和 `p-` 是正负 prompt，分别描述希望增强和希望抑制的属性。`y(p+)` 和 `y(p-)` 是通过同一个 MLP 得到的全局调制向量。两者之差就是在调制空间中的“语义方向”，乘上强度 `w` 后加到原始 `y` 上。整个过程只改变一个很小的全局向量，不涉及注意力图或额外去噪分支，因此计算开销极低。这个公式与 CFG 的线性外推形式相似，但外推发生在全局调制向量上，而不是去噪输出上。CFG 通常需要完整网络的前向（甚至两次），调制引导只需要在全局向量上做加法。

动态版本在公式 3 基础上，把 `w` 变成随层变化的 `w(i)`。对于策略 1，`w(i)=0` 当 `i<i_start`，否则 `w(i)=w`；对于策略 4，是分段常数值：`w1` 用于 `i1` 到 `i2`，`w2` 用于 `i2` 到 `i3`，其余区间为 0。其直觉是：浅层负责粗粒度结构，如果一开始就强引导会破坏原文语义；拿到中后层再施加，可以专门改变局部细节。这与表 7 中策略 4 在手部修正上最优的表现相吻合——策略 4 在 13–30 层用强度 3、30–45 层用强度 1，正好避开了早期整体布局，只加强中间层对局部属性的塑造。动态策略的代价是引入了 `i_start`（或 `i1,i2,i3`）与 `w`（或 `w1,w2`）这些需要手工选择的超参数，论文未给出自动确定方法。

## 6. 训练到底怎么跑

严格说，**已经带 CLIP 的模型完全不需要训练**，如 FLUX schnell、FLUX dev、SD3.5 Large、HiDream、Hunyuan 13B 和 FLUX Kontext。推理时只需要提前选定正负 prompt 和动态策略。真正涉及训练的是两类原本没有 CLIP 的模型：COSMOS（文本到图像）和 CausVid（文本到视频）。

训练目标不是学引导方向，而是给这些模型补上 CLIP 条件入口。具体流程如下：

1. **冻结整个原模型**，只在 timestep embedding 旁边加一个小 MLP，把 CLIP pooled embedding 映射成向量，再和原始 timestep embedding 相加。这个小 MLP 是新引入的唯一可训练参数。论文没有披露这个 MLP 的具体层数或参数量，只写“small MLP”。
2. **文本传播设计**：将 T5 输入换成无条件 prompt，强制文本信息只能通过 CLIP pooled embedding 进入模型。这样训练后，当 pooled embedding 设为零时，模型会退化为原始模型——因为 T5 是无条件，CLIP 也置零，整个模型与原始版本一致。这个性质非常重要，它保证了适配后的模型在不启用引导时行为不变。
3. **数据来源**：不使用外部新数据集。论文强调“用模型自己的合成数据”，避免引入分布差异。COSMOS 使用 500K 张自己生成的图像，训练 4K iterations；CausVid 训练 1K iterations。采样设置遵循各自原论文（Agarwal et al., 2025；Yin et al., 2024b），提示词来自 Li et al.（2024）。生成 500K 合成样本需要先运行原始模型，这是一次性的前期成本。
4. **训练方法**：采用蒸馏式 MSE。对一张干净图像，加噪到某个时间步；分别用原始模型（没有 CLIP 分支）和修改模型（有 CLIP 分支）做一次预测；让两个预测之间的 MSE 尽量小。这个损失非常适合少步蒸馏模型，因为它消除了对复杂对抗损失或分布匹配损失的需求（这些常见于一步或少步模型训练，如 Yin et al., 2024a 中讨论）。具体操作是：采样干净图像 x0，按噪声调度加噪得到 x_t，然后两个模型分别预测目标（噪声或速度），计算它们输出的均方误差并反向传播更新小 MLP。
5. 训练后的模型，若 pooled embedding 置 0，输出与原始模型完全一致；若非零，则为引导提供可用的全局方向。训练时只更新那个小 MLP，其余权重冻结，因此不会破坏原始生成能力。

这里需要区分：训练只是为无 CLIP 模型构建接口，并不改变原有生成能力。论文未披露优化器、学习率、batch size、混合精度等细节，只给了迭代次数和样本量。因此复现时可能需要按模型大小自行选择常见配置。另外，训练数据完全由模型自身合成，因此最终性能的上限受原始模型能力约束；如果原始模型某些属性本就表现弱，那么这个适配训练也只能教会 MLP 在现有分布内做映射。

## 7. 推理到底怎么跑

推理阶段对已有 CLIP 的模型非常直接。

1. 对原始 prompt `p`，用 T5 编码得到 token embeddings，用 CLIP 编码得到 pooled embedding。这两部分在每一步去噪中都复用。
2. 若开启调制引导，额外对正 prompt `p+` 和负 prompt `p-` 各做一次 CLIP 编码，得到两个 pooled embedding。这一步可以缓存：同一对正负 prompt 在多次生成中复用，不需要每步重复编码。对一个批量内的所有样本，如果使用相同的属性引导，只需编码一次。
3. 用时间步 `t` 和 `CLIP(p)` 计算原始全局条件 `y(p,t)`。时间步 `t` 随去噪步变化，因此这一步每步都要算，但只涉及一个小 MLP，不经过主干网络。
4. 用同一个 MLP 分别计算 `y(p+,t)` 和 `y(p-,t)`，再按公式 3 得到 `y_hat`。`w` 由动态策略决定：例如美学任务的 strategy 1 是 `i=5, w=3`，表示前 5 层不用引导，第 5 层及以后使用强度 3；手部修正 strategy 4 是 `i1=13, i2=30, i3=45`，在 13–30 层用 `w1=3`，30–45 层用 `w2=1`，其余层为 0。
5. 后续每一步去噪，都用 `y_hat` 作为全局条件送入所有调制层；注意力部分仍然使用 `[x, T5(p)]`，不变。所以图像内容和文本 token 的对齐不受引导影响。这里的 x 表示当前时间步的图像 token 序列，去噪步数由模型默认或用户指定。
6. 对原本没有 CLIP 的 COSMOS 或 CausVid，先经过训练好的小 MLP 得到 pooled embedding 的映射并加到 timestep embedding 上，再执行同样的引导计算。此时 `y(p,t)` 中的 `CLIP(p)` 部分来自新加的 MLP 输出。
7. 达到指定步数后，解码潜变量得到最终图像或视频。

最关键开销点是第 2 和第 4 步：只需额外两次 CLIP 文本编码（或缓存复用）和两次全局向量前向，外加一次减法和加权。`y_hat` 在所有 block 共享，不改变注意力矩阵的计算，因此论文说“几乎不可忽略的延迟”（实际上是“negligible runtime overhead”）。与注意力引导不同，后者要对正负 prompt 做完整注意力和网络前向，成本高得多。论文还指出调制引导可以与 CFG 同时使用：图 15 显示在不同 CFG 值下调制引导都能带来提升，表明两者互补。这样，对于本就有 CFG 的模型，调制引导作为额外旋钮叠加，不会与 CFG 冲突。

**最关键的消融**是 Table 7 中动态策略 vs 常数策略。它证明一个常数 `w` 虽然也能提升美学，但容易过度强调要求、忽略原 prompt，甚至引入伪影。在 hands correction 上，常数策略反而比原始更差（48% win rate，原始 52%），而策略 4 达到 59%。这直接支撑“动态调制引导比常量更安全、更有效”的结论。策略 4 具体参数为 `i1=13, i2=30, i3=45, w1=3, w2=1`，它的三段式激活正好匹配附录 B 中局部特征在 10–30 和 42–58 层集中出现的分析。图 13、14 进一步显示：起始层越晚，越能保留原图同时细化局部；`w` 过大（如 8.0）会产生伪影。另一个消融是图 15，表明调制引导可与 CFG 叠加，在不同 CFG 值下都提升。

**失败模式**在消融中被明确记录。第一，常数 `w` 在 hands correction 上为负收益（48% vs 原始 52%），说明不加选择的全局引导会损害细粒度属性。第二，图 14 中 `w=8.0` 时出现 artifacts，证明存在强度上限。第三，Table 2 中 COSMOS +CLIP 的 defects 人类胜率只有 43，低于 50，说明单独补 CLIP 不仅无益还可能有害；FLUX dev 的 relevance 人类胜率在美学引导后为 44，低于 50，存在轻微语义偏离。第四，Table 10 中 FLUX Kontext 调制引导的 reference preservation 在 Replace object 子类从 90 降到 89（−1），说明编辑强度提升可能带来微弱保真度代价。

**长提示与短提示分析**（附录 G，Table 11）：原始 CLIP 只在短提示上有影响，但调制引导对长提示同样有效。在 FLUX schnell 长提示上，美学引导的 aesthetics 人类胜率从 30.1 提升到 60（+20% 是相对提升？实际是 win rate 60 vs 原始），complexity 从 73 胜率中体现；自动指标 IR 从 10.3 升到 11.0、HPSv3 从 10.8 升到 11.3。短提示上美学引导的复杂度 win rate 达到 81，比原始高得多。这回应了“原 CLIP 只在短提示上有影响”的观察，并表明引导不是对原始条件的简单放大。

**尚未证明的主张**：论文没有证明调制引导能改善“文本-图像语义对齐”。作者在 Limitations（§H）明确说，这个方法不处理文本对应，不能提升生成图像对 prompt 的准确反映。另外，“对无 CLIP 模型仅需小 MLP 就能补上条件”更像工程适配，不是理论证明。动态策略引入的超参数（起始层、强度、分段）需要逐任务微调，没有给出自动选择方法。自动指标提升幅度通常较小，更大提升来自人类偏好和 VBench 的 dynamic degree。图 4 观察到调制引导使模型更关注 hands、child 等目标 token，但论文没有给出为什么调制空间方向会影响注意力的严格因果分析。此外，4000 次迭代的 COSMOS 适配训练是否足够收敛、对更大模型是否同样有效，论文未做系统研究。

## 9. 与前作怎么选

**Normalized Attention Guidance（NAG, Chen et al., 2025）**：同样是正负 prompt 引导，但在注意力空间进行外推。它的优势是对注意力重点有较强直接控制；代价是每次推理都要对正负 prompt 做完整网络前向，尤其 attention 层计算量大。本文 Table 8 显示调制引导在美感和复杂度上分别高出 34、58 个百分点，而且几乎无额外开销。当你要极致控制注意力、且不在乎延迟时，可选 NAG；否则选调制引导。注意 NAG 不适用于不带注意力引导设计的少步模型。

**Concept Sliders（Gandikota et al., 2024）**：通过学习 LoRA 方向实现精确属性编辑，适合固定语义控制（如手部），但需要测试时优化或训练。本文 Table 9 显示调制引导在手部修正上比 Concept Sliders 还高出 16 个百分点，并且无需训练。当你想快速换属性方向、不想为每个属性保存 LoRA 或跑测试时优化时，选调制引导。

**LLM-enhanced prompts**：用大模型改写成更丰富/更美的 prompt，简单通用，但可能引入额外文本偏差，也可能改变原意。本文 Table 8 表明调制引导可以与 LLM prompt 叠加，进一步获得提升：在 FLUX schnell 上，Ours + LLM-enhanced 的复杂度胜率达到 74，而基线为 26，说明组合优势明显。所以它们不是互斥，而是可组合：用 LLM 提升 prompt 表达，用调制引导做无训练的视觉属性偏移。

**CFG**：CFG 是主流条件增强手段，但很多少步蒸馏模型不支持 CFG。调制引导不依赖 CFG，且能与 CFG 叠加（附录 C，图 15）。因此，如果模型已经使用 CFG，可以把调制引导作为额外旋钮；如果模型是少步无 CFG 类型（如一些蒸馏模型），调制引导是目前少数能在推理端提升质量的方法之一。

**何时不选**：如果你的核心目标是修复属性错绑、实体缺失、文本语义不符，调制引导帮不上忙，应该用注意力优化或训练方法。如果嫌正负 prompt 和动态策略设计麻烦，那就用现成的 LLM prompt 修饰或 CFG。如果模型没有 CLIP 且你没有计算资源做合成数据训练小 MLP，也不能直接应用。另外，如果你的应用对 reference preservation 要求极高，图像编辑场景可能不适合把引导强度调得过大。

## 10. 工程判断：可行性、风险与上限

**数据与算力**：对已有 CLIP 模型，推理零训练、零外部数据。对无 CLIP 模型如 COSMOS，需要 500K 合成样本和 4K iterations 训练一个小 MLP；CausVid 需要 1K iterations。是轻量微调，但需要先运行原始模型生成训练集，成本取决于模型尺寸。论文未披露具体 GPU 时数或优化配置、batch size 等，生产中需自行估算生成 500K 样本的一次性成本。小 MLP 参数量极小，训练本身非常轻，但生成数据集可能占主要时间。对于视频模型 CausVid，生成训练视频序列的成本高于图像。

**延迟**：量化上是额外两次 CLIP 文本编码和全局向量计算，这个向量在所有 block 共享，不引入额外注意力计算，因此可忽略。不同于 NAG，后者要跑额外完整前向，延迟会明显增加。论文在 §5 明确写“negligible runtime overhead”，但未给出毫秒级测量。**实际监控**应重点看：PickScore/IR/HPSv3 是否随 `w` 上升而上升、CLIP Score 是否保持稳定、人类评估中 relevance 是否下降。如果 relevance 明显下降，说明 `w` 过大或起始层太早。对于手部修正等特定属性，还要监控 defects 等指标，因为引导可能把注意力从其他区域转移。

**实现难点**：一是正负 prompt 设计。论文附录 D 给了模板，但针对新任务需重新设计。二是动态策略超参数：起始层 `i` 和强度 `w` 需要调。调得不好，常数引导反而比原始更差（Table 7 hands correction constant 48% vs original 52%）。三是对无 CLIP 模型，要先训练一个微小的 MLP。如果实现时不冻结原模型，可能破坏预训练权重。四是无法自动判断哪层最适合引导，需要复现附录 B 的注意力分析或直接尝试策略 1、4。附录 B 的注意力分析需要针对局部/全局特征子集各自收集注意力图，然后绘制层曲线，这本身需要额外数据和分析工程。

**风险与失败环节**：`w` 过大导致视觉伪影、忽略原 prompt 中的其他内容；图 14 显示 `w=8.0` 时生成图像出现 artifacts。在 COSMOS 上某些变体 defects 指标变差（Table 2, +CLIP 导致 defects 人类胜率从 50 降到 43）；在图像编辑中，reference preservation 在替换物体子类略有下降，从 90 降到 89（Table 10）。此外，FLUX dev 的 text relevance 人类胜率在美学引导后为 44，低于 50，表明有轻微语义偏离。自动化指标提升很小，可能导致上线时感知收益不足。对于少步模型，如果每一步都用相同 `y_hat`，一些步可能被过度引导，需要动态按层策略减轻。

**指标上限**：本方法能被看作一个“风格偏好控制器”，而不是“语义对齐工具”。它在前述美学、复杂度、动态程度、物体计数和手部上提升，但 Limitations 明确说“不解决文本到图像对应”，也即不能修“数错了还是属性错配”。因此上限并不是全面替代训练或 RLHF，而是作为低成本的后处理型引导。对于需要提升 prompt 对齐质量的场景，应当与 CFG、注意力优化方法或训练方案结合。人类评估的收益（+10% 到 +48% win rate）说明在实际视觉感知层面改进明显，但自动指标通常只有不到 1 个点的变化，这意味着 A/B 测试时选择评测方式非常关键。

**未回答问题**：为什么 pooled embedding 常规无效但方向引导有效，只有注意力变化的观察（图 4），缺少理论证明；动态策略没有自动选择机制；对超大模型、不同 DiT 变体、文生 3D 或多模态视频的泛化性未验证；训练引入 CLIP 对合成数据的依赖是否掩盖了真实分布差异；人类评估和自动指标之间的一致性也需要更多数据支持。这些问题在论文中未得到回答，表明该方向的适用范围仍有待进一步研究。

## 11. 放回研究脉络并收束

这篇论文处在两条研究线的交叉点。一条是**扩散模型的文本条件设计**：从 UNet+attention（Ho et al., 2020; Rombach et al., 2022）到 SDXL 引入 CLIP pooled embedding 的调制机制（Podell et al., 2023），再到 DiT（Peebles & Xie, 2023）成为主流后，近期模型如 Wan、Qwen-Image、Sana 开始去掉全局条件。作者用诊断数据反驳了“全局条件无用”的简单判断，给设计回退提供一个反对证据。另一条是**推理期引导**：CFG（Ho & Salimans, 2022）、注意力引导（Chen et al., 2025; Hong et al., 2023）、测试时注意力优化（Chefer et al., 2023）、可学习方向 LoRA（Gandikota et al., 2024），都在输出空间或特征空间上做优化。本文把 StyleGAN 的调制空间和 CLIP 的语义方向结合，把“条件”重新解释为“引导”，从而跨过 CFG 对少步模型不友好的限制。因此它更接近 TokenVerse 式的调制空间编辑（Garibi et al., 2025），而不是传统文本对齐。它在实践上提供了一种几乎免费的属性增强开关，这在少步蒸馏模型上尤其有价值，因为此类模型往往缺少 CFG 或其他推理时控制手段。

**读完必须记住的 5 件事**：
1. 常规 CLIP pooled embedding 在多数现代 DiT 中影响微弱，但不应直接删除，因为它可以被重新激活为引导信号。
2. 调制引导公式 `ŷ = y + w*(y(p+)-y(p-))` 在全局调制向量上做方向外推，几乎零开销，不触及注意力。
3. 动态按层引导优于常数 `w`，尤其对手部修正：策略 4 在前若干层关闭、中后层激活，胜率从常数 48% 提升到 59%（对比原始 52%）。
4. 没有 CLIP 的模型可以冻结主干，只训小 MLP，并用自己的合成数据蒸馏引入 CLIP 条件；COSMOS 用 500K 样本、4K iterations，CausVid 用 1K iterations。
5. 该方法不能改善文本-图像语义对齐，它提升的是美学、复杂度、动态度和特定属性（计数、手部），这是其明确的边界。

**5 道自测题**：
1. 论文中 CLIP 在 FLUX schnell 的长提示和 HiDream-Fast 上分别表现出什么行为？长提示去掉 CLIP 的 CLIP Score 只降 0.3，PickScore 不变；HiDream-Fast 短/长提示均无变化。
2. 写出调制引导公式，并解释 `y(p+,t) - y(p-,t)` 为什么能被当作语义方向？因为 CLIP 训练成图文共享的可解释空间，两个文本 pooled embedding 的差在调制向量空间中对应某个语义变化方向；将这一方向加到原始 `y` 上可推动生成朝正属性移动。
3. 动态调制引导 strategy 1 和 strategy 4 分别针对什么任务？其核心差别是什么？策略 1 用于美学、复杂度、物体计数等全局/复杂任务，前 `i` 层关闭后启用固定 `w`；策略 4 用于手部修正，采用三段式区间（13–30 层 `w=3`，30–45 层 `w=1`），更精细地匹配局部属性所在的层区间。
4. COSMOS 原本没有 CLIP，作者如何为它补上 CLIP pooling？训练损失是什么？数据从哪来？冻结原模型，在 timestep embedding 旁加小 MLP 映射 CLIP pooled 并相加；T5 输入换成无条件，强制文本只经 CLIP 进入；损失是原始模型和修改模型在同一加噪输入上的预测 MSE；数据是 COSMOS 自己生成的 500K 合成图像，提示词来自 Li et al.（2024）。
5. 论文在哪些指标上报告了提升？它明确不解决什么问题？提升包括 GenEval 的计数/颜色/位置、VBench dynamic degree、美学/复杂度人类胜率、编辑强度；但它不解决文本到图像语义对齐，且需要手动设计正负 prompt 和动态策略超参数。

最终一句话总结：**全局文本条件不是没用，而是被用错了地方；当它从“条件输入”改造成“调制空间引导”时，就能以几乎零成本成为跨模型、跨任务的质量控制旋钮。**
