# 大白话深读《Classifier-Free-Guidance》

## 1. 30 秒定位

这篇论文提出“无分类器引导”（classifier-free guidance，CFG），用于扩散模型的条件生成。此前 Dhariwal & Nichol（2021）的分类器引导需要额外训练一个在噪声图像上工作的图像分类器，并在采样时用分类器梯度修正扩散模型分数；这带来训练管线复杂化、对抗性解释等问题。本文证明：不训练分类器也能获得类似的“降低多样性、提升单样本质量”的效果。做法是联合训练一个条件扩散模型和一个无条件扩散模型，两者共享同一个神经网络；采样时用线性组合“条件分数估计”和“无条件分数估计”来引导生成。在 ImageNet 64×64 和 128×128 类条件图像生成上，无分类器引导展示了与分类器引导相似的 FID/IS 权衡曲线，并在 128×128 上以 w=0.3 取得 FID 2.43，优于 ADM-G 的 2.97（Table 2）。核心贡献是方法极简：训练时随机丢弃条件，采样时分数混合即可；代价是推理时每步需要两次主网络前向。

## 2. 为什么这篇论文会出现

论文开头指出扩散模型在图像和音频合成上已经能给出有竞争力的样本质量与似然（§1）。Dhariwal & Nichol（2021）提出分类器引导，使得扩散模型能像 BigGAN 截断或 Glow 低温采样那样，在样本保真度与多样性之间取舍。分类器引导把扩散模型的条件分数估计与一个额外分类器的对数概率梯度混合：

\[
\tilde{\epsilon}_\theta(z_\lambda,c) = \epsilon_\theta(z_\lambda,c) - w\sigma_\lambda \nabla_{z_\lambda} \log p_\theta(c|z_\lambda)
\]

其中 w 控制引导强度。该方法有效，但带来几个问题：

1. **训练成本与复杂性**：必须额外训练一个分类器，而且该分类器必须在不同噪声水平 \(z_\lambda\) 上训练，因为采样逐级去噪时中间状态都是带噪图像；一般干净图像上预训练的分类器不能直接使用（§1）。这使训练管线多出一套模型、数据加载和调参。
2. **对抗性解释**：分类器引导的采样方向是分类器梯度的方向，可视为对图像分类器的梯度对抗攻击；这让人怀疑它在 FID、Inception Score 等依赖分类器特征的指标上的提升，是不是靠“骗过”分类器得来的（§1）。
3. **与 GAN 的相似性**：沿分类器梯度行走类似 GAN 训练，特别是非参数生成器情形；这也引发疑问：分类器引导模型是否只是在向已在这些指标上表现好的 GAN 靠拢，而非真正提升生成分布本身（§1）。

因此作者想回答：能否完全不使用分类器实现引导？本文提出无分类器引导，用一个生成模型自身完成“低温采样”式权衡。这既简化训练，又避免对抗性与分类器偏差解释。论文强调其目的是“概念验证”（proof of concept），要证明纯生成扩散模型也能在分类器指标上达到强效果，而不是针对 SOTA 做极限调参（§4 开头）。它还指出该工作曾以短版出现在 NeurIPS 2021 Deep Generative Models Workshop（arXiv 首页注记）。

## 3. 读懂前需要的最小概念

- **连续时间扩散模型**：本文使用 Song et al.（2021b）等的连续时间框架。前向过程从干净数据 x 逐渐加噪，用对数信噪比 λ 标记噪声水平。λ 越大噪声越小；前向过程沿 λ 减小方向进行。
- **对数信噪比 λ**：定义为 \(\lambda = \log(\alpha_\lambda^2 / \sigma_\lambda^2)\)。\(\alpha_\lambda\) 和 \(\sigma_\lambda\) 是噪声调度参数，满足 \(\alpha_\lambda^2 = 1/(1+e^{-\lambda})\)，\(\sigma_\lambda^2 = 1-\alpha_\lambda^2\)。所以 λ 直接表示当前噪声状态的信号与噪声比的对数。
- **前向过程**：\(q(z_\lambda|x) = \mathcal{N}(\alpha_\lambda x, \sigma_\lambda^2 I)\)。zλ 是加噪后的数据。当 λ 很小时，zλ 接近纯高斯噪声；当 λ=λmax 时接近干净图像。不过 λmax=20 时 \(\sigma_\lambda\) 并不严格为零，因此最后采样仍会残留极少量噪声，最终输出用 \(\hat{x}_t\) 作为干净预测（Algorithm 2）。
- **反向转移**：给定 x 时，反向条件分布 \(q(z_{\lambda'}|z_\lambda,x)\) 可由前向核与干净 x 解析计算，均值包含对 x 的依赖；生成模型用网络预测 \(\hat{x}_\theta(z_\lambda)\) 替代真实 x，得到近似反向核（§2，公式(3)(4)）。
- **去噪分数匹配**：训练时最小化 \(\mathbb{E}_{\epsilon,\lambda}[\|\epsilon_\theta(z_\lambda) - \epsilon\|_2^2]\)，其中 \(\epsilon \sim \mathcal{N}(0,I)\)，\(z_\lambda = \alpha_\lambda x + \sigma_\lambda \epsilon\)。神经网络 \(\epsilon_\theta\) 学习预测加入的噪声 \(\epsilon\)，这个预测与分数函数有关：\(\epsilon_\theta(z_\lambda) \approx -\sigma_\lambda \nabla_{z_\lambda} \log p(z_\lambda)\)。
- **条件与无条件模型**：条件模型 \(\epsilon_\theta(z_\lambda,c)\) 接收类别标签 c；无条件模型 \(\epsilon_\theta(z_\lambda)\) 不接收类别，等价于输入空标记 \(\varnothing\)。本文用一个网络同时实现两者，训练时随机把 c 替换为 \(\varnothing\)。
- **引导**：类似于 GAN 的截断，通过改变采样分布来降低多样性、提高单样本质量。分类器引导用分类器梯度；无分类器引导用条件与无条件分数之差。
- **FID 与 IS**：FID（Fréchet Inception Distance，Fréchet 起始距离）越低越好，反映生成分布与真实数据分布在 Inception 特征空间的距离；IS（Inception Score，起始分数）越高越好，反映类别置信度和样本质量。二者存在典型权衡：提高 IS 常导致 FID 上升。

## 4. 方法全景：先看数据流

### ASCII 数据流

```
训练阶段（Algorithm 1）：
输入数据 (x, c) ──► 以概率 puncond 将 c 替换为 ∅ ──► 采样 λ ~ p(λ) ──► 采样 ε ~ N(0,I)
          │
          ▼
构造噪声 zλ = αλ x + σλ ε ──► 网络 εθ(zλ, c) ──► 计算损失 ||εθ(zλ,c) - ε||²
          │
          ▼
梯度下降更新 θ（条件与无条件共享网络）
```

```
推理阶段（Algorithm 2）：
初始 z1 ~ N(0,I) ──► 对 t = 1,...,T:
   │
   ├─ 计算条件分数 εθ(zt, c) 和 无条件分数 εθ(zt, ∅)
   ├─ 混合：ε̃t = (1+w) εθ(zt,c) - w εθ(zt)
   ├─ 预测干净数据 x̃t = (zt - σλt ε̃t) / αλt
   ├─ 从反向转移采样 zt+1
   │
最后返回 zT+1 作为生成样本
```

### 核心组件及其输入 / 输出 / 目的 / 假设

**1. 噪声调度与对数信噪比分布 p(λ)**
- 输入：λmin、λmax，以及从均匀分布 u∈[0,1] 映射到 λ 的函数。
- 输出：每个训练 step 的噪声水平 λ。
- 目的：在不同噪声尺度上训练去噪网络，使网络能覆盖从纯噪声到近干净图像的整个反向过程。
- 假设：λmin=-20、λmax=20 对所有实验足够；论文采用基于余弦噪声调度的双曲正割分布（§2），但认为该选择受 Nichol & Dhariwal（2021）启发，不一定最优。具体函数为 \(\lambda = -2\log\tan(au+b)\)，其中 \(b=\arctan(e^{-\lambda_{\max}/2})\)，\(a=\arctan(e^{-\lambda_{\min}/2})-b\)，u 从 [0,1] 均匀采样（§2）。

**2. 共享去噪网络 εθ**
- 输入：噪声图像 zλ，条件 c（可为类别标签或空标记 \(\varnothing\)），以及 λ（论文省略标记但实际输入）。
- 输出：预测的噪声向量 εθ(zλ,c)。
- 目的：同时承担条件与无条件分数估计，从而避免训练两个网络。
- 假设：单个网络有足够容量同时处理两类任务；网络参数不保守，分数场不必是某个势的梯度。这是因为网络是无约束的前馈网络，Salimans & Ho（2021）曾指出此类分数估计通常不是保守向量场（§3.2）。

**3. 条件随机丢弃机制**
- 输入：标签 c，概率 puncond。
- 输出：修改后的条件 c（原始或 \(\varnothing\)）。
- 目的：在训练中同时为条件与无条件目标提供梯度信号，实现联合训练。
- 假设：puncond=0.1 或 0.2 即可分配足够容量给无条件任务，过大的 puncond（如0.5）会损害整体质量（§4.2）。

**4. 训练损失**
- 输入：网络输出 εθ(zλ,c)，真实噪声 ε。
- 输出：标量损失 \(\|\epsilon_\theta(z_\lambda,c)-\epsilon\|^2\)。
- 目的：去噪分数匹配，驱动网络逼近噪声的负梯度分数。
- 假设：对所有 λ 的加权（由 p(λ)）优化可以同时提高似然下界与采样质量。论文说明当 p(λ) 均匀时，该目标正比于变分下界（忽略解码器和先验项）；非均匀时是加权变分下界，权重可调以改善采样质量（§2）。

**5. 引导分数混合**
- 输入：条件分数估计 εθ(zt,c)，无条件分数估计 εθ(zt,\(\varnothing\))，引导强度 w。
- 输出：引导分数 \(\tilde{\epsilon}_t = (1+w)\epsilon_\theta(z_t,c) - w\epsilon_\theta(z_t)\)。
- 目的：在采样时放大条件模型对数据分布的影响，降低无条件分布下的概率质量，类似分类器引导。
- 假设：该线性外推在 w>0 时能提升样本保真度；w=0 退化为普通条件采样。论文指出该式不是某个分类器梯度的缩放，而仅是分数估计的组合（§3.2）。

**6. 反向采样步骤**
- 输入：当前 zt，引导分数，调度参数，方差插值系数 v。
- 输出：下一步 zt+1。
- 目的：沿 λ 递增方向逐步去噪，最终生成样本。
- 假设：使用祖先采样和固定的 v 即可有效；v 仅在有限步时影响结果，因为连续极限下两种方差相等（§2）。64×64 使用 v=0.3，128×128 使用 v=0.2（§4.1）。

## 5. 核心公式与直觉

### 公式（1）：前向加噪分布

\[
q(z_\lambda|x) = \mathcal{N}(\alpha_\lambda x, \sigma_\lambda^2 I), \quad \alpha_\lambda^2 = \frac{1}{1+e^{-\lambda}}, \quad \sigma_\lambda^2 = 1-\alpha_\lambda^2
\]

- 变量：x 为干净数据；zλ 为在噪声水平 λ 下的加噪数据；αλ 和 σλ 分别为信号缩放系数和噪声标准差。
- 直觉：λ 越大，αλ 越接近 1，σλ 越接近 0，zλ 越接近 x；λ 越小，zλ 越接近高斯噪声。
- 优化动作：训练时按 λ 分布采样 λ，用 αλ、σλ 构造 zλ。前向过程还定义了相邻 λ 之间的转移 \(q(z_{\lambda'}|z_\lambda)\)（公式(2)），它保证给定 x 时前后噪声状态服从条件高斯，且均值缩放系数为 \(\alpha_{\lambda'}/\alpha_\lambda\)（§2）。

### 公式（5）：训练目标

\[
\mathbb{E}_{\epsilon,\lambda}\left[\|\epsilon_\theta(z_\lambda) - \epsilon\|^2\right]
\]

其中 \(\epsilon \sim \mathcal{N}(0,I)\)，\(z_\lambda = \alpha_\lambda x + \sigma_\lambda \epsilon\)。

- 变量：\(\epsilon_\theta\) 是去噪网络；\(\epsilon\) 是真实加入的噪声；λ 从 p(λ) 采样。
- 优化动作：最小化预测噪声与真实噪声的 L2 误差。这个损失等价于多尺度去噪分数匹配。论文说明当 p(λ) 均匀时，该目标正比于变分下界（忽略解码器和先验项）；非均匀时是加权变分下界，权重可调以改善采样质量（§2）。
- 工程对应：实际训练中 λ 通过余弦调度变换采样，得到接近均匀但两端受限制的分布。对条件模型，把 c 输入网络即可，即损失函数中把 \(\epsilon_\theta(z_\lambda)\) 替换为 \(\epsilon_\theta(z_\lambda,c)\)；无条件时 c 为 \(\varnothing\)。

### 公式（6）：无分类器引导分数

\[
\tilde{\epsilon}_\theta(z_\lambda,c) = (1+w)\epsilon_\theta(z_\lambda,c) - w\epsilon_\theta(z_\lambda)
\]

- 变量：\(w\) 为引导强度；\(\epsilon_\theta(z_\lambda,c)\) 为条件分数估计；\(\epsilon_\theta(z_\lambda)\) 为无条件分数估计（同一网络输入 \(\varnothing\)）。
- 优化动作：推理时用该混合分数替换普通的条件分数。w=0 时无引导；w>0 时，分数朝条件与无条件之差的方向移动。
- 直觉：该式可看作对隐式分类器 \(p^i(c|z_\lambda) \propto p(z_\lambda|c)/p(z_\lambda)\) 的梯度的近似。若用精确分数 \(\epsilon^*\)，隐式分类器梯度为 \(-\frac{1}{\sigma_\lambda}[\epsilon^*(z_\lambda,c) - \epsilon^*(z_\lambda)]\)，对应引导后的分数为 \((1+w)\epsilon^*(z_\lambda,c) - w\epsilon^*(z_\lambda)\)。但论文强调实际网络输出是非保守向量场，所以式（6）不是某个分类器的梯度，这也恰好避免对抗性解释（§3.2）。此外 Grandvalet & Bengio（2004）指出生成模型推导出的隐式分类器通常不如判别模型，即使生成模型设定正确；在模型误设定时，隐式分类器可能不一致（Grünwald & Langford, 2007）。因此论文并不依赖隐式分类器有良好分类性能，只用它作为直觉来源（§3.2）。
- 工程对应：采样每步需要两次前向传播，分别计算无条件和条件输出。由于每个输出都是网络原始结果，不能保证存在标量势，所以与分类器梯度有本质区别。

### 方差插值公式（4）（可选辅助理解）

\[
p_\theta(z_{\lambda'}|z_\lambda) = \mathcal{N}\left(\tilde{\mu}_{\lambda'|\lambda}(z_\lambda,\hat{x}_\theta(z_\lambda)), (\tilde{\sigma}^2_{\lambda'|\lambda})^{1-v}(\sigma^2_{\lambda|\lambda'})^{v}\right)
\]

- 变量：\(v\) 是固定的插值系数；\(\tilde{\sigma}^2_{\lambda'|\lambda}\) 和 \(\sigma^2_{\lambda|\lambda'}\) 分别是精确反向条件方差和正向条件方差。
- 直觉：在连续时间极限下两者等价；有限步时 v 调节注入噪声的幅度。论文对 64×64 使用 v=0.3，128×128 使用 v=0.2（§4.1）。当 \(\lambda'\to\lambda\) 时，\(\tilde{\sigma}^2_{\lambda'|\lambda}\) 和 \(\sigma^2_{\lambda|\lambda'}\) 简化为同一值，所以 v 只影响有限步采样（§2）。

## 6. 训练到底怎么跑

训练采用 Algorithm 1。一轮训练 step 的具体顺序如下：

1. **抽样数据与条件**：从数据集中抽取一对 \((x,c)\)，其中 c 是类别标签，用于类条件 ImageNet 生成。论文没有写明 batch size 等优化器细节。
2. **随机丢弃条件**：以概率 puncond 将 c 替换为空标记 \(\varnothing\)。论文实验用 puncond ∈ {0.1, 0.2, 0.5}，发现 0.5 明显差，0.1 与 0.2 接近且更好（§4.2，Table 1）。这一步使同一网络既训练条件生成又训练无条件生成。
3. **采样对数信噪比 λ**：从连续分布 p(λ) 采样。具体实现中，对均匀 u∈[0,1]，通过 \(\lambda = -2\log\tan(au+b)\) 得到 λ，其中 \(b=\arctan(e^{-\lambda_{\max}/2})\)，\(a=\arctan(e^{-\lambda_{\min}/2})-b\)。λmin = -20，λmax = 20（§2 和 §4.1）。这个分布是修改为有界区间的双曲正割分布，受 Nichol & Dhariwal（2021）的离散时间余弦噪声调度启发。
4. **采样噪声并构造 zλ**：采样 \(\epsilon \sim \mathcal{N}(0,I)\)，计算 \(z_\lambda = \alpha_\lambda x + \sigma_\lambda \epsilon\)。
5. **前向与损失**：把 zλ 和（可能丢弃后的）c 输入网络，得到 \(\epsilon_\theta(z_\lambda,c)\)，计算损失 \(\|\epsilon_\theta(z_\lambda,c)-\epsilon\|^2\)，然后取梯度。
6. **梯度更新**：反向传播更新网络参数 θ。

训练规模：64×64 模型训练 400k 步；128×128 模型训练 2.7M 步（§4.1）。网络架构与 Dhariwal & Nichol（2021）的 guided diffusion 模型相同，但训练改为连续时间，且未针对无分类器引导重新调超参；由于条件与无条件共享同一网络且没有额外分类器，实际使用的模型容量比之前工作少（§4 开头）。优化器、batch size、学习率等论文未明确披露。

联合训练的关键假设是：随机丢弃条件能在不显著增加参数或训练成本的情况下，同时学到两个分数场。论文表明确实如此，且不需要太多无条件容量。需要强调的是，这里“两个模型”并不是分离的参数集，而是同一网络在不同条件输入下的两种行为，所以总参数量不变。

## 7. 推理到底怎么跑

推理采用 Algorithm 2。给定引导强度 w 和条件标签 c，完整采样顺序如下：

1. **初始化**：从标准高斯采样 \(z_1 \sim \mathcal{N}(0,I)\)。这是 λ=λmin 的起始状态，对应纯噪声。论文固定 λ1=λmin=-20。
2. **设定时间序列**：选择递增的 λ 序列 \(\lambda_1 < \lambda_2 < \cdots < \lambda_T\)，其中 \(\lambda_1=\lambda_{\min}\)，\(\lambda_T=\lambda_{\max}\)。论文使用 T 个均匀间隔的 u 对应 λ（§2），即 u 在 [0,1] 上等分，然后映射到 λ。实验探究 T ∈ {128, 256, 1024}（§4.3）。
3. **循环去噪**：对 t=1 到 T：
   - **两次前向传播**：分别在 zt 上计算条件分数 \(\epsilon_\theta(z_t,c)\) 和无条件分数 \(\epsilon_\theta(z_t,\varnothing)\)。
   - **无分类器引导混合**：\(\tilde{\epsilon}_t = (1+w)\epsilon_\theta(z_t,c) - w\epsilon_\theta(z_t)\)。
   - **预测干净样本**：用混合分数反推 \(\tilde{x}_t = (z_t - \sigma_{\lambda_t}\tilde{\epsilon}_t)/\alpha_{\lambda_t}\)。这个式子可由 \(\hat{x}_\theta(z_\lambda) = (z_\lambda - \sigma_\lambda \epsilon_\theta(z_\lambda))/\alpha_\lambda\) 推广而来（§2）。
   - **采样下一步**：若 t<T，从高斯分布 \(\mathcal{N}(\tilde{\mu}_{\lambda_{t+1}|\lambda_t}(z_t,\tilde{x}_t), (\tilde{\sigma}^2_{\lambda_{t+1}|\lambda_t})^{1-v}(\sigma^2_{\lambda_t|\lambda_{t+1}})^{v})\) 采样 \(z_{t+1}\)；若 t=T，直接返回 \(z_{T+1} = \tilde{x}_T\) 作为最终生成样本。
4. **返回结果**：最终输出 zT+1，即干净图像（近似）。论文强调如果使用无限步，采样的 SDE 路径将服从 p(z)，但有限步时使用祖先采样器。

注意：每步需要两次网络评估，这比普通条件模型多一倍计算。论文明确指出，若与 ADM-G 比较采样速度，公平起见应比较 T=128 的引导模型与 ADM-G 的 T=256；此时 FID 为 3.04（w=0.3），略差于 ADM-G 的 2.97；但 w=0.4 时 FID 3.02 也与 2.97 接近（§4.3，Table 2）。这说明双前向成本是该方法的直接代价。

另外，Algorithm 2 中虽然提到“could be replaced by another sampler, e.g. DDIM”，但论文实验使用的是祖先采样方式（§2、Algorithm 2），没有实际切换到 DDIM。

## 8. 实验和消融到底证明了什么

论文实验均为概念验证，没有刻意打 SOTA，但结果仍然有竞争力。核心数据集为 ImageNet 64×64 和 128×128 类条件生成。评估使用 50000 个生成样本计算 FID 和 Inception Score，遵循 Heusel et al.（2017）和 Salimans et al.（2016）流程（§4.1）。所有模型使用 λmin=-20、λmax=20；64×64 模型 v=0.3，训练 400k 步；128×128 模型 v=0.2，训练 2.7M 步（§4.1）。

### 最关键消融及解释

最关键消融是 **puncond**（无条件训练概率）。因为无分类器引导完全依赖无条件分数与条件分数之差。如果无条件模型训练不充分，差值就不准确；如果无条件任务占据过多容量，条件模型本身质量会下降。实验显示 puncond=0.5 整体曲线显著差于 0.1/0.2，说明网络容量分配存在一个偏条件侧的甜点，只需少量无条件训练即可提供有效引导信号（§4.2）。这验证了方法对 puncond 的鲁棒性有限，但设置简单。论文还将该现象与 Dhariwal & Nichol 报告“较小分类器足以完成引导”进行了类比，说明低成本辅助信号在两种引导中都成立（§4.2）。

### 尚未证明的主张

- 论文只验证了 ImageNet 类条件图像生成，未在文本、音频或其他条件类型（如文本到图像）上验证（结论提到“期待未来在更广泛设置和数据模态中探索”）。
- 论文未证明无分类器引导的隐式分类器具有良好校准或分类精度；相反，论文承认生成模型导出的分类器可能不如判别模型，且模型误设定可能导致不一致（§3.2）。
- 论文未给出理论保证：为什么式（6）能产生类似截断的效果，只有直觉和实验支持，缺少严格分析。
- 论文未解决多样性降低的伦理/部署问题，仅提出未来可研究保持多样性的质量提升（§5）。
- 论文未尝试优化超参数或架构以适应 CFG，可能低效；作者明确说超参来自分类器引导工作，可能次优（§4）。
- 论文没有给出 p(λ) 和 v 对无分类器引导的专门消融，这两个参数沿用了前作设定。

## 9. 与前作怎么选

### 与分类器引导（Dhariwal & Nichol, 2021）比较

- **何时选分类器引导**：如果已有在噪声数据上训练好的分类器，且分类器比主扩散模型小很多，推理时分类器引导可能更快（因为分类器前向通常比生成模型便宜）；或者当额外分类器本身有用（如可解释性、可控性）时。论文指出一般分类器可以比生成模型小、快（§5）。
- **何时选无分类器引导**：希望避免训练额外分类器；希望保持训练管线简单；担心分类器引导的对抗性解释；或条件生成任务中没有适合的预训练分类器。论文结果显示 CFG 能达到类似甚至更好的 FID/IS（Table 2 中 w=0.3 优于 ADM-G 的 2.97），但推理需要两次主网络评估。

### 与普通条件扩散模型（无引导，w=0）比较

- **何时选无引导**：当样本多样性比单样本保真度更重要，或推理预算紧张需要单次前向。论文中 w=0 时 FID 差（64×64 为 1.8，128×128 为 8.11），IS 低。
- **何时选 CFG**：需要“低温”样本，即追求更清晰、更典型的类别样本；这是常见的图像生成审美需求。扫 w 可以得到 FID/IS 连续权衡曲线。

### 与 GAN 截断（BigGAN-deep truncation）比较

- **何时选 GAN 截断**：如果已有高性能 GAN 且推理成本限制严格；GAN 单步生成快得多。
- **何时选 CFG**：扩散模型在覆盖模式、似然估计、训练稳定性上可能优于 GAN；Table 2 显示 CFG 在 w=4.0 时 FID 21.53 和 IS 421.03 均优于 BigGAN-deep 最佳 IS 截断水平的 FID 25、IS 253（§4.1）。论文还比较了 CDM（Ho et al., 2021）的 FID 3.52、IS 128.8 和 LOGAN（Wu et al., 2019）的 FID 3.36、IS 148.2，显示 CFG 在这些指标上有竞争力（Table 2）。

总体而言，无分类器引导适合那些已经决定使用扩散模型、希望提升保真度、且不想维护额外分类器的场景。论文也提到若类别分布已知且类别很少，可以从条件分数加权求和得到无条件分数，避免显式训练无条件模型，但计算量与类别数成正比，高维条件不可行（§5）。

## 10. 工程判断：可行性、风险与上限

### 可行性

论文显示的方法可行性很高：实现上只涉及训练时以概率丢弃条件、推理时混合两个分数，改动极小。由于共享一个网络，没有额外参数，训练成本与普通条件扩散模型基本相同，除了每步可能因为条件丢弃导致梯度的统计波动。论文在 ImageNet 64×64 和 128×128 上成功训练，说明在大规模图像生成上可行。

### 数据与算力/延迟

- **数据**：实验仅使用 ImageNet 类条件数据，未展示对小数据集、非类条件（如文本提示）或其他模态的效果。数据规模需求继承自 base 扩散模型，论文未具体分析数据量，但 ImageNet 128×128 约 128 万训练图像，64×64 和 128×128 模型分别训练 400k 和 2.7M 步。
- **算力**：训练额外小，因为网络只前向一次；推理每步需要两次主网络前向，导致延迟约为普通条件扩散模型的两倍。论文指出与 ADM-G 比较时，若考虑相同前向次数，CFG 的 T=128 相当于 ADM-G 的 T=256；此时 FID 3.04 vs 2.97，CFG 略差（§4.3）。因此需要更高质量但可接受更高延迟的场景。
- **推理步数**：T=256 是论文推荐的平衡点；T 更小则 FID 明显上升，更大收益不大。这也与两次前向导致的成本敏感有关。

### 实现难点

- **条件丢弃概率调参**：puncond 需要调整；过大损害条件模型能力，过小可能导致无条件分数噪声大。论文未给出自动调节方式，只给出 0.1/0.2 表现好、0.5 差的经验。
- **引导强度 w 的标定**：不同数据集和模型可能需要不同的 w 范围；论文扫描 w∈{0,0.1,...,4} 发现最优 FID 在 w=0.1 或 0.3，但未给出选择准则。w 没有归一化，跨模型不可直接迁移。
- **网络容量分配**：共享网络需要同时支持条件与无条件任务，可能需要更大的模型容量或 careful tuning。论文使用的 base 架构未调整，但效果可以；对更复杂条件（如长文本）可能成为瓶颈。
- **采样方差 v**：需要固定合适的 v；论文对 64×64 用 0.3，128×128 用 0.2，但这是来自前作的经验。v 不合适可能造成采样过度随机或过度平滑（§2 提到 v 的影响只在有限步出现）。
- **非保守分数场**：因为网络输出不保证是梯度，某些理论工具（如能量解释）不适用于 CFG 分数方向；但论文认为这正是避免对抗性解释的原因（§3.2）。

### 失败环节与监控信号

- **潜在失败**：如果无条件模型训练不足，引导分数 \(\epsilon_\theta(z_\lambda,c)-\epsilon_\theta(z_\lambda)\) 会引入额外噪声，导致样本畸变或模式塌缩；puncond 过大时已经看到整体质量下降。如果 w 过大，FID 会急剧上升（Table 1 中 w=4 时 FID 26），产生极端饱和、多样性极差，如图 6/7 中强引导样本颜色饱和。
- **监控信号**：训练时监控去噪损失（条件与无条件分别）是否收敛；采样时监控引导分数差值的范数；评估时绘制 FID-IS 曲线，观察 w 扫描是否单调合理；观察无条件生成的样本质量以判断 puncond 是否足够。论文没有给出自动化监控方案，这些是基于其描述可合理推断的工程做法。

### 指标上限与未回答问题

- **指标上限**：论文在 128×128 ImageNet 上达到 FID 2.43（w=0.3，T=256）和 IS 421.03（w=4.0），这在当时优于 ADM-G，但论文并未声称这是绝对上限；作者指出超参为分类器引导调优，可能次优，未来调整可能进一步提高。
- **未回答问题**：如何自动选择 w 和 puncond？如何在保持多样性的同时提高保真度？如何在多步推理中降低双前向成本（如后期注入条件）？无分类器引导在其他条件模式（连续条件、文本到图像）上表现如何？隐式分类器的行为是否可理论化？论文在 §5 明确把“多样性降低的接受度”和“减少多 pass 的架构改进”列为未来方向。

## 11. 放回研究脉络并收束

### 研究脉络

本文处于扩散模型生成质量提升的时间线上。早期扩散模型（Ho et al., 2020）在 FID 上不如 GAN；Dhariwal & Nichol（2021）通过架构改进和分类器引导使扩散模型在 ImageNet 上超越 BigGAN。本文延续 Dhariwal & Nichol 的 guided diffusion 框架，但移除分类器，提出更简洁的引导方式。它同时与“低温采样”概念相连：GAN 的截断、流模型的低温采样都是在推理阶段降低多样性提升质量；扩散模型此前缺少有效等价物，简单缩放分数或减少注入噪声不能产生类似效果（Dhariwal & Nichol, 2021）。无分类器引导填补了这个空白，并成为后续文本到图像扩散模型广泛采用的基础技术（论文发表前未提及）。论文还连接了生成模型与隐式分类器的关系，指出非保守分数场的引导不等同于分类器梯度，回应了对抗性解释问题。因此它在概念上厘清了“引导不需要分类器”这一原则，并展示了纯生成模型在分类器风格指标上的能力。

### 读完必须记住的 5 件事

1. **无分类器引导公式**：\(\tilde{\epsilon}_\theta(z_\lambda,c) = (1+w)\epsilon_\theta(z_\lambda,c) - w\epsilon_\theta(z_\lambda)\)，通过混合条件与无条件分数实现引导，无需分类器。
2. **联合训练技巧**：用单个网络，在训练时以概率 puncond 随机将条件 c 替换为空标记 \(\varnothing\)，同时学习条件与无条件模型。
3. **FID/IS 权衡**：w 从 0 增到 4 时，IS 上升、FID 先降后升；最优 FID 在 w≈0.3，最优 IS 在 w≥4。
4. **puncond 只需小概率**：实验显示 0.1 或 0.2 远好于 0.5，说明无需大量容量分配给无条件任务。
5. **成本代价**：推理每步需要两次主网络前向，因此相同前向次数下与分类器引导相比没有速度优势；论文建议比较时公平考虑 T。

### 5 道自测题

1. 写出无分类器引导的分数混合公式，并说明 w=0 和 w>0 分别对应什么行为？
2. 训练时如何让一个网络同时具备条件和无条件去噪能力？关键超参数是什么？
3. 为什么 λ 被称为对数信噪比？前向过程沿哪个方向增加 λ？
4. 在 64×64 ImageNet 实验中，puncond 分别为 0.1、0.2、0.5 时，哪个最差？这说明了什么？
5. 无分类器引导相比分类器引导的推理速度如何？论文如何公平比较采样步数？

**最终一句话总结**：无分类器引导证明，通过对条件与无条件扩散模型分数做简单线性外推，就能在不使用任何分类器的情况下实现扩散模型的“低温采样”，并在 ImageNet 上取得与分类器引导相当的 FID/IS 权衡，代价仅是推理时多一次网络前向。
