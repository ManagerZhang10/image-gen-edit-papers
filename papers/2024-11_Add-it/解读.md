# 大白话深读《Add-it》

## 1. 30 秒定位

Add-it 是一个训练无关（training-free）的图像物体插入方法，目标是根据一句文本提示，把新物体自然地加到现有图像中，同时尽量保留原图的结构与细节。方法基于预训练的 FLUX 扩散模型，通过“加权扩展自注意力”同时利用三个信息源：源图像、文本提示、生成中的目标图像；再配合“结构迁移”和“主体引导潜在混合”两个技巧，在不需要微调模型的情况下完成物体插入。论文还提出“Additing Affordance Benchmark”，专门评估物体是否被放在合理位置。实验显示，在 Emu-Edit 验证子集上，Add-it 的 CLIPdir 为 0.101、CLIPout 0.322、Inclusion 81%（Table 2）；在自建 Affordance 基准上得分 0.828，接近第二名 Prompt-to-Prompt 0.474 的两倍（Table 1）。人类评估中，相比 InstructPix2Pix、EraseDraw、MagicBrush 等胜率超过 79%（Figure 3）。该方法能用于真实图像和生成图像，并支持逐步搭建复杂场景。与监督方法相比，Add-it 不经过任何训练或微调，只依赖预训练扩散模型和外部工具 SAM-2，因此可以快速部署，同时保留了基础模型的生成多样性与开放世界知识。

## 2. 为什么这篇论文会出现

“往图像里加一个物体”看似简单，实际是语义图像编辑中长期未解决的难题。要成功插入物体，必须同时满足三件事：保留源场景、让新物体符合文本指令、把物体放在上下文合理的位置。论文把失败模式归纳为三类：忽视（neglect，根本没加物体）、外观（appearance，加了但视觉不一致）、可供性（affordance，物体放错地方）。早期训练无关方法如 Prompt-to-Prompt（Hertz et al., 2022）和 SDEdit（Meng et al., 2022）虽然在风格迁移、局部修改等任务上有效，但用于物体添加时表现糟糕：Prompt-to-Prompt 会严重改变源图，SDEdit 经常忽略指令（Figure 6）。另一类监督学习方法，如 InstructPix2Pix（Brooks et al., 2023）、MagicBrush（Zhang et al., 2023）、EraseDraw（Canberk et al., 2024），在大规模编辑数据上训练，但它们常常产生伪影、放错位置，尤其是可供性得分极低。论文 Table 1 显示，InstructPix2Pix 的 affordance 只有 0.276，MagicBrush 为 0.418，EraseDraw 为 0.341，而最佳训练无关方法 Prompt-to-Prompt 也只有 0.474，证明现有方法离“开放世界物体插入”还很远。

作者认为，现代扩散模型（如 SD3 和 FLUX）内部已经蕴含丰富的物体-场景关系知识，只要合理控制注意力分配，就能在不训练的情况下利用这些知识。他们的核心思路是：在 MM-DiT 注意力块中，让目标图像同时注意到源图像、自身和文本提示，并引入可调的权重因子 γ 来平衡三者。在此基础上，作者还发现随机种子的结构差异会导致物体尺寸或布局与源图不匹配，因此提出结构迁移来借用源图的全局结构；同时为了保留背景细节，提出主体引导潜在混合。这一思路不需要数据集训练，不需要微调，而且还能评估此前被忽视的“affordance”问题。论文还专门指出，现有 CLIP 类的自动指标无法可靠评估物体放置合理性，因此有必要构建新基准。

## 3. 读懂前需要的最小概念

**扩散模型与去噪**：本文基于 FLUX.1-dev，它在潜在空间（latent）中迭代去噪，从纯噪声逐步生成图像。不同于经典 DDPM，FLUX 使用 rectified flow：前向加噪为 \(X_t = (1-\sigma_t)x_0 + \sigma_t \epsilon\)，其中 \(x_0\) 是原始潜在，\(\epsilon \sim \mathcal{N}(0, I)\)，\(\sigma_t\) 是时间依赖的噪声强度。去噪时网络预测速度 \(v_\theta\)，可用来估计当前 \(X_0\)，公式为 \(X_0 = X_t + (\sigma_{t+1} - \sigma_t)\cdot v_\theta\)，该估计在潜在混合阶段被用来给 SAM-2 提供近似干净图像。

**MM-DiT 注意力**：FLUX 的扩散骨干是 DiT（Diffusion Transformer）。它把文本 token 和图像 patch token 拼接起来送入统一的多模态自注意力层。FLUX 有两种块：Multi-stream blocks（文本和图像用不同的 Q/K/V 投影矩阵）和 Single-stream blocks（共享投影矩阵）。模型结构上先是一系列 Multi-stream blocks，后接一系列 Single-stream blocks。注意力计算就是标准的 softmax(q·k^T/√d_k)·v。本文方法就在这套注意力上做扩展。

**CLIP 指标**：CLIP 是图文对比模型，用来衡量图像和文本的相似度。本文用到 CLIPdir（源-目标图像变化与源-目标文本变化的一致性）、CLIPout（输出图像与目标文本的相似度）、CLIPim（输出与源图的相似度）等。这些指标来自 Emu-Edit 的评估设定。

**其他工具**：Grounding-DINO 是开放词汇检测模型，用于判断物体是否出现以及检测位置；SAM-2 是可提示分割模型，用于生成精细掩码；Otsu 方法是自动阈值算法，用于将注意力图二值化，动态确定分割阈值。

## 4. 方法全景：先看数据流

下面先画整体推理数据流，然后拆解核心组件。

```
源图像 x_source
   │
   ├─(真实图: 随机噪声ε逐步注入)─→ 源潜在 Z_source(t)
   └─(生成图: 保存原噪声 ε_source)─→ 源潜在 Z_source(t)
                                           │
                                  结构迁移: 加噪到 t_struct
                                           │
                                           ▼
文本提示 P_target ────────┐             并行去噪
                           ▼                │
目标噪声 ε_target ──→ 目标潜在 Z_target(t=0)──┤
                                           │
                        加权扩展自注意力（源K/V、文本K/V、目标K/V）
                                           │
                                           ▼
                        到 t_blend，提取注意力图→Otsu→SAM-2 细化
                                           │
                                           ▼
                        潜在混合：M⊙Z_target + (1-M)⊙Z_source
                                           │
                                           ▼
                                      输出图像
```

整个流程可以分成三个阶段：初始化与结构迁移、带加权扩展注意力的并行去噪、主体引导潜在混合。下面逐一拆解。

**核心组件一：加权扩展自注意力（Weighted Extended Self-Attention）**。在 FLUX 的每个 MM-DiT 注意力块中，原来只有文本 token 和当前图像 token。Add-it 让当前目标图像 token 额外注意到源图像 token 的键（K）和值（V），同时给三个来源的键加上权重系数 γ_s、γ_p、γ_t，值向量（V）不加权。实践中发现直接用扩展注意力（γ=1）会导致源图主导，目标图完全复制源图，忽略文本提示，即“neglect”失败模式。因此引入可调权重来重新平衡注意力分布。作者定义了一个函数 \(f(\gamma) = A_{source} - A_{target}\)，其中 \(A_{source}\) 是提示 query 对源图像键的注意力，\(A_{target}\) 是对目标图像键的注意力，两者都除以 softmax 归一化项 Z。使用根求解器（root-solver）找到令 f(γ)=0 的 γ，从而让提示 token 在源图和目标图上的注意力大致相等。在验证集上运行根求解器并取平均后，作者固定 γ=1.05 用于所有实验（附录 A.1），这样避免了每个样本都做根求解的额外开销。Figure 7(B) 展示了 γ=1.0 时源图 token 的注意力远高于目标图，γ=1.2 时发生反转，γ=Auto 时达到平衡，此时物体既能被加入，又不会破坏源图结构。

**核心组件二：结构迁移（Structure Transfer）**。如果随机选择目标噪声，生成图像的物体大小和位置经常与源图不一致，比如狗太大放不下椅子。作者发现，把源潜在变量加噪到较高噪声水平 t_struct 之后再开始去噪，可以保留源图的全局结构，同时允许内容变化。具体做法是按照 rectified flow 公式对干净源潜在 \(X_{source}\) 加噪到时间步 t_struct，得到 \(X_{t_struct}^{source} = (1-\sigma_{t_struct})X_{source} + \sigma_{t_struct}\epsilon\)，其中 \(\epsilon\) 是随机采样的高斯噪声。当 t_struct 足够大时，从这个高噪声状态开始去噪会生成与源图全局结构相似的图像。对于生成图，t_struct=933；对于真实图，t_struct=867（附录 A.1）。这个机制相当于“借用”源图的结构先验，解决随机种子导致的结构偏移。Figure 8 消融显示，t_struct 过大（在高噪声下过早应用结构迁移）会导致生成图与源图结构失配，t_struct 过小（在低噪声下过晚应用）会导致物体被完全忽略，合适的 t_struct 能在两者之间取得平衡。

**核心组件三：主体引导潜在混合（Subject Guided Latent Blending）**。加权注意力和结构迁移可以保持大体一致，但细微纹理和小背景物体可能仍会改变。朴素做法是用掩码把未编辑区域直接粘贴回源图，但完美掩码难获取，且会丢失新物体带来的阴影、反射等间接效果。Add-it 采用两阶段掩码生成：先提取物体 token 对应的自注意力图。具体地，使用目标图像 patch 的 query \(Q_{target}\) 与物体 token 的 key \(k_{object}\) 相乘得到注意力分数，再从指定层聚合。作者通过实验选定了五个层：transformer blocks 13, 14, 18 以及 single transformer blocks 23, 33（附录 A.1）。对这些注意力图应用 Otsu 动态阈值得到粗掩码 M_r。为了给 SAM-2 提供局部化提示，作者迭代地选取注意力图中的局部最大值点：先取最大值点，然后排除该点周围区域，再取下一个最大值，直到选出 4 个点或当前最大值低于初始最大值 p_max 的 0.35 倍。这些点作为 SAM-2 的点提示，生成精细掩码 M。由于 SAM-2 需要输入干净图像而非噪声潜在，作者利用当前速度预测估计 \(X_0\)。最后在 t_blend=500 时执行潜在混合：\(Z_{target} = M \odot Z_{target} + (1-M) \odot Z_{source}\)。这样既保留背景，又允许新物体周围的光影变化（§3.4，Figure 9）。

**真实图像处理**。真实图像没有原始噪声，传统 DDIM 反演在 FLUX 上重建效果差。Add-it 采取一个简单方案：不反演，而是随机采样一个噪声 ε，在每一步构造源潜在 \(X_t^{source} = (1-\sigma_t)X_{source} + \sigma_t \epsilon\)。由于 σ_0=0，最后一步源图能完美重建。然后把源潜在和目标潜在组成 batch 一起送入去噪（§3.5）。这个办法绕开了反演问题，但真实图效果仍略逊于生成图（§6）。

以上所有组件都是推理阶段的操作，没有训练参数。

## 5. 核心公式与直觉

**公式（1）：FLUX 基础 MM-DiT 注意力**
\[
A = \text{softmax}\left(\frac{[Q_p, Q_{img}][K_p, K_{img}]^\top}{\sqrt{d_k}}\right), \quad h = A \cdot [V_p, V_{img}]
\]
变量：\(Q_p, K_p, V_p\) 是文本 prompt 的查询、键、值；\(Q_{img}, K_{img}, V_{img}\) 是图像 patch 的查询、键、值。这是标准自注意力，文本和图像互相看对方。它对应 FLUX 中 Multi-stream 或 Single-stream 块的基本操作。

**公式（2）：朴素扩展注意力**
\[
A = \text{softmax}\left(\frac{[Q_p, Q_{target}][K_{source}, K_p, K_{target}]^\top}{\sqrt{d_k}}\right), \quad h = A \cdot [V_{source}, V_p, V_{target}]
\]
这里目标图像的查询可以额外 attend 到源图像的 K/V。但实验发现源图 token 会吸引过多注意力，导致 prompt 被忽略，最终输出是源图的复制。这体现了不平衡问题。具体来说，提示 token 的注意力在源图上的分布远高于目标图，文本条件失去作用。

**公式（3）：加权扩展注意力**
\[
A = \text{softmax}\left(\frac{[Q_p, Q_{target}][\gamma_s K_{source}, \gamma_p K_p, \gamma_t K_{target}]^\top}{\sqrt{d_k}}\right), \quad h = A \cdot [V_{source}, V_p, V_{target}]
\]
引入缩放因子 γ 对键进行加权，注意值不加权。增大 γ 对应增大对应来源的注意力 logit，从而改变 softmax 分布。实践中设置 γ_s=1，γ_p=γ_t=γ，并自动寻找 γ 使提示 token 在源图和目标图上的注意力相等。定义：
\[
A_{source} = \frac{\exp(Q_p \cdot K_{source})}{Z}, \quad A_{target} = \frac{\exp(\gamma \cdot Q_p \cdot K_{target})}{Z}
\]
其中 Z 是归一化项。令 \(f(\gamma) = A_{source} - A_{target}\)，用根求解器找到使 f(γ)=0 的 γ。在验证集上平均后取 γ=1.05（Appendix A.1）。直觉是：如果 γ 太小，源图注意力占优，物体不加；γ 太大，目标图注意力占优，脱离源结构。Figure 7(B) 展示了 γ=1.0 时源图（紫色）远高于目标图（橙色），γ=1.2 时反转，γ=Auto 时达到平衡。

**整流流加噪公式**：结构迁移中用到
\[
X_t = (1-\sigma_t)x_0 + \sigma_t \epsilon
\]
当 t 大时（接近纯噪声），从 \(X_t\) 开始去噪会生成与 \(x_0\) 全局结构相似的图像。这是源于训练目标：模型在训练时见过带噪样本 \(X_t\) 与干净样本 \(x_0\) 的配对，因此在给定 \(X_t\) 时会趋向重构出与 \(x_0\) 结构一致的图像。作者通过消融发现 t_struct=933（生成图）或 867（真实图）能平衡结构和内容的改变（Figure 8）。

## 6. 训练到底怎么跑

Add-it 没有任何训练步骤。所有参数都来自预训练 FLUX.1-dev，不进行微调、不更新权重、不训练额外模块。因此“训练流程”严格来说不存在。

如果要描述实验准备阶段，只是设置固定的推理超参数。论文及附录 A.1 给出的默认配置如下：
- 使用 FLUX.1-dev 的 diffusers 实现，30 步去噪。
- 结构迁移时间步 t_struct：生成图为 933，真实图为 867。
- 潜在混合时间步 t_blend=500。
- 权重缩放 γ：通过在验证集上运行根求解器，取平均后固定为 1.05。注意实际使用时也可按每个样本动态求解，但论文固定为 1.05，以简化流程并保证稳定性。
- 扩展注意力在 multi-stream blocks 中应用到 t=670 步，在 single-stream blocks 中应用到 t=340 步。也就是说，在去噪后期不再使用扩展注意力，以允许目标图像自由生成细节。对应地，结构迁移和潜在混合发生在这些时间步之前或之中。
- SAM-2 使用的注意力层为 transformer blocks 13, 14, 18 和 single transformer blocks 23, 33。从注意力图采样最多 4 个点作为 SAM-2 提示，点采样条件为局部最大值且当前最大值大于 0.35·p_max（附录 A.1）。

由于是无训练方法，没有损失函数、优化器、学习率、epoch 等概念。整个方法只依赖 FLUX 的推理过程和外部工具（SAM-2、Grounding-DINO 仅用于评估）。这种设计使得 Add-it 可以随时替换为更新、更强的扩散模型，但代价是推理计算比直接生成一张图多：需要并行去噪源图像和目标图像，并在 t_blend 时额外执行一次注意力图提取和 SAM-2 分割。此外，根求解 γ 的过程在论文中只在验证集上进行一次，推理时使用固定值，因此不会引入额外的每样本优化开销。这种“一次性标定，全局使用”的策略降低了工程复杂度。

## 7. 推理到底怎么跑

**输入**：源图像 x_source（真实或生成）、文本提示 P_target（描述要加入的物体，如“A man sitting at the table”）。

**情况 A：源图是生成图**。在生成源图时保存其初始噪声 ε_source。现在采样一个新的目标噪声 ε_target，将它们组成一个 batch。处理时，需要首先获得源图的干净潜在（通常由源图的 VAE 编码得到），然后按结构迁移公式加噪到 t_struct，再与目标潜在一起送入去噪网络。

**情况 B：源图是真实图**。无法获得原始噪声，采用随机噪声法：采样一个随机噪声 ε，在每个去噪步 t 构造源潜在 \(X_t^{source} = (1-\sigma_t)X_{source} + \sigma_t \epsilon\)。目标潜在 \(X_t^{target}\) 从随机噪声开始正常去噪。两者组成 batch。注意这里源潜在在每个去噪步都重新构造，以保证结构迁移在对应时间步 t_struct 时恰好是加噪后的源图。

**结构迁移**：对源潜在 \(X_{source}\) 加噪到 t_struct（生成图 933，真实图 867），使其带有高噪声但保留全局结构。对于真实图，结构迁移是在去噪开始前直接构造出 \(X_{t_struct}^{source}\)；对于生成图，则需要从干净源潜在按同样公式计算。完成结构迁移后，从 t_struct 开始，batch = [源潜在, 目标潜在] 一起送入 FLUX 去噪。

**并行去噪**：从 t=t_struct 开始，batch 送入 FLUX 去噪网络。在每个去噪步中，对 multi-stream blocks（t>670）和 single-stream blocks（t>340）应用加权扩展自注意力。此时目标图像的 query 会同时 attend 到源图像、提示文本、目标图像三类 K/V，但 K 上带权重 γ=1.05。这个机制让目标图像在保留源结构的同时，根据提示生成新物体并合理放置。去噪持续到 t_blend=500。

**潜在混合**：在 t_blend=500 时，暂停去噪，从目标图像的注意力图中提取物体 token 的注意力图。具体地，从预定的五个注意力层（transformer blocks 13,14,18 和 single transformer blocks 23,33）提取 query 与物体 token key 的点积，聚合得到注意力图。用 Otsu 动态阈值得到粗掩码，再按照迭代局部最大值方法采样最多 4 个点作为 SAM-2 的点提示，生成精细掩码 M。由于 SAM-2 需要干净图像输入，先利用当前速度预测估计 \(X_0\)。然后执行 \(Z_{target} = M \odot Z_{target} + (1-M) \odot Z_{source}\)。这样目标潜在中未被物体覆盖的区域直接替换为源潜在，但物体区域及其邻近部分（阴影、反射）仍来自生成过程。混合后继续去噪直到 t=0。

**输出**：解码目标潜在得到最终图像。如果是生成图，整个 batch 包含源图和目标图，输出目标图；如果是真实图，源图在 t=0 时完全等于原始真实图，因此也可以一起输出作为保真参考。

这种并行去噪加混合的设计，使得扩展注意力在早期负责布局和语义，混合在后期负责像素级一致性。整个推理流程不需要对网络权重做任何修改，只改变注意力输入和潜在混合步骤。

**最关键消融：权重 γ 的作用与自动调节**。Figure 7(A) 显示，固定 γ 从 1.0 增大到 1.2，Inclusion 先上升后趋于平稳，Affordance 则在 γ 过大时明显下降。γ=Auto 时两个指标达到较好平衡，作者称自动权重缩放实现了“good balance between the two”。Figure 7(B) 显示提示 token 注意力在源图、目标图、文本上的分布随 γ 变化，γ=Auto 时源图和目标图注意力接近相等。这直接证明了平衡三源注意力是核心机制，也说明 γ 如果设置不当会重新引入“忽视”或“脱离源结构”的失败模式。

**结构迁移时机消融**：Figure 8 展示了不同 t_struct 值对生成结果的影响。当 t_struct 过大（在去噪更早阶段应用结构迁移，噪声过高）时，生成图与源图结构失配，affordance 分数较低；当 t_struct 过小（在去噪较晚阶段应用，噪声过低）时，物体被忽略，Inclusion 指标下降。合适的 t_struct（生成图 933，真实图 867）能同时保持物体出现和位置合理。论文明确说“Applying it too early misaligns the generated images with the source image’s structure while applying it too late causes the output image to neglect the object”，这个消融验证了结构迁移与语义编辑之间的权衡。

**潜在混合的必要性**：Figure 9 显示去掉 latent blending 后，虽然大体结构保留，但会引入源图没有的细节变化（如女孩的眼镜消失、自行车阴影改变）。加入混合后这些背景细节得到恢复，同时新物体区域仍然自然。混合时间 t_blend=500 也是经验选择，论文没有给不同 t_blend 的消融，说明该参数敏感度可能较低。

**未证明或受限的主张**：论文承认真实图像效果不如生成图像，归因于 FLUX 反演算法不够好，并认为更强的反演可能缩小差距（§6）。此外，方法继承预训练模型偏见，可能不适合陌生或高度复杂场景。图 10 显示当源图中已经存在同类物体时，提示“another dog”可能无法添加第二个同类对象，需要更具体的描述如“Two dogs sitting on the grass”。附录 Figure 16 还有更多失败案例：把眼镜放在枕头上时位置不对，把“surfing Pikachu”加到水中时可能替换已有物体，以及复杂烹饪场景中稳定性不足。这些说明方法对提示措辞敏感，并非完全开放世界，且真实图域仍有明显差距。此外，自动指标 CLIPdir 和 CLIPout 的绝对值都不高（最高 0.322），说明 CLIP 对细粒度编辑质量不敏感，人类偏好仍然是更可靠的评价信号。

## 9. 与前作怎么选

对比最接近的几类方案：

- **Prompt-to-Prompt (P2P)**：通过注入源图的交叉注意力图来保留结构。优点是无训练、易实现。缺点是必须知道源图对应的原始 prompt，且对物体添加任务容易忽略目标提示，导致源图大幅改变（Table 2 中 CLIPim 仅 0.850，Additing Benchmark 中 CLIPdir 0.170，Inclusion 高达 97% 但 CLIPim 低）。适合反向修改（如替换物体、风格迁移）而非插入新物体。

- **SDEdit**：对源图加一定噪声再从中间去噪。实现简单，但不理解物体应当放置的合理位置，往往破坏结构或完全忽略提示。Table 2 中 Inclusion 只有 60%，CLIPdir 仅 0.091，CLIPim 0.955 说明其输出与源图相似但变化不足。适合轻度纹理修改或局部增强，不适合开放式物体插入。

- **InstructPix2Pix / MagicBrush / EraseDraw**：都经过监督训练，能够理解显式编辑指令。优点是不需要用户构造目标 prompt，对某些训练分布内的编辑表现好。缺点是泛化差、affordance 极低（Table 1 中 InstructPix2Pix 0.276，MagicBrush 0.418，EraseDraw 0.341），且经常不执行插入（Inclusion 55%~76%）。适合训练数据覆盖的简单编辑，不适合复杂场景或真实开放世界。

- **Add-it**：训练无关，基于 FLUX 的强先验，在各项指标和人类偏好上明显占优。缺点是推理时需要并行去噪加 SAM-2 分割，计算开销高于单个扩散生成；用户需要写目标 prompt 而非直接给指令；对真实图像效果受限。适合需要高质量、合理放置的物体插入，以及逐步构建复杂场景。

选择建议：如果任务要求指令式编辑（如“把左边的椅子换成红色”）且数据分布简单，可先用 InstructPix2Pix 类模型；如果只需轻微改动，SDEdit 足够。但若目标是自然插入新物体，特别是希望合理放置，当前 Add-it 更优，但需接受额外的推理时间和 FLUX 的潜在偏见。另外，对于生成图像的编辑，Add-it 更容易获得源噪声，因此效果更好；对于真实图像，用户需要对结果期望稍低。

## 10. 工程判断：可行性、风险与上限

**数据与依赖**：Add-it 不新增训练数据，只依赖预训练 FLUX.1-dev 和 SAM-2。评估需要 Grounding-DINO。没有额外数据清洗或标注。工程实现上需要集成 diffusers 和 SAM-2，并修改 FLUX 的注意力机制以支持源图 K/V 拼接和权重缩放。论文使用的层选择（transformer blocks 13,14,18 和 single transformer blocks 23,33）是基于 FLUX 的特定架构，若更换基础模型需要重新验证这些层对注意力图质量的影响。

**算力/延迟**：每次编辑需要并行去噪源图和目标图，batch 大小翻倍，显存和耗时大约相对于单图生成增加一倍（30 步去噪）。潜在混合阶段需额外运行 SAM-2，但 SAM-2 推理通常比扩散去噪快。整体延迟可能为单图生成的 1.5~2 倍。对于实时应用有压力，但离线编辑可接受。此外，根求解 γ 只在标定阶段进行，推理时使用固定 1.05，因此不会增加每样本优化开销。

**实现难点**：第一，根求解 γ 需要采样注意力分布，增加额外设计；若固定 γ=1.05 对某些样本可能不平衡，尤其是当源图和目标图的内容复杂度差异大时。第二，注意力图提取质量影响掩码，进而影响混合；复杂场景中物体 token 注意力可能分散，导致 SAM-2 点提示不准。第三，结构迁移超参数 t_struct 依赖于 base 模型和时间步调度，换模型需要重新标定。第四，扩展注意力的时间步范围（multi-stream blocks 到 670，single-stream blocks 到 340）也是与 FLUX 时间步调度绑定的，不可直接迁移到其他扩散模型。

**失败环节**：观察失败案例（Figure 10，附录 Figure 16）包括：源图中已有同类物体时无法添加第二个（出现复制而非新增）；物体太小或与场景交互复杂时可能放错位置；真实图像由于反演缺失，细节保持不如生成图。此外，提示设计不当（如只说“A dog”）会失败，因为模型把它理解为描述现有物体而不是新增物体。还有，位置编码实验（附录 A.3）表明模型强烈依赖源图的位置编码来转移物体位置，如果源图和目标图的布局发生偏移，物体位置会跟着偏移，这可能在某些场景下产生奇怪结果。

**监控信号**：可以通过可视化提示 token 注意力分布来诊断 γ 是否平衡；可以通过 Inclusion 检测物体是否出现；通过 Affordance 检测位置是否合理；通过 CLIPim 检测源图保留程度。这些指标可在离线评估中自动化，但在线实时监控较困难。此外，SAM-2 点提示的数量和质量可用注意力图的最大值与阈值 0.35·p_max 的关系来粗判：如果只得到很少的点，说明注意力图不够集中，掩码可能不可靠。

**指标上限**：Affordance 已达到 0.828，离 1.0 仍有距离，主要受限于复杂场景中可供性推理的困难。CLIPdir 与 CLIPout 绝对值不高（0.101~0.322），因为 CLIP 本身对图像编辑细微差异不敏感，不能完全代表质量。人类偏好胜率超过 80%，说明仍有约 20% 情况不如基线，尤其是真实图像上。

**未回答问题**：真实图像与生成图像的差距能否通过更强反演完全消除？论文未给出解决方案，只是猜测更先进的反演算法可能有帮助。权重 γ 是否可以针对不同样本动态调整而不增加过大开销？论文固定为 1.05，未探索动态根求解在日常推理中的实际收益。注意力层选择（transformer blocks 13,14,18 等）是否对 base 模型鲁棒？论文未做跨模型验证。此外，方法对多物体添加、复杂遮挡、反射等的表现尚未系统测试。最后，论文没有量化 SAM-2 分割失败的概率以及对最终结果的影响。

## 11. 放回研究脉络并收束

从研究脉络看，物体插入经历了从传统图形学（手工放置、合成数据）到早期深度生成模型（Compositing GAN、RelaxedPlacement），再到扩散模型时代。扩散模型方面，Prompt-to-Prompt 开创了通过注意力注入做编辑的思路，SDEdit 提供了加噪去噪的简单框架，但它们在物体添加任务上均不足。监督学习方法（InstructPix2Pix 等）试图大量训练来学习指令，但泛化有限。Add-it 继承扩展注意力（cross-image attention）的脉络，从个性化生成、风格迁移扩展到物体插入，创新点在于三源注意力加权平衡，以及配套的结构迁移和潜在混合，把训练无关方法推到了新阶段。此外，它首次引入物体放置的 Affordance 基准，弥补了自动评估的空白。论文还通过位置编码移位实验展示了 DiT 模型对位置信息的强烈依赖，为未来的编辑方法提供了新的研究线索。

**读完必须记住的 5 件事**
1. Add-it 是训练无关方法，只使用预训练 FLUX 和 SAM-2，在推理时通过加权扩展自注意力把源图、目标图、文本提示三者平衡起来，核心是找到 γ 使源图和目标图的注意力大致相等（γ=1.05）。
2. 结构迁移通过把源潜在加噪到 t_struct（生成图 933，真实图 867）来借用结构，避免随机种子导致物体尺寸/布局与源图不匹配。
3. 主体引导潜在混合在 t_blend=500 时用注意力图+Otsu+SAM-2 获得物体掩码，再执行潜在空间融合，保留背景细节并允许阴影、反射等间接效果。
4. 真实图像编辑不依赖反演，而是每步用随机噪声构造源潜在 \(X_t^{source}=(1-\sigma_t)X_{source}+\sigma_t\epsilon\)，保证最终恢复源图，但真实图编辑效果仍不如生成图。
5. 论文自建 Affordance 基准并证明：训练无关的 Add-it 在可供性上远超监督方法（0.828 vs 0.276），且在人类偏好中胜率超过 79%，在生成图对比中胜率达到 83%~90%。

**5 道自测题**
1. 为什么直接把源图像 K/V 拼接进注意力会导致目标图复制源图？如何自动选择 γ 来平衡？
2. 结构迁移的 t_struct 过大或过小分别会导致什么现象？如何针对真实图和生成图分别设定？
3. 主体引导潜在混合中，粗掩码从哪几层注意力图提取？为什么要用 SAM-2 细化而不用阈值掩码直接混合？
4. Add-it 如何处理真实图像的编辑而不使用 DDIM 反演？这种方法有什么副作用？
5. 在 Emu-Edit 基准上，Add-it 的 Inclusion 是多少？相比 EraseDraw 高多少？为什么 EraseDraw 的 CLIPim 更高但论文认为这个分数被“人为提升”？

最终一句话总结：Add-it 通过巧妙的注意力平衡、结构借用和潜在混合，在不训练的情况下把预训练扩散模型变成了强大的物体插入工具，同时用 Affordance 基准揭示了此前被忽视的“放对位置”问题。
