# 大白话深读《Prompt-to-Prompt》

## 1. 30 秒定位

这篇论文要解决的核心矛盾是：在文本条件扩散模型里，只改一个词，整张图往往变成完全不同的布局和内容。论文提出的正是“Prompt-to-Prompt”图像编辑方法：不训练、不微调、不要用户画掩码（mask），只通过修改文本提示，同时控制预训练模型内部的交叉注意力（cross-attention）图来保留原图结构。它基于预训练 Imagen 模型，核心操作有三种：换词（Word Swap）、增加新短语（Adding a New Phrase）、注意力重加权（Attention Re-weighting）。输入是一个源提示、一个修改后的目标提示和同一个随机种子；输出是源图和编辑图。对真实图像，论文用 DDIM 反演（inversion）先找到近似初始噪声，再应用相同编辑流程；若反演失真明显，则用从注意力图自动导出的掩码保护未编辑区域。论文明确写到，方法无需训练、微调、额外数据或优化（Abstract）。实验主要是视觉对比，论文没有给出量化指标。论文写明的限制是：反演可能失真、注意力图分辨率偏低、不能空间移动物体（§5 Conclusions）。

## 2. 为什么这篇论文会出现

论文的背景很明确：Imagen、DALL·E 2、Parti 等大规模语言-图像（LLI）模型生成能力很强，但编辑能力弱。因为文本条件扩散模型对提示极其敏感，哪怕只把“dog”改成“white dog”，都可能改变狗的形态，甚至整个构图。论文在 Introduction 中写得很直接：在文本模型中，提示的小修改常导致完全不同的输出。于是用户想编辑一个局部细节，比如把“自行车”换成“汽车”，模型却可能生成完全不同的场景。

已有的主流做法是给用户提供 mask，例如 GLIDE、Blended Diffusion 等模型让用户遮住要改的区域，让背景保持大致不变。但 mask 流程很重：第一，用户得手工指定编辑区域，不直观；第二，mask 会把被遮住区域的结构信息完全丢弃，因此无法处理一些编辑任务，比如只改变某个物体的纹理，或改变物体部件而保持轮廓。论文明确说，mask 方法忽略了遮罩区域原来的结构和内容（§1 Introduction）。此外，Blended Latent Diffusion 等工作也依赖 mask，而论文指出这类方法“不能修改复杂结构，如把自行车改成汽车”，因为结构信息被 mask 丢弃了。

与此同时，GAN 与 CLIP 结合的文本编辑方法虽然不需要 mask，但大多在高度受控的数据集（如人脸）上表现好，在多样开放数据上受限。扩散模型在生成质量上已经超过许多 GAN，因此编辑能力逐渐转向扩散模型。这篇论文出现的原因，就是要把“文本只作为编辑接口”的能力，从需 mask 的像素空间，转移到模型内部的注意力表示上。作者观察到交叉注意力图能解释“哪个词影响哪些像素”，因此提出：注入源图的交叉注意力图，让编辑后的图像既尊重新提示，又保留源图空间布局。这是一个很自然的接口选择：用户只改文本，不进入图像空间操作。作者在相关工作中还指出，Text2LIVE 虽然用文本做局部编辑且不需要 mask，但每个输入都需要训练一个网络，而且主要改变纹理，不能进行复杂结构替换（§2 Related work）。

## 3. 读懂前需要的最小概念

第一个概念是**文本条件扩散模型（text-conditioned diffusion model）**。它通过逐步去噪生成图像。论文使用的是 Imagen：一个在 64×64 分辨率上工作的文本到图像扩散模型，后面接两个超分辨率扩散模型，分别到 256×256 和 1024×1024。本文只干预 64×64 文本到图像模型，超分部分原样使用。附录 A.2 写明了 Imagen 三个模型的具体结构：64×64 模型从随机噪声开始，使用 U-Net，在分辨率 [16,8] 上有交叉注意力层，在 [32,16,8] 上有混合注意力层；64→256 超分模型在瓶颈分辨率 32 处有混合注意力；256→1024 超分模型只在瓶颈分辨率 64 处有交叉注意力。

第二个概念是**交叉注意力（cross-attention）**。在去噪 U-Net 中，视觉特征 \(\phi(z_t)\) 投影成查询（Query），文本嵌入 \(\psi(P)\) 投影成键（Key）和值（Value）。每个像素的查询会与每个文本 token 的键计算相似度，得到注意力图，再用这个权重对文本值做加权求和。注意力图就是“像素 i 对词 j 投入多少注意力”的矩阵。论文发现这个矩阵编码了空间布局和语义绑定关系（§3.1，Figure 4：熊像素更多关注“bear”一词）。注意论文说在实际实现中，多头的注意力图是分开保存的，平均只是为了可视化。

第三个概念是 **hybrid attention**。Imagen 除了纯交叉注意力层，还有一种混合注意力层：它同时做自注意力和交叉注意力，做法是直接把文本嵌入序列拼到自注意力的 key-value 序列后面。论文说，本文只干预混合注意力中对应文本 token 的那部分通道，即在 hybrid attention 里只改最后那些与文本 token 相关的通道（§3.1）。这是工程上容易踩坑的地方，因为如果不小心改到自注意力通道，会影响图像自身的空间关系。

第四个概念是 **DDIM 反演（DDIM inversion）**。为了把真实图像送入扩散模型，需要找到一个初始噪声 \(z_T\)，使得从这个噪声出发按去噪步骤能重建出原图。论文采用确定性的 DDIM 采样，把扩散过程反过来：从真实图像 \(x_0\) 逐步接近噪声 \(x_T\)。论文指出这个反演并不总是准，属于本文的配套技术。附录 A.1 给出 DDPM 的采样公式 \(x_{t-1} = \mu_\theta(x_t,t) + \sigma_t z\)，并说明 DDIM 通过设置 \(\sigma_t = 0\) 使过程确定化，这正是反演可控的原因。论文也提到使用改进的反演方法 Dhariwal & Nichol 和 Song et al. 中的确定性 DDIM，而不是朴素的加噪-去噪（§4 Real Image Editing）。

第五个概念是**无分类器引导（classifier-free guidance）**。论文在真实图像实验中提到，降低这个引导参数会改善反演重建，但也会减弱编辑能力。这是需要理解的平衡变量之一。§4 中写：“reducing the classifier-free guidance parameter (i.e., reducing the prompt influence) improves reconstruction but constrains our ability to perform significant manipulations.” 这反映了失真-可编辑性权衡。

## 4. 方法全景：先看数据流

本文方法不是重新训练一个模型，而是在推理时用同一个预训练扩散模型跑两条去噪链：一条用源提示 \(P\)，另一条用目标提示 \(P^*\)。以下是核心数据流。

```text
源提示 P  ─────────────────────────┐
                                    ▼
随机种子 s ──► 初始化 z_T,z_T* 相同  ──► 对 t=T..1 循环：
                                    │
目标提示 P* ───────────────┐        │
                          ▼        ▼
                     DM(z_t,P,t,s)  → z_{t-1}, M_t        （源去噪步）
                     DM(z_t*,P*,t,s) → M_t*               （目标注意力计算）
                          │          │
                          ▼          ▼
                        Edit(M_t, M_t*, t) → M̂_t         （编辑函数）
                          │
                          ▼
                     DM(z_t*,P*,t,s){M ← M̂_t} → z_{t-1}* （注入后的目标去噪步）
                          │
                          ▼
                    返回 z_0（源图）, z_0*（编辑图）
                     ↓
              64→256→1024 超分模型原样放大
```

核心组件如下。

**源去噪步 DM(z_t,P,t,s)**：输入当前噪声、源提示、时间步、随机种子；输出下一步噪声 \(z_{t-1}\) 和内部交叉注意力图 \(M_t\)。作用是生成需要保留的结构参考。论文 Algorithm 1 中第 6 行是这个步骤。

**目标注意力计算 DM(z_t^*,P^*,t,s)**：输入目标噪声和目标提示；输出目标提示下的注意力图 \(M_t^*\)。这个步骤本身不直接用来生成 \(z_{t-1}^*\)，只是拿到模型对新提示的自然注意力分布。Algorithm 1 中第 7 行就是这个。论文提到这一行可以优化：可以在目标去噪的 forward 函数内部就应用 Edit，从而跳过这一步单独的 forward 调用。

**编辑函数 Edit(M_t,M_t^*,t)**：根据任务选择如何结合源注意力和目标注意力。它有三种形式，后面公式部分展开。编辑函数输入是两个分支在第 \(t\) 步的注意力图，输出是用于目标分支的最终注意力图。

**注入后的目标去噪步 DM(z_t^*,P^*,t,s){M ← M̂_t}**：目标分支真正产生 \(z_{t-1}^*\) 的步骤，此时注意力图被源图注意力约束，但键和值仍然来自目标提示 \(P^*\)。也就是说，像素保持源图布局，但内容由新提示决定。Algorithm 1 中第 9 行是这个步骤。论文特别说明，注入时只覆盖注意力图 \(M\)，但保留来自目标提示的值 \(V\)（§3.2 中 DM 的定义）。

**超分阶段**：论文明确只在 64×64 文本到图像模型上做干预，64→256 和 256→1024 超分模型不修改。因此方法的数据流在 64 分辨率完成主要结构和编辑，后续只放大。§3 中写：“Since the composition and geometry are mostly determined at the 64 ×64 resolution, we only adapt the text-to-image diffusion model, using the super-resolution process as is.”

**假设**：该流程能成立，论文依赖两个观察。一是扩散过程的早期步骤已经决定图像结构，因此可以只在部分早期步骤注入注意力；二是固定随机种子并不能保持结构，必须注入注意力图。论文在 Figure 2 用“lemon cake”到“pumpkin cake”等例子说明：只用相同随机种子，结构完全变化；注入注意力后结构保留。Figure 4 进一步展示早期步骤的注意力图已经反映出对象位置。

论文还提到，为了方法可复现，必须固定内部随机性。这在 Algorithm 1 第 3-4 行体现：\(z_T\) 和 \(z_T^*\) 初始化为相同的单位高斯噪声，使用同一个随机种子 \(s\)。如果种子不同，即使注入注意力也无法保证对应关系。

## 5. 核心公式与直觉

本文理解贡献的核心公式只有四组，都是关于交叉注意力和编辑函数。它们不涉及模型训练，只是推理时的控制变量。

**公式 1：交叉注意力图**

\[
M = \text{Softmax}\left(\frac{QK^T}{\sqrt{d}}\right)
\]

变量含义：\(Q = \ell_Q(\phi(z_t))\) 是像素特征投影成的查询矩阵；\(K = \ell_K(\psi(P))\) 是文本特征投影成的键矩阵；\(d\) 是键和查询的投影维度，用来尺度归一化。\(M_{ij}\) 表示第 \(i\) 个像素对第 \(j\) 个文本 token 的注意力权重。直觉是：像素特征与某个词的键越相似，这个像素就越听这个词的指挥。论文说这是控制空间布局的核心手柄，因为注意力图把像素和词绑定在一起。工程上，它就是去噪 U-Net 里交叉注意力层保存下来的一批张量。公式来自 §3.1 Equation (1)。交叉注意力输出是 \(\hat\phi(z_t) = MV\)，即注意力图作为权重对文本值 \(V\) 做加权平均。

**公式 2：Word Swap 编辑函数**

\[
\text{Edit}(M_t,M_t^*,t) :=
\begin{cases}
M_t^*, & \text{若 } t < \tau \\
M_t, & \text{否则}
\end{cases}
\]

这里 \(\tau\) 是一个时间步阈值。含义是：在早期步骤 \(t \ge \tau\) 用源图注意力，后期步骤 \(t < \tau\) 用目标提示自己的注意力。直觉是：构图在早期已经定下来，所以早期注入源注意力保留结构；后期让目标提示自由发挥，允许必要的几何调整。论文在 Figure 6 中从 0% 到 100% 注入步数展示这种权衡：完全不注入会得到不同图像；全步注入可能过约束，例如把“bicycle”换成“car”时，车还是太像自行车。论文还提到，如果两个词用不同数量的 token 表示，可以通过对齐函数把注意力图复制或平均（§3.2 Word Swap）。

**公式 3：Adding a New Phrase 编辑函数**

\[
(\text{Edit}(M_t,M_t^*,t))_{i,j} :=
\begin{cases}
(M_t^*)_{i,j}, & \text{若 } A(j) = \text{None} \\
(M_t)_{i,A(j)}, & \text{否则}
\end{cases}
\]

这里 \(i\) 是像素下标，\(j\) 是目标提示 token 下标，\(A\) 是对齐函数。对齐函数输入目标提示的 token 下标，输出源提示中对应的 token 下标；如果该 token 是新增词，则输出 None。直觉是：目标提示中与源提示共有的词，沿用源图注意力；新增词不指定旧结构，让模型自然生成新内容。例如源提示“a castle next to a river”变成“children drawing of a castle next to a river”，前几个公共 token 的注意力被冻结，新 token “children drawing of” 可以自由吸引像素。这用于局部描述和全局风格编辑，也用于图 7 的“crushed car”这类增词编辑。

**公式 4：Attention Re-weighting 编辑函数**

\[
(\text{Edit}(M_t,M_t^*,t))_{i,j} :=
\begin{cases}
c \cdot (M_t)_{i,j}, & \text{若 } j = j^* \\
(M_t)_{i,j}, & \text{否则}
\end{cases}
\]

这里 \(j^*\) 是用户指定的词，\(c \in [-2,2]\) 是缩放系数。含义是只放大或缩小某个词对应注意力图的值，其他不变。论文称这是 fader control：例如“snowy mountain”中，通过减小或增大“snowy”的注意力来调节山上雪量。注意这里没有用 \(M_t^*\)，只修改源注意力，所以它不是基于目标提示的重排，而是直接调制影响强度。论文说用户可以强化或弱化一个 token 对结果的影响程度，而无需修改提示词本身。

## 6. 训练到底怎么跑

一句话先说清楚：**本文没有新训练步骤**。论文的方法不训练、不微调、不更新任何模型参数，也没有额外的文本-图像数据集或优化目标。它直接调用预训练 Imagen 模型，在推理时修改注意力图。论文 Abstract 和 Introduction 都写了 “does not require model training, fine-tuning, extra data, or optimization”。

所以如果严格问“一轮训练 step 怎么跑”，答案是不存在本文定义的训练 step。若从模型本身的去噪过程看，一轮调用是 DM：输入当前噪声 \(z_t\)、文本嵌入、时间步 \(t\)，U-Net 预测噪声，并产生交叉注意力图；然后用预测噪声更新 \(z_t\) 得到 \(z_{t-1}\)。但这是推理中的去噪步，不是训练中的前向/反向。

论文附录 A 给出的扩散模型训练目标为：

\[
\min_\theta \mathbb{E}_{x_0,w,t}\|w - \epsilon_\theta(x_t,t)\|_2^2
\]

这是 DDPM 背景，说明预训练模型如何学习去噪；但本文没有做这个训练。这个公式不能被理解为本文的训练 loop。论文中所有模型权重是 Imagen 训练好的，本文方法只在采样时注入和重加权注意力。

因此工程上，“训练流程”这一节应改写为：**冻结的预训练模型 + 推理期控制**。唯一需要准备的是源提示、目标提示和随机种子，三条都不是数据。这也意味着本文无法通过训练改善编辑能力，所有控制都来自对现有注意力行为的假设。若未来想提升，需要改变训练目标或加入高分辨率注意力，但论文把这些留作 future work（§5 Conclusions：建议在更高分辨率层加入交叉注意力，但需要分析训练过程，超出当前范围）。

如果要复现本文，关键不是“训练”，而是把预训练 Imagen 的交叉注意力图保存和修改功能接好。论文没有公开实现细节，比如钩子位置、头数、内存管理，这些需要工程判断。

## 7. 推理到底怎么跑

完整推理分成两个场景。

**场景一：从随机噪声生成源图并做编辑。** 这是论文主推的方式。给定源提示 \(P\)、目标提示 \(P^*\) 和随机种子 \(s\)，算法按以下顺序：

1. 用种子 \(s\) 生成同一个高斯噪声 \(z_T\)，同时设置 \(z_T^* \leftarrow z_T\)。这一步在 Algorithm 1 第 3-4 行。
2. 从 \(t=T\) 到 \(1\) 循环：
   - 调用源去噪步，得到 \(z_{t-1}\) 和 \(M_t\)（Algorithm 1 第 6 行）。
   - 调用目标注意力计算，得到 \(M_t^*\)（Algorithm 1 第 7 行）。论文说明这一步可以合并到目标去噪的 forward 中，减少一次调用。
   - 根据编辑类型计算 \(\hat M_t\)：
     - 换词：早期用 \(M_t\)，后期用 \(M_t^*\)。
     - 加短语：公共 token 用 \(M_t\)，新增 token 用 \(M_t^*\)。
     - 重加权：直接缩放 \(M_t\) 的指定 token。
   - 用 \(P^*\) 对应的键、值，但注入 \(\hat M_t\)，执行目标去噪步，生成 \(z_{t-1}^*\)（Algorithm 1 第 9 行）。
3. 返回 \(z_0\) 和 \(z_0^*\)，送入两个超分模型，得到最终 1024×1024 源图和编辑图。

**场景二：真实图像编辑。** 论文先做 DDIM 反演。它从真实图像 \(x_0\) 开始，逐步执行反向去噪流程，得到一个初始噪声 \(x_T\)。论文说这常用 DDIM 而非 DDPM，因为 DDIM 是确定性的，反演比较稳定。之后从 \(x_T\) 出发，运行与场景一同样的 Prompt-to-Prompt 编辑循环。若反演重建质量不理想，论文采用**注意力导出的掩码**：用源提示中某个词对应的注意力图生成掩码，对未编辑区域做保护，恢复原图内容。例如 Figure 12 中“cat wearing a floral shirt”，把“shirt”的注意力图作为空间信息，保护猫的未被修改部分。具体流程在 Figure 12 的图注中描述：先对真图加噪并 resize，与提示词一起输入得到去噪结果和注意力图，在超分前用注意力图对未编辑区域做混合，再进行超分。

推理的计算开销：论文在 Algorithm 1 后面说明，源分支和目标分支的 DM 调用可以放在同一个 batch 中并行，所以相对原始推理只有一个 step 的额外开销。但要注意，这不是说零成本，它仍然意味着目标分支至少要跑完一次去噪，并且源分支也要跑完一次去噪；只是两者可以并行。不同编辑操作对注意力图存储的需求不同，尤其是 Word Swap 和 Adding a New Phrase 需要同时维护两套注意力图，内存比普通推理高。

**最关键的消融**是 Figure 6 的注入步数 \(\tau\)。它说明本文的核心假设成立：早期扩散步骤决定结构，所以只需要在早期注入源注意力，后期可以交给目标提示。这个结果表明编辑质量不只是“注入”或“不注入”的二选一，而是一个连续权衡：注入步数越多，源图保真度越高，但对目标提示的适应空间越小。这个权衡是用户可调的：不同 token 甚至可以有不同的注入步数。论文还指出，对于结构变化很大的替换（如 bicycle→car），全步注入会导致低文本保真度，因此需要软约束，即 \(\tau\) 控制。

**尚未证明的主张**：论文只在视觉层面展示了多样性结果，没有给出可复现的量化评估，例如布局保持度、文本匹配度、用户偏好或 FID 等。它也没有证明方法在除 Imagen 外的其他文本条件扩散模型上同样有效。虽然论文提出“应用可泛化到其他模型”，但未提供实验支持。移动现有物体、高分辨率注意力这些是 future work，不能认为已经解决。真实图像编辑的反演成功率也没有给定统计数字，只称为“初步结果”。论文在 §5 Conclusions 中承认，反演在某些测试图像上有可见失真，且用户需要提供合适提示，注意力图分辨率低限制了更精确的局部编辑。

## 9. 与前作怎么选

与本方法最接近的方案有三类。

**第一类：mask 驱动的扩散编辑。** 例如 GLIDE、Blended Diffusion、Blended Latent Diffusion。这些方法依赖用户提供的 mask，编辑只发生在 mask 内，背景保护较好。什么时候选：用户愿意画 mask，或需要非常明确的空间限制，例如只需要替换一小块区域而完全不动其他区域。什么时候不选：用户想要纯文本、快速、无需像素级操作；或者 mask 会丢掉区域内重要结构，导致纹理修改、轮廓替换不自然。Prompt-to-Prompt 恰好弥补这个缺口。论文指出 mask 方法本质上忽略了原图内容，因此无法完成类似“改变物体纹理同时保持轮廓”的任务。

**第二类：只做全局编辑的扩散/CLIP 方法。** 例如 DiffusionCLIP。它通过优化或在 CLIP 引导下做全局属性修改，例如风格化、年龄变化。什么时候选：编辑目标是整体风格、天气、光照等，而不需要保持原图结构。什么时候不选：需要局部替换物体、保留原图对象身份和轮廓时。Prompt-to-Prompt 用添加短语也能做全局风格，但它的动机是保留原构图。

**第三类：每输入训练一个网络的文本驱动编辑，例如 Text2LIVE。** Text2LIVE 可以对单张图像/视频建立分层表示，进行纹理编辑，但论文指出它需要为每个输入训练网络，且主要能修改纹理，不能把自行车改成汽车这种结构变化。什么时候选：需要视频一致编辑、纹理替换而不改结构、能接受每输入训练成本。什么时候不选：快速单图编辑、复杂结构修改、无额外训练预算。

总的来说：如果要保留原有空间关系，又不想画 mask，也不想训练，Prompt-to-Prompt 是合适的。若已有高质量 mask，或需要强背景锁定，mask 方法可控性更直接。若只改风格不关心结构，CLIP 类方法也可以。论文在 Introduction 还提到 Bar-Tal et al. 的 Text2LIVE 是文本驱动的局部编辑，但需要训练网络，这限制了快速应用。

## 10. 工程判断：可行性、风险与上限

**数据**：论文方法不需要任何额外训练数据或成对编辑数据。这是部署上的显著优点。但对真实图像编辑，用户需要提供一个合适的源提示来配合反演；论文明确说复杂构图下提示很难写。也就是说，虽然不需要训练数据，但需要用户的文本描述与图像对齐。这是潜在工程门槛。论文在 §5 说“the inversion requires the user to come up with a suitable prompt. This could be challenging for complicated compositions.”

**算力/延迟**：算法需要为源分支和目标分支执行扩散循环。论文写可以放在同一个 batch 中并行，因此相对原始推理只多一个 step 的开销。但这里“只多一个 step”是个工程理想化说法：它指的是每轮循环中多出的计算量与单次 DM 步相当，而不是总延迟只加一个 step。还要保存多组注意力图，尤其多头注意力张量，内存占用比普通推理高。超分模型不参与编辑，因此高分辨率超分带来的开销与原始模型一致。论文没有给出具体延迟或显存测量，所以这些是推断。

**实现难点**：第一，需要插入钩子保存和修改交叉注意力图，包括跨多个分辨率层和多头；第二，Hybrid attention 中只干预文本 token 对应的通道，否则会意外改掉自注意力；第三，Word Swap 遇到两个词 token 数不同时，需要复制或平均注意力图，论文提到 alignment function，但未给具体实现细节；第四，\(\tau\) 和 \(c\) 需要手工调试，没有自动选取机制。第五，真实图像反演质量依赖 prompt 和引导参数，调试成本较高。

**失败环节**：论文自己列出三个限制：反演失真、低分辨率注意力图限制精确局部编辑、不能移动对象。此外还可能在以下环节失败：全步注入导致结构过约束；注意力图平均或多头部不匹配导致伪影；源 prompt 描述与图像语义不一致，使注意力 mask 对不上实际目标；超分模型未干预，可能在 64×64 决定的结构向上放大时出现模糊或纹理不一致。

**监控信号**：工程上可以把交叉注意力图可视化，检查源图与编辑图在同一 token 上的注意力分布是否接近；也可以监控源提示与目标提示公共 token 的注意力差异。若编辑后目标 token 的注意力图没有向新词靠拢，可能注入过强。若保真度过高但编辑失败，可降低 \(\tau\) 或增大后期注意力自由程度。对于真实图反演，可比较重建图和原图的结构相似度，作为反演质量参考。论文没有给出具体监控指标，这些是工程推断。

**指标上限**：由于论文没有量化指标，目前无法给出可达到的数值上限。但从方法原理看，在 64×64 注意力层上控制，空间精度受层分辨率限制；如果要精确到像素级的局部边界，需要更高分辨率注意力。它适合语义级编辑，不适合像素级修图。对真实图像的上限还受限于 DDIM 反演能力。移动对象、改变遮挡关系、跨模态替换（例如重新放置某物）均在本文技术能力之外。论文在 §5 明文将“不能空间移动对象”列为限制，且指出低分辨率注意力来自交叉注意力处于网络瓶颈。

## 11. 放回研究脉络并收束

这篇论文在研究脉络上位于“文本驱动图像编辑”从 GAN 转向扩散模型的节点。早期 GAN+CLIP 方法验证了纯文本编辑可行，但在多样数据上受限。扩散模型出现后，编辑研究开始迁移，但多数方法仍沿用 mask 作为空间控制信号。本文发现交叉注意力图已经包含词-像素空间映射，于是把控制接口从用户提供的 mask 改成了模型内部已有的注意力图。它的贡献不是更复杂的网络，而是一种不训练、不改结构的编辑策略：把“保留结构”这个编辑中的核心目标，转化为“在采样时替换注意力图”。论文把编辑控制从像素空间移动到注意力空间，为后续工程式控制提供了基础。作者在 §5 中也强调，这项工作只是第一步，未来可在高分辨率注意力、反演质量和空间移动上继续。

**读完必须记住的 5 件事**：

1. 交叉注意力图 \(M\) 是像素对文本 token 的权重矩阵，它编码了图像空间布局与词之间的绑定关系；注入或修改这张图可以控制生成图像结构。
2. 换词编辑使用 Word Swap：早期去噪步注入源注意力，后期使用目标注意力；阈值 \(\tau\) 是保真度与编辑自由度的开关。
3. 加短语编辑使用对齐函数：公共 token 保留源注意力，新增 token 自由生成，因此能实现局部描述或全局风格编辑。
4. Attention Re-weighting 只缩放指定词的注意力，可实现连续 fader 控制，不需要修改提示本身。
5. 真实图像编辑需要先做 DDIM 反演，反演不一定准确；论文用从注意力图自动提取的 mask 来保护未编辑区域，但这仍是初步方案。

**5 道自测题**：

1. 为什么固定随机种子重新生成同一提示下的图像，仍不能保持结构稳定？Prompt-to-Prompt 是如何解决的？
2. 写出 Word Swap 的编辑函数，并解释 \(\tau\) 的含义。如果 \(\tau\) 设得过大，可能发生什么？
3. 在 Adding a New Phrase 中，对齐函数 \(A\) 输出 None 表示什么？对应注意力图如何选择？
4. 真实图像编辑为什么需要 DDIM 反演？论文如何应对反演重建失败？
5. 本文没有给出哪些关键定量证据？列举至少两类未证明或未量化的问题。

最终一句话：Prompt-to-Prompt 把文本驱动编辑的重心从用户画 mask 转移到模型内部的交叉注意力图控制，提供了一条无需训练、无需成对数据的文本编辑路线；但它的精度受注意力层分辨率限制，真实图反演和空间移动能力是后续要补齐的缺口。
