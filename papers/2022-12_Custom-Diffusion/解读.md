# 大白话深读《Custom-Diffusion》

## 1. 30 秒定位

Custom-Diffusion 是一种面向文本到图像扩散模型的少样本定制方法。它的核心做法是：给定几张某个新概念的照片，只微调 Stable Diffusion 交叉注意力层里的 key、value 投影矩阵，以及一个新增的修饰符 token embedding V*，让模型学会生成该概念的新图像。论文同时处理单概念定制和多概念组合：多概念可以通过联合训练，也可以先把多个单概念模型分别训练好，再用带约束的最小二乘求出合并权重。

根据论文报告，单概念微调在两块 A100 上约 6 分钟，只保存约 75MB 权重，比 DreamBooth 的全参数微调更快、更省存储。实验中，Custom-Diffusion 在 CLIP 文本对齐和图像对齐上优于 Textual Inversion，与 DreamBooth 互有胜负或略优；在多概念组合上，它的 joint training 和 optimization 合并都优于 DreamBooth。论文还展示了在 101 个概念的 CustomConcept101 数据集上的结果，并验证了低秩压缩可将存储降到约 15MB 而不明显损失性能。主要代价是：模型继承 Stable Diffusion 本身对困难组合的局限，超过两个新概念的组合仍不稳定。这篇论文属于 2022 年底的定制化生成工作，与 DreamBooth、Textual Inversion 构成同一时期的不同路线。

## 2. 为什么这篇论文会出现

大型文本到图像模型如 Stable Diffusion、DALL·E、Imagen 在通用文本描述下能生成高质量图像，但用户经常希望生成自己生活中的特定实例：自己的狗、朋友的脸、家里的沙发、刚去过的花园。这些概念在预训练数据中未必出现，甚至根本不存在对应词。仅靠更长、更具体的文本描述往往不能恢复目标实例，因为自然语言对视觉细节的表达有限。论文 Figure 23 直接展示了：即使给出“a small siberian kitten with blue eyes and brown fur”这类详细描述，预训练模型仍不能生成与用户给的猫一致的形象。

于是问题变成：能否只给几张图，就教会模型一个新概念？这个“定制”需要满足几个条件：第一，新概念要能在未见背景、不同风格、不同属性变化中生成；第二，模型不能忘记已有概念，例如学会“moongate”之后，不能把“moon”也生成成月亮门；第三，不能过拟合到几张训练图，否则失去采样多样性；第四，多个新概念还要能同时出现在同一场景里，比如“V* dog wearing sunglasses in front of a moongate”。

论文指出，已有工作 Textual Inversion 只优化新 token embedding，训练快但很容易过拟合目标图，文本对齐差，且多概念组合困难；DreamBooth 冻结文本编码器、微调整个 U-Net，虽然图像保真较强，但训练约一小时、存储约 3GB，且多概念联合训练时经常漏生成某个对象。Custom-Diffusion 的动机就是找到“最小但足够”的参数子集。作者通过观察全参数微调时各层权重的相对变化，发现交叉注意力层虽然只占模型参数约 5%，权重变化却明显高于其他层，于是选择只微调这些层里的 Wk 和 Wv。这个选择同时解决了效率、遗忘和组合问题。论文还观察到，全参数微调成本高、容易过拟合，而只改文本到图像映射的关键矩阵可以在不牺牲太多保真度的前提下改善泛化。

## 3. 读懂前需要的最小概念

**潜在扩散模型 / Stable Diffusion。** Stable Diffusion 不是直接在高分辨率像素图上做扩散，而是先训练一个 VAE 编码器把图像压到低维潜在空间，然后在潜在空间里训练扩散 U-Net。生成时从高斯噪声开始逐步去噪，再通过 VAE 解码器恢复图像。文本条件通过交叉注意力注入 U-Net。

**扩散去噪目标。** 扩散模型学习从带噪潜变量 xt 预测噪声 ε。训练目标是让预测噪声 εθ(xt,c,t) 接近真实噪声 ε，其中 c 是文本条件，t 是时间步。推理时从 xT ~ N(0,I) 出发，逐步用模型去噪得到 x0。

**交叉注意力。** U-Net 中的交叉注意力块接收两类特征：一是来自图像潜变量的 query，二是来自文本编码器的 key、value。计算如下：Q = Wq f，K = Wk c，V = Wv c，然后 Attention(Q,K,V) = softmax(QK^T / sqrt(d')) V。文本信息通过 K、V 进入图像特征。论文的关键假设是：学习“新概念”主要是在改变文本特征到图像特征的映射，而以文本特征为输入的可学习矩阵只有 Wk 和 Wv，因此更新它们足够。

**修饰符 token V*。** 对个人物体，如“这只狗”，文本描述没有对应词条。论文引入一个稀有 token，比如 V*，放在类别词前面，构成“photo of a V* dog”。训练时优化 V* 的 embedding。这样 V* 承载该实例的独有身份，类别词保留通用先验。论文在 200K 条 LAION-400M caption 中统计 token 出现次数，选择出现约 5~10 次、有字母表示且不是其他 token 子串的 token-id 作为 V* 初始化；单概念和第一个概念用 token-id 42170，联合训练第二个概念用 47629。

**灾难性遗忘 / 语言漂移。** 当只在少数目标图上微调时，模型可能改变已有词的视觉含义。比如学会“moongate”后，输入“photo of a moon”也可能画出月亮门。论文用 200 张从 LAION-400M 检索到的相似类别真实图像作为正则化集，检索阈值是 CLIP 文本特征相似度高于 0.85，缓解这种漂移。

**CLIP 图像对齐 / 文本对齐 / KID。** 图像对齐是生成图与目标概念图在 CLIP 图像特征空间的余弦相似度；文本对齐是生成图与文本提示在 CLIP 图像-文本特征空间的相似度。KID（Kernel Inception Distance）在相似类别真实验证集上度量生成分布与真实分布差异，用来衡量是否过拟合、是否忘了类别先验。论文在相似类别的 500 张真实图像验证集上计算 KID，生成 1000 张图像比较。FID 也用 MS-COCO 验证通用概念丢失情况。

## 4. 方法全景：先看数据流

下面是 Custom-Diffusion 训练与推理的整体数据流，方括号表示可训练组件，圆括号表示冻结或外部数据：

```
目标概念图（4~135张）
      │
      ▼
构建文本提示：photo of a V* dog  或 photo of a moongate
      │
      ▼
从 LAION-400M 检索 200 张相似类别图 + 对应caption
      │
      ├──── 目标图 + 正则图组成 batch
      │
      ▼
VAE 编码 → 潜变量 f
      │
      ▼
文本编码器 → 文本特征 c ∈ R^{s×d}
      │              │
      │              ▼
      │      交叉注意力层：Q=Wq f, K=[Wk] c, V=[Wv] c
      │              │
      │              ▼
      │      Attention = softmax(QK^T/√d') V
      │              │
      ▼              ▼
扩散 U-Net 去噪（仅 Wk、Wv、V* embedding 更新）
      │
      ▼
扩散损失反向传播，只对有效区域计算loss
      │
      ▼
保存：基础模型 + ΔWk/ΔWv 低秩分解 + V* embedding
```

对于多概念，还有两条路径：

- **联合训练**：把多个概念的目标图和正则图混在一个训练集里，使用不同修饰符 token，例如 V1* dog、V2* cat。更新共享的 Wk、Wv 和各自的 V* embedding，训练 500 步。
- **优化合并**：每个概念先单独微调，得到各自的 Wk,n、Wv,n。然后用约束最小二乘求出一个新的 W，使其在正则化文本特征上尽量接近原始 W0，同时在目标文本特征上精确匹配各微调模型的 value 映射。论文报道这个合并约 2 秒。

核心组件拆解如下：

**目标图像与文本 prompt。** 输入是几张目标图；如果有现成词如 moongate，就用该词；如果没有，就引入 V* 作为修饰符。目的：为模型提供新概念的视觉-文本配对。假设：目标概念可以绑定到一个 token 或 token 序列上。

**正则化数据集。** 从 LAION-400M 中按 CLIP 文本特征相似度高于 0.85 检索约 200 张相似类别图像。目的：防止语言漂移和过拟合。假设：相似的类别真实图像可以帮助模型保留类别词的原义和多样性。论文在附录 C 中展示，无正则化时“photo of a {category}”会向目标图漂移；使用真实图比生成图更好。

**交叉注意力 KV 投影。** 只训练 U-Net 交叉注意力层中的 Wk 和 Wv。输入是文本特征 c，输出是用于注意力的 key 和 value。目的：改变文本概念到图像特征的映射。假设：交叉注意力是调控文本条件生成的关键瓶颈，更新它足够表示新概念。论文 Figure 3 显示交叉注意力层的 Δl 明显更高，但只占参数 5%。

**V* token embedding。** 从 CLIP tokenizer 中选择一个在 200K captions 中仅出现约 5~10 次的稀有 token 作为初始化，并加入优化。目的：为个性化实例提供可学习的语义锚点。假设：稀有 token 原义很弱，不会干扰训练，并可绑定新视觉身份。训练时 detach start token embedding，避免无关 token 被更新。

**多概念合并器。** 输入多个微调模型的 Wk/Wv 和预训练 W0，以及目标文本特征 C 和正则化文本特征 Creg（约 1000 条随机 caption 的文本特征）。输出一个合并后的 W。目的：无需重新联合训练即可组合多个概念。假设：优化目标可以在保持正则化文本映射不变的同时精确匹配目标文本映射，且 Creg 非退化、约束可行。

## 5. 核心公式与直觉

论文中理解贡献必需的公式有三个半，分别是扩散训练目标、交叉注意力、合并约束优化，以及权重变化率分析中的 Δl 定义。这里重点解释前三个。

**扩散训练目标（论文 Eq. 2）**

```
E_{ε,x,c,t} [ w_t || ε - εθ(xt, c, t) || ]
```

其中 xt 是时间步 t 的带噪潜变量，ε 是真实添加的高斯噪声，εθ 是模型预测的噪声。wt 是时间相关的损失权重。c 是文本条件。这个目标让模型学会从带噪样本中恢复干净潜变量。在微调 Custom-Diffusion 时，εθ 内部的 Wk、Wv 和 V* 是被更新的对象；基础 U-Net 的其他权重冻结。论文未披露 wt 的具体设置，只写明采用扩散模型的简化目标。

**交叉注意力（论文 Eq. 3）**

```
Attention(Q, K, V) = Softmax(Q K^T / sqrt(d')) V
```

其中 Q = Wq f，K = Wk c，V = Wv c。f 是图像潜特征，c 是文本特征，d' 是 key/query 输出维度。softmax 的结果可以看作“图像位置应该关注哪些文本 token”。Wq 接收图像特征，不直接决定文本到图像的映射；Wk、Wv 接收文本特征，因此它们的变化直接影响文本 token 如何参与生成。这也是论文只微调 KV 的理由。

**权重变化率分析（论文 Section 3.1）**

```
Δl = ||θ'_l - θ_l|| / ||θ_l||
```

θ'_l 是微调后某层参数，θ_l 是预训练模型该层参数。作者在“moongate”目标上做全参数微调，发现交叉注意力层平均 Δl 显著高于 self-attention 和其余层，而交叉注意力只占总参数约 5%。这个分析不是最终训练公式，但它是选择 Wk/Wv 的实验依据。论文 Figure 3 展示三类层的平均 Δl 对比：cross-attn 最高，self-attn 和 other 明显更低，其他数据集也有类似现象。

**多概念合并约束优化（论文 Eq. 4 与 Eq. 5）**

```
W_hat = arg min_W || W C_reg^T - W0 C_reg^T ||_F
s.t. W C^T = V,
其中 C = [c1 ... cN]^T，V = [W1 c1^T ... WN cN^T]^T
```

目标函数要求合并后的 W 在正则化文本特征 Creg 上的 value 映射尽量接近预训练模型 W0，以保留原有概念。约束要求合并后的 W 对每个目标概念的文本特征 ci 产生的 value 等于各自微调模型 Wi 产生的 value，即精确保留每个新概念。解法用了 Lagrange 乘子法，论文 Eq. 5 给出闭式解：

```
W_hat = W0 + v^T d
其中 d = C (C_reg^T C_reg)^{-1}
v^T = (V - W0 C^T)(d C^T)^{-1}
```

直觉上，它是在“不改变正则化文本映射”和“精确满足目标文本映射”之间求解一个加权偏移。相比反过来重新做联合训练，这个闭式解只需要已有的微调权重和文本特征，计算代价约 2 秒。论文 Appendix B 给了完整推导：对 Lagrangian L 求导取零，假设 Creg 非退化，得到 W = W0 + v^T C (C_reg^T C_reg)^{-1}，再代入约束求解 v。该优化对所有层和 key/value 矩阵统一执行，论文省略层号和 k/v 上标。

## 6. 训练到底怎么跑

这里以单概念为例，说明一轮 training step 的完整流程；多概念联合训练在数据组织和步数上不同，但每个 step 的前向、反传结构相同。

**数据准备。** 每个训练 batch 同时包含目标概念图和正则化图。目标图就是用户给的少数图像，例如 7 张 barn 或 10 张 dog；Moongate 用了 135 张，数据集规模括号中标注。正则化集是从 LAION-400M 检索到的高相似 caption 对应的真实图像，通常 200 张。训练时对目标图过采样，保持目标样本和正则样本的采样比例。文本 prompt 分两类：目标图用“photo of a V* dog”或“photo of a moongate”；正则图用其原始 caption。

**图像增强。** 训练时随机缩放目标图。论文原文与 Appendix E 给出细节：约每 3 次中有 1 次随机 resize 到 1.2~1.4×，并在 prompt 后追加“zoomed in”或“close up”；其余时间随机 resize 到 0.4~1.0×，如果比例小于 0.6，追加“far away”或“very small”。增强只对有效图像区域计算损失，不回传 padding 区域的 loss。这个操作旨在让模型见过不同大小和远近距离，提高视觉相似度。由于微调步数很少，论文未观察到增强泄漏到模型。

**前向与损失。** 对每张图用 VAE 得到潜变量，并从训练数据中采样时间步 t，按扩散过程加噪得到 xt。文本通过冻结的 CLIP 文本编码器得到 c，其中 V* 使用当前可训练 embedding。把 xt 和时间步 t、文本特征 c 送入 U-Net。U-Net 内部的交叉注意力层使用当前正在更新的 Wk、Wv 计算 K、V；其他层权重冻结。模型输出预测噪声 εθ。损失函数为对预测噪声和真实噪声的加权 L2 误差，相当于 Eq. 2 在 batch 上的样本近似。

**反向传播与参数更新。** 只对 Wk、Wv 和 V* embedding 计算梯度。V* 之外的其他 token embedding 不更新。论文还提到会 detach start token embedding。优化器默认学习率为 8×10^-5，batch size 8，这个学习率是基础学习率乘以 batch size 后的有效学习率；原文写的是 learning rate 10^-5 scaled by batch size to 8×10^-5。单概念训练 250 步；多概念联合训练 500 步。如果使用“Ours w/ fine-tune all”基线，则所有 U-Net 参数都更新，学习率降到 8×10^-6，单概念 500 步，多概念 1000 步，其他设置与标准方法相同。

**V* token 的选择与初始化。** 在训练前，从 CLIP tokenizer 的总共 49408 个 token 中统计 200K 条 LAION caption 的出现次数，选择出现约 5~10 次、有字母表示、且不是其他 token 子串的 token。单概念及多概念第一个概念用 token-id 42170；联合训练第二个概念用 token-id 47629。论文还消融了：随机用现有 token 的均值/标准差初始化 V*、以及不优化 V* 的情形，结果见 Table 5：不优化 V* 导致图像对齐显著下降；随机初始化会提高文本对齐但使原始类别词“a dog”等向目标图漂移。

**优化合并路径。** 当多个概念分别训练完成后，不需要再走上述训练 step。论文直接用 Eq. 5 闭式解合并每个概念的 Wk、Wv。合并时需要目标概念文本特征和约 1000 条随机 caption 的文本特征作为 Creg。最终保存合并后的权重和所有 V* embedding。这个路径约 2 秒。联合训练通常表现比优化合并略好，但需要重新训练。

**存储与压缩。** 保存的不是完整微调模型，而是预训练模型与微调模型在 Wk、Wv 上的差值。论文分析差值矩阵的奇异值下降很快，可以用 SVD 做低秩压缩。不压缩时约 75MB；保留 top 60% 奇异值时约 15MB，性能接近；保留 top 10% 约 5MB，top 1% 约 1MB，但图像对齐下降。Appendix C 的 Figure 15 和 Figure 21 展示了压缩后性能变化。这个压缩不是训练必需，但显著降低多概念存储成本。

## 7. 推理到底怎么跑

推理时不需要重新训练，流程如下：

**加载权重。** 基础 Stable Diffusion 权重保持默认；微调后的 Wk、Wv 差值或低秩分解被加回到交叉注意力层对应矩阵上；V* 使用训练后的 embedding 替换稀有 token 原词条。如果模型经过优化合并，则使用一个共享的合并 Wk/Wv，但仍然有多个 V* token。论文未明确说明推理显存与延迟，但可以推断由于基础模型不变、只增加小矩阵，推理速度与预训练模型基本一致。

**构造 prompt。** 用户给一个包含新概念的文本，例如“A digital illustration of a V* dog in front of a moongate”或“A V* dog wearing sunglasses”。文本编码器将整句编码为 token 序列；V* 被映射到对应训练后的 embedding，普通词条保持原状。推理时不需要正则化集。

**扩散去噪。** 从随机高斯潜变量 xT 出发，进入 U-Net。交叉注意力层接收潜特征 f 和文本特征 c，使用加载的 Wq、Wk、Wv 计算注意力。Wq 不更新，但 Wk、Wv 来自微调结果。U-Net 根据时间步 t 和文本特征输出噪声预测。采样可以使用 DDPM 采样器，论文多数实验用 200 步或 50 步；定量评估的 Table 1 使用 50 步 DDPM、classifier-free guidance scale 6，人类偏好和部分定性图使用 200 步 DDPM、scale 6。DDIM 也可以用在基础模型上，但论文未报告定制后 DDIM 结果。

**解码与后处理。** 去噪得到的潜变量送入冻结的 VAE 解码器，生成最终图像。输出可以用于 Prompt-to-Prompt 等已有图像编辑方法；论文 Figure 10 展示了修改同一张生成图中的帽子或风格化生成结果。多概念组合的推理就是在一个 prompt 里放入多个 V* token，例如“V1* cat is sitting inside a V2* wooden pot”。模型通过交叉注意力同时吸收多个新概念的文本映射，生成包含这些实例的场景。对于风格类定制，prompt 形式可以是“Painting in the style of V* art”，此时目标图是风格样本图，训练时使用与“art”高相似的正则化图像。

论文在 10 个目标数据集上做了单概念和多概念评估，数据集数量不同，从 4 张到 135 张不等，例如 Moongate 135 张、Wooden Pot 4 张、Dog 10 张。评价指标包括 CLIP 图像对齐、文本对齐、KID、FID 和 AMT 人类偏好。下面的表汇总关键证据：

最关键的消融是 **正则化数据集**。Table 3 显示，去掉正则化集后，KID 从 20.96 上升到 32.64，说明模型明显过拟合，验证集分布偏移增大；图 5 直接展示无正则化时“photo of a moon”会生成月亮门。换成生成图做正则化（Ours w/ Gen）后目标概念性能接近，但 KID 升到 34.70，并且论文 Appendix C 提到对“a dog”这类原始类别词的生成会出现饱和伪影，提示生成图正则化下高学习率会导致类别词质量下降。这个消融证明：保留类别先验不能只用生成图，真实图正则化更有效。

另一重要消融是 **V* 初始化与优化**。Table 5 显示，不优化 V* 时图像对齐从 0.775 降到 0.733；随机初始化 V* 会提高文本对齐到 0.805，但 Figure 18 显示“a dog”等类别词生成会漂移到目标形象。这说明 V* 的选择与优化直接影响概念绑定和类别先验。

**尚未证明的主张。** 论文声称方法能扩展到更多概念，但 Figure 11 和 Figure 16 显示，三个以上概念只在部分组合中可行；难以组合的“cat + dog”场景中，预训练模型本身也失败，论文说这是继承的局限，并未提出解决方案。多概念优化合并虽在几个组合上有效，但没有系统研究合并误差随概念数量增加的变化。CustomConcept101 实验中 Optimization 方法在某些概念上图像对齐不佳，如 Figure 13 中“sofa”形象没有被保留。论文没有在非 Stable Diffusion 的主干模型上验证，也没有对推理延迟做系统测量。

## 9. 与前作怎么选

需要比较的三个最接近方案是 Textual Inversion、DreamBooth 和 Custom-Diffusion 的全参数微调版本。

**Textual Inversion。** 只优化一个新 token embedding，不改变模型权重。优点是每个概念只需保存 token embedding，体积极小，且模型主体不变；缺点是模型对目标概念的表达能力受限于原有权重，文本对齐明显差，过拟合严重，多概念组合困难。在 CustomConcept101 上，其单概念文本对齐仅 0.612、图像对齐 0.752，而 DreamBooth 是 0.752/0.752、Custom-Diffusion 是 0.760/0.744。适合用户只想要一个可复用的文本触发器，并且能接受生成多样性较差的情况。

**DreamBooth。** 冻结文本编码器，微调整个 U-Net，并使用生成图做正则化。优点是图像保真强，尤其适合需要高度还原目标实例的场景；缺点是训练约 1 小时、保存约 3GB，耗时耗存储；多概念联合训练时经常出现漏生成，Figure 7 第一行 DreamBooth 在 4 张中 3 张漏掉猫。在单概念上，DreamBooth 图像对齐 0.776 高于 Custom-Diffusion 的 0.775，但 KID 32.53 明显更高，说明更易过拟合。适合对存储和计算不敏感、只定制单个高质量概念且不频繁组合多概念的用户。

**Custom-Diffusion。** 只更新 KV 矩阵和 V* token。训练约 6 分钟，存储 75MB，低秩压缩可到 15MB 甚至更低。单概念文本对齐优于 DreamBooth，图像对齐与 DreamBooth 接近；多概念联合训练和优化合并在 Table 1 中均优于 DreamBooth。在 CustomConcept101 上，优化合并文本对齐 0.763、联合训练 0.757，均高于 DreamBooth 的 0.738。它特别适合需要快速定制多个概念、希望合并生成同一场景且对成本敏感的场景。缺点是图像对齐在某些数据集上略低于 Textual Inversion 或 DreamBooth，且困难组合仍不稳定。

**Ours w/ fine-tune all。** 这是 Custom-Diffusion 的全参数版本。Table 1 单概念中它的文本对齐也是 0.795，图像对齐 0.748，低于 Custom-Diffusion 的 0.775；训练约 20 分钟且存储更大。所以当用户需要单概念定制时，没有明显理由选择全参数版本；但若方法未来扩展到更复杂的任务，全参数微调可能仍保留更多灵活性。

## 10. 工程判断：可行性、风险与上限

**数据可行性与成本。** 论文主要实验使用 4~12 张目标图，Moongate 用了 135 张。对个人宠物、玩具、家具等，用户通常容易提供 4~10 张。正则化集从 LAION-400M 自动检索，论文设置 CLIP 文本相似度阈值 0.85、数量 200。实际工程中需要处理检索结果质量，以及目标类别词可能与 LAION 中 caption 不匹配的情况。算力上，论文报告 2 块 A100 训练约 6 分钟，这对个人用户仍有一定门槛，但明显低于 DreamBooth 的 1 小时。存储 75MB 对本地部署友好，低秩压缩后可降到 15MB 左右。

**实现难点。** 一是 V* token 的选择：要选在 200K captions 中只出现约 5~10 次、且有字母表示、不是其他 token 子串的词条；实现时如果选择不当会干扰普通文本。二是多概念合并需要保证 Creg 非退化，尤其当概念数量增加、目标文本特征维度有限时，约束可能不稳定。三是训练中要对目标图和正则图采样比例、resize 范围和 prompt 追加词保持敏感；这些增强对图像对齐有影响。四是 Wk/Wv 更新幅度不大，可能对某些概念表达不足，但过训练又会遗忘，步数需要小心控制。五是生成图正则化虽然能保留目标概念性能，但会导致原始类别词质量下降，实际使用中倾向真实图检索。

**失败环节。** 论文明确提到两个失败类型：第一，困难多对象组合，像 pet dog 和 pet cat 一起生成时，模型可能合并不出两个个体；注意力可视化显示“dog”和“cat” token 的 attention map 高度重叠，导致语义混淆。第二，三个及以上新概念的组合只对部分组合有效。第三，正则化用生成图会导致原类别词质量下降；第四，压缩过狠会丢掉目标图像对齐。这些都是实际部署时可能遇到的瓶颈。

**监控信号。** 论文用 CLIP 图像对齐、文本对齐和 KID 来监控。工程上可以同时观察：目标 prompt 的视觉相似度是否上升；正则化类别 prompt 例如“a dog”的生成是否保持多样；KID 或 FID 是否显著高于预训练基线。训练步数上，论文 Figure 20 显示文本对齐随训练缓慢下降、图像对齐上升，需要在该曲线上选点。人类偏好可以补充自动指标的盲区，但成本高。FID 在 MS-COCO 上可以监控通用概念是否被破坏，论文 Table 6 显示 Custom-Diffusion 的 FID 在 16.05~17.21，接近预训练模型 16.35，说明通用生成能力保持较好。

**指标上限与未回答问题。** 论文没有在所有数据集上超越 DreamBooth 的图像对齐；Table 1 单概念图像对齐为 0.775，略低于 Textual Inversion 0.827，这反映只更新 KV 的表达能力仍有上限。多概念联合训练的平均图像对齐为 0.706，稳定但并不高。论文未给出推理延迟和显存占用的严格数字；也未讨论如何扩展到更多主干模型；多概念合并的闭式解在概念数量增大时的数值稳定性没有证明。更重要的是，论文没有回答“定制模型对生成安全的影响如何量化”，虽然 Societal Impact 提到检测假图，但没有给出本方法特有的缓解方案。

## 11. 放回研究脉络并收束

Custom-Diffusion 位于“大模型少样本适配”与“文本到图像生成个性化”的交汇点。它和 DreamBooth、Textual Inversion 几乎同时出现，分别代表三种更新范围：全参数、词向量、注意力 KV 子集。Custom-Diffusion 的关键贡献是证明交叉注意力中的 KV 投影是一个高效且强大的适配点，并给出了多概念合并的闭式解。

将其放到更大脉络中，这与 LoRA、adapter、prefix tuning 等参数高效微调思路同源，但应用在生成模型的文本条件模块上。论文在 Related Work 明确提到 LoRA 等判别式领域工作，并强调自己不加额外参数、只更新现有权重的小子集。论文没有声称完全解决组合生成，而是指出目标模型自身的组合能力构成上限。它也没有提出新的生成理论，而是做了一种“最小干预”式的工程精确验证。

**读完必须记住的 5 件事：**

1. Custom-Diffusion 只微调 Stable Diffusion 交叉注意力层中的 Wk、Wv 和一个新的修饰符 token V*，不更新其他 U-Net 权重；选择依据是 Figure 3 中交叉注意力层权重变化率显著更高但仅占参数 5%。
2. 正则化集使用约 200 张从 LAION-400M 检索的相似真实图像，CLIP 文本相似度阈值 0.85；去掉它会使 KID 从 20.96 升到 32.64，出现语言漂移和过拟合。
3. 多概念有两种方式：联合训练 500 步，或各自微调后用约束最小二乘闭式解合并，合并约 2 秒；合并时用约 1000 条随机 caption 的文本特征作为 Creg。
4. 单概念训练约 6 分钟、存储约 75MB；定量上文本对齐 0.795、图像对齐 0.775，多概念 joint training 文本/图像对齐 0.801/0.706，均优于 DreamBooth；低秩压缩后存储可降到 15MB 且性能接近。
5. 方法继承 Stable Diffusion 的困难组合限制，cat+dog 等多概念组合仍失败，三个以上概念仅部分组合可用；注意力图显示 cat、dog token 高度重叠，导致语义混淆。

**5 道自测题：**

1. 为什么论文只更新交叉注意力层的 Wk、Wv，而不更新 Wq？请从公式输入来源和权重变化分析两方面回答。
2. 如果用户想定制一只泰迪熊，应该怎样构造文本提示？V* 和类别词分别起什么作用？训练时 V* 如何初始化？
3. 多概念优化合并的目标函数中，约束项 W C^T = V 的物理含义是什么？如果 Creg 退化会发生什么？
4. 论文用 KID 衡量什么？Ours w/o Reg 和 Ours w/ Gen 的 KID 分别是多少，说明什么？生成图正则化还有哪些副作用？
5. 在什么条件下你更愿意选 DreamBooth，而不是 Custom-Diffusion？请给出存储、训练时间和多概念组合三个维度的理由。

最后用一句话收束：Custom-Diffusion 用“只改交叉注意力 KV 和 V* token”这个小而准的切入点，在少样本个性化文本到图像生成上取得了效率、保真度和多概念组合之间的平衡，但也清晰暴露了扩散模型底层的组合生成上限。
