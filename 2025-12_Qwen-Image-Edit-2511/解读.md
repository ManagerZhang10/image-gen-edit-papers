# Qwen-Image-Edit-2511 官方模型卡核验笔记

## 一句话结论

Qwen-Image-Edit-2511 是 Qwen-Image-Edit 的产品级权重更新，官方声称重点改善 image drift、人物一致性、多人融合、几何推理并内置部分 LoRA 能力；这些更新只有官方模型卡与定性样例，没有独立技术论文或公开量化消融，不能当作已被论文证明的身份保持方案。

## 与 Qwen-Image 论文的关系

该模型卡引用 arXiv:2508.02324《Qwen-Image Technical Report》，但那是整个 Qwen-Image 家族的技术报告，不是 2511 更新报告。正式报告 PDF 已存放在 `2025-08_Qwen-Image/paper.pdf`，不应在这里重复下载并冒充 2511 的独立论文。

Qwen-Image 编辑的核心基础在技术报告中是双路径输入：输入图像同时经过 Qwen2.5-VL 提供高层语义控制，也经过 VAE encoder 提供外观/像素条件。模型卡将基础模型标为 20B、BF16，并通过专用 image-edit pipeline 推理。

## 2511 官方新增主张

官方模型卡列出：

- 缓解 image drift；
- 提升单人和多人 character consistency；
- 把选定社区 LoRA 能力整合进基础模型；
- 加强工业设计生成与材质替换；
- 加强几何推理，例如生成辅助构造线。

模型卡 quick start 使用 40 inference steps、`true_cfg_scale=4.0`，并支持多图输入。这个示例是推荐配置，不是速度或最优质量的正式评测。

## 数据、训练与评测

2511 页面没有披露增量训练数据、损失、LoRA 合并清单、训练算力、对照实验、身份相似度、未编辑区 PSNR/LPIPS 或多轮漂移曲线。展示图只能说明官方选择的案例可达，不能证明平均性能或失败率。

因此 Lark 笔记中“2511 改善 image drift 和人物一致性”本身与官方模型卡一致，但证据等级应写成“官方版本说明/定性展示”，不应写成论文定量结论。

## 局限与决策意义

- **简单人像编辑**：是值得实测的开源强候选，但 20B BF16、40 步示例意味着资源和延迟不可忽略。
- **身份保持**：官方明确宣称提升，但必须在自有人像集上测单人、多人物、遮挡、侧脸和大姿态改变；还要看是否把身份锁得过强，导致指令执行不足。
- **局部保持**：image drift 改善不是像素保证。应单独测蒙版外 LPIPS/PSNR、背景文字、饰品和手部漂移。
- **多轮编辑**：官方页没有多轮误差累积曲线，不能从单轮样例外推。
- **技术复现**：若需要知道为什么 2511 变好，公开资料不足；只能把它视为 checkpoint 选择，而不是新架构选择。
