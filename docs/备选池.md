## 七、与 image_edit_paper 的重叠

Top 20 里有 **12 篇**在 `../image_edit_paper/papers/` 下已有解读（按 arXiv ID 逐条核过）：

```
SD3  VAR  Emu3  Flow-GRPO  BAGEL  FLUX.1 Kontext  Qwen-Image
Seedream 4.0  HunyuanImage 3.0  Z-Image  Qwen-Image-2.0  SenseNova-U1
（SD3 在那边的目录名是 2024-03_SD3-RectifiedFlow）
```

只有 6 篇没有重叠：**SDXL、Consistency Models、GenEval、DMD、MAR、REPA**
——外加两篇无 arXiv 条目的 DALL·E 3 与 Kolors，那边不可能有。

重叠比例这么高是有原因的：`image_edit_paper` 收了 186 篇，把编辑与统一模型这条线扫得很干净，
而 2025 年之后的厂商旗舰全都同时做生成与编辑，不存在「只做生成」的旗舰。三个选项：

| 选项 | 后果 |
| --- | --- |
| 照样重新生成 | 本仓库自洽，但同一篇会有两份解读，口径可能不一致；12 篇的生成成本重复付一次 |
| 重叠的只留索引，链到 image_edit_paper | 省 12 篇成本，但仓库不能独立分发，README 里 12 行的「解读」列指向另一个仓库 |
| 换成没重叠的 | 清单不再是真正的影响力前 20，等于为了不重复而选次要论文 |
