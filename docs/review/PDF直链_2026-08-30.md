# 原文直链核验

> 读者：想确认"点开这条链接拿到的 PDF，就是写这篇解读时读的那一份"的人
> 目标：读完知道核验口径是什么、三条特例为什么要单独指定、怎么自己复跑
> 元信息：186 个目录 · 脚本 [`scripts/verify_pdf_links.py`](../../scripts/verify_pdf_links.py) · 规则 [`scripts/pdf_sources.py`](../../scripts/pdf_sources.py) · 结果 `_work/pdf_link_check.json`
> 最后核对：2026-08-30

## 0. 为什么不能只看链接能不能打开

"链接有效"和"链接指向的是同一份文件"是两回事。arXiv 会改版本、会改题目；CVF proceedings 版和 arXiv 预印本经常页数都不一样。
本库的解读是对着**某一份具体的 PDF** 写的，如果 README 里给的链接指到另一个渲染版本，读者按图索骥会对不上号。

所以核验口径是**字节级**，不是"HTTP 200"。

## 1. 口径

对每条链接发一个 `Range: bytes=0-3` 请求，四项全过才算 OK：

| 检查 | 期望 |
| --- | --- |
| HTTP 状态 | `206 Partial Content` |
| `Content-Type` | `application/pdf` |
| 头 4 字节 | `%PDF` |
| `Content-Range` 里的总字节数 | **等于本地 `paper.pdf` 的字节数** |

第四项是关键：同一篇论文的不同渲染版本，字节数几乎不可能撞上。

## 3. 三条必须手工指定的链接

默认规则是"有 arXiv ID 就用 arXiv，否则认 CVF 的 `/html/` → `/papers/` 变换"。下面三条走默认规则会拿到**能打开但不是本库读的那一份**。

### 3.1 FlowChef —— arXiv 上已经不是同一篇论文了

`2412.00100` 现在的题目是 *Steering Rectified Flow Models in the Vector Field for Controlled Image Generation*，正文大幅改写，13,933,891 字节。
本库解读依据的是 ICCV 2025 proceedings 版，**7,278,431 字节**，CVF 那条与本地 sha256 一致。

### 3.2 ug-fight-dpo —— 裸链 404，带版本号才行

`https://arxiv.org/pdf/2603.17044` 稳定返回 404（复测 2 次），`.../2603.17044v1` 正常，565,863 字节与本地一致。
这不是 arXiv 的普遍行为，是这一条的个例，所以写死在 `OVERRIDES` 里而不是给所有链接加 `v1`。

### 3.3 DICE —— 从"版本存疑"降级为已核验

这条上一版标着 ⚠️ 渲染版本存疑，本轮定位清楚了：

| | arXiv v1 | 本地 `paper.pdf` |
| --- | --- | --- |
| 页数 | 15 | **10** |
| 字节 | 4,016,508 | **1,739,117** |

本地那份的 PDF 元数据写着 `/Producer: pikepdf 9.11.0`、`/Subject: IEEE International Conference on Computer Vision`——就是 ICCV 2025 proceedings 版。
把 CVF 那条实拉下来，sha256 `3148fc367915ca2be0530e06275489277379c3659b37456e4cd26948c765a570`，与本地完全一致。

`scripts/pdf_sources.py` 里的 `RENDITION_DIFFERS` 机制因此**清空**了（保留结构，下次再遇到同类情况直接往里加）。

## 4. 怎么自己复跑

```bash
python3 scripts/verify_pdf_links.py                    # 全量重跑，覆盖 _work/pdf_link_check.json
python3 scripts/verify_pdf_links.py 2023-02_ControlNet # 只核一个，结果并回既有 json
python3 _work/gen_paper_table.py                       # 按新结果重生成 README 全量清单的表
python3 _work/check_table_rows.py                      # 核对表格行数与目录数一致
```

⚠️ 全量复跑是**串行**的，`DELAY = 3.0` 秒（arXiv 对批量访问要求 ≥3s 间隔），跑完约 **9 分钟**。不要改成并发——会被限流，而且限流返回的 HTTP 状态不是 206，全部记成 MISMATCH。
