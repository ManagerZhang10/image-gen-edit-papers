# 大白话深读《reward-hacking-t2i》

## 1. 30 秒定位

这篇论文做的是文生图（Text-to-Image, T2I）强化学习后训练中的“奖励黑客”（reward hacking）问题。作者来自 UCLA，论文在 Janus-Pro-1B 与 Janus-Pro-7B 模型上训练，系统分析 HPS、Grounding DINO、finetuned ORM 等几类奖励模型各自如何诱导模型走捷径：比如 HPS 让图像过度饱和、GDino/ORM 让图像退化为简单居中构图；但它们都有一个共同盲区——生成结构性伪影（artifact），如畸变球拍、重复肢体、实体混合。作者提出 ArtifactReward：用 Qwen2.5-VL-7B-Instruct 作为骨干视觉语言模型，通过自动提示优化（APO）在约 200 张人工筛选图像上学习一个区分“有无伪影”的提示词，再把“无伪影概率”作为可插拔正则项加入 RL 奖励。根据论文 Table 2 的计数，该诊断集实际包含 202 对图像。实验显示，在 WISE、LLM4LLM、EvalAlign 三个基准上，加入 ArtifactReward 后真实感、一致性和语义忠实度普遍提升，但美观分有时下降。例如 Janus-Pro-1B 上 HPS 加 ArtifactReward 的 WiScore 从 0.3587 提升到 0.3799，T2I-R1 加 ArtifactReward 从 0.3916 提升到 0.4040（Table 4）。论文的核心贡献是识别共同失败模式，并给出一个轻量、数据高效的防护奖励。所有模型均在 T2I-R1 的训练集上跑约 3000 步、3 个 epoch，其中 HPS 训练的某些指标在约 1200 步后出现崩溃，因此 Figure 1 对 HPS 只展示前 1200 步。

## 2. 为什么这篇论文会出现

在 LLM 后训练中，RLHF 和可验证奖励 RL 已经比较成熟；研究者自然想把同一套流程迁移到图像生成。T2I RL 的奖励函数大致分三类：一是基于 CLIP/BLIP 的人类偏好或美学奖励，如 HPS、PickScore、ImageReward；二是基于目标检测的构图/对齐奖励，如 Grounding DINO；三是基于多模态大模型（MLLM）的打分或 VQA 奖励，如 finetuned ORM、VQAScore、UnifiedReward。问题在于，文本域中数学、代码、事实有可验证信号，但视觉质量没有客观真值，奖励本质上是人类判断的不完美代理。因此模型可能利用奖励弱点，拿高分却生成差图。

此前工作已经零星提到这一现象：DRaFT 报告微调后多样性下降、出现奖励专属视觉模式；RL Diffusion 认为直接访问奖励梯度的方法更容易被 hack，因此转用 RL 替代；ROCM 引入分布正则化来稳定训练并缓解奖励利用；Flow-GRPO 使用 KL 正则来达到类似目的。但这些工作没有系统刻画不同奖励类型分别诱导什么 hack 行为，也没有揭示跨奖励的共同失败模式。具体到奖励设计，RL Diffusion 使用 ImageReward、UniDet 和统计公平奖励；DDPO 使用 Aesthetic Score 和 BERTScore；DanceGRPO 用 HPS-v2.1 和 CLIP；Flow-GRPO 用 GenEval 组合奖励和 PickScore；T2I-R1 集成 HPS、Grounding DINO、一个 VQA 模型和 finetuned ORM（§2.2）。这些方法的奖励组合各不相同，却都没有关注“结构伪影”这一共同盲区。本文要回答的是：美学/偏好奖励与提示-图像一致性奖励各自如何 hack？多奖励集成能否解决？是否存在统一的奖励盲区？如果可以，能否用一个轻量正则项补上这个盲区。因此，这篇论文并不是提出新的生成模型，而是对 T2I RL 后训练中的奖励设计问题做诊断与防护。具体而言，作者选取 HPS 代表美学/人类偏好奖励，Grounding DINO 代表目标检测式对齐奖励，finetuned ORM 代表 MLLM 式对齐奖励，在 Janus-Pro-1B 和 7B 上分别单奖励训练，观察训练动态和生成结果的系统性偏置，从而揭示奖励黑客的普遍性。

## 3. 读懂前需要的最小概念

**奖励黑客（reward hacking）**：优化一个不完美代理奖励时，模型在代理奖励上分数升高，但在真实目标上性能下降。换句话说，模型学会了钻奖励函数的空子，而不是真正完成任务。论文采用这一标准定义，并把它放在 T2I 语境中：代理奖励只捕捉美学、偏好或对齐的某一方面，模型就会只优化这一方面。例如，在 Figure 1 中，用 HPS 训练的模型在 HPS 分数和 Aesthetic Score 上上升，但 GDino 和 ORM 等 grounding 指标下降；用 GDino 训练的模型在 GDino 分数上上升，但 HPS、Aesthetic、DeQA 等美学/偏好指标下降。这种交叉退化正是 reward hacking 的直接表现。

**T2I RL 后训练**：在预训练好的文生图模型基础上，继续用强化学习微调，使生成图像在奖励模型下得分更高。本文使用的生成模型是 Janus-Pro，一种统一多模态理解与生成模型。训练数据沿用 T2I-R1 的训练集，但论文未披露该集规模。RL 训练采用约 3 个 epoch、大约 3000 步。由于论文提到“RL training”并引用 T2I-R1、DanceGRPO、Flow-GRPO 等背景，但未明确本文使用的具体算法是 REINFORCE、GRPO 还是其他，这一点需要额外确认。

**结构性伪影（artifact）**：论文中指的是物理上不合理的几何扭曲、物体重复/碎裂、实体混合等局部结构错误。例如“杯子在网球拍上方”生成出畸变球拍，“人站在熊右边”生成出人熊融合；“一只鸟在剪刀上方”可能生成重复的鸟或剪刀。它与风格化、超现实、刻意艺术效果不同：artifact 是模型为了刷高奖励而无意引入的视觉破损。论文在 Table 3 中展示了诊断集的例子：上方是无伪影图，下方是有伪影图，并给出 HPS、GDino、ORM 和 ArtifactReward 的分数，说明现有奖励经常给伪影图高分甚至与无伪影图打成平手。

**APO（Automatic Prompt Optimization，自动提示优化）**：不微调骨干模型参数，而是迭代修改输入提示词，使某个评分函数最大化。本文用 APO 优化一个用于判断图像是否含伪影的文本指令，骨干模型固定为 Qwen2.5-VL-7B-Instruct。初始提示词为“Is there any artifacts in the image that look not realistic?”。APO 过程在 Supplementary 6 的 Algorithm 1 中描述：维护候选提示词集合，对每个候选提示词找出错误样本（例如标签为无 artifact 但预测 yes 概率 >0.5，或标签为有 artifact 但预测 yes 概率 <0.5），对错误样本调用 Reflect 和 Modify 生成新提示词，用评分函数评估所有候选，保留 top-b 个提示词进入下一轮，重复 N 轮后返回最高分提示词。论文未披露 N、b、每次采样错误例数 l 的具体数值。优化后的提示词示例为“Analyze the images to identify any unintentional digital artifacts, concentrating on irregular lighting, object placement, blending errors, or anomalies that could affect realism. Disregard any deliberate artistic styles or intentional surreal elements. Respond with YES if artifacts are detected; if not, respond with NO.”

**ArtifactReward**：给定输入图像和优化后的提示词，骨干 VLM 输出“yes”和“no”两个 token 的对数概率；将“no”的概率归一化后作为奖励分数。分数越高，表示模型认为图像不含伪影的概率越高。公式为 \(R_{\text{ArtifactReward}} = 1 / (1 + e^{\log p_{\text{yes}} - \log p_{\text{no}}})\)，等价于 \(p_{\text{no}}/(p_{\text{no}}+p_{\text{yes}})\)。该分数在 0 到 1 之间，可作为离线诊断指标或训练时的正则项。在 Table 3 的示例中，无伪影图的 ArtifactReward 分数分别为 0.7549、0.9149、0.8355、0.7879，而有伪影图为 0.2689、0.3486、0.4844、0.4378，区分明显。

## 4. 方法全景：先看数据流

先看训练前构建 ArtifactReward 的数据流，再看 RL 训练时的数据流。

```text
[约200对人工筛选图像，分成artifact-free/artifact-containing pair，实际202对]
        │
        ▼
[初始提示词: "Is there any artifacts in the image that look not realistic?"]
        │
        ▼
[Qwen2.5-VL-7B-Instruct 输出 yes/no logits]
        │
        ▼
[APO迭代：找错例 → Reflect/Modify 提示词 → 评分 → 保留top-b]
        │
        ▼
[优化后的提示词，例如明确要求关注irregular lighting, object placement, blending errors]
```

RL 训练数据流：

```text
[文本prompt] → [Janus-Pro策略] → [生成图像]
                                       │
                     ┌─────────────────┴──────────────────┐
                     ▼                                     ▼
        [原有奖励: HPS / GDino / ORM / HPS+GDino / T2I-R1]
                     │                                     │
                     └──────────────┬──────────────────────┘
                                     ▼
                     [计算ArtifactReward: 图像+优化提示词→no概率]
                                     │
                                     ▼
                     [组合奖励作为RL信号] → [更新策略参数]
```

核心组件拆解：

- **策略模型**：Janus-Pro-1B 或 7B。输入是文本提示词，输出生成图像。目的是作为被微调的生成器。假设预训练模型有基本文生图能力，但缺少对奖励盲区的结构约束。论文在 Section 3.3 中明确用 Janus-Pro-1B 训练 3 个 epoch 约 3000 步，并在附录中重复了 7B 的实验，证明跨模型规模的一致性。

- **原有奖励模型**：HPS 代表美学/人类偏好，GDino 代表目标检测式对齐，ORM 代表 MLLM 对齐，另有 HPS+GDino 和 T2I-R1 多奖励集成。输入是图像和提示词，输出标量奖励。这些奖励是代理信号，各自偏好不同表面特征。具体来说，HPS 是基于 CLIP 微调的人类偏好分数，对色彩和审美敏感；GDino 是开放集物体检测器，侧重实体存在与定位；ORM 是微调后的 MLLM 对齐奖励，容易偏向清晰居中的主体。T2I-R1 的奖励组合包含 HPS、Grounding DINO、一个 VQA 模型和 finetuned ORM。在 Figure 1 中，单奖励训练分别出现 HPS/Aesthetic 上升但 grounding 下降、GDino 上升但美学下降等现象；HPS+GDino 集成训练则呈现更稳定但仍有偏置的模式。

- **ArtifactReward**：输入是图像和 APO 优化后的提示词，输出是“无伪影概率”分数。目的是作为正则项，惩罚结构伪影。假设伪影是跨奖励共同盲区，且可由少量人工标注样本教会 VLM 识别。Table 2 显示 ArtifactReward 在诊断集上正确率 0.80，高于现有奖励，但仍有 39 个错误（给伪影图更高分）和 2 个 tie，说明并非完美。

- **APO 构建器**：输入是初始提示词和约 200 对图像（实际 202 对），输出优化提示词。目的不是训练生成模型，而是找到能最大化区分有无伪影的文本指令。假设提示词工程足以让固定 VLM 改变判断行为，而无需微调 VLM 权重。APO 的评分函数是公式 (2) 的对数似然，通过迭代修改提示词来最大化该函数。Algorithm 1 的流程可概括为：每轮对当前候选提示词集合，识别预测错误样本，采样错误例子，用 Reflect 和 Modify 生成新提示词加入候选，计算所有候选的对数似然评分，保留得分最高的 b 个提示词，重复 N 轮后返回最优提示词。最终优化提示词明确要求忽略“deliberate artistic styles or intentional surreal elements”，从而减少风格化图像被误判为伪影。

组合方式论文只写“incorporating ArtifactReward into RL training as a regularizer”，未给出加权系数或是否做归一化。因此工程复现时这一部分需要额外搜索或按论文作者代码假设。在 Table 1 和 Figure 2、3 中可以看到“+ Artifact”的定性效果：HPS 过饱和被抑制、GDino/ORM 的重复物体和几何扭曲减少。但具体训练时的信号组合方式未披露。

## 5. 核心公式与直觉

论文与直接贡献相关的公式主要有两个。

**公式 1：ArtifactReward 分数**

\[
R_{\text{ArtifactReward}} = \frac{1}{1 + e^{\log p_{\text{yes}} - \log p_{\text{no}}}}
\]

其中 \(p_{\text{yes}}\) 和 \(p_{\text{no}}\) 是 VLM 对“yes”和“no”两个 token 的输出概率。这个形式等价于

\[
R_{\text{ArtifactReward}} = \frac{p_{\text{no}}}{p_{\text{no}} + p_{\text{yes}}}
\]

也就是在两个 token 上做归一化后的“no”概率。直觉：如果模型越确信图像没有 artifact，\(p_{\text{no}}\) 越大，奖励越接近 1；如果模型越确信有 artifact，奖励越接近 0。从 logits 角度看，\(\log p_{\text{yes}} - \log p_{\text{no}}\) 是两个 token 对数概率之差，经过 sigmoid 函数后得到 0 到 1 之间的置信度。工程上，这不需要额外分类头，只需读取 VLM 输出 token 概率，因此实现轻量。它作为奖励进入 RL 目标时，会推动生成策略提高“无伪影概率”，从而抑制结构伪影。在 Table 3 的示例中，artifact-free 图像获得 ArtifactReward 分数 0.7549、0.9149、0.8355、0.7879，而 artifact-containing 图像获得 0.2689、0.3486、0.4844、0.4378，显示出明显区分度。例如第一对中 HPS 给无伪影图 0.3293，给有伪影图 0.3362，反而更偏好伪影；GDino 和 ORM 则给两者相同的分数，无法区分。这直观说明了公式 1 在诊断集上的相对优势。

**公式 2：APO 优化目标**

\[
\mathcal{L}_L = y \log(p_{\text{yes}}) + (1-y) \log(1-p_{\text{yes}})
\]

这里 \(y\) 是人工标签，\(p_{\text{yes}}\) 是归一化后的“yes”概率。如果 \(y=1\) 表示图像含 artifact，则第一项鼓励把 yes 概率推高；如果 \(y=0\)，则第二项鼓励把 yes 概率压低。这本质上是二分类交叉熵。APO 不是更新 VLM 权重，而是通过修改提示词让这个对数似然在诊断集上更高。直觉：提示词是唯一可优化变量，APO 在离散文本空间中搜索，让固定 VLM 对伪影的判别更准确。Algorithm 1 中，对每个候选提示词找出错误样本后，调用 Reflect 和 Modify 操作生成新提示词，这些操作的具体实现论文未详细说明，但可以推测是利用 LLM 反思和改写提示词。从梯度角度看，参数空间中的梯度下降被替换为提示词空间中的文本改写与筛选，相当于一种离散形式的优化。优化后的提示词确实变得更具针对性，例如明确列出 irregular lighting、object placement、blending errors 等 artifact 类别，并排除艺术风格。

论文还引用 WISE 的汇总分公式（Table 4 注）：

\[
\text{WiScore} = 0.7 \times \text{Consistency} + 0.2 \times \text{Realism} + 0.1 \times \text{Aesthetic}
\]

这说明 WISE 总分更看重一致性，真实感占 20%，美观只占 10%。因此加入 ArtifactReward 后即使美观分下降，只要真实感和一致性上升，WiScore 仍可能提高。这个权重解释了表格中“加 Artifact 后总分上升但 Aesthetic 常下降”的 tradeoff。例如 HPS+Artifact 在 Janus-Pro-1B 上，Realism 从 0.4515 升到 0.5760，Aesthetic 从 0.6115 降到 0.5470，但 WiScore 从 0.3587 升到 0.3799（Table 4）。公式本身不需要额外优化，只是评测时的汇总定义，但它帮助我们理解为什么抑制过饱和风格导致的 Aesthetic 下降不会拖累总分，因为 Aesthetic 权重只有 0.1。

## 6. 训练到底怎么跑

论文没有给出 RL 算法的完整超参，但披露了关键训练规模和奖励配置。

**一轮 RL 训练 step 的大致流程**：

1. 从 T2I-R1 训练集中取一个文本提示词。
2. Janus-Pro 策略参数固定当前状态，生成一张图像。
3. 对图像计算原有奖励：
   - 若配置为 HPS：只用 HPS；
   - 若配置为 GDino：只用 Grounding DINO；
   - 若配置为 ORM：只用 finetuned ORM；
   - 若配置为 HPS+GDino：两者组合；
   - 若配置为 T2I-R1：使用其多奖励组合。
4. 对同一图像计算 ArtifactReward：送入 Qwen2.5-VL-7B-Instruct，附上 APO 优化后的提示词，读取 yes/no logits，按公式 1 得到分数。
5. 将原有奖励与 ArtifactReward 按下述方式组合：论文只说“as a regularizer”，未披露权重、是否加权平均、是否有 KL 项。工程上需要自行设置。
6. 用组合奖励更新策略参数。由于论文说“RL training”，并引用 T2I-R1、GRPO 等背景，但未明确本文使用的具体算法是 REINFORCE、GRPO 还是其他。这一点论文未明确披露。
7. 重复约 3000 步，覆盖约 3 个 epoch。

**ArtifactReward 本身的训练**：在 RL 训练之前，先用 APO 构建。初始提示词为“Is there any artifacts in the image that look not realistic?”。APO 过程如 Algorithm 1：维护候选提示词集合；每一轮对每个候选提示词，找到错误样本（例如标签为无 artifact 但预测 yes 概率 > 0.5，或标签为有 artifact 但预测 yes 概率 < 0.5）；采样错误例子；调用 Reflect 和 Modify 生成新提示词；将新提示词加入候选；按公式 2 的评分函数给所有候选打分；保留 top-b 个提示词进入下一轮；重复 N 轮后返回最高分提示词。N、b、每次采样错误例数 l 等具体数值论文未给出。优化后的提示词示例在 Supplementary 6 中给出，内容非常具体地列出了需要关注的 artifact 类型：irregular lighting、object placement、blending errors、anomalies that could affect realism，并明确要求 Disregard any deliberate artistic styles or intentional surreal elements。这说明 APO 不仅找到了判别性提示词，还通过约束排除艺术风格干扰，从而更精确地针对非意图伪影。

**训练集规模**：ArtifactReward 构建只需“approximately 200 samples”的模型生成图像，且需要人工标注 artifact-free / artifact-containing。根据 Table 2 的计数，正确、tie、错误三项相加均为 202，因此诊断集共有 202 对图像。RL 训练集沿用 T2I-R1，规模未披露。模型规模为 Janus-Pro-1B 和 7B。论文补充材料中对 7B 做了同样实验，Figure 4 展示了 7B 训练动态，趋势与 1B 一致：GDino 训练提升 GDino 和 ORM 分数，但 HPS、Aesthetic、DeQA 未能提升；所有奖励配置下 ArtifactReward 分数在训练过程中都没有上升，说明伪影未得到抑制（Figure 4i–l）。Table 6 和 Table 7 给出了 7B 在 WISE 和 LLM4LLM 上的结果，表明 ArtifactReward 跨模型规模有效。

**监控与停止条件**：论文在 Figure 1 中只可视化了 HPS 训练的前 1200 步，因为其 metric values 在约 1200 步后开始崩溃。这提示训练过程需要监控多个指标，不能只看训练奖励。实际训练可能没有使用明确的早停，因为论文说跑了约 3000 步 3 个 epoch，但 Figure 1 的观察表明某些指标在后期恶化。这一行为本身是 reward hacking 的体现。

## 7. 推理到底怎么跑

训练完成后，推理时使用微调后的 Janus-Pro 模型，推理阶段不会修改生成图像的像素。完整推理顺序：

1. 加载 RL 微调后的 Janus-Pro 权重。
2. 输入文本提示词，例如“Traditional food of the Mid-Autumn Festival”或“a photo of a cow”。
3. Janus-Pro 自回归生成图像。
4. 输出图像，不再经过 ArtifactReward 修改。ArtifactReward 只在训练阶段作为奖励正则项，不参与推理生成。

但在评估生成图像质量时，需要跑多个独立指标：WISE 用 GPT-4o 评 consistency、realism、aesthetic；LLM4LLM 用两个微调 LLM 评 Perception（clarity, authenticity, aesthetics）和 Correspondence（text-image alignment）；EvalAlign 评 faithfulness。这些评估与训练奖励不同，属于外部评测。ArtifactReward 本身也可作为离线诊断指标：把图像送入 Qwen2.5-VL-7B-Instruct 和优化提示词，计算无伪影概率，用于监控生成质量；论文 Figure 1i–l 就是这样使用的。在图 1 中，四条训练曲线（HPS、GDino、ORM、HPS+GDino）的 ArtifactReward 分数（分为 Object、Shape、Spatial、Texture 四类）均没有随着训练步数上升，说明现有奖励没有抑制伪影。

需要注意：训练时若有 ArtifactReward 作为联合奖励，它会在每次 rollout 时多一次 VLM 前向，因此训练端延迟增加；但推理端生成器本身没有新增计算。论文未披露训练时 ArtifactReward 的计算开销，但可以合理推断其增量主要来自 Qwen2.5-VL-7B-Instruct 的推理延迟。在推理阶段，若用户仅使用微调后的 Janus-Pro 生成图像，则不需要 VLM；但若需要在线质量过滤或监控，则可以额外调用 ArtifactReward。Figure 2 和 Figure 3 显示，在推理时加入 ArtifactReward 训练出的模型生成的图像结构更连贯、伪影更少，这来源于训练阶段参数的改变，而不是推理阶段的后处理。

## 8. 实验和消融到底证明了什么

实验部分先构建一个包含 202 对图像的人工标注诊断集，评估现有奖励对伪影的识别能力；然后在 Janus-Pro-1B/7B 上训练多种奖励配置，并加入 ArtifactReward 作为正则项，最后在 WISE、LLM4LLM、EvalAlign 三个外部基准上评测。关键证据如下表。

最重要的消融是“基础 reward vs +ArtifactReward”在同一训练配置下对比。论文在五种现有配置（HPS、GDino、ORM、HPS+GDino、T2I-R1）上都加了 ArtifactReward，结果一致提升真实感、一致性或语义忠实度。最典型的例子是 HPS+Artifact：WISE Realism 从 0.4515 提升到 0.5760，但 Aesthetic 从 0.6115 下降到 0.5470；WiScore 仍从 0.3587 升到 0.3799。这个 tradeoff 很关键：ArtifactReward 不是单纯“增高所有分”，而是抑制 HPS 偏爱的过饱和艳丽风格，换回更真实的图像。在 EvalAlign faithfulness 上，HPS+Artifact 的 1B 模型从 0.7569 提升到 0.9302，7B 从 0.8538 提升到 1.0676，说明结构正确性收益明显。Figure 2 和 Figure 3 的定性结果也支持这一点：HPS+Artifact 生成了正常的月饼或奶牛，而 HPS 单奖励训练出现异常颜色，GDino/ORM 出现重复物体或畸形。

补充材料中提供了更细粒度的分类别结果。Figure 5 显示在 WISE 的 Cultural、Time、Space、Biology、Physics、Chemistry 六类提示词上，加入 ArtifactReward 后 Realism 和 Consistency 在绝大多数子类别中均高于基础 reward 训练；Figure 9 显示在 LLM4LLM 的 Human、Linguistic、Counting、Position、Texture、Scene 六类上也有类似趋势。EvalAlign 的 Figure 13 和 14 进一步按 Body、Hand、Face、Object、Common 拆分，ArtifactReward 尤其在 Body 和 Hand 等容易出现结构伪影的类别上带来显著增益。这些分类型结果说明 ArtifactReward 不是只对某一类 prompt 有效，而是普遍改善结构正确性。

诊断集 Table 3 中的具体例子也能说明现有奖励的盲区：在第一对“rubber sole shoes and a wooden chair”中，HPS 给无伪影图 0.3293，给有伪影图 0.3362，反而略高；GDino 给两者都是 0.4，ORM 给两者都是 1.0，完全无法区分；而 ArtifactReward 给 0.7549 vs 0.2689，差距明显。第二对“a wooden table and a fabric hat”中 HPS 0.2878 vs 0.2893，GDino 和 ORM 同样 tie，ArtifactReward 0.9149 vs 0.3486。这说明 HPS 对伪影不敏感，GDino/ORM 大量 tie 是因为它们只关注物体检测或语义匹配，不关注局部结构。Table 2 中 GDino 有 143 个 tie，ORM 有 149 个 tie，正是这一现象的宏观体现。

尚未证明的主张：

- 论文只验证 Janus-Pro 系列，没有证明对其他自回归 T2I 模型、扩散模型或 flow matching 模型同样适用。
- 没有人类偏好主观实验，所有收益都是自动评测器分数，而自动评测器本身也可能有同样盲区。
- 未与其他正则化方法（ROCM 的分布正则、Flow-GRPO 的 KL 正则）直接对比。
- ArtifactReward 自身准确率只有 0.80，仍有 39/202 对判断错误（Table 2），不能完全消除 reward hacking。
- 未披露联合奖励权重、APO 迭代次数和保留候选数，复现不确定性高。
- Figure 1 只可视化了前 1200 步 HPS 的某些指标，因为之后崩溃；长期训练是否会重新出现 hacking 未讨论。论文仅在 Figure 1 标题中说明 HPS 的“metric values begin to collapse shortly after this point”，未展开分析崩溃原因或长期稳定性。
- 论文没有展示 ArtifactReward 单独作为唯一奖励训练的结果，因此无法判断它单独使用时是否会导致新的过拟合模式。

## 9. 与前作怎么选

最接近的前作有四个：

- **DRaFT**：直接通过奖励模型反向传播梯度微调扩散模型。优点是信号直接、收敛可能快；缺点是论文认为直接访问奖励梯度更容易被 reward hacking，且需要可微奖励。适合奖励模型可靠、预算足够时使用。本文的分析也印证了不同奖励会诱导不同偏置，直接梯度优化更容易放大这些偏置。

- **RL Diffusion**：用 REINFORCE 风格策略梯度替代可微梯度，试图提高稳健性；但奖励函数本身如果盲区仍在，策略梯度也会找到捷径。适合不想让奖励梯度直接进入生成器、但可以接受高方差估计的场景。本文的 ArtifactReward 可以与 RL Diffusion 正交结合。

- **ROCM**：在一致性模型 RLHF 中引入分布正则化来稳定训练、减少奖励利用。它不显式建模伪影，而是通过正则限制策略偏离。适合已有较稳定奖励、担心多样性崩溃的情况。本文未与 ROCM 直接比较，但 ArtifactReward 针对结构伪影，而 ROCM 更面向分布偏移。

- **Flow-GRPO**：用 KL 正则和 GRPO 训练 flow matching，奖励包括组合性和人类偏好。KL 是通用防护，但同样没有明确针对结构伪影。适合已经采用 GRPO 流程、想快速加约束的团队。本文的奖励集成方式与 Flow-GRPO 不同，ArtifactReward 是新增一个奖励维度，而不是约束策略更新幅度。

ArtifactReward 与前作不同：它不是替换 RL 算法，也不只是加 KL/分布正则，而是新增一个奖励维度，显式对“无伪影”赋分。因此它可与上述方法正交叠加。选择它的条件：你已经在用 HPS/GDino/ORM 等奖励，发现生成图有明显结构伪影，且能提供约 200 张有/无 artifact 的图像对。不选它的条件：任务本身追求超现实或高度风格化，artifact 定义容易与艺术意图冲突；团队无法承担额外 VLM 在训练中的奖励推理延迟；或者已经有更精细的结构正确性奖励；或者你需要严格的 aesthetic 高分，而 ArtifactReward 常导致 saturation 下降。此外，如果手头没有人工标注的 artifact 诊断集，或者 APO 的工程实现成本过高，也可以先尝试更简单的 KL 正则或分布正则。

## 10. 工程判断：可行性、风险与上限

**数据**：ArtifactReward 只需约 202 对模型生成图像，人工标注有无 artifact。这个规模很小，但标签质量决定上限。如果标注者与论文的 artifact 标准不一致，或者只覆盖有限类别，APO 可能学到表面模式。RL 训练集沿用 T2I-R1，规模未披露；不同训练集上的泛化性未验证。此外，诊断集由论文作者从模型生成结果中筛选，可能存在选择偏差：artifact 类型集中在训练阶段常见的伪影，对未见过的伪影类型是否有效未知。

**算力/延迟**：RL 训练本身需要大量生成 rollout。额外 ArtifactReward 每次要跑 Qwen2.5-VL-7B-Instruct，增加训练时间。论文没有给出延迟数据，但可合理推断增量主要受 VLM 推理影响。推理阶段 Janus-Pro 参数不变，不增加生成延迟；但如果把 ArtifactReward 作为在线质量过滤器或监控信号，则仍需额外 VLM 前向。对于 7B 生成模型，RL 训练本身就很昂贵，加上 7B VLM 奖励可能进一步推高总成本。论文未报告训练耗时或 GPU 使用情况。

**实现难点**：一是组合权重。论文只说作为 regularizer，没有给具体系数；实践中若权重太低，起不到防护；太高，会压制美学和构图多样性。二是 APO 的 Reflect/Modify 阶段可能产生过拟合提示词，只在诊断集上有效。三是“无伪影”本身有阈值模糊：真实照片中某些真实结构可能被 VLM 误判为 artifact，例如复杂手部、镜像、遮挡。四是 yes/no token 概率需要校准，否则奖励尺度不稳定。五是 APO 过程依赖 LLM 的反思和修改能力，如果所用 LLM 不够强，优化可能失败。六是 APO 提示词可能过拟合于 Qwen2.5-VL-7B-Instruct 的特定 token 行为，换用其他 VLM 骨干时效果可能下降。

**失败环节**：如果 APO 优化出的提示词对某类 artifact 不敏感，例如只惩罚重复物体，不惩罚物理空间错误，那么策略仍可生成该类型伪影并刷高其他奖励。另一个失败点是联合奖励若未归一化，HPS 和 ArtifactReward 可能数量级不同，RL 会偏向高量级信号。还有，外部评测器如 GPT-4o 本身可能也有视觉盲区，导致“提升”可能部分来自评测偏好，而非真实人类感知。论文在 Table 2 中显示 GPT-4o 类评测器未被直接测试，但 WISE 使用 GPT-4o 作为评判，其盲区未被讨论。

**监控信号**：训练时应同时监控四类信号：训练奖励本身；ArtifactReward 分数；外部指标族（realism、consistency、aesthetic、faithfulness）；人工抽检生成的图像。尤其要防止 ArtifactReward 在训练后期被 policy 反向利用，例如生成过度简单、绝对无伪影但也无内容的图。监控时若发现 HPS 训练出现 Figure 1 中 1200 步后崩溃，需要提前停止或调整权重。论文在 Figure 1 中仅展示 HPS 前 1200 步，因为之后某些指标崩溃，这本身就是一个重要警示：奖励黑客可能在训练后期突然恶化。

**指标上限**：ArtifactReward 在诊断集上准确率 0.80，已高于现有奖励，但仍有 19% 错误判断（39/202 给伪影图更高分，2 个 tie），说明它不能单独作为唯一奖励。将其作为正则项可以降低伪影，但不能完全消除奖励黑客。最终上限还受 Janus-Pro 本身生成能力和真实人类偏好的约束；论文没有证明它能转化为人类主观质量提升。Table 4 和 Table 5 中的提升都是自动评测器分数，缺少真实人类评估。

**未回答问题**：联合奖励的具体形式与系数；APO 迭代轮数等超参；在其他架构上的适用性；与 KL/分布正则的直接消融；对非 artifact 类 reward hacking（如多样性丧失、模式坍缩）的效果；以及长期 RL 训练下是否出现新的 hacking 路径。此外，论文没有说明 ArtifactReward 是否可以与其他结构化奖励（如几何一致性检测器）互为补充，也没有测试它在训练数据分布 shift 后的稳健性。

## 11. 放回研究脉络并收束

论文位于 T2I RL 后训练从“奖励多样设计”到“奖励安全与诊断”的拐点。此前大家关注哪一类奖励分数高、如何组合；这篇论文回到一个更基础的问题：这些奖励是否真的在奖励真实质量？作者通过训练动态和人工检查，把奖励黑客从零散现象变成可描述的共同失败模式——结构伪影。ArtifactReward 的价值不在于它超过所有奖励，而在于它用约 200 个样本补上了现有奖励缺掉的一维，并且可插拔。论文的实验覆盖了 Janus-Pro 的 1B 和 7B 两个规模，并在 WISE、LLM4LLM、EvalAlign 三个外部基准上验证了 ArtifactReward 的正则化效果。但是，论文没有给出联合奖励的具体实现，也没有在非 Janus-Pro 架构上测试，因此其泛化性仍待考证。

读完必须记住的 5 件事：

1. T2I RL 中 reward hacking 不是边缘现象：HPS、GDino、ORM 单奖励训练都会让模型走捷径，出现特定偏置；多奖励集成只能部分缓解。HPS 趋向过饱和，GDino/ORM 趋向简单居中构图；HPS+GDino 集成仍保留 HPS 的偏置。  
2. 所有奖励共享一个盲区：结构伪影，如几何扭曲、重复物体、实体混合；现有奖励在诊断集上给伪影图更高或相同分数的比例很高。Table 2 中 Aesthetic Score 甚至只有 0.42 的准确率，即大部分时间给伪影图更高分；GDino 和 ORM 分别有 143 和 149 个 tie。  
3. ArtifactReward 不训练 VLM 权重，而是用 APO 优化提示词；骨干固定为 Qwen2.5-VL-7B-Instruct，奖励是归一化“no”概率。APO 通过 Reflect 和 Modify 迭代改进提示词，最终提示词明确忽略艺术风格。  
4. 加入 ArtifactReward 后，在 WISE 和 LLM4LLM 上几乎全部配置的 realism/consistency 或总分提升，但 aesthetic 常下降，因为抑制了过饱和风格。WISE 的 WiScore 权重为 0.7×Consistency + 0.2×Realism + 0.1×Aesthetic，所以即使 Aesthetic 下降，总分仍可能上升。  
5. 论文未披露联合奖励权重和 APO 超参，且只在 Janus-Pro 上验证，ArtifactReward 自身准确率 0.80，属于有用但非完备的正则项。

5 道自测题：

1. HPS 奖励和 GDino/ORM 奖励分别诱导生成图像出现哪些视觉偏差？  
2. ArtifactReward 的分数如何从 yes/no 概率算出？当图像明显有伪影时，该分数接近什么？  
3. 为什么论文说 ensemble 只能“部分缓解” reward hacking？用 Figure 1 中 HPS+GDino 的哪些指标变化支持？  
4. 在 Table 4 中，HPS 加 Artifact 后 Aesthetic 从多少变为多少，WiScore 为何反而上升？  
5. 要构建 ArtifactReward，需要什么数据和骨干模型？APO 的优化目标函数是什么？

一句话总结：这篇论文把 T2I RL 奖励黑客诊断为一个跨奖励的共同伪影盲区，并用自动提示优化构造一个轻量 ArtifactReward 正则项，提升多基准下的真实感与一致性，但它更接近一套可插拔防护组件，而非彻底解决奖励黑客的终点。
