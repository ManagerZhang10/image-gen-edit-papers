# 大白话深读《cfg-inversion-fail》

## 1. 30 秒定位

这篇论文不提出新的通用图像编辑框架，而是在做一个诊断性研究：当一张图像是由高分类器自由引导（classifier-free guidance，CFG）的扩散轨迹生成时，这条轨迹什么时候能被成功反演？论文把问题放在一个受控的“生成—反演—重建”环境中：使用 Stable Diffusion v1.4，DDIM 采样器固定 50 步，CFG 尺度固定为 7。对 PIE-Bench 的 700 个 prompt，每个 prompt 配 10 个相同 seed 索引的初始 latent，共 7000 个 prompt–seed 对，用高保真固定点反演（fixed-point inversion，FPI）来重建。结果显示 prompt 层面有三种行为：easy prompt 对大多数初始 latent 都能重建；hard prompt 对大多数初始 latent 都失败；intermediate prompt 的成败取决于具体的 prompt–latent 配对。论文定义了“prompt pressure”来量化生成过程中 CFG 把去噪更新推离无条件轨迹的程度。全局上压力越高重建越差，prompt 层 Pearson 相关为 -0.693，但它无法解释中间组的配对级失败。文本侧实验表明主视觉对象比背景上下文影响更大，措辞可以改变难易。最后用一个只在不稳定逆步骤局部降低 guidance 的 SKIPINV 诊断干预，说明高 CFG 反演失败需要局部、轨迹感知的分析，而不是简单用低 CFG 反演。

## 2. 为什么这篇论文会出现

文本引导扩散反演是图像编辑的核心步骤：把图像映射到初始 latent，然后在修改后的 prompt 下重放去噪过程来编辑。实践中常见一个看似矛盾的做法：反演时用较低的 CFG，生成或编辑时用较高的 CFG。这种 mismatch 在经验上有效，但留下一个基本问题没有回答——如果目标图像是由高 CFG 轨迹生成的，这条轨迹到底什么时候可逆？

已有工作提供了不同角度的工具和线索。DDIM inversion 直接沿确定性 DDIM 轨迹反演，但局部线性化误差可能让失败被归因于反演近似本身。Null-text inversion 通过优化空文本嵌入改善重建；Prompt-to-Prompt 用交叉注意力控制编辑；AIDI 做加速迭代反演。最近的不动点分析把 DDIM 反演视为隐式不动点问题，给高保真反演提供了理论基础。CFG++ 把 DDIM 反演困难和模式坍缩归因于标准 CFG 下的离流形行为；可逆一致性蒸馏观察到高 CFG 会加剧重建误差，动态 guidance 可以缓解；Feedback Guidance 则把 guidance 当作轨迹和状态依赖，而不是固定超参数。这些工作共同指向一个判断：高 CFG 失败不能只看 prompt 或只看 seed，而要联合看 prompt 内容、初始 latent、时间步和 guidance 动态。

但已有研究没有系统地回答：哪些生成样本会变得难反演，为什么？本文正是补这个诊断缺口。作者没有提出新的通用反演框架，而是用受控实验分析 prompt 内容和初始 latent 如何共同影响高 CFG 轨迹的稳定性。选择 FPI 作为基线是因为它比 DDIM inversion 更干净，不会把反演失败全部归咎于局部线性化误差；同时它没有每图嵌入优化或辅助耦合轨迹，适合做诊断。这种“不堆方法，先理解失败”的思路，是本文区别于前作的主要动机。

## 3. 读懂前需要的最小概念

**潜在扩散模型（latent diffusion model，LDM）**：本文用的 Stable Diffusion v1.4 是一种 LDM，它通过 VAE 编码器把 RGB 图像映射到低维 latent 空间，再在 latent 上做扩散去噪，最后用 VAE 解码器还原图像。论文中 z 表示 latent，z_T 是初始高斯 latent，z_0 是终端 latent。生成图像 RGB 记为 x，由 G(p,z;ω)=D_VAE(F(p,z;ω)) 给出。

**DDIM 确定性采样**：给定 prompt p、初始 latent z_T 和 CFG 尺度 ω，DDIM 产生一条确定性轨迹 z_T → z_{T-1} → … → z_0。完整生成过程记为 F(p,z;ω)=z_0。反向的一步更新可写为 z_{t-1} = k_1(t) z_t + k_2(t) \tilde{\epsilon}_θ(z_t,t,p;ω)，其中 k_1(t) 和 k_2(t) 是 DDIM 调度器给出的时间步依赖系数。论文强调 seed 本身不直接参与去噪动态，它只是通过固定伪随机生成器 Γ(s) 索引一组可复现的初始 latent 列表 Z_s。这种设计让论文可以把 prompt 效应和初始 latent 效应分开。

**反演（inversion）**：从已知的 z_0 恢复初始 latent \hat z，然后重放同一去噪过程得到重建。本文设置做了一个重要简化：直接取生成轨迹的终端 latent z_0 作为反演输入，而不经过 VAE 解码再编码，因此避免了像素域往返引入的额外误差。这使诊断更干净，但也意味着结论不能直接等同于真实图像编辑。

**固定点反演（FPI）**：DDIM 反演的每一步可以写成隐式不动点问题 z_t = g_t(z_t; z_{t-1}, p, ω)，其中 g_t 是 DDIM 的单步逆更新。FPI 迭代求解这个方程，残差定义为当前迭代与更新后迭代之间的 latent 均方误差。论文基线使用无松弛的原始一步逆更新，即新迭代直接取 g_t 的输出，不用松弛系数。求解器在残差相对上一次迭代增加时停止，不设置硬性最大迭代次数，因为迭代通常要么快速收敛要么快速发散。

**Prompt pressure（提示压力）**：这是论文定义的核心量，用来度量生成过程中每一步 CFG 将去噪更新推离无条件轨迹的强度。它等于 ω 乘以 DDIM 系数 k_2(t) 的绝对值，再乘以条件噪声预测与无条件噪声预测差值的 L2 范数。总压力沿 50 步求和。这个标量汇总了 prompt 对轨迹的扰动强度。注意它只取量级，不保留每步方向随时间的变化。

## 4. 方法全景：先看数据流

本文的实验可以分成一条主数据流和两条辅助分析流。主数据流是生成—反演—重建，用于收集所有 prompt–seed 对的 PSNR。辅助流之一是 prompt pressure 分析，它在生成过程中额外记录每步的 CFG 方向和范数；辅助流之二是文本侧扰动网格，包括 subject–context 组合和 paraphrase 改写。最后还有 SKIPINV 诊断干预，它修改反演步骤的 guidance 调度。

```text
主数据流：
prompt p  +  seed s
        |
        v
采样初始 latent z_{p,s}（固定生成器 Γ(s)）
        |
        v
高 CFG DDIM 生成 50 步：z_T -> z_{T-1} -> ... -> z_0
        |                                |
        |                                +--> 记录每步 Δt、Pt，求和 Ptot
        v
终端 latent z_{0,p,s} 直接作为反演输入（不经过 VAE 解码/编码）
        |
        v
FPI 反演：从 z_0 逐步解固定点 z_t = g_t(z_t; z_{t-1}, p, ω)
        |
        v
恢复初始 latent \hat z_{p,s}
        |
        v
用同 prompt 同 CFG 重放 DDIM，得到 \hat z_0，再解码成 \hat x_{p,s}
        |
        v
计算重建 PSNR(x_{p,s}, \hat x_{p,s})，也可以算 CLIP 相似度和 CLIP text score
```

核心组件拆解：

**生成器**：输入 prompt p、初始 latent z_{p,s}、CFG ω=7、DDIM 步数 50。输出 terminal latent z_0 和中间轨迹。每步调用 U-Net 两次，一次带 prompt 条件 p，一次带空文本条件 ∅，按 CFG 组合预测，再用 DDIM 更新得到下一 latent。目的是获得一条确定性的高 CFG 轨迹作为反演基准。假设是该轨迹对应于某个可被反演的生成样本。

**FPI 反演器**：输入 terminal latent z_0、同一 prompt p、同一 ω。输出恢复的初始 latent \hat z。每步把逆 DDIM 关系当作不动点迭代，残差为 latent 空间均方误差。目的是以高保真方式恢复初始 latent，而不是用低 CFG 或嵌入优化。假设是如果反演稳定，恢复 latent 应接近真实初始 latent。

**重建器**：输入 \hat z、p、ω。输出解码后的重建图像 \hat x。目的是通过重放同一高 CFG 轨迹来判断反演是否成功。假设是重建 PSNR 能反映反演质量。重建 PSNR 在 RGB 像素值 0–255 尺度上计算，用生成图像 x 和重建图像 \hat x 之间的均方误差取对数分贝。

**Prompt pressure 计算器**：输入生成轨迹上的每步 z_t、条件和无条件噪声预测。输出每步 Pt 和总压力 Ptot。目的是把 prompt 对轨迹的推离强度压缩成标量，看它是否解释反演难度。假设是推离越强越难反演。实际计算时需要在生成阶段额外保存每步的两个噪声预测，属于辅助记录，不改变生成结果。

**文本扰动网格**：不依赖主数据流的共享 seed 设置，而是用 14 个 subject 和论文声称的 10 个 context（正文列表实际出现 9 个，未明确披露是否排版缺漏）构造 140 个 prompt，每个 10 个随机初始 latent。目的是分离主对象和背景对难易的影响。同时有 paraphrase 网格，对三个 base concept 各生成 10 个 paraphrase，评估措辞的调节作用。这些实验使用独立采样的初始 latent，避免限制图像多样性。

**SKIPINV 干预**：在 FPI 基础上修改反演阶段。当某步残差不再下降时，先减少松弛系数 α，若仍不收敛则降低 guidance 并重试该步。记录一个单调非增的 guidance 调度，在重建或编辑时按正向顺序重放。目的是验证“局部不稳定”是否比全局低 guidance 更合理。它不修改注意力图、不优化文本嵌入、不添加编辑控制，因此只能作为轨迹一致性诊断，而不是生产编辑工具。

## 5. 核心公式与直觉

理解本文贡献需要四个公式。它们都围绕“prompt 如何影响生成轨迹”这一核心问题。

首先是 CFG 的组合预测：

$$
\tilde{\epsilon}_\theta(z_t,t,p;\omega)=\epsilon_\theta(z_t,t,\varnothing)+\omega\left(\epsilon_\theta(z_t,t,p)-\epsilon_\theta(z_t,t,\varnothing)\right)
$$

其中 z_t 是时间步 t 的 latent，ε_θ 是噪声预测网络，∅ 表示空文本条件，ω 是 CFG 尺度。这个公式说明：CFG 把无条件预测作为基底，再沿“条件预测减去无条件预测”的方向放大。ω 越大，prompt 对去噪更新的影响越强。DDIM 一步更新把这个组合预测乘以 k_2(t) 再加到 k_1(t) z_t 上，所以 CFG 的实际作用会经过调度器系数缩放。

第二个公式定义了这个方向：

$$
\Delta_t(z_t,p)=\epsilon_\theta(z_t,t,p)-\epsilon_\theta(z_t,t,\varnothing)
$$

Δ_t 就是 prompt 引入的引导方向。它是条件预测和无条件预测的差，反映 prompt 把去噪更新推离无条件轨迹的方向。它的大小和方向都会随时间步和 latent 状态变化。论文没有单独分析 Δ_t 的方向，而是把它压缩成范数。

第三个公式把 Δ_t 转化为实际的 step-wise prompt pressure：

$$
P_t(z_t,p)=\omega |k_2(t)|\,\|\Delta_t(z_t,p)\|_2
$$

其中 k_2(t) 是 DDIM 调度器中的时间步依赖系数，它把噪声预测缩放成 latent 空间的实际更新量。乘以 ω 是因为 CFG 已经把方向差放大了一次。这个公式的直觉是：真正影响轨迹的不是 Δ_t 本身，而是它乘上 DDIM 系数后对 latent 更新产生的“推力”。|k_2(t)| 保证压力非负，L2 范数捕获方向差的大小。如果 k_2(t) 在某个时间步很小，即使 Δ_t 很大，该步的 pressure 也可能很低。

第四个公式沿生成轨迹聚合：

$$
P^{tot}_{p,s}=\sum_t P_t(z_{t,p,s},p)
$$

Ptot 把 50 步的压力加总，得到单个 prompt–seed 对的全局扰动强度。论文用它做相关性分析：prompt 层面 Pearson 相关为 -0.693，pair 层面为 -0.458。这说明压力越大，重建 PSNR 越低。但公式的局限也很明显：Ptot 是一个标量求和，它丢失了时间结构、方向变化和局部不稳定性。因此它只能区分 easy 和 hard 这样的稳定区，不能预测 intermediate prompt 中哪一个具体 seed 会失败。例如论文举例“a plant against a wall”有两个 seed 的 Ptot 分别为 22.26 和 22.14，几乎相同，但 PSNR 分别是 8.62 dB 和 64.50 dB。这说明总压力相等时，轨迹局部性质仍能导致完全不同的反演结果。

## 6. 训练到底怎么跑

需要先说明：本文没有训练任何新神经网络，所有实验都基于预训练的 Stable Diffusion v1.4 和固定冻结的 CLIP ViT-B/32 做推理。所谓“训练流程”实际上是实验运行流程，一个 step 对应一个 prompt–seed 对的生成—反演—重建循环。

一轮 step 的具体顺序如下：

1. 从 PIE-Bench 取一个 prompt p，选择一个 seed 索引 s。
2. 用固定伪随机高斯生成器 Γ 采样初始 latent z_{p,s}。在主基准中，前 700 个 prompt 共享同一组 10 个 seed-indexed latent，因此 z_{p,s}=z_s，便于分离 prompt 和 seed 的主效应。这些 latent 的 seed 索引固定为 1 到 10，所有 prompt 复用同一组。
3. 运行 DDIM 生成，50 步，CFG=7。每步调用 U-Net 两次（一次条件 p，一次无条件 ∅），按 CFG 公式组合预测，用 DDIM 更新得到 z_{t-1}。同时记录每步的 Δ_t、Pt，并累加得到 Ptot。此阶段不涉及 VAE。
4. 生成结束后，取 terminal latent z_0 作为反演输入。这里不经过 VAE 解码和编码，避免像素域误差。这是与控制变量设计直接相关的关键选择。
5. 执行 FPI 反演。从 t=0 开始逐步求解 z_t。每步使用原始一步逆更新作为迭代函数。迭代公式为 z_t^{(i+1)} = g_t(z_t^{(i)}; z_{t-1}, p, ω)。残差定义为 ℓ_i = ||g_t(z_t^{(i)}) - z_t^{(i)}||_2^2。迭代停止条件是残差相对上一次迭代增加，不设置硬性最大迭代次数。论文说明基线不使用松弛，因为通常要么快速收敛要么快速发散。
6. 反演得到 \hat z，用同一 prompt 和 ω=7 重放 DDIM 生成 \hat z_0，再 VAE 解码得到重建图像 \hat x。
7. 在 RGB 像素值 0–255 尺度上计算生成图像 x 与重建图像 \hat x 之间的 PSNR。同时可计算 CLIP 图像相似度和 CLIP text score，CLIP 使用 OpenAI ViT-B/32。
8. 对 700×10 的完整网格重复，得到 7000 个 PSNR。

在 Section 5 的文本侧实验中，不再共享同一组 seed，而是独立采样初始 latent。subject–context 网格有 14 个 subject，10 个 context（正文列表出现 9 个），共 140 个 prompt，每个 10 个随机初始 latent，共 1400 对；paraphrase 网格有 3 个 base concept 各 10 个 paraphrase，每个 paraphrase 用相同的 10 个 seed-indexed latent，共 300 对。Section 6 的 SKIPINV 干预把反演步骤替换为：每步先做标准 FPI，若残差不再下降，先减小松弛系数 α，即采用 z_t^{(i+1)} = (1-α_i) z_t^{(i)} + α_i g_t(...)；若仍不收敛到阈值，就降低 guidance 并重试该步。一旦降低，后续步骤沿用降低后的 guidance，调度单调非增。具体 α 初始值、降低策略、收敛阈值未在正文给出，论文说明在补充材料中。重建或编辑时按记录的 schedule 正向重放。

## 7. 推理到底怎么跑

推理阶段包含反演和重放两个顺序过程，在论文中有两种变体：纯重建和编辑。对于纯重建，输入是生成轨迹的 terminal latent z_0 和生成时使用的 prompt p、CFG ω=7。

反演顺序如下：

1. 初始化 z_0 为已知值。
2. 对每个逆时间步 t 从 0 到 T-1（对应生成时从 T 到 0 的反向），给定 z_{t-1}，用 FPI 求解 z_t。迭代公式是 z_t^{(i+1)} = g_t(z_t^{(i)}; z_{t-1}, p, ω)，其中 g_t 是 DDIM 单步逆更新。
3. 每次迭代计算残差 ℓ_i = ||g_t(z_t^{(i)}) - z_t^{(i)}||_2^2。如果残差相对上次增加，停止该步，取当前迭代作为解。基线无松弛，所以 α 恒为 1，新迭代直接等于 g_t 输出。
4. 若使用 SKIPINV，则在残差增大时先减少松弛系数 α，即采用 z_t^{(i+1)} = (1-α_i)z_t^{(i)} + α_i g_t(...)。若仍不收敛，就降低该步的 guidance ω_t，并重试。降低后的 ω_t 被记录，后续步骤使用不高于该值的 guidance。最终形成单调非增调度 ω_1 ≥ ω_2 ≥ … ≥ ω_T。
5. 反演完成后，得到 \hat z_T 和 guidance 调度。

重放顺序：

1. 从 \hat z_T 开始，按正向时间步 T → T-1 → … → 0 运行 DDIM。如果是标准 FPI，每一步使用 ω=7；如果是 SKIPINV，使用记录的单调非增调度 ω_1 ≥ ω_2 ≥ … ≥ ω_T。
2. 生成 terminal latent \hat z_0，再通过 VAE 解码得到 \hat x。
3. 对于编辑，使用 Prompt-to-Prompt，在重放阶段修改交叉注意力图来实现编辑意图。编辑时 source image 来自生成图像，target prompt 由编辑目标给出。评估用 CLIP text score 衡量编辑后图像与目标提示的一致性，用 Edit PSNR 衡量编辑图与源图的保留度。

实际应用中，如果输入是真实图像而不是 terminal latent，需要先把 RGB 编码到 latent，这一步会引入 VAE 误差。论文明确说自己的设置避免了这种误差，因此 SKIPINV 的结果不能直接外推到真实图像编辑。这是阅读实验结论时必须保留的边界。

最关键消融是压力分析的局限。论文先定义 Ptot 并发现全局负相关，随后把它放进 intermediate 组去检验是否解释成功/失败分裂。结果是组内相关系数极低，而且两个几乎相同 Ptot 的样本可以一个 8.62 dB 一个 64.50 dB。这说明总压力标量不足以作为成败的充分判据。论文还检查了 Pt 沿 50 步的时间剖面，包括归一化压力曲线、峰值、熵和 Gini 集中度，这些统计都没有找到区分 intermediate 成功与失败的稳定模式。另一个关键消融是 SKIPINV 的对照：AIDI-GS1/GS7 是常见低 CFG 反演—高 CFG 重建，AIDI-GS7/GS7 是全匹配，SKIPINV 在匹配基础上局部降 guidance。结果显示低 CFG 反演会得到与高 CFG 重构动力不一致的 latent，而局部放松可以在不牺牲目标轨迹一致性的情况下改善稳定性。

论文尚未证明的主张包括：为什么 intermediate prompt 中某些 prompt–latent 对失败而另一些成功？作者尝试了压力曲线、峰值、熵、Gini 集中度等时间统计，都没有找到一致模式。text-side 显示 subject 而非 context 是主要难易轴，但 subject 内部有哪些视觉或概念特征导致难反演，论文没有继续深入。SKIPINV 只在合成 z_0 条件下评估，未在真实图像 VAE 编码误差存在时验证。此外，实验只用 SD1.4、DDIM 50 步、CFG=7，是否能推广到其他 checkpoint、采样器或 guidance 尺度也是未回答的问题。

## 9. 与前作怎么选

与本文最接近的方案是 DDIM inversion、Null-text inversion、AIDI 和本文使用的 FPI/SKIPINV。选择哪个取决于目标、资源和误差容忍度。

**DDIM inversion**：速度快，实现简单，每个时间步只做一次局部线性化更新。但它把高 CFG 下的近似误差累积起来，容易把方法误差和轨迹本身的不稳定性混在一起。适合做快速原型或低要求重建，不适合精确诊断或高 CFG 编辑。

**Null-text inversion**：通过优化每个时间步的空文本嵌入来改善重建，能处理真实图像。但需要额外优化循环，计算开销较大，而且优化的是无条件分支，不是直接处理 prompt–latent 交互。适合需要高质量真实图像重建的场景，但本文没有比较 Null-text，因为作者聚焦于受控轨迹诊断。

**AIDI**：加速迭代反演，在编辑任务中常用。论文用 AIDI-GS1/GS7 和 AIDI-GS7/GS7 作为对照。AIDI 在低 CFG 反演时文本对齐尚可，但 Edit PSNR 较低；匹配 CFG 后改善明显。适合需要比 Null-text 更快但仍保持较好编辑质量的应用。相比之下，SKIPINV 只在这个受控集上略优于 AIDI-GS7/GS7，不能证明它是通用上更优的方法。

**FPI/SKIPINV**：FPI 适合作为诊断基线，因为无嵌入优化、无耦合轨迹，迭代要么快收敛要么快发散。SKIPINV 适合验证局部轨迹一致性假设，但不建议直接当作生产编辑工具：它需要记录并重放单调非增 guidance 调度，且评估范围有限。

选择建议：如果你关心的是“为什么高 CFG 反演会失败”，用 FPI 做诊断；如果你要做真实图像编辑，优先考虑 Null-text 或 AIDI 并匹配 guidance；如果你已经决定用高 CFG 且愿意做局部迭代，可以试验 SKIPINV 的松弛和降 guidance 策略，但需要额外调参和真实图像验证。需要注意的是，SKIPINV 在论文中只是诊断工具，不能视为对 AIDI 或 Null-text 的替代。

## 10. 工程判断：可行性、风险与上限

**数据可行性**：论文使用 PIE-Bench 的 700 个 prompt，主要包含自然物体、动物、场景和少量风格描述。这个数据集对 subject–context 分析足够，但缺少复杂组合、多对象属性、空间关系和长文本。SD1.4 是较旧的 latent diffusion checkpoint，其 U-Net 结构和 VAE 能力与后续模型差异较大。如果要在新模型上验证这些结论，需要重跑受控网格，并注意不同模型的 latent 分布和 CFG 行为可能不同。论文没有披露运行资源、单次 FPI 迭代的平均次数或总耗时，因此算力成本只能基于工程推断：FPI 每步可能调用 U-Net 多次，重试降 guidance 还会进一步增加推理延迟。文本侧 subject–context 网格和 paraphrase 网格需要额外生成 1400 和 300 个 prompt–seed 对，数据规模不大，但需要可复现的伪随机生成器保证 seed 一致性。

**实现难点**：FPI 的停止条件“残差相对上次增加”需要在每次迭代都计算 latent 范数，这在批量推理中增加同步开销。SKIPINV 的 guidance 调度需要记录每一步的最终 ω 值，并在重建时严格按正向顺序使用。如果调度保存或重放出错，编辑结果会偏离预期。另一个难点是参数 α 的松弛策略和降 guidance 的触发阈值，论文未给出具体超参，只说明在补充材料中。实际部署需要扫描这些超参。此外，FPI 基线无松弛意味着每次迭代直接跳到 g_t 输出，这可能导致残差振荡，SKIPINV 的松弛正是为了缓解这种振荡，但 α 的选择没有统一规则。

**失败环节**：从论文证据看，最可能失败的环节是 intermediate prompt 的 seed 选择。无法提前用 Ptot 或简单时间统计预测哪个 seed 会失败。如果应用场景需要稳定反演，可能需要为每个 prompt–seed 对做多次尝试，或运行 SKIPINV 并监控哪些步触发了 guidance 降低。另一个失败来源是 real image 的 VAE 编码误差，论文主动绕开了这个问题，因此真实图像反演可能会比这里报告的 PSNR 更差。此外，hard prompt 如 squirrel/fence 和 Great Wave 在 paraphrase 下仍保持低 PSNR，说明有些视觉概念本身天然难反演，可能无法通过文本措辞调整解决。

**监控信号**：可监控的指标包括：FPI 每步残差是否下降；有多少时间步触发 guidance 降低；生成的 Ptot；重建 PSNR；编辑的 CLIP text score 和 Edit PSNR。如果某个 prompt 的 Ptot 很高且重建 PSNR 低，可以判定为 hard 区；如果 Ptot 中等但 PSNR 方差大，需要额外注意 seed 选择。对于 SKIPINV，可以记录降低 guidance 的时间步位置，作为轨迹局部不稳定性的指示器。

**指标上限**：受控设置中 7000 对 PSNR 最大值为 69.61 dB，但这不代表所有图像都能达到。编辑上界为 CLIP text 0.3121 和 Edit PSNR 22.76 dB，SKIPINV 接近这一上界但没有超过。因此，在同类设置下可期望的编辑 PSNR 上限大约在 22–23 dB，CLIP text 上限约 0.31。这些上界只适用于 SD1.4、DDIM 50 步、CFG=7 和 PIE-Bench prompt 分布。未回答问题包括：intermediate 失败的具体轨迹几何机制是什么？能否在生成前或反演前预测某个 prompt–latent 对会失败？这些都需要进一步研究。工程上，如果对高 CFG 编辑的一致性要求很高，目前最稳妥的做法仍是匹配 guidance 并配以局部迭代稳定化，而不是依赖低 CFG 反演。

## 11. 放回研究脉络并收束

这篇论文处于扩散反演从“提出方法”到“理解失败机制”的转折线上。DDIM inversion 最早给出确定性反演路径，随后 Null-text inversion 和 Prompt-to-Prompt 解决了真实图像编辑中的重建和编辑控制问题，AIDI 提高了迭代效率，固定点分析提供了理论工具。CFG++ 和可逆一致性蒸馏把注意力引向 CFG 对反演稳定性的影响。本文没有继续堆方法，而是转向受控诊断，试图区分哪些失败来自 prompt 内容，哪些来自初始 latent，哪些来自局部轨迹动态。

读完必须记住的 5 件事：

1. 7000 对 FPI 重建 PSNR 的分布很宽：均值 40.61 dB，标准差 20.35 dB，最低 6.08 dB，最高 69.61 dB。这说明高 CFG 反演不是均匀可靠。Table 1 同时显示 prompt-wise mean 标准差 12.70，而 latent-wise mean 标准差只有 1.61，说明差异主要来自 prompt 而不是 seed 主效应。
2. prompt 层面形成三类行为：easy prompt 对大多数 seed 都成功，hard prompt 对大多数 seed 都失败，intermediate prompt 的成败高度依赖 prompt–latent 配对。Figure 1 中 easy/hard 组标准差小，intermediate 组标准差大；Figure 2 给出定性例子。
3. prompt pressure 总压力与重建 PSNR 有负相关，prompt 层 r=-0.693，pair 层 r=-0.458，但它不能解释 intermediate 组内的成功/失败分裂；相同 Ptot 的两个样本可以一个 8.62 dB 一个 64.50 dB。Table 2 显示 intermediate 组内 r 仅 -0.089。
4. 文本侧主效应表明，主视觉对象解释了 25.3% 的 PSNR 方差，而背景上下文只解释 3.0%；subject 如 squirrel 的主体均值仅 14.99 dB，而 dog 为 47.70 dB。wording 可以移动 borderline prompt，例如 cat/table 的 paraphrase 跨度 30.34–54.32 dB，但 hard concept 如 squirrel/fence 和 Great Wave 在 paraphrase 下仍难反演。
5. SKIPINV 的对照实验显示：低 CFG 反演—高 CFG 重建（AIDI-GS1/GS7）会得到与高 CFG 动力学不一致的 latent；匹配高 CFG 并只在局部不稳定步降低 guidance 能改善重建和编辑，AIDI-GS7/GS7 的 Edit PSNR 为 20.92 dB，SKIPINV 为 22.30 dB，接近上界 22.76 dB。说明失败是局部、轨迹感知的。

5 道自测题：

1. 论文为什么选择固定点反演而不是 DDIM inversion 作为诊断基线？  
   答：DDIM inversion 的局部线性化误差可能让失败被归因于反演近似本身；FPI 用隐式不动点求解每步，能提供更干净的高保真基线，且没有每图嵌入优化或辅助耦合轨迹。

2. prompt pressure 的公式是什么？它为什么不足以解释 intermediate 组的失败？  
   答：P_t = ω|k_2(t)| ||Δ_t||_2，Δt 是条件与无条件噪声预测差，Ptot = Σ_t P_t。它是标量求和，丢失时间结构和局部方向信息，无法区分相同压力下不同 seed 的成败；论文还检查了归一化压力曲线、峰值、熵和 Gini 浓度，均无一致模式。

3. 论文如何分离 prompt 主效应和初始 latent 主效应？结果是什么？  
   答：前 7000 对使用 700×10 完整网格，每个 prompt 配相同的 10 个 seed-indexed latent。加性双因素 ANOVA 显示 prompt 主效应解释 38.9% 方差，latent 主效应只解释 0.56%，说明没有全局好或坏的 seed；因为每个 cell 只有一次观测，交互被并入残差，所以该检验不解释 intermediate 的 seed 敏感性。

4. SKIPINV 与 AIDI-GS7/GS7 的核心区别是什么？  
   答：AIDI-GS7/GS7 在反演和重建全程都用 CFG=7；SKIPINV 在 FPI 残差不下降时先减少松弛系数 α，再局部降低 guidance 并重试，记录单调非增调度，重建按该调度重放。它不修改注意力图、不优化文本嵌入。

5. 本文最未能回答的问题是什么？  
   答：为什么 intermediate prompt 中某些 prompt–latent 对成功而另一些失败？压力曲线、峰值、熵、Gini 浓度等时间统计都没有找到一致模式，论文未给出机制层面的解释；也未证明 subject 内部什么视觉/概念特征导致难反演。

最终一句话总结：高 CFG 扩散反演的失败不是由 prompt 或 seed 单独决定的，而是由 prompt 内容与初始 latent 共同塑造的局部轨迹不稳定性决定的，全局压力只能给出粗略难易排序，真正可操作的干预需要轨迹感知的局部 guidance 调整。
