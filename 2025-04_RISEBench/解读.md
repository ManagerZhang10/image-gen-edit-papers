# 大白话深读《RISEBench》

## 1. 30 秒定位

这篇论文提出 **RISEBench**，一个专门评测“推理引导视觉编辑”（Reasoning-Informed Visual Editing，简称 RISE）的基准。它要回答的问题不是“模型能不能修图”，而是“模型能不能像人一样，先理解物理、时间、空间或逻辑规则，再对图像做符合推论的修改”。例如，给定一张小孩照片，要求“画出他们十年后的样子”，模型需要先理解成长带来的面部变化，再输出编辑后的图像；或者给定一块冰块，问“夏天 30 秒后是什么样”。基准把这类任务分成 **时间推理、因果推理、空间推理、逻辑推理** 四类，共 **360 个人工标注样本**（§2.1）。评估时，论文不只看“指令是否做对”，还看“没让改的地方是否保住了”和“生成图是否真实合理”。用 GPT-4.1 作为自动裁判（LMM-as-a-judge），并用人类评分验证了相关性（总体 MAE 分别 0.5、0.7、0.4，§3.3 Table 2）。在 8 个代表性模型上评测，最强模型 GPT-4o-Image 总体准确率只有 **28.9%**（Table 1），开放模型基本接近 0。因此结论是：当前模型在推理式视觉编辑上还远未成熟，逻辑推理是尤其明显的瓶颈。

## 2. 为什么这篇论文会出现

论文的背景是大规模多模态模型（Large Multi-modality Models，LMMs）在视觉理解和视觉生成上分别进步很快，但“通用视觉编辑”（General Visual Editing）仍然有三个常见短板：第一是复杂指令跟随不准（如空间关系、因果链条）；第二是编辑时无法保持原图外观一致性；第三是输入格式不够灵活，比如多图、自然语言指令混合。论文指出，传统基于扩散模型的编辑方法（如 Prompt-to-Prompt、InstructPix2Pix）通常只做局部语义编辑，缺乏对世界知识的推理能力；而近期部分统一 LMM（如 Chameleon、Emu3、Show-o）虽然开始同时处理理解和生成，但“理解和生成能否互相增强”仍是开放问题（§A.2）。

与此同时，闭源模型 GPT-4o-Image 和 Gemini-2.0-Flash 展现出明显的“推理式编辑”能力：它们不只是改几个像素，而是根据语境和逻辑做智能修改，例如调整光照以匹配时间、根据因果推断物体状态。论文作者认为，这种能力很有价值，但领域内 **没有一个专门基准来系统量化它**。现有的文本到图像评估基准（如 GenEval、T2I-CompBench++、HPS）大多测量图文对齐、组合性或人类偏好，不强调“推理驱动”的图像编辑，也不区分指令推理、外观一致性和视觉合理性（§A.3）。于是他们构建 RISEBench，用四类核心推理任务和高标准的三维评估框架，来揭示现有模型的真实局限，尤其是逻辑推理的短板。这个动机决定了基准不是追求大规模覆盖，而是小而精、高质量、能区分明显能力差异。

## 3. 读懂前需要的最小概念

要理解这篇论文，需要先建立几个概念：

**视觉编辑（Visual Editing）**：给定一张输入图像和一条文本指令，输出一张修改后的图像。如果指令不是“把红色改蓝色”这种表面改动，而是“画出被摇匀并打开后的可乐瓶”，就是编辑任务，但难度更高。

**推理引导视觉编辑（RISE）**：模型必须先对图像内容、物理规律、时间演化或逻辑规则做推理，再把推理结果投影到像素空间。它不同于简单风格迁移或掩码局部编辑，因为它隐含“世界知识”和“多步推理”。

**四类推理**：
- **时间推理（Temporal Reasoning）**：自然过程随时间的演化，如腐烂、生锈、成长、昼夜。
- **因果推理（Causal Reasoning）**：外部因素导致的变化，如碰撞变形、冷冻相变、化学反应。
- **空间推理（Spatial Reasoning）**：几何关系、组装、视角变换、遮挡补全、布局调整。
- **逻辑推理（Logical Reasoning）**：基于规则的视觉谜题，如数独、迷宫、火柴棍等式。

**LMM-as-a-judge**：用大模型（这里是 GPT-4.1）当自动评分器，根据精心设计的提示词给生成图打分。需要验证它与人类评分的一致性。

**三个评估维度**：
- **指令推理（Instruction Reasoning）**：输出是否真正执行了指令，包括隐含要求。
- **外观一致性（Appearance Consistency）**：指令没有要求改变的部分是否与原图一致。
- **视觉合理性（Visual Plausibility）**：输出是否清晰、自然、符合物理规律。

**成功判据**：论文规定，只有三个维度都拿到满分 5 分，样本才算“成功”；准确率就是成功样本占总样本的比例。这个定义非常严格，导致即使 GPT-4o-Image 也只有 28.9%。

## 4. 方法全景：先看数据流

论文的方法核心不是训练新模型，而是构建一个高难度测试集和一套可扩展的评估管线。整体数据流如下：

```
┌──────────────────────────────────────────────┐
│ 数据构建阶段                                  │
│                                              │
│ 人工设计任务/收集输入图像                     │
│   │                                          │
│   ├─ Temporal: 85 样本                       │
│   ├─ Causal: 90 样本                         │
│   ├─ Spatial: 100 样本                       │
│   └─ Logical: 85 样本                        │
│       │                                      │
│       ▼                                      │
│ 为每个样本标注参考答案                        │
│   ├─ 简单场景 → 参考文本 (reference text)     │
│   └─ 复杂形状/逻辑题 → 参考图像 (reference image)│
└──────────────────────────────────────────────┘
                    │
                    ▼
┌──────────────────────────────────────────────┐
│ 模型推理阶段                                  │
│                                              │
│  输入：原图 + 指令                           │
│  输出：编辑后的图像                           │
│  （评测 8 个模型，均直接调用 API 或本地推理）  │
└──────────────────────────────────────────────┘
                    │
                    ▼
┌──────────────────────────────────────────────┐
│ 评估阶段（LMM-as-a-judge / 人类）             │
│                                              │
│  对每个输出，按三个维度打分：                 │
│  Instruction Reasoning: 1-5                  │
│  Appearance Consistency: 1-5 或 0/1→1/5      │
│  Visual Plausibility: 1-5（仅自然图任务）     │
│                                              │
│  三条维度均=5 → 样本成功                      │
│  准确率 = 成功样本数 / 总样本数                │
└──────────────────────────────────────────────┘
```

核心组件拆解：

**输入样本**：每个样本由“输入图像 + 指令”组成（§2.1）。输入图像来源有四类：模型生成图、Blender 3D 渲染、现有基准图（LogicVista、LEGO-Puzzles）、互联网许可图片（§B）。指令通常是自然语言，要求描述“画成什么状态”。指令经过人工精心设计，部分指令带有多步推理或隐含条件，例如“这是北半球观测到的月亮，画出 7 天后的样子”，要求模型理解月相周期。

**参考标注**：评估指令推理时需要“标准答案”。如果场景能用文本充分描述，就人工写参考文本；如果涉及复杂形状、布局或逻辑解（如迷宫路径、组装图），就提供参考图像。这个混合方案让 LMM judge 能在不同任务类型下可靠判断（§2.2 Dimension 1）。例如，对于“把六个相邻方块剪成一个有效的展开骰子网”，参考图像直接呈现正确展开图；对于“可乐瓶被剧烈摇晃后打开”，参考文本描述可乐喷涌、瓶口有泡沫、瓶身可能有液体残留等关键视觉特征。

**评估维度计算**：
- 指令推理：比较输出图与参考文本/参考图像的一致性。自然图任务使用 1–5 分，逻辑任务使用 0/1 二元判断（逻辑正确性），再映射为 1 或 5。
- 外观一致性：比较输出图与输入图，忽略指令明确要求改变的部分。对时间、因果、空间任务用 1–5 分级；对逻辑任务由于输入通常是极简图，用二元方案（5 或 1）。
- 视觉合理性：仅对时间、因果、空间任务评分，因为逻辑任务输出往往是示意图，不要求真实感。

**裁判模型**：GPT-4.1 对每个维度使用不同细致提示词（§H，Figure 18–25），输出 1–5 分或 0/1。提示词包含详细评分标准、正例和反例，以及“忽略水印”等特殊指令。例如，空间推理的外观一致性提示词明确说明：“如果原始背景是模糊的，且图像 B 的背景也是类似的模糊，则可以忽略背景一致性”，并提示忽略左下角的蓝色菱形水印。逻辑任务提示词要求裁判输出“逻辑正确性, 外观一致性”两个分数，例如：“Final Score: 1,0”。

**假设**：LMM 裁判能理解图像和复杂指令，从而近似人类专家；成功判据使用“全满分”可能过于严格，但能凸显最前沿差距。此外，论文假设四类推理任务能覆盖 RISE 的核心能力，且人工标注的标准答案足够可靠。

## 5. 核心公式与直觉

这篇论文几乎没有传统意义的优化公式或损失函数，它的核心“公式”主要体现在评估规则上。以下是理解贡献所必需的几条：

**（1）归一化得分与成功判据**

所有维度分数被归一化到区间 \( [1,5] \)。一个样本被判定为成功当且仅当：

\[
\text{Success}(x) = 
\begin{cases}
1, & \text{if } S_{\text{IR}}=5 \,\text{and}\, S_{\text{AC}}=5 \,\text{and}\, (S_{\text{VP}}=5 \,\text{or VP不适用}) \\
0, & \text{otherwise}
\end{cases}
\]

其中 \( S_{\text{IR}} \) 是指令推理分，\( S_{\text{AC}} \) 是外观一致性分，\( S_{\text{VP}} \) 是视觉合理性分。准确率定义为：

\[
\text{Accuracy} = \frac{\sum_{i=1}^{N} \text{Success}(x_i)}{N} \times 100\%
\]

例如 Table 1 中 GPT-4o-Image 总准确率 28.9%，意味着 360 个样本中只有约 104 个在所有适用维度上拿了满分。注意“满分才算成功”这一设定非常苛刻，哪怕一个维度只拿 4 分，整体也算失败。它的直觉是：一个编辑命令只有在完全正确、完全保真、完全合理时才算真正完成，这也解释了为什么最强模型分数也很低。

**（2）逻辑推理任务的二元评分映射**

对于逻辑推理任务，外观一致性不采用 1–5 连续分，而是二元：

\[
S_{\text{AC}} \in \{1, 5\}
\]

即要么完全保留视觉属性（5），要么有重大偏差（1）。同样，逻辑正确性也是 0/1，映射后只有成功或失败。这个设计的原因是逻辑题输入通常是简洁的示意图，没有丰富纹理可供细微打分；一旦风格或布局变了，就认为一致性丧失。实质上，它把“部分正确”在中低分数段压缩成二分，进一步提高了逻辑任务的难度。例如，如果一个迷宫题模型画出了正确路径，但改变了迷宫墙壁颜色，逻辑正确性可能得 1，外观一致性会得 0，导致样本无法成功，尽管内容基本正确。

**（3）LMM 与人类评分一致性度量**

论文用平均绝对误差（Mean Absolute Error，MAE）量化 LMM 裁判和人类专家的分歧：

\[
\text{MAE} = \frac{1}{M}\sum_{j=1}^{M} |s_j^{\text{LMM}} - s_j^{\text{human}}|
\]

其中 \( M \) 是样本数。表 2 报告总体 MAE 分别是指令推理 0.5、外观一致性 0.7、视觉合理性 0.4。由于评分范围是 1–5，MAE 小于 1 表示平均误差不到一个评分档，作者据此认为自动裁判与人类高度一致。直觉是：如果 LMM 打分与人类专家平均只差半个等级，那用 LMM 替代人工评分是可接受的，从而支持大规模评测的可扩展性。注意，表 2 还给出了每个 LMM 分数档对应的人类平均分和标准差，比如 LMM 打 5 分的指令推理样本，人类平均 4.7，标准差 0.4；打 1 分的指令推理样本，人类平均 1.1，标准差仅 0.1，说明极端的判断更一致。

需要说明：论文没有给出用于训练模型或优化参数的公式，因为这是 benchmark 论文，不训练生成模型。核心“动作”是评估器 score 计算和聚合，而不是反向传播。

## 6. 训练到底怎么跑

严格说，RISEBench **不训练任何生成模型**。它的角色是测试集与评估协议，而不是训练框架。但为了回答“训练/准备阶段怎么跑”，我们可以把数据构建与评估器搭建看成一整套流程。

**一轮准备 step（对应“训练”成本）**：

- **数据收集与任务设计**：研究者根据四类推理定义，人工设计具体指令。例如时间推理的子类别涵盖生命成长、环境循环、材料状态变化、社会变迁；因果推理有结构变形、状态转变、化学生物变化、物理表现；空间推理有组件组装、物体排列、视角生成、结构补全、布局推理；逻辑推理有谜题、数学推导、模式预测。总共 360 个样本。图 3 展示了任务分布，但具体每个子类的数量需要看 Table 3 的样本数，例如 Life Progression 任务 GPT-4o 在该子任务准确率 52.6%，说明该类样本数相对较多；但文本未明确各子类样本总数，仅 Table 3 给出各模型在子任务上的准确率。附录 B 显示，输入图像来源包括：模型生成图、Blender 3D 渲染、现有数据集（LogicVista、LEGO-Puzzles）和互联网许可图片。这些来源保证了图像质量可控，且避免版权问题。

- **参考答案标注**：对每个样本，人工撰写参考文本或制作参考图像，作为指令推理的真值。例如一个 T 恤洗涤指令，参考文本会描述“T 恤上无棕色污渍但仍保持形状”。对逻辑谜题，参考图像直接给出解（如迷宫蓝色路径）。这些标注由论文作者完成，没有披露具体标注者人数和预算，但附录 E 展示了人工标注的交互界面（Figure 9），说明研究者开发了专用 UI 来收集和整理标注。

- **裁判提示词设计**：为三个维度和不同任务类型分别写提示词，包括评分标准、例子、输出格式。附录 H 给出了完整模板，共 8 个提示词（Figure 18–25）。例如，外观一致性提示词给出了 5 个等级的详细定义，并用“金发、白皮肤、右肩有纹身的男人”作为示例，说明什么变化算 4 分、3 分等。对逻辑任务，提示词明确要求输出“Logical Correctness, Appearance Consistency”两个 0/1 分数。提示词还包含对水印的忽略规则，以及对模糊背景的特殊处理。

- **模型调用**：论文没有训练模型，而是选取 8 个模型直接推理。闭源模型（GPT-4o-Image、Gemini 两个版本、HiDream）通过官方 API 调用；开源模型（FLUX.1-Canny、BAGEL、Step1X-Edit、OmniGen、EMU2）本地加载或按官方方式生成。论文没有描述具体的超参数或生成采样设置，可能采用默认配置。对于 FLUX.1-Canny，可能使用了 Canny 控制条件；对于自回归模型如 OmniGen、EMU2，可能采用默认的生成长度和温度。

所以，如果把“训练”理解为“构建基准和准备评测环境”，主要成本在人工标注和提示词工程，而非梯度更新。整个准备过程没有超参数搜索，也没有损失函数。

## 7. 推理到底怎么跑

完整推理与评估顺序如下：

1. **输入准备**：取一个样本，包含原始图像 \( I \) 和文本指令 \( T \)。指令可能是“画出它在夏天 30 秒后的样子”或“移动两根火柴使等式成立”。输入图像可能是自然照片、渲染图、示意图或合成图，取决于任务类别。模型需要同时处理图像和指令。

2. **模型生成编辑结果**：将 \( I \) 和 \( T \) 送入被评测模型，得到输出图像 \( O \)。不同模型架构不同：扩散编辑模型（如 FLUX.1-Canny）通常需要输入原图 + 指令 + 可能的 Canny 控制；自回归 LMM（如 EMU2）把图与文 token 化后逐 token 生成；GPT-4o-Image 和 Gemini 通过 API 直接生成。论文没有描述每个模型的具体调用协议，只是说“通过官方 API 服务”获得闭源模型输出。生成时没有使用参考答案或任何额外提示，完全依赖模型自身能力。这一步产生的输出图像可能包含水印（如 Gemini 输出左下角蓝菱形水印），提示词中已嘱咐裁判忽略。

3. **裁判打分**：把 \( I \)、\( T \)、\( O \) 以及参考文本或参考图像送入 GPT-4.1。对自然图任务（时间、因果、空间）：
   - **指令推理**：比较 \( O \) 与参考内容，按 1–5 打分。例如，如果参考文本描述“可乐瓶打开后可乐喷出、瓶口有泡沫”，输出图若只有瓶盖打开但无喷溅，可能只拿 3 分。
   - **外观一致性**：比较 \( O \) 与 \( I \)，排除指令要求改变的部分，按 1–5 打分。提示词强调“忽略指令明确要求的变化”，例如指令要求把车移到左边，那么车的位置变化不算不一致，但背景、车颜色等未提及的变化要扣分。
   - **视觉合理性**：只看 \( O \)，评估清晰度、真实感、物理合理性，按 1–5 打分。例如，如果生成了违背透视原理的结构或出现多余肢体，会得到低分。
   对逻辑任务：比较 \( O \) 与参考答案（参考图像或文本解），输出逻辑正确性（0/1）和外观一致性（0/1），最终映射为 1 或 5。例如，迷宫题的参考解是一条蓝色路径，若模型画出路径但颜色为红，逻辑正确性 1，外观一致性 0；若画错路径，逻辑正确性 0。

4. **聚合判断**：只有当所有适用维度均为满分 5 时，该样本记为成功。整体准确率 = 成功样本数 / 总样本数 × 100%。论文同时报告各维度平均分（Figure 5）来补充更细粒度信息，避免只看准确率的过严偏差。例如，GPT-4o-Image 在指令推理平均分 55.3？实际 Figure 5 显示 GPT-4o-Image 在指令推理维度平均约 4.4（如果百分制 55.3 可能是百分制？这里注意 Figure 5 的数据是用 0-100 还是 1-5？从图看是百分制，但正文未明确。草稿中未提及，我们避免引入不确定数字）。我们不说具体数字，只说给出平均分。

5. **可选人工复核**：论文从 100 个随机样本（来自 GPT-4o-Image 和 Gemini-2.0-Flash-Exp 的输出）让 6 位专家独立评分，计算 MAE 验证裁判可靠性。这些专家根据与 LMM 相同的标准进行打分，使用相同的 1–5 量表。

这个流程的关键是：模型在推理时完全不知道参考答案，它只能依赖原图和指令；裁判在打分时才看到参考内容。因此模型需要真正具备推理能力，而不是简单记忆或匹配。此外，裁判模型对每个输出可能调用多次，每次只评一个维度，以避免维度间相互干扰。

## 8. 实验和消融到底证明了什么

论文主要报告了 8 个模型在 RISEBench 上的准确率、三个维度平均分、子任务细分以及裁判-人类一致性。下面用表格给出关键证据：

| 证据 | 数据锚点 | 核心结论 |
|---|---|---|
| 主结果：GPT-4o-Image 准确率 28.9%，Gemini-Exp 13.3%，Gemini-Pre 9.4%，其余接近 0 | Table 1 | 当前最强模型也远未解决 RISE；开放模型接近随机 |
| 维度得分：GPT-4o 三项均最高，逻辑推理仅 10.6%；Gemini-Pre 空间能力从 23.0% 降至 11.0% | Table 1, Figure 5 | 逻辑推理是 GPT-4o 明显瓶颈；Gemini 空间能力波动大 |
| 子任务细粒度：GPT-4o 在 Life Progression 52.6%、Structural Deformation 41.7%、Component Assembly 56.5%，但在 Chemical & Biological Transform 12.5%、Pattern Prediction 3.22% | Table 3, Appendix C | 模型在狭窄但常见的世界知识上较好，在冷门因果链和规则推断上退化；Societal Transformation 为 0% |
| 裁判可靠性：总体 MAE 分别 0.5/0.7/0.4；LMM 打 5 分时人类平均 4.7/4.7/4.8；LMM 打 1 分时指令推理人类平均 1.1 | Table 2 | LMM 打分与人类高度一致，自动评估有效，尤其对高分和低分样本 |
| 打分分布：开放模型大量低分，OmniGen 视觉合理性最差；BAGEL 指令理解尚可但生成质量差 | Figure 8, §3.1 | 模型失败模式不同：有的不理解指令，有的生成质量差；HiDream 指令推理尚可但外观一致性最低 |

**最关键“消融”**：严格说论文没有做传统消融（比如去掉某个模块看性能变化）。最接近消融的是 **LMM-as-judge 的有效性验证**（Table 2）。它随机抽了 100 个输出，覆盖两个强模型（GPT-4o-Image 和 Gemini-2.0-Flash-Experimental），由 6 位人类专家独立打分，再统计每个 LMM 分数档对应的人类平均分和 MAE。结果显示 LMM 打 5 分的样本，人类平均分 4.7/4.7/4.8，MAE ≤ 0.3；LMM 打 1 分的指令推理样本，人类平均 1.1，MAE 仅 0.1。这说明裁判对“明显成功”和“明显失败”的判断非常可靠；但在中间分数（2、3 分）一致度下降，例如 LMM 打 3 分的外观一致性样本，人类平均 3.6，但标准差 0.5，人类有倾向给更高分（人类平均高于 LMM 分数 0.6）。作者据此认为该自动评估管线可以扩展到更大规模，但中间分数的模糊性是潜在误差来源。另外，表 2 中显示指令推理得 1 分的比例高达 27%，说明很多样本输出被裁判判为完全失败，对应人类也基本同意（平均 1.1）。

**尚未证明的主张**：论文证明了 GPT-4o-Image 在自身题库上大幅领先，但有几个论点未被实验直接支撑：
- “LMM-as-judge 可推广到所有模型和所有任务”：相关性只在两个闭源强模型上测过，且只有 100 个样本，没有覆盖弱开放模型。对开放模型大量 0 分或 1 分的场景，一致性可能有所不同。
- “四类推理足够全面”：作者自己在 Limitations 里承认类别不穷尽，数据集仅 360 题。例如，社会推理、情感推理等未覆盖。
- “推理式编辑能力来自统一 LMM 训练”：论文观察到闭源强模型表现好，但并未做训练范式对比，无法归因。也许只是模型规模或数据量更大，而非统一训练。
- “准确率低意味着实用价值低”：可能真实用户对“接近正确但不够满分”的编辑能容忍，论文的全满分判据夸大了差距。例如，GPT-4o-Image 在指令推理维度可能平均分较高，但仍然只有 28.9% 满分，说明很多输出在某一维度上只差一点。

## 9. 与前作怎么选

RISEBench 与几个相关方向的基准/方法需要放到一起选型。

**与传统图像编辑基准（如 MagicBrush、InstructPix2Pix、HIVe）对比**：这些基准主要测“指令理解 + 局部编辑”，任务包括换背景、改颜色、移除对象，输入通常是自然图像，但不要求世界知识推理。**什么时候选 RISEBench**：如果要评估模型是否能依据物理规律、时间演化或空间推理做编辑，传统基准会失真——很多模型靠文本匹配就能拿高分，但换成“画十年后的孩子”就失败。**什么时候不选 RISEBench**：如果只关心低层编辑保真度、局部变化准确性，或需要大规模自动化评估（例如几万样本），RISEBench 的 360 题太小，且人工构建成本高，不如 MagicBrush 这类大规模配对数据。MagicBrush 包含 10,000 个手动标注的三元组（输入图、指令、输出图），规模远超 RISEBench，但缺乏推理深度。

**与统一 LMM 图像生成基准（如 Emu3、Show-o 的评测）对比**：后者通常测文生图或通用编辑的图文对齐，使用 CLIPScore、FID 或人类偏好。**选 RISEBench 的场景**：你的模型卖点是“会推理的图像编辑”，想突出复杂指令跟随和世界知识。**不选 RISEBench**：如果任务是通用文生图质量，或开源模型还在优化基本生成稳定性，门槛太高，大部分模型会拿 0%，没有区分度。例如，FLUX.1-Canny 在 RISEBench 总分 0.0%，说明其作为纯结构控制编辑模型，对推理任务完全失效，但在传统编辑基准上可能有较好表现。

**与推理多媒体基准（如 LogicVista、LEGO-Puzzles、WISE）对比**：LogicVista 测多模态逻辑推理但输出是文本选择，不是图像；LEGO-Puzzles 测多步空间推理但也输出文本或布局理解；WISE 测世界知识在文生图中的体现，但不包含编辑输入和外观一致性评估。**选 RISEBench**：需要端到端评估“推理→图像编辑”闭环，且包含外观一致性和视觉合理性。**不选 RISEBench**：如果只需要测推理能力本身，不关心生成保真度，用 LogicVista 成本更低；如果只看文生图的世界知识，WISE 更直接。例如，WISE 使用知识图谱构建 800 个样本评估文生图的世界知识，但不涉及编辑输入图的一致性。

**与前作怎么选总结**：RISEBench 的独特价值是“高难度推理编辑的严格满分率”，适合前沿闭源模型的瓶颈分析；不适合大规模回归测试或低门槛模型筛选。如果你的目标是快速筛选基础能力合格的模型，先用传统基准（如 MagicBrush）做初筛，再用 RISEBench 做深度评估。

## 10. 工程判断：可行性、风险与上限

**数据**：360 个样本全部人工标注，规模小，不能覆盖所有推理类型。附录 B 表明输入图像来自四个来源：生成模型图、Blender 3D 渲染、现有基准（LogicVista、LEGO-Puzzles）和互联网许可图片。这种多样性有利于避免数据偏差，但也带来图像风格、分辨率不统一的问题。复现成本主要在人工设计和标注：每个样本需要写指令、找或生成输入图、写参考文本或制作参考图像。论文没有披露标注总工时或资金，但附录 E 展示了专用标注界面，说明标注流程较为正式。如果要扩展，风险在于题目质量不均；例如 Table 3 显示 GPT-4o 在 Societal Transformation 上 0%，可能因为该类样本极少（可能只有 1-2 个）或定义模糊。需要投入领域专家审核物理、化学指令的合理性，避免科学错误。另外，互联网来源图片可能涉及版权，虽然论文声明是许可图片，但大规模扩展需更严格的合规审查。

**算力/延迟**：评测本身不需要训练，但调用 8 个模型对 360 个样本生成输出，需要 API 费用或 GPU 推理。闭源模型 API 调用有费用和速率限制；开放模型本地推理需要合适的 GPU 环境。裁判阶段用 GPT-4.1 对每个输出评三个维度，单样本需要多次提示，有 token 和时间成本。论文未给出总 API 花费，但估计每个样本的裁判成本可能在几分美元（工程推断，基于多模态 API 定价）。如果扩展到几千样本，裁判成本会线性增长，且中间分数噪声会累积。可以通过采样或两阶段评估（先筛查低分，再人工复核）来控制成本。

**实现难点**：
- 参考图像与文本混合会给裁判输入不一致，可能影响公平性；需要为不同任务类型分别设计提示词模板。例如，参考图像任务和参考文本任务使用的提示词不同（Figure 18–25），需要维护多套模板，增加工程复杂度。
- 逻辑任务采用二元评分，但如果模型输出“接近正确但颜色不同”，会被直接判 0，可能低估部分正确解。这意味着对一些创意性解（如路径颜色非蓝色但路径正确）不公平。
- 全满分判据太严格，导致准确率很低，统计显著性弱；如果要比较两个强模型，需要更多样本才能检测小差异。例如，GPT-4o 和 Gemini-Exp 相差 15.6 个百分点，但如果两者接近，360 样本可能不足以区分。
- LMM 裁判可能存在偏见，例如对水印的误判、对特定风格或模型的偏好。论文通过提示词要求忽略水印，但没有验证裁判是否真的做到了。

**失败环节**：从 Figure 6 和 §3.2 可看出，开放模型主要在指令理解和外观一致性上崩溃；Gemini 系列在误解指令时容易引入额外物体或严重失真，导致一致性下降；GPT-4o 在常见场景稳健，但在冷门因果或逻辑谜题上会“不动不改”或“乱改”，说明失败集中在推理深度，而非生成质量。例如，在逻辑推理中，GPT-4o 经常保持原图不变以保持外观一致性，从而在指令推理上拿 0 分，但外观一致性满分。这种“保守策略”虽然提高了外观一致性，但无法完成指令。监控信号：应该监控三个维度的平均分分布（Figure 8），特别是中低分段（2–3）的比例，而不是只看准确率。如果某模型在指令推理上大量 1 分，说明它几乎不理解指令；如果外观一致性大量低分，说明它倾向于重新生成而非编辑。

**指标上限**：当前最强 28.9% 意味着还有约 71% 样本未完全解决，但这不是理论上限。如果未来模型在逻辑推理达到与时间/空间相近的 30% 以上，整体大概能到 60% 以上；如果外观一致性和视觉合理性继续提升，瓶颈会转移到指令推理的深度和广度。目前未回答的问题：如何让模型在“不确定”时保持原图不变（GPT-4o 的稳健能力显示这一点有用）；如何统一连续评分与二元评分；LMM 裁判本身是否受模型偏见影响；是否需要更大规模的数据来覆盖化学、生物、物理等冷门因果。另外，论文没有讨论如何利用 RISE 任务进行训练，例如是否可以通过强化学习或合成数据提升推理编辑能力，这是未来的方向。

## 11. 放回研究脉络并收束

RISEBench 处在三条研究脉络的交汇点：一是视觉编辑从“局部像素修改”走向“指令驱动生成”（SDEdit、Prompt-to-Prompt、InstructPix2Pix）；二是统一 LMM 试图融合理解与生成（Chameleon、Emu3、Show-o、SynerGen-VL）；三是多模态评测从“图文对齐”走向“世界知识与推理”（LogicVista、WISE、T2I-CompBench++）。它第一次把“推理引导视觉编辑”作为一个明确任务提出，并用严格的全满分准确率暴露了当前模型的差距。

**读完必须记住的 5 件事**：
1. RISEBench 是第一个针对推理式视觉编辑的基准，含 360 个人工标注样本，覆盖时间、因果、空间、逻辑四类推理；输入图像来源包括生成图、3D 渲染、现有基准和互联网许可图片。
2. 评估三个维度：指令推理、外观一致性、视觉合理性；只有三项均满分才算成功，因此最强 GPT-4o-Image 也仅 28.9%；开放模型几乎全部接近 0%。
3. 逻辑推理是 GPT-4o 的明显短板（10.6%），而冷门因果任务（化学、生物、物理）表现也显著下降；子任务中 Life Progression（52.6%）和 Component Assembly（56.5%）相对较高，Pattern Prediction 仅 3.22%。
4. LMM-as-a-judge 与人类评分在极高分和极低分档高度一致（MAE 0.5/0.7/0.4），中间分档一致度下降，但总体可扩展；裁判对完全失败样本的识别尤其可靠（指令推理得 1 分时人类平均 1.1）。
5. GPT-4o-Image 的稳健性体现在它不会乱改，而会保持原图；这种“不犯错”策略有助于外观一致性，但不能解决需要深度推理的编辑任务。
