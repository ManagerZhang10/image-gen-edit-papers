# WiseEdit：技术决策型阅读笔记

## 一句话结论

WiseEdit 是一个面向“认知与创意驱动图像编辑”的基准测试，将编辑过程分解为 Awareness、Interpretation、Imagination 三个级联步骤并增设 Complex 任务，覆盖陈述性、程序性、元认知三类知识；论文名义上以 1220 例中英双语用例评估 22 个模型，闭源模型 Nano Banana Pro 的英文 Overall 为 82.4，最佳开源模型 FLUX.2 Dev 为 61.8，知识保真与创意融合是当前主要瓶颈。名义总数与附录分项不自洽，详见后文审计。

## 问题与适用边界

论文要解决的问题是：现有图像编辑基准（MagicBrush、AnyEdit、UltraEdit 等）大多只测简单局部编辑，指令直接指明修改对象与方式，无法评估模型在需要认知推理与创意生成时的真实能力。较新的 KrisBench 等虽引入世界知识推理，但主要停留在 Interpretation 阶段，未覆盖 Awareness、Imagination 与元认知知识，且以单图输入和英文指令为主。

WiseEdit 的适用边界在于：它衡量的是“知识密集型、认知与创意驱动”的编辑能力，而非基础编辑精度或速度。其任务设计刻意提高三个认知步骤的难度，因此对仅擅长简单指令执行的模型不友好。基准包含多图输入（26% 用例）与中英双语指令，适合评估统一理解-生成架构模型，但部分纯扩散模型因无法处理多图输入而在 Complex 任务中被排除。论文未声称该基准适用于视频编辑、3D 编辑或交互式多轮编辑场景。

## 方法/数据构造

### 任务分解

论文将图像编辑类比人类认知创作过程，分解为三个级联步骤：

- **Awareness（觉察）**：模型作为视觉观察者建立选择性注意，在无显式空间信息下定位修改目标。子任务包括属性比较、区域感知、细粒度 OCR 搜索、相机深度判断、功能识别、地理定位、跨图视觉对应。
- **Interpretation（解释）**：认知核心，将编辑指令解析为可执行的感知级视觉变化。子任务包括错误纠正、违规纠正、常识推理、级联变化预测、规则推理、复杂指代、生物/数学/物理/化学推理、逻辑推理、条件推断、空间排序、多指令组合。
- **Imagination（想象）**：生成引擎，在保持主体身份的同时执行创意性主体驱动生成。子任务包括纹理迁移、风格迁移、水印增删、反事实场景、时序预测、姿态/场景/视角/服装变更、主体身份变更、人-物互转、物体状态修改、物体修复、主题场景设计、平面设计、Logo 设计、建筑设计。
- **WiseEdit-Complex**：三个步骤均难以轻松完成，要求模型同时进行复杂推理与创意生成。

### 知识维度

覆盖三类知识：陈述性知识（knowing what，事实与概念）、程序性知识（knowing how，多步任务分解与执行）、元认知知识（knowing about knowing，何时调用何种知识及如何组合）。知识领域涵盖文化常识、自然科学、时空逻辑推理。

### 数据规模与构成

论文摘要与正文多处声明总计 1220 例。Appendix B 给出分项：Awareness 362 例（单图 281，双图 81）、Interpretation 317 例（全部单图）、Imagination 451 例、Complex 80 例（双图 47，三图 17，四图 16）。**但存在论文内部计数冲突**：362 + 317 + 451 + 80 = 1210，不等于 1220。此外，Imagination 分项为 320（单图）+ 109（双图）+ 8（三图）+ 16（四图）+ 8（五图）= 461，与同段声明的 451 不一致。论文未解释这两个 10 例差异的来源，应视为论文内部计数口径冲突，而非笔误可简单归因。

数据来源为互联网收集或生成模型生成，极少量来自现有数据集。指令由训练有素的人工标注者初拟，GPT-4 在不改变语义的前提下增强多样性，并生成中文翻译；最终经博士专家与 GPT-4 双重筛选。

### 模型口径冲突

Appendix C 明确列出 22 个模型（18 开源 + 4 闭源）：8 个扩散模型、10 个统一理解-生成模型、4 个闭源模型。但引言写“21 leading models (17 open-source, 4 closed-source)”。这是论文内部口径冲突。Table 2 实际列出 22 个模型，应以 Appendix C 和 Table 2 的 22 个为准。

## 评测指标

论文采用 GPT-4o 作为自动评测器，所有指标在 1–10 分制上评分后线性映射到 0–100。五个指标：

- **Instruction Following (IF)**：编辑结果是否准确遵循指令，包括所有子任务是否完成。
- **Detail Preserving (DP)**：未涉及指令的部分是否忠实保留。注意：DP 不是身份保持（FaceID）指标，它衡量的是非目标区域的整体细节一致性，不等同于面部身份验证。
- **Visual Quality (VQ)**：生成图像的感知质量、自然度与伪影情况。
- **Knowledge Fidelity (KF)**：编辑结果是否符合真实世界逻辑与知识（物理、生物、化学、文化、常识），基于提供的知识提示作为参考。仅用于 Awareness、Interpretation、Complex 任务。
- **Creative Fusion (CF)**：编辑结果相对原图的概念新颖性、表达转换与想象深度。仅用于 Imagination 与 Complex 任务。

Overall 计算公式：AVG = (IF + DP + VQ + α·KF + β·CF) / (3 + α + β)，其中 α、β 在对应指标适用时为 1，否则为 0。

评测可靠性验证：论文通过人类专家评分与 VLM 评分的 Pearson 相关系数比较了四种评测管线（GPT-ours、GPT-Kris、Gemini-ours、Qwen-ours），声称其提出的协议相关性最强（Fig. 5a）。这是实验支持，但相关系数具体数值未在正文给出。

## 局限与未证实主张

**论文写明的局限**：所有模型均无法解决逻辑类问题（如火柴棒题），这被论文定义为当前能力边界（Sec. 4.4 Qualitative Comparisons）。知识推理虽有进展但仍是瓶颈；组合创意生成中主体身份保持不足，Imagination 的 DP 分数普遍偏低。

**论文内部计数冲突**：如前所述，1220 与 1210、Imagination 451 与 461 的矛盾论文未解释。模型数量 21 与 22 的口径冲突同样未说明。

**未证实主张**：论文声称 GPT-image-1 与 Nano Banana 的架构是“VLM 与扩散模型的组合”，但明确标注这是“社区主流观点”（prevailing view），并非官方技术报告证实。论文声称其评测协议相关性最强，但未给出具体相关系数值，仅以柱状图呈现。论文把 Nano Banana Pro 描述为榜首，这只由本基准结果支持，不代表它在所有编辑场景下均最优。

**工程推断边界**：论文未披露任何模型训练配置、训练数据或推理耗时。WiseEdit 本身是基准，不训练编辑器。评测所用 GPT-4o 的具体版本号、温度参数、采样策略论文未明确披露。知识提示（knowledge hint）的具体生成流程与质量控制标准论文未详细说明。

## 对“简单人像编辑、身份保持、局部保持”的选型意义

**简单人像编辑**：WiseEdit 的结果表明，对于仅需直接指令执行的简单人像编辑（如“给猫加蓝帽子”），早期模型如 InstructPix2Pix、MagicBrush 即可完成，但 WiseEdit 刻意不测这类任务。选型意义在于：若产品需求仅停留在简单局部编辑，轻量扩散模型可能足够；但若需处理隐含指代（如“让更开心的人戴上帽子”），则需统一理解-生成架构。Table 2 显示 InstructPix2Pix 英文 Overall 仅 34.4，而 Qwen-Image-Edit 达 60.2，差距主要在 Awareness 与 Interpretation 任务，说明简单编辑能力不能外推至认知驱动编辑。

**身份保持**：论文在 Imagination 任务中明确要求“保持主体身份”，但评测指标中**没有专门的 FaceID 或身份保持指标**。DP 衡量的是非指令区域的整体细节保留，包括但不限于身份特征。论文在 Sec. 4.2 结论(4) 中指出“模型在改变姿态或视角时难以充分保持主体身份”，这是基于 DP 分数偏低的推断，而非专用身份指标的测量结果。选型意义：若应用场景对身份保持有严格要求（如虚拟试衣、角色一致性生成），当前基准无法提供直接的身份保持量化证据，需另行引入专用身份保持评测。论文未明确披露是否在 DP 提示词中特别强调面部身份保持。

**局部保持**：DP 指标直接对应局部保持需求。Table 2 显示闭源模型在 DP 上总体更强（例如 Nano Banana Pro 英文 Awareness DP 88.6，DreamOmni2 为 74.4）。但 Imagination 任务中所有模型 DP 均未超过 80，说明在创意性主体变换场景下，局部保持仍是普遍弱点。选型意义：若应用需要“只改指定区域、其余区域不变”，应按具体任务复测 DP，并额外加入掩码或像素级保持检查；不能仅凭 Overall 或开源/闭源标签决定。若涉及大幅度主体变换，本论文没有给出任何模型可稳定保证局部保持的证据。
